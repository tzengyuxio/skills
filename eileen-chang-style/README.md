# Eileen-chang-style — 改寫成張愛玲體

把任何文章改寫成張愛玲式的蒼涼散文敘事。

不是把句子加感傷，不是仿民國語，而是**讓世界悄悄陷下去一寸**——讀完讓人
覺得情緒被壓住、世界低了一階、時間像玻璃罩裡的標本。

## 什麼是張愛玲體？

張愛玲（1920–1995），上海／香港作家。代表作：

| 作品 | 年代 | 風格特徵 |
|---|---|---|
| 〈第一爐香〉 | 1943 | 戰時香港、年輕女子的沉淪、低光燈下的家內政治 |
| 〈金鎖記〉 | 1943 | 上海大宅、女性自毀、鴉片煙與銅鎖 |
| 《傾城之戀》 | 1943 | 戰時香港、白流蘇與范柳原、淺灘上的愛情 |
| 〈紅玫瑰與白玫瑰〉 | 1944 | 兩種女人、男性視角下的女性凝視倒映 |
| 《半生緣》 | 1948–50 | 上海、十八年後重逢、低音量的時代沉沒 |

`eileen-chang-style` 鎖定其共通 DNA：**蒼涼基調 + 女性凝視 + 反高潮收尾**。

## 不會做的事

- 不寫爆破情感（哭天搶地、誓言、三疊嘆——爆出來就破功）
- 不寫明亮陽剛（豪情、慷慨、英雄氣不在張派的世界裡）
- 不寫純紅／純白／純黑（張派要降一階：暗紅、象牙、月白、藕色、煙紫）
- 不寫現代網路語、表情包、emoji
- 不每篇都用舊上海公寓——場景庫含弄堂、戰時香港、茶樓、客輪、百貨、祖宅

## 預期輸出篇幅

繁體中文現代白話為基底（可糅滬語與少量文言虛詞），**400–1000 字**。
低於 300 字無法承載心理切片與細節暴力，超過 1500 字會失去張派「短篇」
的節制感。

## 適合的源文

- 哲學散文／議論文（先抽冷下來瞬間）
- 寓言／諷刺寓言（《差不多先生》）
- 都市生活軼事
- 個人成長／人際窘迫小品
- 家族故事

## 不太適合的源文

- 充滿現代專名／科技／政治的新聞報導
- 純技術文件、程式碼說明
- 英雄史詩、戰爭場面（張派以小寫大，不寫大場面）
- 已有完整圓滿結局的故事（張派要反高潮）

## 安裝

一行安裝：

```bash
git clone --depth 1 https://github.com/tzengyuxio/skills.git /tmp/tz-skills \
  && mkdir -p ~/.claude/skills \
  && cp -r /tmp/tz-skills/eileen-chang-style ~/.claude/skills/ \
  && rm -rf /tmp/tz-skills
```

或透過 plugin marketplace：

```
/plugin marketplace add tzengyuxio/skills
/plugin install eileen-chang-style@tzengyuxio-skills
```

手動安裝：

```bash
cp -r eileen-chang-style ~/.claude/skills/eileen-chang-style
```

## 使用方式

```
/eileen-chang-style path/to/article.md
```

也可以直接貼一段文字進來，或剛寫完一份文件後無參數呼叫。

**觸發詞：** `/eileen-chang-style`、「改寫成張愛玲」「張愛玲體」「張派」
「上海蒼涼派」「rewrite as Eileen Chang」

## 三條靈魂條款

張愛玲體的指紋：

1. **C-02 蒼涼基調必現** — 至少一處讓溫暖場景陡然降溫
2. **S-02 反高潮收尾** — 退場／冷凝／錯置三擇一，不下定論
3. **S-03 細節暴力** — 一個極小細節承載整段感情，且不解釋

三者缺一就不是張派。其餘 18 條 checklist 都在服務這三條。
