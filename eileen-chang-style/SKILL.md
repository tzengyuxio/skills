# Eileen-chang-style — 改寫成張愛玲體

把任何文章改寫成張愛玲式的蒼涼散文敘事——舊上海公寓的暗黃燈、戰時香港的
潮悶霉味、旗袍下擺的一道襪縫、玻璃罩內凝住的時間，讀完讓人覺得世界悄悄
陷下去一寸。風格指紋是**蒼涼基調 + 女性凝視 + 反高潮收尾**：情緒從不爆破，
總在最熱處陡然降溫。

## 一句話靈魂

**蒼涼基調必現**——文章中至少一處要讓溫暖場景陡然降溫，出現「冷」「涼」
「灰」「枯」「霉」一類基調轉折；讀者讀到那一刻，會感覺世界稍稍陷下去。
情感始終「壓住」，**不爆破、不哭喊、不誓言**。其餘 20 條 checklist 都在
服務這一條。

> **補注（張愛玲自述美學）**：張愛玲在〈自己的文章〉裡說過——「悲壯是一種完成，蒼涼則是一種啟示」「蒼涼之所以有更深長的回味，就因為它像葱綠配桃紅，是一種**參差的對照**」。她偏愛寫**人生安穩的底子**，而非飛揚的戰鬥。本 skill 的「蒼涼基調」「反高潮」「壓住不爆破」皆從此出。

## Step 1: Load the Text

- 若提供 `$0`，讀取該檔案。
- 若無引數，找對話中最近撰寫或編輯的 Markdown 檔，或請使用者提供文字。
- 若原文不是繁體中文，先在心中譯為繁體中文（不必輸出），再做改寫。

## Step 2: Read Source and Extract One Cool-down Moment

張愛玲體不是把原文翻譯成感傷句，而是**找出一個可以讓世界陷下去的瞬間，
重新把整段話圍著那個瞬間寫**。

讀完原文後，用一句話自答：

> 這篇裡頭，**哪一個瞬間最值得突然冷下來**？是某個眼神？某個細節（口紅、襪縫、瓷碗、銅扣）？某句被人忽略的話？某個人的退場？

可能的冷下來來源：被遺忘的稱呼、桌上一道指印、簾後沒寫完的字、樓下傳上
來的一句弄堂話、鏡子裡多出的一道紋、抽屜深處的舊照片、煙灰缸裡熄了一半
的菸。

若原文太長（超過 1500 字），只取一個情境改寫，不要硬塞所有內容。

## Step 3: Decide Modern → 張派 Mise-en-scène Mapping

若原文涉及現代生活（科技、職場、政治、消費），**把場景搬移**到張愛玲熟悉
的時空。**多寫幾篇就要換場**——不要每篇都用舊上海公寓；張派的場景庫不只
一處：

| 場景 | 風物 | 適合題材 |
|---|---|---|
| 舊上海公寓 | 暗黃燈、留聲機、玻璃罩鐘、樟腦氣 | 都市寂寞、家內權力 |
| 上海弄堂 | 灶間油煙、晾衣竹竿、後門石階、煤球爐 | 鄰里、旁觀者敘事 |
| 戰時香港 | 山邊洋房、霉味、潮悶、報紙上的炮聲 | 戰亂中的小日常、避難 |
| 老式茶樓 | 瓷茶杯、甘草梅、蒸籠白氣、方桌油痕 | 久別重逢、世故對話 |
| 客輪艙房 | 舷窗一塊海、銅扣箱子、鏡前梳子、夜裡引擎 | 出走、流離、隔離 |
| 上海百貨 | 玻璃櫃、絲襪、口紅試色、電梯黃銅 | 慾望、消費、女體 |
| 鄉下祖宅 | 舊銅器、霉壁、八仙桌、鴉片煙 | 家族敗落、時代倒退 |
| 老上海電車／封鎖街口 | 電車鈴、軌道、賣花女、玻璃窗外的雨 | 都市偶遇、隔絕的對話 |

> **補注（高頻 motif）**：張派的場景並非只是布景，而是反覆出現的**聲音與物件 motif**。校對你的稿子時，看看下列 motif 出現了幾個—— **月亮、電車（鈴）、胡琴／粵曲／無線電、香爐／沉香屑、樓下叫賣**—— 這些是張派最頻繁出現的「聲音／物件」原型。〈金鎖記〉開頭即以「三十年前的月亮」起，再以月亮收；〈傾城之戀〉開頭即以「胡琴咿咿啞啞拉著⋯⋯說不盡的蒼涼的故事──不問也罷！」起調；〈封鎖〉開頭以電車鈴聲「叮玲玲玲玲玲，每一個玲字是冷冷的一小點」起；〈第一爐香〉開頭以「霉綠斑斕的銅香爐，點上一爐沉香屑」起。**至少安排一個聲音 motif** 穿過全篇（首尾呼應更佳）。

**例外**：使用者明確要求保留某一現代詞作為刻意時代錯位，可保留 1–2 個。

## Step 4: Choose Female Gaze Anchor

張派最強的並非情節，而是**女性凝視**——以女性的眼睛看衣著質料、看神情、
看家庭裡權力的微差。**從以下任挑一種凝視主**（不一定要是主角；旁觀的女性
角色亦可）：

| 凝視主 | 看到的東西 | 場景重心 |
|---|---|---|
| 妻 | 丈夫的領子、旁邊女人的香水味 | 婚姻內的失重 |
| 女兒 | 母親的銅鐲、簾後的吵聲 | 家門等級 |
| 姨太 | 正房的襪縫、晚飯的座次 | 邊緣處的氣壓 |
| 寡婦 | 自己抹了一半的口紅、鏡裡的時間 | 等待、停滯 |
| 婢／僕 | 主人家的茶碗、自己的指甲 | 階級的隔膜 |
| 旁觀少女 | 弄堂對門的家戲、樓上女人的咳 | 半懂的世故 |

主角無須是女性；但**敘事的眼睛**最好是女性的——這是張派的魂。男性主角也
可，但必須有一個女性角色作為核心觀察者或被觀察者，否則容易失去凝視層次。

## Step 5: Choose 細節 + 顏色 + 反高潮

三項是張派的「裝備清單」，**缺一不可**：

### 細節暴力（一筆抵一段）
從以下類型挑 1–2 個細節，讓它在文中**承載整段感情**，不解釋：

| 類型 | 例子 |
|---|---|
| 衣物織理 | 旗袍下擺的襪縫、領口的霉斑、絲綢的滑、棉的舊 |
| 器物殘痕 | 碗沿一道指印、茶杯口的口紅、玻璃罩內的塵 |
| 身體微動 | 手指停在第三顆扣子上、眼皮垂了一下、唇色淡了一層 |
| 聲音縫隙 | 樓下那句弄堂話、鐘擺剛敲一下又停、無線電裡的廣告詞 |
| 氣味 | 樟腦、霉、菸、舊銅、潮、煤煙、香水殘味 |

### 顏色（低飽和度）
畫面**至少出現 2 種**：暗黃、月白、灰青、土黃、霉綠、煙紫、舊銅、暖灰、
象牙、藕色、鸚哥綠、銅綠、蟹殼青、蜜合色、紫銅。**不寫純紅、純白、純黑**
——張派的世界永遠有點髒、有點舊。

> **補注**：「霉綠」「銅綠」「鸚哥綠」是張派的標誌色。〈第一爐香〉開頭即點出「霉綠斑斕的銅香爐」，定下整個世界的色相基調。寫稿時，不妨刻意挑一兩個比一般作家更**冷僻、更具體**的顏色詞（不是「綠」，而是「鸚哥綠一塊」「霉綠斑斕」「銅綠」），這是張派色彩的指紋。

### 反高潮（情感最高處戛然而止）
**結尾必須在情緒最高處陷下去或退場**，不可給讀者一個「合」段、不可下定論、
不可走向圓滿，也不可哭天搶地。三種常見收法：

1. **退場式**：主角／核心人物默默離場，剩下一個物件（茶杯、菸頭、鏡子）
2. **冷凝式**：時間像玻璃罩裡的標本，慢、停滯、世界稍稍陷下去
3. **錯置式**：高潮處把鏡頭挪到一個無關的細節（樓下叫賣聲、窗外日影）

選定後在筆記裡寫下：「凝視主 = X，主細節 = Y，主場景 = Z，反高潮收法 = W。」

## Step 6: First Draft

寫一稿。原則：

- **語感**：現代白話為基底，可糅入舊上海弄堂用語（曉得、勿要、阿是）與
  少量文言虛詞（卻、也、倒、原是、只是、未必）；**精緻而不文雅**，可以俗
  但不能粗
- **句式偏好**：「**也**」字句、「**卻**」字句、「**倒**」字句頻繁——以
  微弱轉折承載重量。例：「她也笑了，**卻**沒甚麼可笑的；那笑也淡，**倒**
  像是替別人笑似的。」此外，張派常用「**參差的對照**」——把兩個不和諧、
  低度反差的東西並置（如「蚊子血／床前明月光」「飯黏子／硃砂痣」），讓
  讀者自己感受落差，**不解釋哪個更好**
- **時態冷凝**：時間慢、停滯，可用「⋯⋯彷彿」「⋯⋯像是」「⋯⋯久久」
  「⋯⋯總沒有」這類拖沓句尾
- **激情側寫**：不正面寫激情。激情用退場、缺席、隔著什麼來寫——隔窗、
  隔簾、隔煙、隔一條弄堂、隔一面鏡
- **心理切片**：角色內心獨白與外部冷靜敘述**交錯**，雙線同行（一句敘事 +
  一句心想 + 一句敘事）
- **顏色與細節**並置：每段至少 1 處低飽和度顏色 + 1 個細節
- **篇幅**：原文短（< 200 字）寫 400–600 字；中（200–800）寫 500–800
  字；長（800+）取單一情境寫 700–1000 字
- **結尾**：反高潮收場——退場、冷凝、或錯置三擇一；**絕不總結、絕不下定
  論、絕不誓言**

## Step 8: Find the Weakest Paragraph and Rewrite

通常**結尾段**或**激情段**最弱：

- 若結尾下了結論（「這就是命運」「人生不過如此」），刪掉，改成退場／
  冷凝／錯置
- 若激情段正面寫，改成隔窗、隔簾、隔煙、隔鏡的側寫
- 若三疊嘆爆出了，刪掉，改成一個細節（指停在第三顆扣子上）
- 若顏色太鮮（紅色、白色），降一階（暗紅、象牙、藕色、月白）
- 若沒有「也／卻／倒」的微弱轉折，至少補 2–3 處

「**情緒壓住，世界陷下去**」是張派的鐵律。爆出來就破功。

## Step 9: 標點清理

最後一道工序：

- **全形標點（鐵律）**：CJK 文本中所有標點一律全形。**ASCII 半形 `, ; : ? !` 在 CJK 字之間出現一律是 bug**，必須換成全形 `，；：？！`。對照表：

  | 半形（禁） | 全形（用） | Unicode |
  |---|---|---|
  | `,` | `，` | U+FF0C |
  | `;` | `；` | U+FF1B |
  | `:` | `：` | U+FF1A |
  | `?` | `？` | U+FF1F |
  | `!` | `！` | U+FF01 |
  | `(` `)` | `（` `）` | U+FF08 / U+FF09 |

- **破折號**用兩個全形「—」連寫成「——」，不寫成 `--` 也不寫成單個「—」
- **引號**用「」與『』，不用 `"` `'`
- **句號**用「。」，不用 `.`
- **全形標點與 CJK 之間零空格**

- **寫完後必跑自檢指令**（指令名留作機械驗證，不可省略）：

  ```bash
  python3 -c "
  import re, sys
  text = open(sys.argv[1]).read()
  bad = re.findall(r'[^\x00-\x7f][,;:?!][^\x00-\x7f]', text)
  print(f'half-width punct between CJK: {len(bad)}')
  for b in bad[:5]: print(repr(b))
  " 輸出檔.md
  ```

  結果必須為 `0`。非 0 表示輸出時混入了 ASCII 半形，回到輸出檔逐字替換後重跑，直到歸零才算交付。

## Anti-patterns（常見失敗模式）

寫完一稿、自檢之前，先掃一眼這 9 條最容易踩的坑：

1. **爆破式情感** — 寫成哭天搶地、誓言、三疊嘆。張派的鐵律是壓住，爆出來
   就破功（違反 M-02）
2. **明亮陽剛** — 寫成豪情、慷慨、英雄氣。張派的世界一律低光、低飽和、
   低音量（違反 M-03）
3. **每篇都是公寓** — 多寫幾篇就要換場（弄堂、戰時香港、茶樓、客輪、百貨、
   祖宅都是張派的），不可每篇都用舊上海公寓
4. **解釋細節** — 把「碗沿一道指印」寫成「那是因為他剛才⋯⋯」。細節暴力的
   要點是**不解釋**——讓細節自己承載（違反 S-03）
5. **正面寫激情** — 把擁抱、爭吵、告別寫得像電視劇直拍。張派的激情永遠
   隔著什麼（隔窗、隔簾、隔煙、隔鏡）（違反 V-02）
6. **沒有「也／卻／倒」** — 寫成現代直敘流，失去張派的微弱轉折節奏
   （違反 V-01）
7. **顏色太鮮** — 出現純紅、純白、純黑。張派要降一階：暗紅、象牙、暖灰、
   月白、藕色（違反 V-03）
8. **下定論的結尾** — 「這就是人生」「果然世事如此」。反高潮的精髓在於
   讓讀者自己陷下去，不是替讀者陷（違反 S-02）
9. **半形標點混入** — 輸出時把 `,;:?!` 打成 ASCII 半形而非全形 `，；：？！`。
   常見原因是 IME 切換失誤或從英文 prompt 複製字串。寫完務必跑 Step 9 自檢
   指令，計數歸零才算交付（違反 M-06）

## Core Example: 木匠雕神像

源文（現代軼事）：一名工程師接到三日交專案的死線，連夜加班寫出醜陋程式
碼，事後重構，最後產品被取消。下方為改寫成功的版本——把這個瞬間搬到
舊上海某弄堂後門的小木舖，從一個旁觀少女的眼睛看出去，讓「失敗」這件事
不爆出來，只是**慢慢冷下去**。

> 弄堂後門那家小木舖，原是只剩一個老木匠的。三日前接了個活，是城西公館裡訂的一尊文判官，限三日交。老木匠是隔壁張師母的遠房，張師母同我說：「他這雙手，曉得的人都曉得；不曉得的，就只當是個破舖子。」她說這話的時候，倒不像在誇人，倒像是替老木匠先把日子收一收。我那時十四歲，蹲在後門石階上看他刻木，第一晚看到他刻刀劃過的木屑，是暖黃色的；第二晚那木屑就成了灰青；第三晚清晨，他的手停在判官的眉眼上，停了很久，終於還是落下去了。眉眼略偏了一分，他自己也曉得，卻沒有再動。使者一早來收，老木匠把神像奉了出去，回身在門口站了一會兒，望著弄堂口那塊霉綠的牆，沒說話。後來聽張師母說，那公館前一日已被徵作了別的用處，神像送過去就擱在後院，連供桌也未及備。老木匠倒也沒回來訴甚麼，只是從那以後不再開工，刻刀放在抽屜最底下，刀身上落了一層象牙色的塵。我有一次去他舖子，桌上一只白瓷碗，碗沿留著一道淡淡的指印，像是誰昨日剛端過。樓下弄堂口有人在叫賣甘草梅，叫了一聲，又一聲，便沒了。

**達標清單**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留「急工→失敗→自悔」核心張力 |
| C-02 | ✓ | 蒼涼基調：「霉綠的牆」「象牙色的塵」「淡淡的指印」三處基調轉折 |
| C-03 | ✓ | 無現代專名（公館、文判官、神像、舖子、弄堂皆民國／前現代）|
| C-04 | ✓ | 場景錨定：上海弄堂後門小木舖，遠處公館 |
| C-05 | ✓ | 女性凝視：14 歲少女的眼睛 + 張師母的旁觀 |
| S-01 | ✓ | 約 480 字 |
| S-02 | ✓ | 反高潮收尾：錯置式（最高處挪鏡到樓下叫賣聲，「叫了一聲，又一聲，便沒了」）|
| S-03 | ✓ | 細節暴力：碗沿指印、刀上一層象牙色塵、手停在眉眼上停了很久——皆不解釋 |
| S-04 | ✓ | 心理切片交錯：張師母「替老木匠先把日子收一收」+ 少女「我那時十四歲」+ 外部敘述交錯 |
| V-01 | ✓ | 「也／卻／倒」頻繁：「倒不像在誇人」「倒像是替⋯⋯」「他自己也曉得，卻沒有再動」「老木匠倒也沒回來訴甚麼」 |
| V-02 | ✓ | 激情側寫：失敗不爆出來，隔著一個小女孩的眼睛、隔著張師母的話、隔著一只白瓷碗 |
| V-03 | ✓ | 低飽和度顏色：暖黃、灰青、霉綠、象牙——4 種低飽和顏色並置 |
| V-04 | ✓ | 弄堂語：「曉得的人都曉得」「不曉得的，就只當是」 |
| V-05 | ✓ | 拖沓尾：「停了很久」「望著⋯⋯沒說話」「叫了一聲，又一聲，便沒了」|
| S-06 | ✓ | 比喻冷而非甜：「替老木匠先把日子收一收」（張師母把日子當成可以收起來的東西）|
| M-02 | ✓ | 全文無爆哭、無誓言、無三疊嘆 |
| M-03 | ✓ | 全文壓住，無豪情、無慷慨 |

**對照結論**：張派不是「給故事加感傷」，而是**讓世界悄悄陷下去**——
「叫了一聲，又一聲，便沒了」沒有解釋這跟老木匠有何關聯，但讀完整段你會
知道：那是一個人收掉一身手藝的瞬間，唯一還能聽見的，是樓下一個無關的
叫賣聲，叫到第三聲就沒了。**這就是反高潮**——讀者自己陷下去，不是被作者
推下去。

## Scope Boundary

| 想做的事 | 用哪個 skill |
|---|---|
| 把文章改寫為張愛玲式蒼涼散文（本 skill 目標）| **eileen-chang-style** |
| 寫民國言情通俗小說腔（張恨水／鴛鴦蝴蝶派）| （不在本 skill 範圍）|
| 寫五四白話散文（朱自清／徐志摩）| （不在本 skill 範圍）|
| 寫敘事公案 | `koanify` |
| 寫志怪短篇 | `liaozhai-tale` |
| 寫瓊瑤式愛情敘事 | `qiongyao-style`（瓊瑤體**爆**情感，本 skill **壓**情感）|

如果使用者要的是**爆情感的愛情**或**英雄式豪情**，告訴使用者本 skill
是壓住式的蒼涼派，不適合。

## Important Notes

- 本 skill 是**體裁轉換工具**，不是「給文章加冷字」工具。原文的核心張力
  必須被保留，以蒼涼壓住的形式重新承載
- **壓住，不爆破**——這是張派的命。一旦爆出來（哭天搶地、誓言、三疊嘆），
  立刻破功
- **女性凝視不等於女性主角**——是敘事的眼睛是女性的；男性主角也可，但
  必須有女性核心觀察者／被觀察者
- **細節暴力的要點是不解釋**——讓細節（碗沿指印、襪縫、樓下叫賣聲）自己
  承載，作者不出來說明
- **顏色降一階**——純紅變暗紅／藕色，純白變象牙／月白，純黑變煙紫／灰青
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
