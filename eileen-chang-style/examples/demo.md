# Eileen-chang-style — 示範

展示 `eileen-chang-style` 如何把現代文章改寫成張愛玲式蒼涼散文，以及好的
張派腔長什麼樣子。

> **源文與引用說明**：範例一、範例二為依張愛玲風格自編的「目標範例」，用以示範靈魂條款怎麼落地，**非實際張愛玲作品**。範例三的源文 [《差不多先生傳》（胡適， 1924）](../../examples/source-texts/mr-chabuduo.md) 來自共用源文庫，公有領域。範例四的源文 [〈雨天故事〉](../../examples/source-texts/weather-rain.md) 為自編短篇。文中對張愛玲代表作（《傾城之戀》《半生緣》《第一爐香》《金鎖記》）的指涉僅作風格座標說明，未引用整段原文。

---

## 範例一：風格目標 — 戰時香港山邊洋房（女性凝視 + 反高潮）

這是 eileen-chang-style 的「品牌示範」——展示**女性凝視 + 蒼涼基調 + 反
高潮收尾**最純粹的樣態。場景設在戰時香港，一名年輕女子寄住在表姨家中，
聽見樓下傳來的零碎消息。

### 自編目標範例

> 山邊那幢半舊的洋房，原是表姨從人家手裡頂下來的，算她運氣，挑在開戰前。如今戰是已經開了，房倒還是那房，只是窗外整日有種潮悶的霉味，跟下午的雨混著。表姨從早上起就在樓下廳裡看報，看著看著就把報紙折了三折，又攤開，又折。她也沒甚麼好說的，只是把茶喝完，倒一杯，又喝完。我坐在樓上窗邊看她，看得久了，發現她那杯子的口沿上有一道淡淡的口紅，是早上才抹的，倒比她的臉還新。樓下隔一條巷子有人在唱粵曲，唱了半句就停，像是中途想起甚麼似的。表姨忽然抬頭問我：「儂曉得伊（他）今朝有否來信？」我說沒有。她「哦」了一聲，便又低頭去看那張已經折了三折的報。窗外的雨倒是落得很慢，像是不曉得自己應該停在哪一刻才好。後來姨夫從外頭回來，進門時抖了一下傘上的水，水珠落在象牙色的地磚上，停了一停，才滲下去。表姨沒抬頭。我也沒。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 場景：戰時香港山邊洋房 | C-04 場景錨定 | 不用舊上海公寓，避免與其他 demo 共用骨架 |
| 凝視主：表外甥女看表姨 | C-05 女性凝視 | 旁觀者敘事，雙重女性視角 |
| 蒼涼基調：「潮悶的霉味」「象牙色的地磚」「窗外的雨倒是落得很慢」 | C-02 靈魂條款 | 三處基調轉折，世界陷下去 |
| 細節暴力：杯口一道口紅、報紙折了三折又攤開、水珠停了一停才滲 | S-03 不解釋 | 不說明來信是何人、口紅為誰抹 |
| 反高潮收尾：「表姨沒抬頭。我也沒」 | S-02 退場式 | 最高處不爆，兩人都不抬頭 |
| 「也／卻／倒」轉折：「她也沒甚麼好說」「倒比她的臉還新」「窗外的雨倒是落得很慢」 | V-01 微弱轉折 | 至少 3 處 |
| 顏色：象牙色、霉、潮悶（暗）、淡淡口紅 | V-03 低飽和 | 無純紅／白／黑 |
| 弄堂語／滬語：「儂」「伊」「今朝」「有否」 | V-04 古典-通俗夾雜 | 滬語自然嵌入 |
| 激情側寫：等信／不問是誰，全程隔著一份報紙 | V-02 隔著什麼 | 隔報、隔茶、隔雨 |

**風格座標**：與《傾城之戀》戰時香港場景的低光潮悶氣質相承——**戰是大事，
但小日子裡只剩茶杯口的口紅、折了三次的報紙**。粵曲 motif（「樓下隔一條
巷子有人在唱粵曲，唱了半句就停」）回應張派慣用的聲音元素：〈傾城之戀〉
開頭以「胡琴咿咿啞啞拉著⋯⋯說不盡的蒼涼的故事」起調，本例用粵曲半句而
止，是同一種「**用一個聲音劃開整段時間**」的手法。

## 範例二：風格目標 — 老式茶樓重逢（細節暴力 + 心理切片）

示範第二種配置——**老式茶樓**。久別的兩個女人（曾為閨蜜）在茶樓相見，
談了一席話，誰也沒說當年的事。展現**細節暴力 + 心理切片與外部敘述交錯**
最純粹的樣態。

### 自編目標範例

> 茶樓裡的方桌油痕擦了不曉得多少回，倒像是越擦越深似的。她坐下時把絲手套擱在桌沿，手套邊緣磨得起了毛，是從前留下的——我是曉得的，那年她出門前還是新的。她沒提，我也沒提。她叫了一壺普洱，茶壺嘴上有一道舊銅補過的痕跡，補得不甚齊整。「你也老了。」她說，倒像是替自己也說了一句。我看她的時候，發現她左耳的耳環只剩一隻，另一隻不曉得甚麼時候掉的；她或許自己曉得，或許不曉得。她講起這幾年的事，講得很慢，像在替別人講似的。我聽著，心裡卻在數她講到「他」那個字的時候停頓了幾次——三次，第三次最久，但她也並沒有把那個字說出來，只是繞過去。蒸籠白氣從隔桌冒上來，飄到她臉上散了，散了又冒。我把茶喝完，她替我倒，我倒不曉得該不該謝。臨走時她說：「下回再約。」聲音是淡的，倒像是替我們兩個一道把這句話收了。出茶樓的時候，外頭天色是暖灰的，弄堂口那家賣甘草梅的還在；可是我已不太記得我們上回見面是哪一年了。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 場景：老式茶樓 | C-04 場景錨定 | 換場，不重複上一例的洋房 |
| 凝視主：旁觀少婦看舊閨蜜 | C-05 女性凝視 | 「我」與「她」雙線並行 |
| 細節暴力：手套磨毛、茶壺嘴銅補、耳環只剩一隻 | S-03 不解釋 | 三個細節各自承載一段往事 |
| 心理切片交錯：「她或許自己曉得，或許不曉得」「我心裡卻在數她講到『他』停頓了幾次」 | S-04 雙線交錯 | 內心與敘述輪替 |
| 蒼涼基調：「方桌油痕越擦越深」「暖灰的天色」「我已不太記得我們上回見面是哪一年」 | C-02 靈魂條款 | 三處基調轉折 |
| 反高潮收尾：冷凝式（時間像玻璃罩裡的標本，記不得上回是哪一年）| S-02 冷凝 | 不下定論 |
| 「也／卻／倒」：「倒像是越擦越深」「我也沒提」「倒像是替自己也說了一句」「我倒不曉得該不該謝」「倒像是替我們兩個一道把這句話收了」 | V-01 至少 3 處 | 達 5 處 |
| 顏色：舊銅、暖灰、白氣、方桌油痕（暗） | V-03 低飽和 | 無鮮色 |
| 激情側寫：「他」字繞過去，三次停頓 | V-02 隔著省略 | 整段感情藏在繞過的字裡 |

**風格座標**：與《半生緣》中曼楨與世鈞十八年後重逢場景的低音量氣質相承
——**重逢不寫激情，寫一只茶壺嘴上補過的舊銅、一個人耳上少了一隻的耳環**。
此例運用了張派的「**參差的對照**」：磨毛的舊絲手套（從前留下的）／補過
的茶壺嘴（補得不齊整）／只剩一隻的耳環——三個低度反差的「殘」物並置，
不說哪個重要，**讓讀者自己感受落差**。這正是張愛玲〈自己的文章〉中所說
「葱綠配桃紅，是一種參差的對照」的句法移植到物件層次。

## 範例三：改寫示範 — 《差不多先生傳》→ 張愛玲體

源文：**胡適《差不多先生傳》（1924）摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 原文

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不多，是各省各縣各村人氏。⋯⋯
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」
>
> 後來他得急病，趕快叫家人去請東街的汪先生。一面慌一面跑，人急了，東西兩街，汪王不分，跑到西街牛醫王大夫家裡。⋯⋯王大夫用醫牛之法給他治病，差不多先生就此一命嗚呼。

（原文採取**諷刺寓言**體例。「差不多先生」是國民性的擬人化批判。）

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽冷下來瞬間 | 不在「臨終」，而在臨終後家裡其他人**繼續過日子那一刻**——差不多先生的太太把他抹過的薄荷油收進抽屜，說「也罷」 |
| 場景搬移 | **客輪艙房**——差不多先生原本要從上海回鄉的船上突發急症；場景集中在艙房與甲板 |
| 凝視主 | 差太太（妻），看艙窗外、看丈夫的領子、看一個沒擰緊的瓶蓋 |
| 主細節 | 領子的霉斑、薄荷油瓶蓋沒擰緊、艙裡的銅扣箱子 |
| 主顏色 | 暗黃（艙裡燈）、霉綠（領子）、煙紫（海面）、舊銅（箱扣） |
| 反高潮 | 退場式：差太太把瓶蓋擰緊，收進抽屜，「也罷」 |

### 改寫後

> 差先生姓差名不多，平日是個不太計較的人。船是從上海回寧波那一班，預備走兩夜的，他卻在頭一夜就病了。差太太那時還在艙房裡的小銅鏡前抹甘油——抹了一半，回頭看他坐在床沿，臉色倒沒甚麼，只是手按著胸口。她也沒太當回事，他平日就是這樣，凡事差不多。「儂喊伊來瞧瞧好伐？」她問的是船上那個跟班的。差先生擺擺手，說：「請哪個都差不多。」過了一刻，跟班還是去喊了人來。來的不是船醫，是頭等艙隔壁那位獸醫先生——差先生半睜眼看了一眼，笑了一下，倒也沒爭辯，只說：「醫人醫畜，差不多。」獸醫先生姓王，倒是位和氣人，給他下了一帖牛馬上慣用的散邪劑。差太太站在艙門邊看著，發現丈夫領子上靠近後頸處，有一塊小小的霉綠——是上回出門前漿洗時沒漿透的，她當時也曉得，原想等回去再說。差先生喝完那帖，咳了兩聲，便睡了。睡到後半夜便沒了氣。差太太坐在床邊看了他很久，看到艙窗外的海是煙紫的，遠處有一點燈，倒像是在替別的人家亮的。桌上一只薄荷油的瓶子，瓶蓋他沒擰緊。差太太伸手把那瓶蓋擰緊了，收進抽屜深處，那抽屜底下還壓著一張兩人新婚時的照片，邊角已起了一層舊銅色的鏽。她說：「也罷。」聲音很輕，倒像是替差先生也說了一句。船還在走，艙裡的燈是暗黃的。

（約 580 字）

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留「差不多」核心張力，但將諷刺轉為蒼涼 |
| C-02 | ✓ | 蒼涼基調：「煙紫的海」「舊銅色的鏽」「暗黃的燈」「替別的人家亮的」 |
| C-03 | ✓ | 無現代專名 |
| C-04 | ✓ | 場景錨定：上海回寧波客輪艙房（換場，不重複前兩例）|
| C-05 | ✓ | 女性凝視：差太太作為觀察者 |
| S-01 | ✓ | 約 580 字，正中典型範圍 |
| S-02 | ✓ | 反高潮收尾：退場式（瓶蓋擰緊、收進抽屜，「也罷」）|
| S-03 | ✓ | 細節暴力：領子霉斑、瓶蓋沒擰緊、抽屜底下的舊照——皆不解釋 |
| S-04 | ✓ | 心理切片交錯：「她也沒太當回事」「她當時也曉得，原想等回去再說」與外部敘述交錯 |
| S-05 | ✓ | 段落鏡頭切換多 |
| S-06 | ✓ | 比喻冷：「倒像是在替別的人家亮的」「倒像是替差先生也說了一句」 |
| V-01 | ✓ | 「也／卻／倒」頻繁：「他卻在頭一夜就病了」「她也沒太當回事」「倒沒甚麼」「倒也沒爭辯」「倒像是在替別的人家亮的」「倒像是替差先生也說了一句」 |
| V-02 | ✓ | 激情側寫：死亡不正面寫，隔著瓶蓋、隔著霉斑、隔著抽屜底下的舊照 |
| V-03 | ✓ | 顏色：暗黃、霉綠、煙紫、舊銅——4 種低飽和 |
| V-04 | ✓ | 滬語：「儂喊伊來瞧瞧好伐」「哪個都差不多」 |
| V-05 | ✓ | 拖沓尾：「看了他很久」「聲音很輕」 |
| M-02 | ✓ | 無爆哭、無誓言、無三疊嘆 |
| M-03 | ✓ | 全文壓住，無豪情 |

**改寫的核心動作**：把胡適原文「明寫的諷刺」轉為「張派式的蒼涼退場」。
原文是雜文體諷刺，張派版讓「差不多」不再是國民性的擬人化批判，而是一個
妻子在艙房裡，把丈夫沒擰緊的薄荷油瓶蓋擰緊、收進抽屜的瞬間——**他不是
死於差不多，他是死於日子本身的差不多**——而這個道理，由那塊沒漿透的霉綠
領子、由抽屜底下起鏽的舊照片、由「也罷」這兩個字共同承擔。

## 範例四：改寫示範 — 〈雨天故事〉→ 張愛玲體

源文：[`examples/source-texts/weather-rain.md`](../../examples/source-texts/weather-rain.md)，自編短篇。

### 原文

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽冷下來瞬間 | 「鑰匙忘在辦公室／錢包沒帶」這個不大不小的窘——把它放大成一個女人在門口站著進不去的長長一刻 |
| 場景搬移 | **上海弄堂**（換場，不再用艙房／公寓／茶樓）— 民國時期某弄堂裡，雨天回不了家的少婦 |
| 凝視主 | 隔壁少婦的旁觀（一個 17 歲少女的鄰居視角，從二樓窗子看下去）|
| 主細節 | 旗袍下擺一道泥水痕、髮髻一縷散下來、隔壁鞋底踩在石階上的水印 |
| 主顏色 | 月白（旗袍）、霉綠（牆）、藕色（雨幕）、暗黃（弄堂口的燈）|
| 反高潮 | 錯置式：高潮處挪鏡到弄堂口賣花的老婦人 |

### 改寫後

> 那年初夏，黃梅雨落了三日，落得人不曉得是早上還是下午。我從二樓窗口看下去，看見弄堂口那邊走進一個女人，是隔壁三號的少奶奶。她穿一件月白旗袍，下擺已經有一道泥水痕，是從石板路那一段濺上來的。她沒帶傘——也許出門時是沒下雨的，也許帶了傘卻丟在哪兒了，這是說不準的。她走到她家門口站了一會兒，從袖子裡掏東西，掏了又放回去，又掏。後來我才曉得，她是把鑰匙忘在了甚麼地方。她也沒敲門，只是站著。三號的灶間有沒有人她其實是曉得的，但她沒敲。她只是把那一縷從髮髻上散下來的頭髮，往耳後別了又別，別了又散，像是別不住似的。雨還是落，藕色的一片，像隔了層舊薄紗。隔壁王伯母從她家窗口探了一下頭，笑著說：「儂哪能勿叫部車子啊？」少奶奶轉過頭來，笑了一下，那笑也是淡的，回說：「我銅鈿勿曾帶。」說完便又轉回去，看自己的鞋尖。鞋尖上沾了一點泥，她也沒去擦。弄堂口那家賣白蘭花的老婦人還在，雨裡也照舊坐著，竹籃上蓋了塊舊油布，油布上有一道暗黃的燈光從對面舖子裡漏過來，倒像是替老婦人留的，又倒像是替少奶奶留的。少奶奶在門口站了很久。後來王伯母也不再探頭了。後來雨倒是落得更慢了一些，慢得像是不曉得自己應該停在哪一刻才好。

（約 540 字）

### 達標清單
