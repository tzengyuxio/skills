# Yu Guangzhong-style — 改寫成余光中體散文

把任何文章改寫成余光中（1928–2017）式的散文家筆法。

不是「把句子加長加文言」、不是「夾用幾個古人名」，而是**讓現代的小事件接
上一個巨大的地理／歷史抒情落差**——讀完讓人覺得這篇散文不只是描述當下，
而是在當下這一寸時間裡望見了千里之外的某一條江、某一座山、某一個自己。

## 一句話靈魂

**文白交織必現**——古典詩文意象／句法 與 現代漢語 在同一段落並置，使讀者
感到時空疊印。古典不是引用，是**化進**現代語境。

## 三條風格指紋

1. **長句鋪排** — 平均句長 ≥25 字，部分拉到 30–60 字，連動式動詞推進
2. **真排比** — 一篇至少一段三排以上，須結構對稱、內容遞進
3. **地理縱深 + 鄉愁母題** — 地名當意象用，承載「在此處懷彼處」的抒情落差

## 何時使用

- 想把一篇現代散文升格為有古典縱深的抒情散文
- 想在敘事中加入長江／太平洋／香港等地理意象作為情緒之錨
- 想體驗「文白交織」如何讓古今語感無縫疊印
- 想學「典故化用」與「典故引用」的真正差別

## 何時**不**用

- 想寫詩體（〈鄉愁〉四行式）— 本 skill 鎖定**散文家的余光中**，不是詩人
- 想寫五四式白話散文 — 余光中刻意反五四歐化
- 想寫女性低語抒情 — 余的散文柔處仍有骨，更陽剛壯闊
- 想寫純文言散文 — 本 skill 是現代漢語為基底的文白交織
- 純技術文件、新聞報導 — 沒有可承載的抒情錨點

## 預期輸出篇幅

繁體中文現代漢語為基底的文白交織散文，**400–1100 字**：

| 原文長度 | 余體目標 |
|---|---|
| 短（< 200 字）| 400–700 字 |
| 中（200–800 字）| 500–900 字 |
| 長（800+ 字）| 700–1100 字 |

## 安裝

```bash
git clone --depth 1 https://github.com/tzengyuxio/skills.git /tmp/tz-skills \
  && mkdir -p ~/.claude/skills \
  && cp -r /tmp/tz-skills/yu-guangzhong-style ~/.claude/skills/ \
  && rm -rf /tmp/tz-skills
```

或手動：

```bash
cp -r yu-guangzhong-style ~/.claude/skills/yu-guangzhong-style
```

## 使用方式

```
/yu-guangzhong-style path/to/article.md
```

也可以直接貼一段文字進來，或剛寫完一份文件後無參數呼叫。

**觸發詞：** `/yu-guangzhong-style`、「改寫成余光中」「余光中體」「余派
散文」「余光中風格」「文白雜糅散文」「rewrite as Yu Guangzhong」
