# Yu Guangzhong-style — 示範

展示 `yu-guangzhong-style` 如何把現代文章改寫成余光中式散文，以及好的余體
散文長什麼樣子。

> **源文與引用說明**：範例三的源文 [《差不多先生傳》（胡適， 1924）](../../examples/source-texts/mr-chabuduo.md)、範例一的源文 [雨天故事](../../examples/source-texts/weather-rain.md) 來自共用源文庫。範例二為自編短篇。文中對余光中散文集（《聽聽那冷雨》《我的四個假想敵》《催魂鈴》《沙田山居》）的指涉僅作風格座標說明，未引用整段原文。

---

## 範例一：海島地理錨 — 一場沒帶傘的雨

源文：[共用源文庫《雨天故事》](../../examples/source-texts/weather-rain.md)。

### 原文

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抒情錨點 | 在這場高雄午後雨裡，懷起十八歲那年廈門海邊一場沒帶傘的雨 |
| 主錨地理 | 海島／海岸體系：高雄、鼓浪嶼、台灣海峽、廈門 |
| 落差 | 此地的雨已不是彼地的雨；此身不在彼身 |
| 排比 | 「雨打在 X，雨打在 Y，雨打在 Z」三排以上 |
| 典故化用 | 蘇軾〈定風波〉「莫聽穿林打葉聲」化進騎樓 |
| 反句 | 「並非⋯⋯亦非⋯⋯實乃⋯⋯」 |

### 改寫後

> 從圖書館出來的時候，雨忽然就下了，下得不問你帶傘沒帶。我站在西子灣那排印度紫檀下，看雨從太平洋方向斜斜地撲過來，像四十年前那一場從鼓浪嶼方向斜斜地撲過來的雨。雨打在屋簷，雨打在路面，雨打在那位撐傘走過的小女孩睫毛上，雨打在我十八歲那年在廈門海邊忘記帶傘的少年的記憶裡。
>
> 我終究決定走回家。**莫聽穿林打葉聲**——蘇東坡那七個字，三十年來我教了不知多少遍給高雄的大學生，今夜方第一次在自己的肩膀上讀到。騎樓底下的人撐著各色雨傘，有的紅、有的黑、有的印著速食店的廣告，他們是從這場雨裡借來一座小屋頂的人；而我並非沒有屋頂可借，亦非不知道計程車的存在，實乃這身濕漉漉，恰好像我那年在鼓浪嶼海堤上讓海風橫吹的少年——我捨不得讓這場雨也學會打傘。
>
> 到家才發現鑰匙忘在系館抽屜裡。鄰居太太從她那一扇有桂花的窗探出頭來，笑說：「你怎麼不叫計程車？」我只好苦笑：「我忘了帶錢包。」她聽了，又笑了一聲，把窗關上。我於是站在自家門外的樓梯間，看雨從欄杆滴下，一滴一滴，敲在水泥地上，敲在 homesick 這個英文字的第一個音節上——這個字三個音節，比「思鄉」兩個字多了一個 sick；也比「鄉愁」兩個字，多了一個生病的彎。
>
> 雨還在下。台灣海峽的對面，鼓浪嶼此刻必也在雨中；那年那個沒帶傘的少年，必也仍在某一條海堤上，等他這一身，從一九八二年走到今晚。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 文白交織 | C-02 | 「莫聽穿林打葉聲」化進高雄騎樓；「實乃」「亦非」白話中點綴 |
| 地理縱深 | C-03 | 西子灣、太平洋、鼓浪嶼、廈門、台灣海峽、高雄——海島地理體系密集 |
| 鄉愁母題 | C-04 | 在高雄午後雨懷十八歲廈門海邊一場雨；此身不在彼身 |
| 真排比 | S-03 | 「雨打在屋簷，雨打在路面，雨打在睫毛，雨打在少年的記憶裡」四排，地點＋時間遞進 |
| 典故化用 | S-04 | 蘇軾〈定風波〉「莫聽穿林打葉聲」化進雨中走路場景，無引號注釋 |
| 反句 | S-05 | 「並非沒有屋頂可借，亦非不知道計程車的存在，實乃⋯⋯」 |
| 雙語比較癖 | V-03 | homesick 三音節 vs 思鄉／鄉愁的微差，恰好一處 |
| 結尾遠方意象 | S-06 | 「鼓浪嶼此刻必也在雨中；那年那個沒帶傘的少年，必也仍在某一條海堤上」 |
| 學者自嘲 | C-06 | 「我教了不知多少遍給高雄的大學生，今夜方第一次在自己的肩膀上讀到」 |

**風格座標**：與《聽聽那冷雨》同樣「以雨為媒介把此地接到彼地」的母題相
近——但本 skill 的範例**不抄那篇的句構**，僅承襲「雨／渡海／文白交織」
的氣質。

## 範例二：內陸山城地理錨 — 沙田老書房

源文（自編短篇）：

> 在香港沙田的老社區，有一位退休教授整理書房。他發現一本三十年前學生送的詩集，上面的題字已經褪色。他坐了很久，最後把書放回原位，泡了一杯茶。

### 改寫

> 沙田這個地方，我住了二十一年。窗外是城門河與獅子山之間那一條被開了又開的公路，每逢暮色四合，便有一種介乎九龍與廣州之間的光，恰好夠我把書房裡那一櫃舊書看見一個輪廓。今晨整理至底層，赫然抽出一本褪了色的詩集——是學生贈我的，三十年前；題字那一行原本是寶藍墨水，如今淡得像是在吐露港的水裡泡過一夜。
>
> 我坐下來。書房窗外馬鞍山的方向偶有飛機掠過，往北是廣州、往南是赤鱲角，而我此刻只想往東——往那年贈書的學生此刻不知身在何處的那個方向。詩集翻開，第一頁的題字寫著：「老師，望你常如山。」八個字，少年手筆，少年膽量。蓋少年所以能寫此語者，正因他不知山亦會老；老師所以能收此語者，正因他願意暫且裝作此山未老。
>
> 馬鞍山的鳥還在叫。九龍的車聲遠得像隔了一條長江。我把詩集重新放回原位——並非懷舊，亦非感傷，實乃此書此刻若再多翻一頁，便要把我這退休後最後一點英文系教授的矜持，全部翻成 sentimental 那個英文字底下的小注。Sentimental 四個音節，比「多情」兩個字多了三個音節的彎，但我想，年輕人以為「多情」是情之豐沛，老年人才知道「多情」其實是「多餘的情」——多了一份此刻不該再起的情。
>
> 我去煮水。瓦斯爐藍焰一蹦，茶葉在水裡舒開來，像那年王維說的「春草明年綠」，只是綠在我這把九龍買來的紫砂杯裡，綠在沙田這個下午的最後一道光裡，綠在三十年前那位學生此刻坐在地球某一座城市某一張桌前喝著的某一杯不同的茶裡。
>
> 我終於沒有再翻開那本書。窗外，獅子山仍在那裡——它不問來客是誰，它只負責讓暮色從它的背後，緩緩降到沙田。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 主錨地理 | C-03 | 沙田／馬鞍山／獅子山／九龍／城門河／吐露港／赤鱲角／廣州——港城／沙田時期體系 |
| 鄉愁母題（廣義）| C-04 | 在沙田老書房懷三十年前學生此刻所在的他方；在老年懷少年時的師生情誼 |
| 文白交織 | C-02 | 「蓋少年所以能寫此語者⋯⋯」古典句式與沙田公路、瓦斯爐並置 |
| 真排比 | S-03 | 「綠在紫砂杯裡，綠在沙田下午的光裡，綠在三十年前學生喝著的茶裡」三排層遞 |
| 典故化用 | S-04 | 王維「春草明年綠」化進茶葉舒開的瞬間，無引號 |
| 反句 | S-05 | 「並非懷舊，亦非感傷，實乃⋯⋯」 |
| 雙語比較癖 | V-03 | sentimental 四音節 vs 多情兩字的微差 |
| 學者自嘲 | C-06 | 「最後一點英文系教授的矜持」「老年人才知道多情其實是多餘的情」 |
| 結尾遠方意象 | S-06 | 「獅子山⋯⋯只負責讓暮色從它的背後，緩緩降到沙田」——不下定論 |
| 文言虛詞 | V-02 | 蓋／所以⋯⋯者／實乃／亦非——點綴 |

**風格座標**：與《沙田山居》同樣以南方山城／殖民港城作為知識分子漂泊之
錨——退休、書房、舊物、暮色，是這個地理錨最能承載的情境。

## 範例三：長江流域地理錨 — 《差不多先生傳》

源文：**胡適《差不多先生傳》（1924）摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 原文

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不多，是各省各縣各村人氏。⋯⋯他常常說：「凡事只要差不多，就好了。何必太精明呢？」
>
> 他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：「錯了。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」⋯⋯
>
> 後來他得急病，趕快叫家人去請東街的汪先生。一面慌一面跑，人急了，東西兩街，汪王不分，跑到西街牛醫王大夫家裡。⋯⋯王大夫用醫牛之法給他治病，差不多先生就此一命嗚呼。

（原文是諷刺寓言，「差不多先生」是國民性的擬人化批判。）

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抒情錨點 | 在這個精確時代懷念那個差不多時代；在我這個半生在香港在台北在 Iowa 教書的人身上，發現自己也有一根「差不多」的根 |
| 主錨地理 | 長江流域：長江、洞庭、岳陽、武漢、洞庭湖、白帝城 |
| 落差 | 在 GPS 時代懷地圖時代；在電腦時代懷手抄時代 |
| 排比 | 「陝西山西、紅糖白糖、汪先生王先生」原文已有三排，余體再加層 |
| 典故化用 | 杜甫〈登岳陽樓〉「親朋無一字」化進臨終病榻 |

### 改寫後

> 差不多先生這個人，胡適先生寫他的時候是民國十三年，我讀他的時候是民國四十幾年的台灣中部，那時我還是個會把山西寫成陝西、把白糖買成紅糖的高中生。蓋差不多先生並非別人，他正是每一個還沒有被印刷術、被 GPS、被精確化的咖啡豆秤所教訓過的我們自己。
>
> 你看他的長相吧——一雙眼睛看得不很清楚，兩隻耳朵聽得不很分明，鼻子嘴巴對氣味口味都不甚講究。他是一個經過洞庭湖的霧、經過白帝城的雨、經過長江上每一座還未被衛星定位的小渡口而磨蝕出來的中國人。他不是不識字，是他所識的字，原本就允許一寸的偏差；他不是不認方位，是他所認的方位，原本就以「差不多」為單位——差不多在江東，差不多在江西，差不多就是岳陽以南那一片煙水迷離。
>
> 然此公的悲劇不在於他差不多，而在於他**忘了差不多也有它差不多不得的時候**。紅糖白糖，差不多；陝西山西，差不多；汪先生王先生，亦差不多——並非沒有人曾告訴他這些差別，亦非他不曾在課堂上聽老師正色指出，實乃他自小生長在那一條從重慶蜿蜒到上海、從來不肯為任何一座小鎮停下來精確報座標的長江邊，而長江本身就是中國最大的「差不多」。
>
> 他臨終那一刻，家人去請東街的汪先生。差不多先生躺在床上，氣喘喘地等。然鄉間黃昏，跑得急的人，看東看西，看汪看王，差一條街，差一個字，便差出了一整個生死。王大夫提著醫牛的針來，差不多先生沒有力氣再說那句他這一生說了千百遍的話了。臨終之際，他望著屋頂的橫樑，忽然想起多年前先生在學堂讀過的杜工部〈登岳陽樓〉——不是那兩句「吳楚東南坼，乾坤日夜浮」，而是更後面的一句：**親朋無一字**。原來「親朋」與「醫牛」，到了最後一刻，也終究是差不多。
>
> 一命嗚呼。差不多先生死了。胡適先生於是嘆息，說這位是中國全國人的代表。
>
> 而我此刻坐在二十一世紀的台北，用一台會自動校對的電腦寫這篇文章。我的軟體告訴我「岳陽」二字無誤，「洞庭」二字無誤，「差不多」三字無誤——但它沒有辦法告訴我，原來差不多先生其實從未死去，他只是換了一個城市、換了一支不會校對的筆，仍在我心裡那條長江邊，等他的汪先生。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 文白交織 | C-02 | 「蓋差不多先生並非別人」「然此公的悲劇」與 GPS、咖啡豆秤、自動校對軟體並置 |
| 地理縱深 | C-03 | 長江、洞庭湖、白帝城、岳陽、重慶、上海、台北——長江流域主錨 ≥4 次 |
| 鄉愁母題 | C-04 | 在精確時代懷差不多時代；在台北懷長江邊 |
| 真排比 | S-03 | 「差不多在江東，差不多在江西，差不多就是岳陽以南」三排；「紅糖白糖／陝西山西／汪先生王先生」三排原文加余體層 |
| 典故化用 | S-04 | 杜甫〈登岳陽樓〉「親朋無一字」化進差不多先生臨終一刻，銜接「親朋」「醫牛」差不多 |
| 反句 | S-05 | 「並非沒有人曾告訴他⋯⋯亦非他不曾⋯⋯實乃⋯⋯」 |
| 結尾遠方意象 | S-06 | 「他只是換了一個城市⋯⋯仍在我心裡那條長江邊，等他的汪先生」——不下定論 |
| 學者自嘲 | C-06 | 「那時我還是個會把山西寫成陝西、把白糖買成紅糖的高中生」 |
| 文言虛詞 | V-02 | 蓋／然／實乃／亦非——點綴 |
| 陽剛底色 | M-04 | 長江、岳陽、橫樑、生死——非低語喃喃 |

**改寫的核心動作**：把胡適原文的「明寫的諷刺」轉為「在精確時代懷差不多
時代」的余光中式抒情落差。原文是雜文體諷刺，余體版讓「差不多先生」成為
**整條長江上飄出來的某一個我們自己**——而結尾不是教訓，是一個遠方意象：
「仍在我心裡那條長江邊，等他的汪先生」。

## 速查：Checklist 重點

21 條中最常踩的：

| 編號 | 規則 | 怎麼用 |
|---|---|---|
| C-02 | 文白交織必現 | 寫之前找一處古典意象化進現代場景 |
| C-03 | 地理縱深 | 主錨地名 ≥2 次，地名要當意象不只是座標 |
| C-04 | 鄉愁母題（廣義）| 一句話自答「在哪裡懷哪裡／在何時懷何時」 |
| S-02 | 長句鋪排 | 平均句長 ≥25 字，至少 3 處 30–60 字長句 |
| S-03 | 真排比 | 三句結構對稱＋內容遞進，不可虛排 |
| S-04 | 典故化用 | 化進，不引進；無引號注釋 |
| S-06 | 結尾遠方意象 | 不下定論，留餘韻 |
| M-03 | 不過量典故 | 排比可三排五排，典故宜一二處 |

完整 21 項與 9 步流程見 [SKILL.md](../SKILL.md)。
