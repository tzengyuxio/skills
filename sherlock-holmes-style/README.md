# Sherlock Holmes-style — 改寫成朱生豪式中譯維多利亞偵探小說腔

把任何文章改寫成 Conan Doyle《福爾摩斯探案》中譯本式的維多利亞偵探敘事。

不是「給句子加幾個推理橋段」、不是「把人物改名叫福爾摩斯」、更**不是
用中華公案小說的骨架披一件偵探外衣**——而是**整篇位移到 1880–1900 年
的倫敦，由華生醫生第一人稱回憶，福爾摩斯從外觀逆推事件，背景是煤氣
燈、馬車鈴與倫敦霧**。

## 一句話靈魂

**華生回憶 + 福爾摩斯演繹 + 維多利亞物件**——華生第一人稱回憶開場
（「我永遠記得那年三月某日的早晨⋯⋯」）+ 福爾摩斯演繹獨白（「我親愛
的華生，當你觀察 X，便可推知 Y⋯⋯」）+ 案件三幕（委託登門→現場勘察→
演繹揭曉）+ 煤氣燈／懷錶／菸斗／馬車／哈德森太太／蘇格蘭場構成的倫
敦氛圍。

## 三條風格指紋

1. **C-01 維多利亞英倫世界觀** — 場景必為倫敦／貝克街／鄉間別莊／火
   車車廂；中華具體專名（衙門／縣令／嘉興／銀子）禁用
2. **V-01 第一人稱華生回憶體** — 「我」字至少 5 處浮出；首段含時間錨
   點開場
3. **V-03 福爾摩斯演繹獨白** — 至少一段「我親愛的華生」式獨白，從外
   觀逆推事件的推理鏈

三者缺一就不是中譯維多利亞偵探腔。其餘 18 條 checklist 都在服務這三條。

## 中譯翻譯腔是 feature，不是 bug

本 skill 的本質是「**中譯**維多利亞偵探小說腔」，非原創中文偵探小說：

- **歐化句法允許**：「對於這件事而言」「不得不承認」「他是一個 X 的
  人」「不僅⋯⋯而且⋯⋯」「當你觀察 X 你會注意到」
- **稱謂直譯保留**：「我親愛的華生」「先生」「閣下」「夫人」（不用
  「賢弟」「兄台」「老爺」）
- **長子句堆疊**：模仿英文修飾語並列（「一位身材魁梧、面色蒼白、衣著
  考究的中年紳士」）

這些不是違規，是中譯維多利亞偵探小說的指紋之一。中譯本傳統參考：群眾
出版社版（1981）、俞步凡譯本（2010s）、遠流／臉譜版（台灣）。

## 雙重位移（極重要）

若源文是中華情境，**須做雙重位移**——把場景連同物件一起搬到維多利亞
英倫，不可只換語氣留著中華骨架：

| 中華原型 | 維多利亞等價 |
|---|---|
| 衙門 / 公堂 | 蘇格蘭場 / 治安所 |
| 縣令 / 知府 | 治安官 / 地方法官 |
| 嘉興 / 湖廣 | 倫敦東區 / 薩塞克斯郡 |
| 廟祝 / 道士 | 教區牧師 / 神父 |
| 銀兩 / 銀針 | 英鎊 / 金幣 |
| 客棧 / 茶樓 | 旅館 / 俱樂部 |

## 何時使用

- 想把一段現代軼事改寫成福爾摩斯短篇
- 想體驗中譯維多利亞偵探小說的具體手法
- 想學「演繹獨白」如何從外觀逆推事件
- 想把一個尋常事件包裝成案件三幕

## 何時**不**用

- 想寫中華公案小說（包公／狄公）— 本 skill **不做這件事**，世界觀必
  走西洋
- 想寫現代偵探小說（電腦／DNA／監視器）— 本 skill 限定維多利亞時代
- 想寫純抒情散文 — 本 skill 是案件結構不是抒情

## 預期輸出篇幅

繁體中文中譯維多利亞偵探小說腔，按強度分級：

| 強度 | 字數 |
|---|---|
| Light（只調語氣稱謂）| 400–600 字 |
| Medium（加案件三幕）| 600–900 字 |
| Heavy（重寫為新短篇）| 800–1200 字 |

## 適合的源文

- 失蹤／失竊／身分疑團類軼事
- 帶有「未解之謎」「待釋之事」的故事
- 含具體物件（信件／手錶／鑰匙）的事件
- 個人軼事可重組為案件
- 寓言（《差不多先生》《小王子》一類）

## 不太適合的源文

- 純技術文件、新聞報導
- 純抒情詩、散文
- 已經是偵探小說的源文（改寫意義不大）
- 純中華武俠 / 公案題材（雙重位移困難）

## 運作流程

1. **讀原文 + 抽核心事件** — 一句話自答：「這篇裡有什麼可疑事件、未解
   之謎、待釋之事？」
2. **設定世界觀（雙重位移）** — 場景必走維多利亞英倫；中華具體專名禁用
3. **設計華生第一人稱開場** — 時間錨點／札記翻檢／比較陳述／事後揭露
   四種模板擇一
4. **草現場勘察段** — 委託人到貝克街，福爾摩斯沉默觀察
5. **草演繹獨白段** — 「我親愛的華生」+「當你觀察 X」+「不僅⋯⋯而且
   ⋯⋯」+「這乃是因為⋯⋯」+「由此可推知⋯⋯」骨架
6. **草演繹揭曉段** — 現場對峙／書信揭露／靜默追蹤三擇一
7. **草華生收尾段** — 時間後設／道德低語／讀者邀請三擇一
8. **標點清理 + 自檢** — 全形標點、案件三幕完整性、維多利亞物件密度
9. **Checklist 自檢** — 21 條（Hard 18 + Soft 3）
10. **抓最弱段重寫** — 通常是演繹獨白或收尾段
11. **輸出** — 寫入 `<原檔名>_sherlock.md`

## 改寫原則（checklist 摘要）

| 類別 | 編號 | 要點 |
|------|------|------|
| Concrete | C-01~C-05 | 維多利亞英倫世界觀、中華專名禁令、核心稱謂、物件密度、委託人外貌速寫 |
| Surface | S-01~S-04 | 中譯翻譯腔為 feature、稱謂直譯保留、破折號 ——、中等逗號密度 |
| Voice | V-01~V-05 | 第一人稱華生回憶體、時間錨點開場、福爾摩斯演繹獨白、演繹語法骨架、華生驚嘆 |
| Meta | M-01~M-07 | 案件三幕結構、歐化是 feature、華生收尾、不附評論、不寫現代偵探、不寫覺悟句、全形標點零違規 |

完整 21 項 checklist 與 12 步 workflow 見 [SKILL.md](./SKILL.md)。

## 維多利亞物件詞彙清單

至少出現 4 種：

| 類別 | 詞彙 |
|---|---|
| 居所 | 貝克街 221B、客廳、壁爐、波斯拖鞋、土耳其菸盒、化學試劑架 |
| 街景 | 煤氣燈、四輪馬車、雙輪馬車、倫敦霧、河堤、報童 |
| 通訊 | 電報、信件、便條、《泰晤士報》、《每日電訊報》 |
| 隨身物 | 懷錶、菸斗、菸絲、放大鏡、左輪手槍、手杖、禮帽 |
| 場域 | 蘇格蘭場、克勒肯維爾、河岸街、皮卡迪利、車站候車室 |
| 案件物 | 鴉片煙、嗎啡、密碼信、印鑑、足印、雪茄灰、墨漬 |

| 角色 | 中譯 |
|---|---|
| Sherlock Holmes | 福爾摩斯（先生）|
| Dr. John Watson | 華生（醫生）|
| Mrs. Hudson | 哈德森太太 |
| Inspector Lestrade | 雷斯垂德警官／探長 |
| 一般禮稱 | 先生、閣下、夫人、太太、女士 |
