# Liaozhai-tale — 示範

展示 `liaozhai-tale` 如何把現代文章改寫成聊齋體文言短篇，以及好的聊齋體
長什麼樣子。本 skill 沒有強度分層，單一目標：**蒲松齡《聊齋誌異》流派的
文言志怪短篇**。

> **源文說明**：範例一、二為《聊齋誌異》原典(蒲松齡， 1740，公有領域)，
> 作為「目標範例」展示風格，不屬於本 skill 的輸出產物。範例三的源文
> [《差不多先生傳》(胡適， 1924)](../../examples/source-texts/mr-chabuduo.md)
> 來自共用源文庫。範例四為自編現代軼事 + 對照改寫。

---

## 範例一：風格目標 — 《種梨》(完整含異史氏曰)

聊齋名篇之一。展示**完整聊齋結構**：史傳式開頭 + 異化(道士幻術)+ 因果
反轉(梨乃車轅所化)+ 異史氏曰(諷刺鄉人吝嗇)。

### 原典

> 有鄉人貨梨於市，頗甘芳，價騰貴。有道士破巾絮衣，丐於車前。鄉人咄之，
> 亦不去；鄉人怒，加以叱罵。道士曰：「一車數百顆，老衲止丐其一，於居士
> 亦無大損，何怒為？」觀者勸置劣者一枚令去，鄉人執不肯。肆中傭保者，見
> 喋聒不堪，遂出錢市一枚，付道士。道士拜謝，謂眾曰：「出家人不解吝惜。
> 我有佳梨，請出供客。」或曰：「既有之，何不自食？」曰：「吾特需此核作
> 種。」於是掬梨大啖，且盡，把核於手，解肩上鑱，坎地深數寸，納之而覆
> 以土。向市人索湯沃灌。好事者於臨路店索得沸瀋，道士接浸坎處。萬目攢
> 視，見有勾萌出，漸大；俄成樹，枝葉扶疏；倏而花，倏而實，碩大芳馥，
> 纍纍滿樹。道人乃即樹頭摘賜觀者，頃刻而盡。已，乃以鑱伐樹，丁丁良久
> 方斷；帶葉荷肩頭，從容徐步而去。
>
> 初，道士作法時，鄉人亦雜立眾中，引領注目，竟忘其業。道士既去，始顧
> 車中，則梨已空矣，方悟適所俵散，皆己物也。又細視車上一靶亡，是新鑿
> 斷者。心大憤恨。急跡之。轉過牆隅，則斷靶棄垣下，始知所伐梨本，即是
> 物也。道士不知所在。一市粲然。
>
> 異史氏曰：「鄉人憒憒，憨狀可掬，其見笑於市人，有以哉！每見鄉中稱素
> 封者，良朋乞米，則怫然色變，且計曰：『是固數日之資也。』或勸濟一危
> 難，飯一煢獨，則又忿然，又計曰：『此十人五人之食也。』甚而父子兄弟，
> 較盡錙銖。及至淫博迷心，傾囊不吝；刀鋸臨頭，刑贖不遑。諸如此類，正
> 不勝道，蠢爾鄉人，又何足怪！」

### 結構標註

| 段落 | 功能 | 對照規則 |
|---|---|---|
| 「有鄉人貨梨於市⋯⋯」 | 史傳式開頭(無姓名，行業先行) | S-02 |
| 「有道士破巾絮衣⋯⋯」 | 異類介入(道士為神/異人) | C-02、C-03 |
| 「於是掬梨大啖⋯⋯纍纍滿樹」 | 幻術展演(冷靜寫實，非誇張) | M-02 |
| 「初，道士作法時⋯⋯始知所伐梨本，即是物也」 | 因果反轉(梨乃自車轅所化) | C-05、S-03 |
| 「異史氏曰⋯⋯蠢爾鄉人，又何足怪」 | 諷刺評語(由具體事件升至一般道理) | S-04、M-04 |

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 全篇純文言 | V-01 | 「咄之」「怒」「市」「叱罵」皆單字動詞 |
| 句短：「鄉人怒，加以叱罵」 | V-02 | 平均單句 ≤15 字 |
| 道士冷靜，不誇張 | M-02 | 只「破巾絮衣」「從容徐步而去」此類描寫，絕無「奸笑」「邪魅」 |
| 異史氏曰由事件升至吝嗇之人 | M-04 | 不離題，不另寫雜論 |
| 鄉人、道士、傭保、鄉中素封者 | M-01 | 角色皆取無名 |

## 範例二：風格目標 — 《耳中人》(無異史氏曰版)

短篇代表。展示**純記事不附評語**的聊齋路線——故事本身的怪誕已自顯張力，
不需作者再下評論。

### 原典

> 譚晉玄，邑諸生也。篤信導引之術，寒暑不輟，行之數月，若有所得。一日，
> 方趺坐，聞耳中小語如蠅，曰：「可以見矣。」開目即不復聞；合眸定息，又
> 聞如故。意其丹將成，竊喜。自是每坐輒聞。因俟其再言，當應以覘之。
>
> 一日又言。乃微應曰：「可以見矣。」俄覺耳中習習作癢，似有物出，微睨之，
> 小人長三寸許，貌獰惡，如夜叉狀，旋轉地上。心竊異之，姑凝神以觀其變。
> 忽有鄰人假物，扣門而呼。小人聞之，意張皇，繞屋而轉，如鼠失窟。譚覺
> 神魂俱失，復不知小人何所之矣。遂得顛疾，號叫不寧，醫藥半年，始漸愈。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 「譚晉玄，邑諸生也」 | S-02 史傳式開頭 | 點名籍貫與身份(諸生) |
| 「小人長三寸許，貌獰惡」 | C-02 異化 / C-03 具體類型 | 異類為「物精/魘魅」(身體裡長出的小人) |
| 「遂得顛疾，號叫不寧，醫藥半年，始漸愈」 | S-03 結尾收束 | 因果完整(走火 → 失神 → 致疾 → 漸愈) |
| **無異史氏曰** | S-04 條件附評 | 原文純記事，無諷刺/感慨/教訓調性，故不附 |
| 「篤信導引之術，寒暑不輟」 | V-01 純文言 / V-02 句短 | 連珠短句、無一字白話 |

**S-04 判斷依據**：這則的張力(走火入魔→失神致疾)是**故事自身已給出收束**，
不需作者再評斷。同樣不附評語的還有《王六郎》《促織》某些版本——當故事
本身已自帶因果完整性，異史氏曰反而會稀釋餘味。

## 範例三：對照範例 — 木匠雕神像(失敗版 vs 成功版)

源文(自編)：**現代軼事** — 一名工程師接到三天內交專案的死線，連夜加班
寫出醜陋的程式碼，事後花更多時間重構，最後產品被取消。

### 失敗版(犯了多項陷阱)

> 從前有一個叫小明的程式設計師，他接到老闆的命令，要在三天內寫完一個專
> 案。他廢寢忘食地敲打鍵盤，終於在最後一刻交出。但程式碼又亂又難維護，
> 他後悔莫及。後來他花了更多時間重構，但兩個月後，老闆告訴他這個產品取
> 消了。
>
> 異史氏曰：急於求成，反而失去了一切。世人皆如此，真正的快是慢，真正的
> 慢是快。

**犯規清單**

| 編號 | 違反 | 出處 |
|---|---|---|
| C-02 | **無異化** | 沒有狐鬼妖精，只是用文言寫現代故事——這是 liaozhai-tale 的最大禁忌 |
| C-04 | 現代專名 | 「程式設計師」「鍵盤」「專案」「老闆」「重構」 |
| V-01 | 白話混入 | 「他」「但」「後來」「但是」「的」「了」 |
| V-03 | 心理描述 | 「廢寢忘食」「後悔莫及」 |
| S-02 | 無史傳式開頭 | 「從前有一個叫小明的」是話本式不是聊齋式 |
| M-04 | 異史氏曰用白話 | 「真正的快是慢」是現代格言不是文言議論 |

### 成功版(正確異化：廟祝 → 城隍判)

> 王生，膠州人，業木工，巧於斫雕。邑廟欲祀新神，聘其雕像，期三日成。
>
> 生夜不寐，刀痕雜亂。第三日成，木屑滿地，神像目偏。送至廟，廟祝接而
> 視之，默然置於案。生歸。
>
> 越半月，生重雕一像，妙絕，自負勝前。再送至廟，廟祝坐簷下，白髯垂胸，
> 不顧。生問：「像可乎？」廟祝抬目，雙瞳赤如丹砂。生駭，趨而退。歸途
> 風起，木葉滿衣。
>
> 是夜夢神來，曰：「廟前日已圮，汝送像於空地耳。」生驚醒，夢中之像置
> 於床頭，目仍偏。
>
> 翌晨往視之，廟果毀，址夷為平。神像獨立瓦礫間，風雨剝蝕，目偏處已蝕
> 成一陷，反似含怒。村人傳：廟祝乃城隍判，已三百年，專收急工之像為使。
> 生家自此木業不興，生改業耕讀，終不復雕。
>
> 異史氏曰：工求其速，則失於精；事求其急，則失於正。木非不可雕，神非
> 不可祀，然以三日之功責終身之妙，則雕者怒，神者亦怒。世之催趣者，皆
> 廟祝之屬也。

**達標清單**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留核心張力(急工 → 失敗 → 自悔) |
| C-02 | ✓ | 異化主體 = 廟祝 → 城隍判鬼神 |
| C-03 | ✓ | 具體類型(神/鬼判) |
| C-04 | ✓ | 無現代專名 |
| C-05 | ✓ | 因果結構(急工 → 廟祝赤瞳 → 廟毀 → 改業) |
| S-01 | ✓ | 約 320 字，在 200–800 區間 |
| S-02 | ✓ | 史傳式開頭「王生，膠州人，業木工」 |
| S-03 | ✓ | 結尾收束(改業耕讀，終不復雕) |
| S-04 | ✓ | 附異史氏曰(原文有諷刺急工調性) |
| V-01 | ✓ | 純文言，虛詞用「之/於/以/曰/乃/遂/俄/越」 |
| V-02 | ✓ | 句短(平均約 12 字) |
| V-03 | ✓ | 無心理描述(「驚醒」「駭趨而退」是動作) |
| M-01 | ✓ | 無虛構姓名(王生、膠州、邑廟皆通用) |
| M-02 | ✓ | 廟祝舉止冷靜，只「雙瞳赤如丹砂」一處露異 |
| M-04 | ✓ | 異史氏曰呼應故事(「催趣者，皆廟祝之屬也」) |

**對照結論**：聊齋體不是給故事穿文言外衣，而是讓**現代焦慮在志怪場景中
重生**——廟祝赤瞳那一瞬，是「老闆無情」與「冥府差吏」的合一；只有透過
異化，原文的張力才能在新文體中被重新感受。

## 範例四：改寫示範 — 《差不多先生傳》→ 聊齋體

源文：**胡適《差不多先生傳》(1924)摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 原文(Before，節錄)

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不多，
> 是各省各縣各村人氏。⋯⋯
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」
>
> 他小的時候，他媽叫他去買紅糖，他買了白糖回來。⋯⋯先生問他：「直隸省的
> 西邊是哪一省？」他說是陝西。⋯⋯

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽張力 | 「差不多」是放棄區分的執著——表面隨和，實則消解一切判準 |
| 異化主體 | 老者本人 → **早年遇狐被觸，自此凡物不別**(狐性=不別精粗) |
| 異類類型 | **狐**(智慧、亦正亦邪、能授「不分」之印) |
| 場景 | 滕縣鄉間 + 老來病死 + **死後妻整遺物，鏡中現狐** + 鄰耄揭舊事 |
| 結構 | 三疊式(三次「差不多」)+ 病死 + **古鏡映狐 + 鄰耄揭舊事** + 異史氏曰 |
| 異史氏曰 | **附**(原文是諷刺寓言，Hu Shih 的批判調性需保留) |

### 改寫後(After)

> 滕縣某老，年六十餘，人皆呼為「差不多公」。蓋其凡事漠然，不別精粗。問
> 紅糖白糖，皆曰差不多；問陝西山西，亦曰差不多；問今日明日，亦曰差不多。
>
> 老忽暴病。家人遣請邑中王大夫。大夫適出。倉皇之間，從鄰巷得一獸醫。獸
> 醫至，老氣喘：「王⋯⋯王大夫不來？」家人對曰：「獸醫已至。」老頷首，
> 曰：「醫人醫獸，差不多耳。」
>
> 獸醫拈針數下。老氣絕。
>
> 死後三日，妻整其遺物。書篋之底，得一古鏡，色黯而塵厚。妻拭之，鏡中忽
> 現一狐——白毛黧目，衣冠儼然，作俯視老榻之狀。妻大駭，鏡墮地碎。
>
> 鄰有耄者聞之，太息曰：「五十年前，老於井邊嘗遇一狐。狐欲授其金，老視
> 之曰：『金石草木，差不多耳。』狐笑曰：『子既不別輕重，當為吾屬。』自
> 是凡事不別，五十年矣。」
>
> 異史氏曰：世之差不多者，其皆有狐之印乎？分善惡而善惡晦，辨輕重而輕重
> 亡。蓋以狐眼視世，則金石草木，皆同一物耳。世人以漠然為達觀，不知其早
> 為狐所引，可哀也夫！

(約 380 字主體 + 100 字異史氏曰)

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留「差不多」核心張力(原文的諷刺被轉化為「狐之印」的志怪寓言) |
| C-02 | ✓ | 異化主體 = 老者 → 受狐印之人(原文純諷刺寓言，異化提供新的張力來源) |
| C-03 | ✓ | 狐(具體類型) |
| C-04 | ✓ | 無現代專名(滕縣、王大夫、獸醫、書篋、古鏡皆前現代) |
| C-05 | ✓ | 因果完整(早年受狐印 → 一生不別 → 死後鏡中映狐) |
| S-01 | ✓ | 約 480 字總計 |
| S-02 | ✓ | 史傳式開頭「滕縣某老，年六十餘」 |
| S-03 | ✓ | 結尾收束(古鏡映狐 + 鄰耄揭五十年前的井邊舊事) |
| S-04 | ✓ | 附異史氏曰(原文諷刺調性) |
| V-01 | ✓ | 純文言，虛詞用「乃/遂/俄/嘗/蓋」 |
| V-02 | ✓ | 句短，平均約 12 字 |
| V-03 | ✓ | 無心理描述(「妻大駭」「鏡墮地碎」是動作) |
| M-01 | ✓ | 角色皆無名(滕縣某老、王大夫、獸醫、妻、鄰耄) |
| M-02 | ✓ | 狐冷靜舉止(「衣冠儼然」「俯視老榻」)，只「白毛黧目」一處露異 |
| M-04 | ✓ | 異史氏曰呼應故事(從「差不多」升至狐眼視世) |

**改寫的核心動作**：原文已是寓言，但寓言本身是現代式批判(胡適直陳國民
性)。聊齋體把這種批判轉換為**志怪因果**——「差不多」不是國民性，而是
「狐之印」；這個位移讓現代讀者意外地重新看見原文的批判力。

## 速查：Checklist 重點

21 條中最常踩的：

| 編號 | 規則 | 怎麼用 |
|---|---|---|
| C-02 | 必須異化 | 沒有狐鬼妖精就不是聊齋，先決定異化主體與類型 |
| C-03 | 異類有具體類型 | 不寫「某種怪物」，寫「狐」「鬼」「物精」 |
| S-02 | 史傳式開頭 | 「X 縣某甲」「某生，字 X」「寓於某」 |
| S-04 | 異史氏曰條件附 | 諷刺/感慨/教訓 → 附；純記事 → 不附 |
| V-01 | 純文言 | 禁「然後」「但是」「他」「她」「的」「了」 |
| V-03 | 禁心理描述 | 「他很憤怒」→ 寫他做了什麼動作或外貌變化 |
| M-02 | 異化不可 caricature | 異類冷靜舉止，只在關鍵處露非人特徵 |

完整 21 項與 9 步流程見 [SKILL.md](../SKILL.md)。
