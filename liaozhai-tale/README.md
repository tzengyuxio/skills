# Liaozhai-tale — 改寫成聊齋體文言短篇

把任何文章改寫成蒲松齡《聊齋誌異》流派的文言短篇——書生遇狐鬼妖精的志怪
敘事，以紀傳體開頭、純文言敘述，結尾依原文調性決定附不附「異史氏曰」評語。

## 什麼是聊齋體？

《聊齋誌異》(蒲松齡， 1740)收錄 491 篇文言短篇，是清代筆記小說的高峰，
也是中國志怪文學最具辨識度的代表作。蒲松齡以平淡冷靜的文言寫鬼狐妖精，
讓異類舉止如常人，只在關鍵處露出非人特徵——這種「冷靜寫實的志怪」是
聊齋體最重要的美學特徵。

聊齋的標誌性結構：

| 元素 | 特徵 |
|---|---|
| **史傳式開頭** | 「X 縣某甲，字 XX」「某生，X 人」「寓於某」 |
| **異化元素** | 必有狐 / 鬼 / 妖 / 精 / 神 / 異獸 / 物精 之一 |
| **冷靜敘述** | 異類舉止如常，描寫不誇張，情緒透過動作呈現 |
| **因果收束** | 結尾必有反轉、化解、報應、離去、化身等收束事件 |
| **「異史氏曰」** | (條件附)針對故事的諷刺 / 感慨 / 教訓段 |

## 風格參考

- **《嬰寧》** — 最有名的狐女故事，異類融入俗世日常
- **《聶小倩》** — 鬼女與書生情緣，後改編電影《倩女幽魂》
- **《促織》** — 兒魂入蟋蟀，諷刺官場索取
- **《種梨》** — 道士幻術懲鄙，標準異史氏曰結構
- **《耳中人》** — 修煉走火，身體裡長小人，純記事不附評語
- **《考城隍》** — 文人應冥試，溫情之作
- **《狐諧》** — 狐女鬥嘴勝諸生，展現聊齋詼諧一面

## 不會做的事

- 不寫白話的鬼故事(現代恐怖小說與本 skill 是兩個體裁)
- 不寫網文 / 爽文式的志怪(聊齋的異類冷靜如常人，不是「妖怪嘎嘎大笑」)
- 不省異化(沒有狐鬼妖精就不叫聊齋，Hard 規則)
- 不留現代專名(「賈伯斯遇狐」會讓整篇崩潰)
- 不下白話結論(「於是某甲明白了」這類是話本式不是聊齋式)

## 預期輸出篇幅

純文言，**200–800 字**(計入標點)，依原文長度決定：

| 原文長度 | 聊齋體目標 |
|---|---|
| 短(< 300 字) | 200–300 字 |
| 中(300–1000 字) | 300–500 字 |
| 長(1000+ 字) | 500–800 字(只取單一主題) |

低於 150 字會像段子，超過 1000 字偏唐傳奇美學。**原文短時就寫短**，不為
湊字數而稀釋密度。原文超過 1500 字，只取一個主題改寫，不硬塞所有內容。

## 適合的源文

- 個人軼事 / 短篇散文(可直接異化)
- 議論文(諷刺/感慨型最佳)— 必須先抽核心張力再設場景
- 寓言 / 童話(已有寓意，容易異化)
- 新聞事件(去現代化後最像聊齋本色，蒲松齡本人就常從鄉野傳聞起手)

## 不太適合的源文

- 純技術文件(無情感張力可異化)
- 純抒情詩(沒有事件，難設場景)
- 已是文言短篇的源文(改寫意義不大)
- 歷史記述(更適合 wenyan-hanwei)

## 運作流程

1. **讀原文 + 抽張力** — 一句話自答：「這篇的『問』是什麼？『應』在哪裡？」
2. **選異化元素** — 從原文人/事/物擇一變怪異(老闆 → 老狐、電腦 → 古鏡)
3. **選異類類型** — 狐 / 鬼 / 妖 / 精 / 神 / 異獸 / 物精
4. **設場景** — 時間(夜/雨/秋)+ 地點(書齋/古宅/驛站)
5. **第一稿** — 史傳式開頭 + 純文言 + 200–800 字
6. **Checklist 自檢** — 21 條(Hard 16 + Soft 5)
7. **異史氏曰判斷** — 原文有諷刺/感慨/教訓 → 附；純記事 → 不附
8. **抓最弱段重寫** — 通常是異化處(易 caricature)
9. **輸出** — 寫入 `<原檔名>_liaozhai.md`

完整 9 步詳述見 [SKILL.md](./SKILL.md)。

## 改寫原則(checklist 摘要)

| 類別 | 編號 | 要點 |
|------|------|------|
| Content | C-01~C-05 | 保留核心張力、必須異化、異類有具體類型、禁現代專名、因果結構 |
| Structure | S-01~S-06 | 200–800 字、史傳式開頭、結尾必有收束、異史氏曰條件附、不下白話結論、結構不機械 |
| Voice | V-01~V-05 | 純文言、句短、禁心理描述、多具體物名、第三人稱 |
| Meta | M-01~M-05 | 角色取無名、異化不可 caricature、三人稱限知、異史氏曰呼應故事、議論文先抽張力 |

完整 21 項 checklist 見 [SKILL.md](./SKILL.md)。

## 異類類型對照

| 異類 | 性格 / 機能 | 代表名篇 |
|---|---|---|
| **狐** | 媚惑、智慧、亦正亦邪 | 嬰寧、阿繡、青鳳、狐諧 |
| **鬼** | 怨念、未了、亡魂 | 聶小倩、王六郎、伍秋月 |
| **妖** | 物老成精、獸化 | 蓮香、白秋練 |
| **精** | 草木金石之精 | 黃英(菊精)、葛巾(牡丹) |
| **神** | 降賜、責罰、考核 | 考城隍、四司、城隍判 |
| **異獸** | 警示、報恩、報怨 | 義犬、靈龜、巨蛇 |
| **物精** | 器物有靈、附人 | 硯靈、鏡精、衣箱中之異 |
