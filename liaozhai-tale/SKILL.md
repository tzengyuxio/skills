# Liaozhai-tale — 改寫成聊齋體文言短篇

把任何文章改寫成蒲松齡《聊齋誌異》流派的文言短篇——書生遇狐鬼妖精的志怪
敘事。純文言、史傳式開頭、必有「異化」元素，結尾依原文調性決定附不附
「異史氏曰」。

風格參照：《聊齋誌異》(蒲松齡， 1740)。代表名篇：《嬰寧》《聶小倩》《狐諧》
《促織》《種梨》《耳中人》《考城隍》《王六郎》。

## 一句話靈魂

**必有「異化」元素**(C-02)——人／事／物擇一變狐鬼妖精神異獸物精，缺異化
就不是聊齋。其餘 20 條 checklist 都在服務這一條。

## Arguments

- `$0` —(選填)Markdown 或純文字檔案路徑。若省略，請使用者提供內文，
  或從對話上下文中找最近編輯的檔案。

## Step 1: Load the Text

- 若提供 `$0`，讀取該檔案。
- 若無引數，找對話中最近撰寫或編輯的 Markdown 檔，或請使用者提供文字。
- 若原文不是繁體中文，先在心中譯為繁體中文(不必輸出)，再做改寫。

## Step 2: Read Source and Extract One Tension

聊齋體不是把原文翻譯成文言，而是**抽出一個核心張力，以「人遇異類」框架重講**。

讀完原文後，用一句話自答：

> 這篇文章的「**問**」是什麼？它的「**應**」在哪裡？

可能的張力來源：得失、慾望、執著、報應、未了之情、生死、明暗、人鬼之隔、
道學虛偽、貪鄙之諷。原文若是議論文/抒情文/學術文，**先抽出核心張力，再
為它設計一個志怪場景**——不要把論點直接「翻譯」成文言對話。

若原文太長(超過 1500 字)，只取一個主題改寫，不要硬塞所有內容。

## Step 3: Choose 異化 Element (Mandatory)

**這是聊齋體的靈魂條款。**從原文中**選一個元素**作異類轉譯——人/事/物擇
一變怪異。沒有異化就不叫聊齋。

| 現代主題 | 聊齋異化方向 |
|---|---|
| 老闆 / 上司 | 老狐所化、坐廨吸氣的鬼判、冥司差吏 |
| 同事 / 朋友 | 狐友、書齋鬼伴、共讀之異客 |
| 老師 / 醫師 | 老法師、山中異人、藥師仙翁 |
| 電腦 / 手機 | 古鏡、能映魂魄的銅器、有靈之硯、靈枕 |
| 演算法 / 系統 | 卜筮、夢中異人指路、神判官的籙 |
| 加班 / 趕工 | 廟祝抄經、為冥府所役、夜夜入夢之差 |
| 失戀 / 分手 | 狐女離去、鬼妻歸塚、夢醒已三十年 |
| 健康 / 病痛 | 邪祟入體、狐媚耗陽、夜半魘魅 |
| 通訊 / 傳遞 | 烽火、信差、托夢報信、紙錢過界 |
| 學業 / 考試 | 考城隍、夢中典試、鬼神助筆 |

選定後在筆記裡明確寫下：**「異化主體 = X(原文何元素)→ Y(何種異類)」**。

## Step 4: Choose 異類 Type

| 異類 | 性格 / 機能 | 範例 |
|---|---|---|
| **狐** | 媚惑、智慧、亦正亦邪 | 嬰寧、阿繡、青鳳 |
| **鬼** | 怨念、未了、亡魂 | 聶小倩、王六郎、伍秋月 |
| **妖** | 物老成精、獸化 | 蓮香(本為狐)、白秋練 |
| **精** | 草木金石之精 | 黃英(菊精)、葛巾(牡丹) |
| **神** | 降賜、責罰、考核 | 城隍、判官、四司 |
| **異獸** | 警示、報恩、報怨 | 義犬、靈龜、巨蛇 |
| **物精** | 器物有靈、附人 | 硯靈、鏡精、衣箱中之異 |

**默認預期**：狐與鬼最常見、最像聊齋。妖、精、神為輔。物精難寫但出彩。

## Step 5: 設場景

時間 + 地點。聊齋場景有強烈程式化特徵：

- **時間**：夜、雨夜、秋暮、燈下、上元、中元、寒食
- **地點**：書齋、古宅、廢園、驛站、山寺、舟中、墳塋、市集、深巷
- **季節氣象**：落葉、薄霧、燭影、月色、寒風

選一組記下：**「場景 = 時 X + 地 Y」**。

## Step 6: First Draft

寫一稿。原則：

- **語感**：純文言。多單字詞，虛詞用「之/於/以/曰/云/乃/遂/既而/嘗/俄/俟/
  忽/惟/而」
- **句長**：平均單句 ≤15 字(聊齋特色)，敘事密度高
- **史傳式開頭**：「X 縣某甲，字 XX，寓於某」「某生，X 人，X 歲」「X 之某，
  X 業」
- **篇幅**：200–800 字(計入標點)，典型 400 字
- **敘述比 ≥ 60%**(對話比聊齋更不重對話)
- **結尾必有收束事件**：反轉、化解、報應、離去、化身——不下白話結論

## Step 7: Self-check Against Checklist

逐條對照下面的 21 條 checklist。**任一條 [Hard] 違反就回 Step 6 重寫該段**。

### Checklist: Content(內容)

> **C-02 是本 skill 的核心規則(靈魂條款)**。其他規則違反可修，C-02 違反等於整體不是聊齋體，必須打掉重寫。

| 編號 | 強度 | 規則 |
|---|---|---|
| C-01 | Hard | **保留原文核心張力**，但用「人遇異類」框架重述。可換場景、可換角色，但「問」與「應」要對得上原文 |
| C-02 | Hard | **必須「異化」原文某元素**(人/事/物擇一變怪異)。沒有異化就不叫聊齋。**這是本 skill 的靈魂條款** |
| C-03 | Hard | **異類必有具體類型**(狐/鬼/妖/精/神/異獸/物精)，不可寫「一個怪物」「某種異物」這類模糊用詞 |
| C-04 | Hard | **不出現現代專名與現代物件**。例外：用功能性指代替換(「東來之商」「邑中人」) |
| C-05 | Soft | **因果結構** — 異類事件有起因，有結果(報應/化解/離去/化身)。不要寫「異類出現，故事結束」這種無因果的敘事 |

### Checklist: Structure(結構)

| 編號 | 強度 | 規則 |
|---|---|---|
| S-01 | Hard | **篇幅 200–800 字**(計入標點)，典型 400 字。低於 150 字會像段子，超過 1000 字偏唐傳奇 |
| S-02 | Hard | **史傳式開頭**：「X 縣某甲，字 XX」「某生，X 人」「寓於某」「X 之 X」。**不可從場景或對話開頭** |
| S-03 | Hard | **結尾必有「轉折/收束」事件**(反轉、化解、報應、離去、化身)。不可在事件未了處戛然而止 |
| S-04 | Soft | **異史氏曰** — 原文若有諷刺/感慨/教訓調性 → 附；純記事/抒情/敘事 → 不附。判斷依據詳見 Step 8 |
| S-05 | Hard | **不下白話結論**。禁用「於是某甲明白了」「從此 X 知道」這類訓誨句。但「異史氏曰」段不算結論——它是另一個文體層 |
| S-06 | Soft | **結構不機械三段**。可加閒筆、入詩、夢境插入、回憶段 |

### Checklist: Voice(語言風格)

| 編號 | 強度 | 規則 |
|---|---|---|
| V-01 | Hard | **純文言**——多單字詞，虛詞「之/於/以/曰/云/乃/遂/既而/嘗/俄/俟/忽/惟/而」適度使用。**禁白話詞**(「然後」「但是」「因為」「所以」「他」「她」) |
| V-02 | Hard | **句長偏短**，平均單句 ≤15 字。聊齋的密度來自短句連珠 |
| V-03 | Hard | **禁心理描述**——不寫「他感到困惑」「她很憤怒」「他突然明白」。情緒以動作、對話、外貌變化(色變、目瞪、汗下、踉蹌)呈現 |

### Checklist: Meta(後設)

| 編號 | 強度 | 規則 |
|---|---|---|
| M-01 | Hard | **角色取「某生/某甲/某客/X 縣 X」優於虛構姓名**。歷史名(蒲松齡、王漁洋等)只能用於史實引用，不可寫進故事人物 |

**總計**：22 條(Hard 17 + Soft 5)。

## Step 8: 異史氏曰 判斷

原文是否有以下調性？有任一 → 附「異史氏曰」；皆無 → 不附：

- **諷刺**(對某類人事物的批判、嘲弄)
- **感慨**(對命運、無常、世事的喟嘆)
- **教訓**(明顯的勸世、戒貪、戒嗔等)
- **道德判斷**(原文有明顯善惡好惡)

不附的情形：
- 純敘事(只講一個事件，不評斷)
- 純抒情(個人感受，無對外論斷)
- 純記錄(像日記、行記)
- 已在故事中自顯張力(像《耳中人》結尾「醫藥半年始漸愈」就是收束，不需評語)

異史氏曰格式：
- 開頭「異史氏曰：」(冒號，非破折號)
- 一段或兩段文言議論
- 篇幅約占故事 1/4 至 1/3，**不可長過故事本身**
- 可從具體事件升至一般道理，但要**呼應故事**而非離題

## Step 9: 標點清理

最後一道工序：

- **全形標點(鐵律)**：CJK 文本中所有標點一律全形。**ASCII 半形 `, ; : ? !` 在 CJK 字之間出現一律是 bug**，必須換成全形 `，；：？！`。對照表：

  | 半形(禁) | 全形(用) | Unicode |
  |---|---|---|
  | `,` | `，` | U+FF0C |
  | `;` | `；` | U+FF1B |
  | `:` | `：` | U+FF1A |
  | `?` | `？` | U+FF1F |
  | `!` | `！` | U+FF01 |
  | `(` `)` | `（` `）` | U+FF08 / U+FF09 |

- **破折號**用兩個全形「—」連寫成「——」，不寫成 `--` 也不寫成單個「—」
- **引號**用「」與『』，不用 `"` `'`
- **句號**用「。」，不用 `.`
- **全形標點與 CJK 之間零空格**

- **寫完後必跑自檢指令**(指令名留作機械驗證，不可省略)：

  ```bash
  python3 -c "
  import re, sys
  text = open(sys.argv[1]).read()
  bad = re.findall(r'[^\x00-\x7f][,;:?!][^\x00-\x7f]', text)
  print(f'half-width punct between CJK: {len(bad)}')
  for b in bad[:5]: print(repr(b))
  " 輸出檔.md
  ```

  結果必須為 `0`。非 0 表示輸出時混入了 ASCII 半形，回到輸出檔逐字替換後重跑，直到歸零才算交付。

## Step 10: Output

1. **檔案輸入**：寫入 `<原檔名>_liaozhai.md`，保留原檔
2. **貼文輸入**：直接輸出聊齋體
3. **不附說明、不附改寫思路、不附「我選擇了狐/鬼...」這類元資訊**

## Anti-patterns(常見失敗模式)

寫完一稿、自檢之前，先掃一眼這 10 條最容易踩的坑：

1. **無異化** — 寫了純文言但沒有狐鬼妖精。聊齋體的核心是「異」，沒異就不叫聊齋
2. **異化 caricature** — 寫成網文/動漫式的妖怪(「妖怪奸笑」「狐狸嬌嗔」)。聊齋的異類是冷靜舉止，只在關鍵處露非人特徵
3. **過度堆砌生僻字** — 文言要凝鍊不要做作，「俯仰之間」勝於「俯仰之頃」勝於「俯仰俄頃」
4. **白話混入** — 文言段中混入「然後」「但是」「他」「她」「的」這類白話詞，語感立刻崩
5. **無史傳式開頭** — 從場景或對話切入(「某夜大雨，書生獨坐」)，違反 S-02
6. **結尾無收束** — 異類出現後事件懸而未決就結束，違反 S-03
7. **異史氏曰離題** — 寫了評語但跟故事關聯薄弱，變成另寫一篇文言雜論
8. **異史氏曰過長** — 評語比故事本身還長，本末倒置
9. **強加「教訓」式結尾** — 不附異史氏曰時，不可在故事末段塞訓誨句替代
10. **半形標點混入** — 輸出時把 `,;:?!` 打成 ASCII 半形而非全形 `，；：？！`。
    常見原因是 IME 切換失誤或從英文 prompt 複製字串。寫完務必跑 Step 9 自檢
    指令，計數歸零才算交付(違反 M-06)

## Core Example: 木匠雕神像

源文(現代軼事)：一名工程師接到三日交專案的死線，連夜加班寫出醜陋程式
碼，事後重構，最後產品被取消。下方為改寫成功的版本——核心改寫動作是
**異化**(廟祝 → 城隍判)，讓現代焦慮在志怪場景中重生。

> 王生，膠州人，業木工，巧於斫雕。邑廟欲祀新神，聘其雕像，期三日成。
>
> 生夜不寐，刀痕雜亂。第三日成，木屑滿地，神像目偏。送至廟，廟祝接而視之，默然置於案。生歸。
>
> 越半月，生重雕一像，妙絕，自負勝前。再送至廟，廟祝坐簷下，白髯垂胸，不顧。生問：「像可乎？」廟祝抬目，雙瞳赤如丹砂。生駭，趨而退。歸途風起，木葉滿衣。
>
> 是夜夢神來，曰：「廟前日已圮，汝送像於空地耳。」生驚醒，夢中之像置於床頭，目仍偏。
>
> 翌晨往視之，廟果毀，址夷為平。神像獨立瓦礫間，風雨剝蝕，目偏處已蝕成一陷，反似含怒。村人傳：廟祝乃城隍判，已三百年，專收急工之像為使。生家自此木業不興，生改業耕讀，終不復雕。
>
> 異史氏曰：工求其速，則失於精；事求其急，則失於正。木非不可雕，神非不可祀，然以三日之功責終身之妙，則雕者怒，神者亦怒。世之催趣者，皆廟祝之屬也。

**達標清單**
- C-01 ✓：保留核心張力(急工→失敗→自悔)
- C-02 ✓：異化(廟祝 → 城隍判；改寫筆記：「異化主體 = 廟祝 → 鬼判」)
- C-03 ✓：具體類型(神/鬼判)
- C-04 ✓：無現代專名
- C-05 ✓：因果結構(急工→廟祝赤瞳→廟毀→改業)
- S-01 ✓：約 320 字
- S-02 ✓：史傳式開頭「王生，膠州人，業木工」
- S-03 ✓：結尾收束(改業耕讀，終不復雕)
- S-04 ✓：附異史氏曰(原文有諷刺急工調性)
- S-05 ✓：無白話結論
- V-01 ✓：純文言，虛詞用「之/於/以/曰/乃/遂/俄/越」
- V-02 ✓：句長偏短(平均 ~12 字)
- V-03 ✓：無心理描述(「驚醒」「駭趨而退」是動作)
- V-05 ✓：第三人稱
- M-01 ✓：無虛構姓名(王生、膠州、邑廟皆通用)
- M-02 ✓：廟祝舉止冷靜，只「雙瞳赤如丹砂」一處露異
- M-04 ✓：異史氏曰呼應故事(催趣者皆廟祝之屬)
- M-05 ✓：議論文/源文先抽張力(急工 vs 慢工)再設場景

**對照結論**：聊齋體不是給故事穿文言外衣，而是讓**現代焦慮在志怪場景中重生**
——廟祝赤瞳那一瞬，是「老闆無情」與「冥府差吏」的合一；只有透過異化，
原文的張力才能在新文體中被重新感受。

## Scope Boundary

| 想做的事 | 用哪個 skill |
|---|---|
| 把文章改寫為聊齋體文言短篇(本 skill 目標) | **liaozhai-tale** |
| 寫敘事公案(白話偏雅，無異類強制) | `koanify` |
| 改寫為唐宋論說文(無敘事框架，無異類) | `wenyan-guwen` |
| 改寫為話本小說體(說書人腔，半文白) | `wenyan-huaben` |
| 改寫為先秦諸子體 / 漢魏史傳體 | `wenyan-xianqin` / `wenyan-hanwei` |
| 寫唐傳奇(篇幅長、人鬼情濃) | (尚未製作；聊齋是其後裔但篇幅與美學皆異) |
| 寫六朝志怪(更短、更素樸) | (尚未製作；與聊齋接近但語感更古拙) |

如果使用者要的是**白話的鬼故事**或**現代奇幻**，告訴使用者本 skill 是
**清代文言筆記體**(非現代恐怖小說)。

## Important Notes

- 本 skill 是**體裁轉換工具**，不是文言翻譯工具。原文不需是敘事——任何
  類型(議論、抒情、學術)都可以，但會被**重構為志怪敘事**
- **異化是 Hard 規則**(C-02)。沒有狐鬼妖精就不是聊齋。如果原文找不到
  可異化的元素，主動為它**虛構一個異類角色**承載原文張力
- **不要寫成網文式爽文/恐怖片**。聊齋的異類冷靜、舉止如常，只在關鍵處
  露出非人特徵——這是「志怪美學」與「網文恐怖」的根本差異
- **保留鋒利的細節**(具體物、聲音、姿勢、外貌變化)，不要磨平成抽象的
  「他感到不安」
- 清單並非窮盡，使用判斷力標記其他感覺不對的句子
