# Jinyong-wuxia — 示範

展示 `jinyong-wuxia` 如何把現代文章改寫成中期黃金期金庸武俠敘事，以及好的
金庸腔長什麼樣子。

> **源文與引用說明**：範例一、範例二為依中期金庸風格自編的「目標範例」，
> 用以示範靈魂條款怎麼落地，**非實際金庸作品**。範例三的源文（現代軼事）
> 為自編。範例四的源文 [《差不多先生傳》(胡適， 1924)](../../examples/source-texts/mr-chabuduo.md)
> 來自共用源文庫，公有領域。文中對中期金庸代表作（《射鵰英雄傳》《神鵰俠
> 侶》《倚天屠龍記》《天龍八部》《笑傲江湖》）的指涉僅作風格座標說明，
> 未引用整段原文。

---

## 範例一：風格目標 — 武當習劍（招式詳寫）

這是 jinyong-wuxia 的第一個「品牌示範」——展示**章回敘事 + 招式詳寫**的
最純粹樣態。師徒配置、習武進境、自編五七言詩詞嵌入。

### 自編目標範例

> **《武當鶴翔記》主題：南宋紹興年間，武當門下少年習得「明心七劍」之
> 第七式，方知劍法在心不在劍。**
>
> 卻說大宋紹興三年秋，武當山秋色正濃，落葉紛紛。山中有一弟子，姓陳
> 名鶴，年方十七，入武當門下三載，專習「明心七劍」。
>
> 是日，師父張清雲長老親自考較。陳鶴拔劍出鞘，劍光如水，先施第一式
> 「白鶴亮翅」，劍尖指向松林之頂；再施第二式「孤雁出群」，身形騰起，
> 劍鋒劃出一道白線。長老立於石台之上，但見鶴弟劍意尚淺，然已得其形。
>
> 至第七式「明心見性」時，長老忽以拂塵點劍頭，曰：「劍應在此處，差
> 之毫釐，內息即亂。」陳鶴持劍而立，默然不語。
>
> 良久，陳鶴收劍入鞘，跪地拜曰：「弟子原以為劍法在外，今日始知劍法
> 在內。」長老撫鬚而笑：「然則明日始可下山。汝且記之——」
>
> 言畢，以劍尖於山石上書一行：
>
> > 千鋒已試三秋月，一劍將酬十載心。
>
> 後人傳之，謂武當門人下山前，皆讀此偈。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 「《武當鶴翔記》主題：⋯⋯」標題 | S-05 章回回目 | 篇幅 <600 字，採「《XX 記》主題」軟回目 |
| 招式名：白鶴亮翅、孤雁出群、明心見性 | S-03 招式詳寫 | 三招意象式命名，且每招有對打／施招理由 |
| 詩詞嵌入：「千鋒已試三秋月，一劍將酬十載心」 | S-04 詩詞嵌入 | 自編五七言對句，呼應十年習劍的情緒高峰 |
| 章回套語：「卻說」「但見」「然則」「言畢」 | V-04 套語點綴 | 自然嵌入，不堆疊 |
| 長句結構，平均 ~22 字 | S-02 長複句 | 「先施第一式『白鶴亮翅』，劍尖指向松林之頂」式層遞 |
| 歷史錨定：大宋紹興三年、武當山 | C-04 歷史錨定 | 朝代＋地名雙錨 |
| 角色：陳鶴、張清雲（金庸式響亮三字名）| C-05 響亮名 | 不取「老李」「小張」 |

**風格座標**：師徒配置與《射鵰》洪七公教郭靖、《笑傲江湖》風清揚授令狐
冲的場景結構相近——**師徒以一招對話，弟子以拜服收束**。

## 範例二：風格目標 — 襄陽城下（家國情義 + 詩詞）

示範第二種配置——**家國對峙**。中期金庸最重的底色：俠之大者為國為民。
這個範例展現詩詞嵌入的另一種用法：引古典詩詞（杜甫〈春望〉）承載家國
分量。

### 自編目標範例

> **《襄陽承志記》主題：南宋淳祐年間，襄陽圍急，少年校尉於樓頭夜讀
> 父書，立志承父志守城。**
>
> 話說南宋淳祐四年冬，蒙古大將忽必烈圍襄陽日久，城內糧盡，守將呂文
> 煥仰天長嘆。是夜，城內小校尉呂應龍持父兵書於樓頭夜讀。其父呂氏為
> 前任都統，半月前戰歿城下，留兵書一卷曰《忠義訣》，遺言：「家國一
> 體，守城即守家。」
>
> 應龍翻閱至第七卷，見其父手書批註，曰：「劍可斷，志不可斷；城可破，
> 氣不可破。」少年讀至此，熱淚奪眶。但見窗外大雪紛飛，蒙古軍燈火萬
> 點，有如群星墜地。
>
> 應龍闔書起立，於樓頭輕誦杜工部〈春望〉之句：
>
> > 國破山河在，城春草木深。
>
> 誦畢，握劍南望，神色凝重而堅。是夜，他下定決心：明晨即赴城頭，代
> 父接戰。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 家國軸：襄陽圍城、父歿、子承 | C-02 家國情義 | 個人之志與家國之難重疊 |
| 詩詞嵌入：杜甫〈春望〉「國破山河在，城春草木深」 | S-04 詩詞嵌入 | 引古典詩詞而非自編，承載歷史悲壯 |
| 歷史錨定：南宋淳祐四年、襄陽、忽必烈、呂文煥 | C-04 歷史錨定 | 朝代＋地名＋歷史人物三重錨 |
| 父子配置：呂應龍 / 父呂氏 | Step 4 配置 | 「家國對峙」變體：以家承國 |
| 結構：起（夜讀）-承（見批註）-轉（聞詩誦）-合（決意接戰）| S-06 起承轉合 | 完整四段式，有「合」段 |
| 角色名：呂應龍 | C-05 響亮三字名 | 父姓＋兩字典雅名 |

**風格座標**：與《神鵰俠侶》末段郭靖力守襄陽、楊過率眾擊退蒙軍的家國
情義底色相承——**俠之大者，為國為民**是金庸對「俠」的最高定義。

## 範例三：改寫示範 — 現代軼事（失敗版 vs 成功版對照）

源文（自編）──**現代軼事**：

> 一名工程師接到三天內交專案的死線，連夜加班寫出醜陋的程式碼，事後花更多
> 時間重構，最後產品被取消。

下面用同一段源文，做兩種改寫對照：**失敗版**犯了多項 [Hard] 規則；**成功
版**通過完整 checklist。

### 失敗版（Before）

> 木匠小明為祠堂雕神像。三天時間。**他用刀使勁砍。**
>
> 「我必須完成。」他想。
>
> 三天到了。他完成了。但廟祝告訴他：「祠堂前日已拆。」
>
> 他終於明白了道理。

**犯規清單**

| 編號 | 違反 | 出處 |
|---|---|---|
| S-01 | 篇幅過短 | 不足 100 字，遠低於 400 字下限 |
| S-02 | 短句連發 | 寫成古龍式節奏，不是金庸 |
| S-03 | 無招式詳寫 | 「使勁砍」毫無招式名 |
| S-04 | 無詩詞嵌入 | 完全缺席 |
| C-04 | 無歷史錨定 | 沒有朝代、地名 |
| S-06 | 留白突兀 | 「他終於明白了道理」未具體展開合段 |
| C-05 | 角色名平淡 | 「小明」失去金庸感 |

### 成功版（After）

> **《敕雕記》主題：北宋徽宗年間，魯班門傳人應敕雕鎮國神像，期三日成，
> 末了卻見祠廟已圮。**
>
> 卻說北宋徽宗政和六年，金兵屢犯北疆，朝廷敕令於汴京西郊建鎮國祠堂
> 一座，內供文武判官二尊神像，以鎮邊事。時嘉興城外有一木匠，姓陸名
> 子修，乃魯班門第七代傳人，雕工精絕，世人稱之「木中聖手」。朝廷使
> 者持敕令到陸氏工坊，限三日內雕神像送達汴京。
>
> 子修接旨，心知時日匆促，當夜即施「魯班三十六刀」中的疾刀八式，自
> 「破柴」起，至「合榫」止，刀刀如風。第一日刻木胎，第二日定五官，
> 第三日清晨，唯餘神像眉眼未開。子修知時不可待，遂運最後一式「移星
> 換斗」——此式講究心、手、刀三合，目隨木走，刀隨心至。誰料連夜未眠，
> 心氣浮亂，刀偏一分，眉眼竟略向左斜。
>
> 子修大驚，欲重雕已不及。但見窗外天色微明，使者已在門外催促。他長
> 嘆一聲，將神像奉上，隨使者北上汴京。臨別之際，望見桃花江上薄霧未
> 散，不禁低吟陸放翁〈書憤〉之句：
>
> > 樓船夜雪瓜洲渡，鐵馬秋風大散關。
>
> 三日後，子修隨使者抵汴京西郊。但見原擬建祠堂之地，已夷為平地。原
> 來金兵南侵之勢急，朝廷已棄此祠改築它處，敕令未及收回。子修立於荒
> 地之上，懷抱神像，半晌無言。
>
> 後人記之：陸子修自此封刀，歸隱嘉興桃花江畔，終身不復雕。神像則由
> 朝廷另覓處供奉，眉眼略偏處，反成天下傳奇——說者謂之「天意難全」。
> 太史氏曰：俠工之道，盡其在己；成敗利鈍，非工所能料也。

**達標清單**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-02 | ✓ | 家國軸：朝廷敕令、金兵南侵、鎮國祠堂、邊事危急 |
| C-04 | ✓ | 歷史錨定：北宋徽宗政和六年、嘉興、汴京、桃花江 |
| C-05 | ✓ | 角色名：陸子修（金庸式三字響亮）|
| S-01 | ✓ | 約 600 字，正中典型範圍 |
| S-02 | ✓ | 章回式長句，平均句長 ~22 字 |
| S-03 | ✓ | 招式：「魯班三十六刀」「疾刀八式」「移星換斗」 |
| S-04 | ✓ | 詩詞：陸游〈書憤〉呼應家國邊事 |
| S-05 | ✓ | 600 字邊界，標「《敕雕記》主題」軟回目 |
| S-06 | ✓ | 起承轉合完整，篇末有「太史氏曰」合段 |
| V-01 | ✓ | 半文白章回語感 |
| V-02 | ✓ | 詳實鋪陳：時序、地理、招式、心理動機 |
| V-03 | ✓ | 武打詳寫：招式有名、施招理由、敗在心氣浮亂 |
| V-04 | ✓ | 套語：「卻說」「誰料」「但見」「原來」 |
| V-05 | ✓ | 篇末「太史氏曰」一句史傳式議論 |

**對照結論**：金庸體不是把句子加長加文，而是**讓江湖長在歷史裡**——
「樓船夜雪瓜洲渡」沒有解釋為何在此引用，但讀完整篇你會知道：那是急工
之上更大的時代焦慮。

**與 gulong 版的核心反差**：gulong 版定格在「殺手走出酒館，外面風很大，
他沒有回頭」——個人孤獨、戛然而止；jinyong 版收在「太史氏曰：俠工之道，
盡其在己」——史傳判詞、起承轉合工整。這正是兩個 skill 對偶的精髓。

## 範例四：改寫示範 — 《差不多先生傳》→ 金庸

源文：**胡適《差不多先生傳》(1924)摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 原文（Before）

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不多，
> 是各省各縣各村人氏。⋯⋯
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」
>
> 他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：
>「錯了。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」⋯⋯
>
> 後來他得急病，趕快叫家人去請東街的汪先生。一面慌一面跑，人急了，東西兩
> 街，汪王不分，跑到西街牛醫王大夫家裡。⋯⋯王大夫用醫牛之法給他治病，差不
> 多先生就此一命嗚呼。

（原文採取**諷刺寓言**體例。「差不多先生」是國民性的擬人化批判。）

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽張力 | 「差不多」是放棄區分的執著——平日無事，但在生死關頭，毫釐之差即為生死之別 |
| 主題抽象化 | 把差不多先生升格為江湖大俠，將「差不多」鑄成「差不多功」——以差不多劍法名動江湖，最終卻死於差不多式內傷與差不多式延醫 |
| 角色配置 | 大俠／傳人（差不多大俠出武當門下）+ 庸醫（牛醫趙大夫）|
| 招式 | 武當「明心七劍」「太極圓融訣」+ 自編「差不多劍」「平脈散邪」|
| 詩詞 | 引辛棄疾〈青玉案·元夕〉「眾裡尋他千百度」呼應臨終的迷茫與所失 |
| 歷史錨定 | 明朝崇禎十六年（1643），武當山、漢陽道——李闖陷京、清兵未入關之亂世前夜 |
| 章回回目 | 篇幅 ~750 字 ≥600 字，須加章回回目對仗 |

### 改寫後（After）

> **第一回　差功成名動江湖**　**第二回　毫釐殞命漢陽道**
>
> 卻說明朝崇禎十六年秋，天下大亂，李闖王已陷北京之初，清兵未入關前，
> 湖廣武林尚有最後一段太平歲月。其時武當山下有一劍客，姓差名不多，
> 自號「差不多大俠」。差大俠武當門下出身，習「明心七劍」十年。師父
> 嘗點劍頭曰：「應在此一寸」，大俠每偏取之，笑曰：「差不多」。如是
> 日久，劍法竟自成一脈，名「差不多劍」。世人或譏或服，不一而論。
>
> 後大俠以「太極圓融訣」內功有成，然每運氣輒稍偏一脈，自不以為意，
> 曰：「差一脈耳，何足道。」豈料百日積成內傷，自不察焉。
>
> 是年中秋之夜，大俠下山赴友人之約，行至漢陽道上，忽覺胸口若火，寒
> 汗淋漓。鄉老急延郎中。其時城中名醫王太醫恰外出未歸，家人慌亂，自
> 鄰巷喚來一牛醫趙大夫應急。但見趙大夫年逾花甲，鬚白如雪，執銀針而
> 至。大俠氣弱問：「來者王太醫乎？」家人答：「牛醫已在門外。」大俠
> 頷首，微笑曰：「醫人醫牛，差不多。」
>
> 但見趙大夫拈三寸銀針，使「平脈散邪」一式，自胸前膻中穴起，連刺三
> 針。豈料趙氏所學原為牛馬之術，人之經絡與牲口大異，三針一下，大俠
> 脈門立絕。臨終之際，大俠舉目望明月，輕誦其師當年所授辛幼安〈青玉
> 案〉之句：
>
> > 眾裡尋他千百度，驀然回首，那人卻在，燈火闌珊處。
>
> 言畢氣絕，神態安詳，似仍以「差不多」三字自慰。
>
> 越日，武林各派聞訊，皆扼腕嘆息。武當張真人下山視之，撫劍低語：
> 「劍可差不多，氣不可差不多；氣可差不多，生死不可差不多。」遂為大
> 俠書墓碑，僅四字曰：「差不多人」。
>
> 太史氏曰：差大俠之差，在生於差，死於差；平生差不多，終亦差不多——
> 獨其臨終之差，卻是大不同。蓋世之以差不多自處者，當知有其差不多不
> 得之時也。
>
> 自是江湖言「差不多」三字，無不噤聲。

（約 750 字）

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留「差不多」核心張力；原文諷刺被轉化為金庸式史傳判詞 |
| C-02 | ✓ | 家國軸：李闖陷京、清兵入關前的亂世背景，承載差大俠之死的時代意義 |
| C-03 | ✓ | 無現代專名 |
| C-04 | ✓ | 歷史錨定：明朝崇禎十六年、武當山、漢陽道、李闖王 |
| C-05 | ✓ | 角色名：差不多（源文角色名）、王太醫、趙大夫、張真人——皆三字響亮 |
| S-01 | ✓ | 約 750 字，典型範圍 |

**改寫的核心動作**：把胡適原文「明寫的諷刺」轉為「金庸式史傳判詞」。
原文是雜文體諷刺，金庸版讓「差不多大俠」成為一個有招式有師承有歷史背景
的悲劇英雄——**他不是被牛醫害死的，是被自己的『差不多』哲學害死的**——
而這個道理，由武當張真人的撫劍低語、太史氏的篇末議論共同承擔。

**結尾差異化說明**：
- koanify 版：童子+三人 echo「差不多」+ 月光下兩糖罐並列定格
- gulong 版：殺手獨行收場「外面風很大，他沒有回頭」
- **jinyong 版：太史氏曰史傳判詞 + 「差不多人」墓碑 + 「江湖言差不多無不
  噤聲」的集體沉默**

三種收束分別代表禪宗的當下定格、古龍的個人孤獨、金庸的史傳定論——體裁
靈魂的差別在結尾最為清晰。
