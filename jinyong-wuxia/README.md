# Jinyong-wuxia — 改寫成中期黃金期金庸武俠

把任何文章改寫成中期金庸流派的武俠敘事。

不是把句子加長加文，不是仿章回小說，而是**讓江湖長在歷史裡**——讀完讓人
覺得江湖與歷史是一體的，俠氣與家國是一體的。

## 什麼是中期黃金期金庸？

中期金庸指 1957 至 1969 年間的成熟期五大代表作。**排除晚期《鹿鼎記》**
（1969–72，反武俠變體會稀釋風格辨識度）：

| 作品 | 年代 | 風格特徵 |
|---|---|---|
| 《射鵰英雄傳》 | 1957–59 | 章回正統、家國史詩、東邪西毒南帝北丐 |
| 《神鵰俠侶》 | 1959–61 | 情之為何物、絕情谷、十六年之約 |
| 《倚天屠龍記》 | 1961–63 | 元末明初、明教正名、張無忌成長 |
| 《天龍八部》 | 1963–66 | 佛理與悲劇、群像對位、喬峰命運 |
| 《笑傲江湖》 | 1967–69 | 江湖政治寓言、令狐冲、獨孤九劍 |

`jinyong-wuxia` 鎖定這個時期的共同 DNA：**章回史傳氣 + 招式詳寫 + 詩詞
嵌入**。

## 風格參考

- **《射鵰英雄傳》**——章回對仗回目最工整（「風雪驚變」「黑風雙煞」「亢
  龍有悔」），家國軸最重，是「金庸體」最典型的代表
- **《神鵰俠侶》**——詩詞嵌入最密集（李莫愁讀〈摸魚兒〉、楊過憶亡父詩文），
  情義底色最濃
- **《天龍八部》**——招式命名最詩意（六脈神劍、北冥神功、降龍十八掌），
  群像結構最複雜
- **《笑傲江湖》**——江湖政治寓言、招式與心境並重（獨孤九劍以「無招勝
  有招」為武學頂點）

## 不會做的事

- 不寫古龍式短句留白（那是 `gulong-wuxia` 的領域，本 skill 的對偶）
- 不寫晚期《鹿鼎記》式戲謔反武俠
- 不寫平江不肖生／還珠樓主式的早期傳統武俠
- 不留白突兀結尾（金庸需要起承轉合「合」段）
- 不為招式而招式、不為詩詞而詩詞（炫技是大忌）
- 不取「老李」「小張」這類平淡角色名（失去金庸感）

## 預期輸出篇幅

繁體中文半文白章回語感，**400–1200 字**（計入標點）：

| 原文長度 | 金庸體目標 | 章回回目 |
|---|---|---|
| 短（< 200 字）| 400–600 字 | 「《XX 記》主題」軟回目 |
| 中（200–800 字）| 500–800 字 | 篇幅 ≥600 字必加章回回目 |
| 長（800+ 字）| 700–1200 字 | 必加章回回目 |

低於 300 字無法承載章回敘事的鋪陳節奏，超過 1500 字會偏連環章節。**章回
回目**（如「第一回 風雪驚變」「第二回 江南七怪」）是 Soft 規則：≥600 字
必加，<600 字標註「《XX 記》主題：⋯⋯」。

## 適合的源文

- 哲學散文／議論文（需先抽核心張力）
- 寓言／諷刺寓言（《差不多先生》《狂人日記》）
- 歷史軼事（自帶歷史錨定）
- 家國／民族敘事（最契合中期金庸底色）
- 個人成長軼事（可改寫為大俠成長路）

## 不太適合的源文

- 充滿現代專名／科技／政治的新聞報導（去脈絡化代價太高）
- 純抒情詩（金庸需要敘事骨架）
- 已經是武俠小說的源文（改寫意義不大）
- 純技術文件、程式碼說明（沒有可承載的歷史場景）

## 與 gulong-wuxia 的對偶設計

`jinyong-wuxia` 與 `gulong-wuxia` 互為精準對偶——`gulong-wuxia` 的 Hard
規則禁止的，這裡多半是 Hard 規則要求的：

| 軸線 | gulong-wuxia | jinyong-wuxia |
|---|---|---|
| 句長 | 極短句、單句成段（≤12 字）| 章回式長複句（平均 ≥18 字）|
| 結構 | 散文化詩意、節奏跳躍 | 章回對仗、線性史傳起承轉合 |
| 武打 | 留白省略、只給結果 | **招式詳寫、招式必有名** |
| 角色 | 殺手 / 孤客 / 浪子 | 大俠 / 情聖 / 門派傳人 |
| 主題 | 個人宿命、孤獨哲理 | **家國情義、江湖正邪** |
| 氛圍 | 現代感的孤寂與荒涼 | 古典史傳氣、明確歷史錨定 |
| 語感 | 白話偏雅 + 警句 | 半文白章回 + 套語 |
| 景物 | 凝鍊符號（取一二）| 詳實鋪陳（時序、地理、風土）|

兩個 skill 的關係類似 `dewesternise` / `westernise`——是文體取捨的兩極。

```

```

「rewrite as Jinyong wuxia」

## 運作流程

1. **讀原文 + 抽張力** — 一句話自答：「這篇的『俠／義』在哪？『家／國』
   在哪？」
2. **主題抽象化** — 若是現代主題，換成江湖等價物（職場政治 → 朝廷派系；
   失戀 → 江湖恩怨）
3. **角色設計** — 從六種配置選一（大俠/傳人、師徒、雙雄、情侶、家國、
   正邪）
4. **招式 + 詩詞 + 歷史錨定** — 至少 1 招式名、1 詩詞嵌入點、明確朝代地名
5. **第一稿** — 章回式長句、必含武打段與詩詞段
6. **Checklist 自檢** — 21 條（Hard 16 + Soft 5）
7. **抓最弱段重寫** — 通常是武打段或詩詞嵌入段
8. **輸出** — 寫入 `<原檔名>_jinyong.md`，含章回回目（若 ≥600 字）

## 改寫原則（checklist 摘要）

| 類別 | 編號 | 要點 |
|------|------|------|
| Content | C-01~C-05 | 保留核心張力、必有家國/正邪軸、禁現代專名、必有歷史錨定、響亮三字名 |
| Structure | S-01~S-06 | 篇幅 400–1200 字、章回式長句、招式必有名、必有詩詞嵌入、章回回目（Soft）、起承轉合工整 |
| Voice | V-01~V-05 | 半文白章回、詳實鋪陳、武打過程詳寫、章回套語、可有史傳式旁白 |
| Meta | M-01~M-05 | 不附評論段、詩詞招式不炫技、響亮名、必有歷史錨定、議論文先抽張力 |

完整 21 項 checklist 與 9 步 workflow 見 [SKILL.md](./SKILL.md)。

## 三條靈魂條款

中期金庸體的指紋：

1. **C-02 家國情義／正邪價值衝突軸** — 俠之大者為國為民／忠義兩難／門派
   恩怨擇一
2. **S-03 招式詳寫，武招必有名** — 數字式 / 典故式 / 意象式擇一
3. **S-04 必有古典詩詞嵌入** — 至少 1 處，呼應情節高峰

三者缺一就不是金庸。其餘 18 條 checklist 都在服務這三條。
