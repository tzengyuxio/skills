# Postmodern-lens — 用後現代的眼光重寫敘事

把一篇文章改寫成「**它自己用後現代的眼光看自己**」的版本。事件不動，
但文章對「應該怎麼講這個故事」的假設——誰有資格講、是不是只有一種版
本、底下那個宏大解釋是不是其實也只是一個小故事——被攤開、被質疑、被
留在懸而未決。

這是一個 **lens skill**——它不像體裁／風格 skill 那樣改變句法、節奏或詞
彙表面，而是改變**詮釋框架**：同一個事件，被重新敘述為一個「對它的講
法本身就有問題」的事件。讀完讓人覺得：這篇文章從一開始就在懷疑自己
能不能被講清楚。

## 一句話靈魂

**事件保留、概念自然發生、元敘事懷疑義務**——三條核心條款並列，缺一就
會掉回兩個失敗模式：要嘛事件被竄改成另一個故事（變創作而非詮釋），要
嘛變成貼在原文後面的學術評論。

> **關鍵分辨**（請務必讀完）：
>
> - **A 路線（本 skill）**：重寫**主敘述**——把「他終於完成了那份報告」改寫為「他完成了一份『報告』——這個詞、這個格式、這個收件人，每一樣都是別人替他先寫好的；他只是把自己的名字塞進已經存在的那個位置。」事件（完成報告）保留，意義被替代、被懷疑、被多版本化。 - **B 路線（嚴禁）**：原文不動，後面接「德希達會說⋯⋯」「傅柯指出⋯⋯」「依據後現代理論⋯⋯」這類論文式評論。這是後現代評論，不是後現代改寫。
>
> 本 skill 永遠走 A 路線。

## 流派選擇（最多兩派相容，不混血）

後現代不是單一立場，是一群有不同切入點的思想家。動筆前**選 1 個或最多
2 個相容流派**為主軸：

- **[L] Lyotard**——元敘事的終結 / 小敘事 / 知識合法化
- **[D] Derrida**——解構 / 二元對立 / différance（延異）/ 痕跡 / 補遺
- **[F] Foucault**——權力 / 知識 / 話語 / 規訓 / 全景敞視
- **[Bd] Baudrillard**——擬象 / 超真實 / 符號消費
- **[J] Jameson**——晚期資本主義 / 拼貼 / 平面化 / 歷史感消失
- **[B] Barthes**——作者之死 / 文本 vs 作品 / 神話學
- **[K] Kristeva**——互文性

**相容組合**（可同篇銜接）：

- **[D] + [B]**（法國解構血脈）——解構二元 + 作者之死
- **[F] + [J]**（權力批判 + 馬克思底色）——話語 / 規訓 + 晚期資本主義
- **[L] + [Bd]**（懷疑大故事 + 符號自我繁殖）——元敘事終結 + 擬象

**禁止混血**：5 個流派全用 = 失敗（讀來像關鍵詞拼盤，不是後現代）。
1 個主軸 + 至多 1 個相容副軸為極限。

## Step 2: Mark Up the Source — Find the Hidden Big Story

讀完原文後，找出**它默認在依靠哪一個更大的解釋**。這個解釋通常隱身、
不被質疑——正因為不被質疑，所以它是元敘事候選：

- 「這是一個關於成長的故事」（成長 = 進步元敘事）
- 「這個人終於釋懷」（釋懷 = 心理治癒元敘事）
- 「他選擇了正確的那一邊」（正/誤二元 = 道德元敘事）
- 「中國最有名的人」（最有名 = 共識可能元敘事）
- 「他下雨天淋濕回家很倒楣」（倒楣 = 「事情該如何」的常識元敘事）

同時標出三類點：

- **事件句**：誰做了什麼。**事實內容不可動**。
- **隱藏假設句**：作者預設你會同意的那些「當然」「應該」「畢竟」。
  這些是改寫主戰場。
- **可被質疑的位置**：誰在講？對誰講？為什麼這個版本被選上？被剪掉的
  是什麼？

## Step 3: Pick One Master Concept（最多兩個相容的）

從概念工具箱中**挑一個**作為這篇改寫的主軸。其他概念可以零星出現，但
必須有一個是貫穿全文的「鏡頭焦距」。

> **C-class Hard 條款（概念自然發生）**：概念須從事件自然長出，不可貼標籤式塞入，不可把工具箱的概念全部用上。一篇文章 1 個主軸 + 至多 1 個副概念為極限。

### 概念工具箱

每條後方標流派。括弧內為原文或標準術語。「自然使用範例」**不是學術定
義**，而是怎麼把概念**寫進敘事**而不是貼在敘事旁邊。

| 概念 | 派 | 一行解釋 | 自然使用範例（怎麼長進敘事裡） |
|---|---|---|---|
| **元敘事的終結 (the end of metanarratives)** | [L] | 拒絕宏大解釋（進步 / 革命 / 啟蒙），只剩彼此競爭的小敘事 | 「他被稱為那個世代最有名的人。但『最有名』需要一個我們都同意要怎麼數的方式——而那種數法早就沒人記得是誰說了算」（不要寫「這是元敘事的崩解」）|
| **小敘事 (petits récits)** | [L] | 局部的、彼此衝突的、不打算統一的敘述單位 | 「在他母親的版本裡，那是一場謊；在弟弟的版本裡，那是一個玩笑；在他自己晚年的版本裡，那是一個他不記得的下午」 |
| **作者之死 (the death of the author)** | [B] | 文本意義不被作者壟斷；意義在讀者那邊發生 | 「他寫下那行字的時候想的是 A。他姪女在三十年後讀到，讀成了 B。他不能跑進那一頁去糾正——而即使他可以，誰說他原來那個 A 才是對的？」 |
| **解構二元對立 (deconstruction of binary)** | [D] | 揭示二元對立中被壓抑的一方，與兩邊互相滲透 | 「他以為他在說真話，沒有說謊。但那個『真話』之所以是真話，是因為旁邊有一個被他壓下去、不能說的版本——少了那個沒被說的，這個說出來的就不再是『真』」 |
| **延異 (différance)** | [D] | 意義不在現場，總被推遲到下一個能指 | 「他每解釋一次自己為什麼來，都得引一個更早的理由；那個更早的理由又得引一個更更早的——他講到後來發現，沒有一個理由是不在引別的理由」 |
| **痕跡 / 補遺 (trace / supplement)** | [D] | 文本中總有未說盡的、被排除的、補上去之後反而動搖原本完整性的東西 | 「他寫的那封信非常完整。完整到有一個地方非得空著——那個空著的位置，是這封信能成立的條件，也是它隨時會塌掉的縫」 |
| **權力 / 話語 (power / discourse)** | [F] | 任何敘述都嵌在權力結構中；說什麼算合法、由誰決定，這本身是權力 | 「他在會議上講的每一句話都通過了。但他自己沒注意到：那個會議室從一開始就有一張看不見的清單——上面寫著哪些字可以說、哪些字一說出來就沒人聽。他講的全在清單上」 |
| **規訓 / 全景敞視 (discipline / panopticon)** | [F] | 不是被人盯著，是『可能被盯著』讓人自己先把自己擺正 | 「沒有人會看他打卡幾點。他自己每天提早八分鐘——那八分鐘是寫給沒有人的」 |
| **擬象 (simulacra)** | [Bd] | 符號優先於真實，最終變成沒有原本可指的拷貝 | 「他想像中那個『家』，是他從別人家的客廳、電影裡的廚房、廣告裡的早餐桌一片一片撿起來的。等他真的有了一個家，他發現他要做的，是把它布置成那個拼貼出來的版本」 |
| **超真實 (hyperreality)** | [Bd] | 真實本身被當成它的影像來生產，分不清原版 | 「她那場婚禮從第一張照片開始，就是替之後要被看見的版本走位。等照片真的傳出去之後，回憶裡那一天，已經是照片裡的那一天，不再是當天」 |
| **晚期資本主義文化邏輯 / 拼貼 / 平面化 (late capitalism / pastiche / depthlessness)** | [J] | 歷史感消失；所有風格都變成可被取用的素材，沒有原本，沒有深度 | 「他穿著像 1970 的襯衫、講著 1990 的笑話、用著當下的軟體——這三層之間沒有時間差，全部攤平在他週四下午的會議桌上，誰都不覺得奇怪」 |
| **戲仿 (pastiche)** | [J] | Jameson 用法：『中性的諷仿』——模仿一個風格但沒有原本可笑、沒有要批判 | 「那段公司願景他寫得字字真誠。但讀的人都知道——他知道，他們也知道，他知道他們知道——這些字本來就是給願景檔案用的字，誰寫都這樣寫」 |
| **互文 (intertextuality)** | [K] | 任何文本都是其他文本的織物；沒有單一起源 | 「他媽叫他去買紅糖那一幕——他後來想起時，發現自己想像那一幕的方式，混進了一齣他十五歲看的家庭劇、一段他祖母講過的話、還有一首他一直忘了名字的歌的副歌」 |
| **不可靠敘事者 (unreliable narrator)** | 文學 | 敘述者本身可疑——記憶、立場、誠實度都打折 | 「我說我那天淋濕走回家。我寫到這裡得停一下——我其實不確定那天有沒有真的下大雨。我只知道我寫過一次『那天下大雨』，後來我就只記得那個寫過的版本」 |

> **關於「元敘事懷疑」的學術根據**：本 skill 的「元敘事懷疑義務」對應的是 Lyotard 對 metanarrative 的「incredulity（不再相信）」、Barthes 對作者權威的解除、與 Foucault 對「誰有資格講」的話語分析——三者都認為：一個故事之所以聽起來自然，是因為一個更大的故事在替它擔保；本 skill 的改寫動作，就是把那層擔保攤開，讓敘述自己懷疑那層擔保。

## Step 4: Plan the Metanarrative Doubt Insertion（元敘事懷疑義務 — 靈魂條款）

選好主概念後，**至少挑一處**讓敘述自我懷疑——不是在文章後面寫一段反
省，而是讓主敘述本身內嵌一道裂縫。常見手法（擇一或混用，但不要全用）：

> **C-class Hard 條款（元敘事懷疑義務）**：不是加一句「但這也不一定」，而是把主敘述本身做出懷疑的形狀。

- **敘述者插話質疑自己**：「我寫到這裡得停一下——」「她說那是一場意外。但『意外』這個詞，是誰先把它放在這裡的？」
- **揭示文本內部矛盾**：兩個句子並列，後一句把前一句的前提抽掉
- **引入競爭版本**：同一個事件並陳兩到三種說法，不收束到哪個是「對的」
- **問「應該怎麼講這個故事」**：把敘述行動本身寫進敘述
- **把元敘事點名**：「這是一個關於進步的故事」——然後讓讀者察覺這個框架是後加的

懷疑插入至少 1 處，理想 1–3 處。多了會崩掉敘事，變成失控的後設。

> ❌ 「他終於釋懷了。但這也許只是一個敘事的方便。」（B 路線：評論貼旁邊）
>
> ✓ 「他終於釋懷了——如果『釋懷』這個說法成立的話。他的姪女後來跟人講起他的最後一年，從來沒用過這個詞；她說的是『他變得更安靜』。哪一個版本是真的？這件事不會再有第三個人來裁。」（A 路線：懷疑內嵌進敘述）

## Step 5: First Draft

寫一稿。原則：

- **事件骨架不動**：時間順序、誰做了什麼、結果如何，全部保留
- **隱藏假設句重寫**：把「他當然知道 X」「畢竟這是 Y」「他終於 Z」這
  類仰賴元敘事的句子，改寫成讓那個元敘事可見、可疑的版本
- **競爭版本插入**：在關鍵事件處插入 1–2 處「另一種說法」「在某某版
  本裡」「但也有人記得不是這樣」
- **敘述者克制的懷疑**：「我寫到這裡——」「這個詞是誰先說的——」
  類句式可用，但每篇 ≤2 處，過密則變搞笑
- **互文化用而非引用**：可以讓原文一個畫面突然「像是從別處來的」，
  不要寫「這令人想起德希達」
- **語氣**：清醒、克制、帶一點冷的好奇。**不亢奮、不戲謔、不嘲弄**
- **篇幅**：大致與原文相當或略長（+0–30%）。不要膨脹

## Step 6: Self-check Against Checklist

逐條對照下面的 22 條 checklist。**任一條 [Hard] 違反就回 Step 5 重寫該段**。

### Checklist: Core（核心三條 — 並列靈魂條款）

| 編號 | 強度 | 規則 |
|---|---|---|
| C-01 | Hard | **事件保留**——不可竄改敘事事實（誰做了什麼、結果如何、時間順序、人物關係）。只能重寫動機句、意義句、心理活動句、敘述者插話 |
| C-02 | Hard | **概念自然發生**——核心概念須從事件自然長出，不可貼標籤式塞入（不可寫「這就是元敘事的終結」）。**禁止全部概念出場**，1 個主軸 + 至多 1 個副概念為極限 |
| C-03 | Hard | **元敘事懷疑義務**——至少 1 處（理想 1–3 處）讓敘述自我懷疑：敘述者插話質疑、文本內部矛盾、競爭版本並陳、或把「應該怎麼講」本身寫進敘述。**不是加註，是改寫主敘述本身** |
| C-04 | Hard | **不寫成評論 / 學術論文 / 注釋**——禁止「德希達會說⋯⋯」「傅柯指出⋯⋯」「依據後現代理論⋯⋯」這類 cite 式句子。理論必須**內化**進敘述 |
| C-05 | Hard | **不嘲弄**——後現代懷疑不等於戲謔。不可寫「他這個可笑的傢伙以為⋯⋯」「這個天真的故事其實⋯⋯」 |

### Checklist: Structure（結構）

| 編號 | 強度 | 規則 |
|---|---|---|
| S-01 | Hard | 篇幅大致與原文相當，允許 ±30% 浮動。不可膨脹為論文 |
| S-02 | Hard | **保留原文段落骨架**——大段落順序與事件對齊，不可隨意重組時間軸 |
| S-03 | Soft | 元敘事懷疑插入位置：優先處理「終於 / 當然 / 畢竟 / 應該 / 最有名 / 真正」這類仰賴大共識的句子 |
| S-04 | Soft | 競爭版本最多 2 處——多了讓敘事散架 |
| S-05 | Soft | 文中文（嵌套敘事 / 信中信 / 夢中夢）至多 1 處——技巧太重會變賣弄 |
| S-06 | Hard | **不寫論文格式**——禁用「摘要 / 前言 / 結論 / 參考文獻」式結構；不分節標題化 |
| S-07 | Hard | **不加招牌標題**——禁止「後現代解讀：XXX」「德希達視角下的 XXX」這類 meta 標題 |

### Checklist: Vocabulary（詞彙）

| 編號 | 強度 | 規則 |
|---|---|---|
| V-01 | Hard | **概念詞自然嵌入**——用「版本」「替誰寫的」「沒人在那裡」「拼貼」「另一個說法」這類詞時，要當作敘述語言的一部分，不是引用術語 |
| V-02 | Soft | 5–10 個核心概念詞可在文中出現，但**不集中堆疊**（同一段不要超過 2 個概念詞）|

### Checklist: Mood（調性）

| 編號 | 強度 | 規則 |
|---|---|---|
| M-01 | Hard | **清醒**——後現代是一種審慎的距離感，不哀嘆、不驚呼、不替敘述蓋章 |
| M-02 | Hard | **不戲謔散文化**——後現代不是反智、不是亂寫、不是耍嘴皮。一旦讀起來像在搞笑，已經失敗 |
| M-03 | Hard | **不寫成宣言或運動聲明**——禁止「我們應當解構⋯⋯」「真理已經死了⋯⋯」「讓我們質疑⋯⋯」這類號召口吻 |
| M-04 | Hard | **不破第四面牆破得太徹底**——讓敘述懷疑自己 ≠ 讓敘述跳出來自我嘲笑。一旦敘述者對讀者眨眼，已經不是後現代是脫口秀 |
| M-05 | Soft | 結尾**不收線**——後現代不結束於「終於懂了」。最後一句允許懸而未決、允許還有別的講法、允許沒有最終版本 |

**總計**：22 條（Hard 16 + Soft 6）。

## Step 7: Verify the Three Core Clauses（核心三條複查）

寫完後**單獨再走一次這三條**——它們是這個 skill 的命脈：

1. **事件保留**：把改寫稿的事件順序列出來，逐一對照原文。任何被改動
   的事實（誰做了什麼、結果如何），都要回 Step 5 改回去。
2. **概念自然**：全文用了幾個概念？如果超過 3 個或跨了 2 個以上流派，
   刪掉最弱的。任何一處讀起來像「貼標籤」（可以替換成「這就是 X 概
   念」而不損失資訊），改寫該句直到它看起來像場景而不是學術注。
3. **元敘事懷疑義務**：有沒有至少一處讓敘述自我懷疑——而且是內嵌進
   主敘述、不是貼在旁邊的反省？如果只有「加註」沒有「內嵌懷疑」，回
   Step 4。

## Step 8: Punctuation & Spacing Cleanup

- 中文用全形標點（，。；：「」『』——⋯⋯）
- 數字與英文與中文之間留半形空格（視專案慣例）
- 破折號用「——」（兩字）而非「—」（一字）或「-」
- 刪節號用「⋯⋯」（兩個）而非「。。。」（三點）
- 引號優先「」，引號內用『』
- blockquote 內 CJK 段落單行不要硬換行——讓 markdown 自然處理

## Step 9: Read Aloud Check

朗讀整篇。三個自問：

- 讀起來像**敘述**還是像**論文**？（像論文 → 回 Step 5）
- 概念詞**長在事件裡**還是**貼在事件旁**？（貼旁邊 → 回 Step 5）
- 結尾**收線**了嗎？（收線了 → 改成懸而未決、留下「也可以那樣講」的
  餘韻）

## Forbidden in Output

寫完一稿、自檢之前先掃一眼這 7 條最容易踩的坑：

1. **招牌標題** ❌ —「後現代解讀：XXX」「德希達視角下的 XXX」「解構
   XXX」這類給文章貼大字標籤的標題，絕對禁止
2. **Cite 式句子** ❌ —「德希達會說」「傅柯指出」「依據後現代理論」
   「Lyotard 在 1979 年⋯⋯」這類引用句，屬於 B 路線
3. **概念全家桶** ❌ — 一篇文章把工具箱的概念都用一遍。1 個主軸 +
   至多 1 個副概念為極限
4. **論文格式** ❌ — 摘要 / 前言 / 結論 / 章節標題；分析摘要表；括號
   註釋
5. **戲謔散文化** ❌ — 把懷疑寫成笑話、把多版本寫成段子、寫到自己也
   覺得在玩。後現代不是反智
6. **宣言聲明** ❌ —「我們應當解構⋯⋯」「真理已死⋯⋯」「讓我們質疑
   ⋯⋯」這類號召口吻屬於運動文宣，不是這個 skill
7. **流派拼盤** ❌ — 同一篇裡 Derrida 詞、Foucault 詞、Baudrillard 詞、
   Lyotard 詞、Jameson 詞全撒一遍。讀者只會讀到關鍵詞列表，不是後現代

## Core Example: 程式碼的競爭版本

源文（現代軼事）：一名工程師接到三日交專案的死線，連夜加班寫出醜陋程
式碼，事後重構，最後產品被取消。下方為改寫成功的版本——事件全保留
（三日死線 / 醜陋程式 / 重構 / 產品取消），但動機句、敘述者插話全部換成
後現代的眼光。**主軸概念**：小敘事 / 競爭版本 [L]（同一段加班過程有三
種彼此不相容的講法）。**副概念**：不可靠敘事者（敘述者中途承認自己不
記得了）。整篇走 [L] 路線。

> 那個三日死線到的時候，他寫了三天程式碼。事後他講起這段，講了三個版本——他自己沒發現它們不能同時是真的。
>
> 在他跟太太講的版本裡，他是被迫的。公司急、時間短、再不交人會被換掉。所以他熬夜，所以那段程式那麼醜——醜是壓力的證據。
>
> 在他跟新來的同事講的版本裡，他是主動的。他知道那段程式碼會醜，他知道事後一定要重構，但他願意先把醜的版本生出來，因為「先有東西，比有完美的東西重要」。醜是判斷力的證據。
>
> 在他跟自己講的版本裡——這個版本他從來沒對任何人講——他是失常的。他在第二天凌晨某個時刻知道自己已經不在做正確的事，但他繼續打字，因為停下來就要面對停下來這件事本身。醜不是證據，醜是他那三天裡少數還記得的、確切發生過的事。
>
> 我寫到這裡得停一下。我用「他」寫這段，但這段是他自己後來告訴我的。他講的時候已經是事後第五年——他講的「凌晨某個時刻」，是他現在能講出口的版本。三天之內他真正想了什麼，沒有人去過那裡，連他自己也已經不能去了。
>
> 死線過了。產品上線了。那段醜陋的程式碼運作正常。然後他開始重構——花了比死線本身還久的時間，一行一行地把它擦掉。
>
> 在「壓力說」的版本裡，重構是補救。
>
> 在「判斷力說」的版本裡，重構是計畫的下一步。
>
> 在「失常說」的版本裡，重構是把那三天的痕跡擦掉，讓那三天可以被當作一段他能描述的時間。
>
> 重構到一半，產品被取消。
>
> 三個版本在這一刻同時失效，又同時得到一個新的結尾。在第一個版本裡，他白幹了。在第二個版本裡，他證明了「先做出來」的代價。在第三個版本裡，那段程式碼最終被擦掉了——不是被他擦掉，是被「整件事不存在」這件事擦掉的。
>
> 他關上電腦。隔天他照常上班。
>
> 我問他：所以那三天到底發生了什麼？他笑了一下，說：你選一個版本。我說我不選。他說：那你就什麼都沒問到。
>
> 這篇文章寫到這裡，它自己也不知道應該怎麼結束——因為它自己也在那三個版本之間，沒有選一個。

**達標複查**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 事件保留：三日死線、寫醜程式、重構、產品取消——全部對齊 |
| C-02 | ✓ | 主軸：小敘事（三個彼此不相容的版本）；副：不可靠敘事者（中段「我寫到這裡得停一下」）；總共 2 個概念，留在 [L] + 文學手法 |
| C-03 | ✓ | 元敘事懷疑至少 4 處：「我寫到這裡得停一下」、產品取消後三個版本同時失效、結尾「你選一個版本」「我不選」、最後一句承認文章自己也不知道怎麼結束 |
| C-04 | ✓ | 全文無 cite 式句子，無學派名稱出現 |
| C-05 | ✓ | 不嘲弄他的三個版本，只並陳 |
| S-01 | ✓ | 約 600 字，原文 60 字概要——但事件骨架對齊 |
| S-06 | ✓ | 無摘要 / 結論 / 標題 |
| S-07 | ✓ | 無「後現代解讀」式招牌標題 |

| V-03 | ✓ | 無「德希達認為」「Lyotard 指出」 |
| V-05 | ✓ | 流派純度：[L] + 不可靠敘事者，無 Foucault 詞、無 Baudrillard 詞、無 Derrida 詞 |
| M-01 | ✓ | 清醒：不哀嘆，不替他蓋章哪個版本是真的 |
| M-04 | ✓ | 第四面牆：敘述者插話有，但沒有跳出來對讀者眨眼搞笑 |
| M-05 | ✓ | 結尾不收線：「它自己也不知道應該怎麼結束」 |

**對照結論**：後現代改寫不是把故事翻譯成術語，而是**讓故事的內部敘述
自己變得多版本、可疑、未完成**——「你選一個版本。我說我不選。」這一
句把整個事件從「他壓力大下加班失敗」重新組織為「沒有一個版本能單獨講
完這件事」。事件沒有變，意義被多版本化了。

## Scope Boundary

| 想做的事 | 用哪個 skill |
|---|---|
| 把文章用後現代的眼光重寫敘事（本 skill）| **postmodern-lens** |
| 寫一篇後現代論文式的評論 | （不在本 skill 範圍 — 那是 B 路線）|
| 翻譯後現代經典文本 | （不在本 skill 範圍）|

如果使用者要的是**論文式分析**或**對作者下後現代診斷**，告訴使用者本
skill 的目標是**重寫敘事**而非**寫評論**，並請對方確認是否仍要繼續。

## Important Notes

- 本 skill 是**詮釋框架轉換工具**，不是「給文章加後現代術語」工具。
  事件骨架必須完整保留，只重組意義
- **元敘事懷疑是靈魂**：沒有至少一處讓敘述自我懷疑、讓「應該怎麼講」
  本身被攤開，就不是這個 skill 的成品。加註不算
- **克制 > 說滿**：概念用得少而準，比用得多而散更接近本 skill 精神。
  一個好的後現代改寫，讀者不會覺得「這篇在後現代」，而會覺得「這篇文
  章自己在懷疑自己能不能被講清楚」
- **不嘲弄 / 不戲謔**：後現代懷疑是一種審慎，不是嘲笑。任何對人物、
  對事件、對讀者的調侃口吻都背叛這個 skill
- **不收線**：後現代不結束於「終於懂了」。結尾允許懸而未決、允許還
  有別的講法、允許沒有最終版本——事實上理想結尾就該如此
- **不刻意賣弄學術詞彙**：概念要長進敘事不要堆疊。讀者該感受到的不是
  「這個作者讀過 Derrida」，而是「這篇文章不一樣了」
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
