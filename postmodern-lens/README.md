# Postmodern-lens — 用後現代的眼光重寫敘事

把一篇文章改寫成「**它自己用後現代的眼光看自己**」的版本。事件保留，
意義重組——而且重組之後，這個故事不再相信只有一個講法。

## 這是一個 lens skill，不是 style skill

Lens skill 不主動改變表面語言（句法 / 詞彙 / 節奏），而是改變**詮釋
框架**：同一個事件，被重新敘述為一個「它自己也不確定該怎麼被講」的
事件。

| 維度 | style skill | lens skill（本 skill）|
|---|---|---|
| 改變什麼 | 語言表面（句法 / 詞彙 / 節奏）| 詮釋框架（敘述者立場 / 大故事 / 多版本）|
| 事件可動 | 視 skill 而定 | **絕不可動** |
| 失敗模式 | 詞彙堆砌、體裁 caricature | 變成論文式評論貼在原文後 |

## 一句話定位

讓文章的**內部敘述本身**變成後現代的——它自己懷疑「應該怎麼講這個
故事」、它自己並陳幾個彼此不相容的版本、它自己讓讀者察覺敘述者也是
一個被選出來的位置——而不是在文章後面接一篇後現代理論評論。

## 何時使用

- 想看一篇文章被「後現代的耳朵」聽完之後的樣子
- 想把一個看似自然的敘述，攤開它底下默認的那個大故事
- 想讓同一個事件並陳幾個不相容的版本、讓敘述者承認自己也記不清
- 想用元敘事終結、解構、權力 / 話語、擬象、互文⋯⋯這些概念自然嵌入
  敘事
- 想保留原文事件骨架，但改寫文章對自己的詮釋

## 不適用

- 想要一篇後現代論文式的評論（本 skill 嚴禁這條路線）
- 想要對作者本人下後現代診斷
- 想要翻譯後現代經典文本
- 純技術文件、無人物無動機的說明文字

## 三條核心條款

1. **事件保留** — 不可竄改敘事事實。只能重寫動機句、意義句、心理活動
   句、敘述者插話
2. **概念自然發生** — 概念須從事件自然長出，不可貼標籤式塞入。一篇
   文章 1 個主軸 + 至多 1 個副概念為極限；不要 5 個流派全撒
3. **元敘事懷疑義務** — 至少 1 處讓敘述自我懷疑：敘述者插話質疑、競
   爭版本並陳、把「應該怎麼講」本身寫進敘述（是改寫主敘述，不是加註）

## 流派選擇（最多兩派相容，不混血）

動筆前選 1 個或最多 2 個相容流派為主軸：

- **[L] Lyotard**——元敘事的終結 / 小敘事
- **[D] Derrida**——解構 / 二元對立 / différance / 痕跡 / 補遺
- **[F] Foucault**——權力 / 話語 / 規訓 / 全景敞視
- **[Bd] Baudrillard**——擬象 / 超真實
- **[J] Jameson**——晚期資本主義 / 拼貼 / 平面化
- **[B] Barthes**——作者之死 / 文本 vs 作品
- **[K] Kristeva**——互文性

**相容組合**：

- **[D] + [B]**（法國解構血脈）
- **[F] + [J]**（權力批判 + 馬克思底色）
- **[L] + [Bd]**（懷疑大故事 + 符號自我繁殖）

5 個流派全用 = 失敗。

## 安裝

```bash
git clone --depth 1 https://github.com/tzengyuxio/skills.git /tmp/tz-skills \
  && mkdir -p ~/.claude/skills \
  && cp -r /tmp/tz-skills/postmodern-lens ~/.claude/skills/ \
  && rm -rf /tmp/tz-skills
```

或手動安裝：

```bash
cp -r postmodern-lens ~/.claude/skills/postmodern-lens
```

## 使用方式

```
/postmodern-lens path/to/article.md
```

也可以直接貼一段文字進來，或剛寫完一份文件後無參數呼叫。

**觸發詞**：`/postmodern-lens`、「後現代重寫」「用後現代改寫」
「postmodern rewrite」「解構視角」「解構式改寫」「元敘事懷疑」「不可
靠敘事」「戲仿」「互文」「Derrida 風格」「Foucault 視角」「Lyotard 視
角」「Baudrillard 改寫」「Jameson 改寫」「作者之死」
