# yizhi-style — 改寫成中文譯製腔(1950–90s 上譯/長譯配音語體)

把任何文章改寫成上海電影譯製廠、長春電影製片廠等老牌譯製機構 1950–
1990 年代為外國電影做中文配音時形成的那種獨特語體——字正腔圓的舞台
腔、歐化的長句、誇張的賭咒與肢體比喻、永遠在用全形破折號頓挫的節
奏。讀完讓人想起《簡愛》裡那一聲「我親愛的——你以為我貧窮——卑微
——不美——我就沒有靈魂沒有心嗎？」,或是《虎口脫險》裡那一句「我
要長刷子——不要扁刷子！」,或是知乎戲仿樓裡那一段「嘿，我親愛的老
夥計，看在上帝的份上——你究竟為什麼不肯告訴我真相？」

風格參照：**上海電影譯製廠**(1957 成立)、**長春電影製片廠**、北影
廠等中國老牌譯製機構 1950–90 年代的配音譯製傳統。代表片：《魂斷藍
橋》(1950s 上譯)、《王子復仇記》(1958 上譯)、《簡愛》(1975 上
譯)、《佐羅》(1978 上譯)、《追捕》(1978 上譯)、《葉塞尼亞》
(1977 上譯)、《尼羅河上的慘案》(1978 上譯)、《音樂之聲》(1980s
上譯)、《虎口脫險》(1982 上譯)、《茜茜公主》(1988 上譯)、《瓦
爾特保衛薩拉熱窩》(1973 北影廠)等。

## 一句話靈魂

**呼語起手 + 賭咒嘆詞 + 歐化句式 + 全形破折號**——四元素至少三項
出現於每段；字正腔圓不縮略、不省略主語、不省略代詞；字面直譯英美俚
語比喻(靴子/兔子/祖父鬍子);世界觀走西洋通名；翻譯腔是 feature,
不是 bug。

> **重要定位(必讀)**:
>
> 1. **集體語體致敬，非個人音色模仿**——本 skill 改寫的是上譯/長譯
>    /北影廠這群配音演員與譯者**共同沉澱出的書面語體**(共同句式、
>    共同套語、共同稱謂體系),**不模仿**邱岳峰、童自榮、畢克、喬榛、
>    丁建華、蘇秀、尚華、于鼎等具體配音家的**個人音色與標誌性發音**。
>    文案/示範中**禁出現**「像邱岳峰那樣⋯⋯」「童自榮式的⋯⋯」此類個
>    人化指涉。
>
> 2. **中譯西洋的雙重位移**——譯製腔本質是「中譯西洋」,世界觀層
>    **必走西洋通名**:**先生/閣下/夫人/小姐/上校/神父**、**教堂
>    /酒館/旅館/公爵領地/鄉間別莊**、**煤氣燈/馬車/懷錶/菸斗
>    /長禮服/燭台**。**禁中華具體專名**:衙門/縣令/廟祝/朝廷敕令
>    /嘉興/湖廣/銀子/銀針/錦衣衛/客棧/相公/姑娘/官人。若源文是
>    中華情境，須做**雙重位移**——把場景、物件、稱謂、官制一起搬到
>    1850–1950 的西洋世界，不可只換語氣留著中華骨架。
>
> 3. **政治避雷**——譯製片大量出自冷戰時期(美/蘇/南斯拉夫/阿爾巴
>    尼亞/北韓等),風格本身中性，但**禁引用涉及意識形態對立的台
>    詞**(批美帝、歌頌革命、煽動階級鬥爭等);選愛情、偵探、喜劇、
>    書信獨白等中性場景作為改寫目標。
>
> 4. **避免文革時代悲劇輕慢化**——邱岳峰 1980 自殺事件帶有時代悲
>    劇色彩，**不宜輕慢化**;**禁**寫成「某某配音家自殺後⋯⋯」式
>    引用。

## 參照樣本(譯製片真實台詞短引)

完整參照清單見 [`references/source-passages.md`](./references/source-passages.md)。
此處摘三段示意：

**《追捕》(1978, 上譯) 詩意誘導獨白**:

> 杜丘，你看，多麼藍的天哪⋯⋯
> 走過去——
> 你就會融化在那藍天裡。
> 一直走，不要朝兩邊看。

**《尼羅河上的慘案》(1978, 上譯) 演繹詠嘆**:

> 小姐，我看見一個女人雙眼下的黑眼圈。
> 我看見那隻緊緊握著陽傘的手——
> 看到它的指關節，都變白了⋯⋯
> 哦，愛情啊，它是這樣的一種東西，它讓人變得盲目，讓人變得愚蠢，
> 讓一個聰明的姑娘，做出最愚蠢的決定。

**《簡愛》(1975, 上譯) 呼語+三重遞進**:

> 我的朋友——
> 你是不是以為，因為我貧窮，因為我卑微，因為我不美，
> 我就沒有靈魂，沒有心嗎？

特徵分析：

- **呼語起手**:「杜丘」「小姐」「我的朋友」等稱呼前置，常與全形破折號連用
- **歐化句式**:「它是這樣的一種東西」「在我的整個生命裡」「同樣完整地擁
  有著」
- **反覆強調**:「讓人變得盲目，讓人變得愚蠢」「因為我貧窮，因為我卑微，
  因為我不美」三疊遞進
- **全形破折號 + 省略號**:停頓、頓挫、餘韻
- **字正腔圓不縮略**:「我從未」「我不會」「我發誓」不寫成「我才不」
  「我哪會」這類口語縮略

## Step 2: 決定強度檔位 + 風格錨點

譯製腔有兩種使用情境：**作為認真的譯製文體**(模擬真實譯製片台詞)
或**作為網路迷因**(老夥計+靴子+祖父鬍子三件套堆滿的戲仿)。**兩
檔擇一，不可混**。

### 強度檔位對照

| 強度 | 風格錨點 | 代表片 | 用法 |
|---|---|---|---|
| **正典** | 莊重抒情、輕快喜劇、童話、偵探 | 《簡愛》/《尼羅河》/《虎口脫險》/《佐羅》/《茜茜公主》/《魂斷藍橋》/《追捕》/《葉塞尼亞》 | 呼語起手 + 歐化句式 + 全形破折號為主軸；賭咒嘆詞自然分佈不堆砌；誇張比喻可有可無 |
| **戲仿** | 知乎/B 站/微博翻譯腔迷因 | 〈如何模仿翻譯腔〉樓的經典樓中樓 | 「哦，我親愛的老夥計」「看在上帝的份上」「用我的靴子狠狠地踢你的屁股」「以我祖父的鬍子發誓」三件套必滿；誇張比喻 ≥ 2 處 |

### 怎麼挑

- 源文是抒情、敘事、童話、書信、偵探推理 → **正典**
- 源文是日常瑣事、爆笑梗、戲謔對話、想刻意搞笑 → **戲仿**
- 不確定就走**正典**——譯製腔的靈魂在莊重的舞台腔，戲仿是其衍生

選定後在內心或筆記中標注 `[正典]` 或 `[戲仿]`,後續每一步都以此檔
位的密度為準。

## Step 2.5: 時代分期 + 類型子檔位(正典檔細化)

譯製腔在 1950–90 年代並非一片均質，可細分四個時代分期 + 五種類型片
譯製腔。**正典檔可進一步選定一個次風格錨點**,讓輸出不會所有正典都
長得一樣。**戲仿檔不需選次風格**(戲仿的是 1980s 上譯腔的集體迷因)。

### 時代分期錨點(正典檔)

| 時代 | 風格特徵 | 代表片 |
|---|---|---|
| **1950s 草創期(莎劇朗誦腔)** | 比後期更「話劇」、更「朗誦」、更「正統」;音色拖腔長；偏「莎劇/俄文學腔」(陳叙一要求譯者讀莎劇/聖經/唐詩) | 《魂斷藍橋》(50s)、《王子復仇記》(1958) |
| **1970s 黃金期(抒情華麗腔)** | 抒情華麗、舞台朗誦感、全形破折號頓挫密集 | 《簡愛》(1975)、《佐羅》(1978)、《追捕》(1978)、《葉塞尼亞》(1977)、《尼羅河上的慘案》(1978) |
| **1980s 喜劇/成熟期** | 急促語速、誇張嘆詞密度更高、押韻或好笑、人物口頭禪反覆 | 《虎口脫險》(1982)、《加里森敢死隊》(把「長官」譯作「頭兒」) |
| **1980s 童話/動畫腔** | 少女明亮腔、童聲抒情、押韻接念白 | 《茜茜公主》(1988)、《音樂之聲》(1980s) |

### 類型片子檔位(正典檔可選)

| 類型 | 子檔位特徵 |
|---|---|
| **悲劇/正劇** | 拖腔長、反覆強調、三疊遞進、破折號密集、全形省略號餘韻；呼語以「我親愛的⋯⋯」為主 |
| **抒情詠嘆** | 詩意誘導獨白、自然意象(藍天/海/雲)、第二人稱呼喚 |
| **偵探/推理** | **演繹詠嘆**「我看見」「我注意到」「您發現了嗎」≥ 2 處、稱謂「小姐」「夫人」「先生」「上校」、推理層次的句式 |
| **喜劇** | 急促語速、音色對比、誇張嘆詞密度 ≥ 5 處、翻譯詞押韻(「長刷子—扁刷子」)、人物口頭禪反覆 |
| **童話/動畫** | 少女明亮腔、唱腔接念白、稱謂「公主」「殿下」「親愛的孩子」 |

選定後在內心或筆記中標注時代+類型(例：`[正典-1970s-悲劇]` 或
`[正典-1980s-喜劇]`),後續密度配合此次風格。**不選也合格**(走通
用正典),但選定可避免風格扁平。

## Step 3: 中譯西洋雙重位移檢查

譯製腔的世界觀**必為西洋**(主要為 19 世紀中至 20 世紀中的歐美/部
分日本)。讀完原文後逐項自答：

1. 原文是否出現中華具體專名？(衙門、縣令、廟祝、朝廷、嘉興、湖廣、
   銀子、銀針、錦衣衛、客棧、相公、姑娘、官人、書院、衙役⋯⋯)
2. 原文是否出現中華具體物件？(算盤、宣紙、毛筆、銅錢、玉佩、繡花
   鞋、唐裝、長衫、龍袍⋯⋯)
3. 原文是否出現中華具體地名？(嘉興、揚州、湖廣、汴梁、長安⋯⋯)
4. 原文是否出現中華節氣/節日具體名？(清明、端午、中秋、重陽⋯⋯)

**任一條為「是」**,須做以下位移對照：

| 中華 | 西洋對等物 |
|---|---|
| 縣令/官 | 治安官/地方法官 / Magistrate |
| 衙門 | 蘇格蘭場/警察局 / 治安署 |
| 廟祝/和尚 | 教區牧師/神父 |
| 朝廷敕令 | 公爵/王室詔書/議會公文 |
| 嘉興/湖廣 | 約克郡/薩塞克斯郡/普羅旺斯 |
| 銀子/銀錢 | 英鎊/先令/法郎 |
| 客棧 | 旅館/驛站(coaching inn) |
| 算盤 | 賬本/銅鑲框眼鏡 |
| 銀針 | 銀燭台/銀餐刀 |
| 相公/官人 | 先生 / Mr. / 閣下 |
| 姑娘 | 小姐 / Miss / 女士 |
| 紙傘 | 油紙傘(蘇格蘭場場景可)/絹傘 |

**注意**:雙重位移不只是把名詞替換，而是**把場景、物件、人物關係、
社會制度一起搬到 1850–1950 的西洋世界**。例如「縣令昨日傳喚張三」
須位移為「治安官昨日傳喚史密斯先生」,張三 → Smith / Mr. Whitmore /
Lord Pemberton 等具體西洋名字。

若源文本就是西洋情境，Step 3 可跳過，直接進 Step 4。

## Step 4: 改寫核心(呼語 + 賭咒 + 歐化 + 物件詞)

譯製腔的四大支柱，逐項落實：

### 4.1 呼語起手式(每段第一/二句必出 ≥ 1)

| 類別 | 樣式 | 範例 |
|---|---|---|
| 親密呼語 | 哦，我親愛的⋯⋯ / 我的朋友 / 我親愛的朋友 | 哦，我親愛的老夥計—— |
| 正式稱謂 | 先生 / 閣下 / 夫人 / 小姐 / 女士 / 上校 / 將軍 / 神父 | 福爾摩斯先生，我懇求您—— |
| 弱勢/下屬 | 我的孩子 / 小傢伙 / 可憐的小傢伙 | 我的孩子，別害怕—— |
| 複數招呼 | 老兄/夥計們 | 夥計們，聽我說—— |
| 嘆息式起手 | 哦，⋯⋯ / 啊，⋯⋯ / 噢，⋯⋯ | 哦，我的天哪，這真是—— |

**典型結構**:**語氣詞 + 形容詞 + 稱謂** 連環疊加(「哦，我親愛的
老夥計」「嘿，你這個可憐的小傢伙」)。

### 4.2 賭咒嘆詞密度(全篇 ≥ 3)

| 類別 | 樣式 |
|---|---|
| 上帝類 | 哦，我的上帝 / 我的天哪 / 上帝啊 / 看在上帝的份上 / 老天爺 |
| 詛咒類 | 該死的 / 見鬼 / 真是見鬼 / 見鬼的(東西) |
| 發誓類 | 我發誓 / 我向上帝發誓 / 我敢打賭 / 我敢說 |
| 否定驚呼 | 哦，不！ / 不，這不可能 |
| 戲仿類(限戲仿檔)| 以我祖父的鬍子起誓 / 以我祖母的烤箱發誓 / 以我母親的名義 |

### 4.3 歐化句式(全篇 ≥ 3 處)

| 樣式 | 範例 |
|---|---|
| 後置原因子句 | 我不能去——你知道的——因為我的母親病了 |
| 不僅⋯⋯而且⋯⋯ | 你不僅遲到了，而且還忘了帶禮物 |
| 為什麼我們不⋯⋯呢？ | 為什麼我們不坐下來喝杯咖啡呢？ |
| 被某種莫名的⋯⋯所支配著 | 他被一種莫名的恐懼所支配著 |
| 這真是⋯⋯的一件事 | 這真是令人不快的一件事 |
| 它是這樣的一種東西 | 愛情啊，它是這樣的一種東西⋯⋯ |
| 在我的整個生命裡 | 在我的整個生命裡，只有過你一個 |

### 4.4 物件詞密度(全篇 ≥ 3 處)

西洋具體物件，**至少 3 種**散佈全篇：

- **室內**:壁爐、煤氣燈、燭台、油畫、瓷器、銀餐具、地毯、扶手椅
- **隨身**:懷錶、菸斗、雪茄、長禮服、長靴、手套、披風、禮帽、絲質
  領巾
- **戶外**:馬車、雙輪馬車、煤氣街燈、教堂塔樓、酒館招牌、石板路
- **儀器**:放大鏡、望遠鏡、羅盤、地圖、信件、電報
- **食物**:白蘭地、雪利酒、紅茶、牛排、麵包、烤火雞

**禁中華具體物件**:見 Step 3 對照表。

### 4.5 西洋語料密度(全篇 ≥ 3 類覆蓋)

物件詞之外，以下四類「**西洋日常語料**」也是譯製腔的辨識基底，**至
少其中 3 類各出現 ≥ 1 處**:

| 類別 | 詞庫 |
|---|---|
| **度量衡/貨幣** | 英鎊/先令/便士/克朗/法郎/盧布/英尺/英寸/英里/碼/磅/盎司/品脫/加侖/一打 |
| **食物/飲料** | 烤火雞/烤牛肉/羊腿/火腿/培根/香腸/麵包/司康/紅茶/下午茶/咖啡/白蘭地/雪利酒/波特酒/波爾多紅葡萄酒/香檳/威士忌 |
| **親屬稱謂** | 親愛的母親/親愛的父親/我的姑媽/我的叔父/我的伯父/我的表哥/堂哥/我的教父/教母(注：**比中華稱謂多一層「我的⋯⋯」(my dear...)**)|
| **罵人話/詛咒** | 該死的笨蛋/你這個老糊塗/狗東西/畜生/笨蛋/蠢貨/惡棍/騙子/無賴 |
| **道別/問候** | 早上好，先生/下午好，夫人/晚上好，女士們先生們/祝你晚安/再見，我的孩子/願上帝保佑你/一路平安/保重，我的朋友/告辭了，先生 |

**典型搭配場景**:
- 「**值五十英鎊**」「**走了一英里多**」「**一打雞蛋**」
- 「**用過早餐了嗎？**」「**請喝杯茶吧**」「**為我們的健康乾杯**」
- 「**我親愛的姑媽**」「**我的叔父**」(中華稱謂前必加「我的⋯⋯」式所有格)
- 「**該死的笨蛋！**」「**你這個老糊塗！**」「**我要把你的腦袋擰下來！**」

## Step 5: 加入指紋元素(破折號/反覆/三層遞進/誇張比喻)

譯製腔的辨識度來自這些次級指紋：

### 5.1 全形破折號 —— (≥ 2 處)

破折號表停頓、頓挫、心理猶疑、追加說明：

- 「哦——!我的上帝——!」
- 「我不能去——你知道的——」
- 「我親愛的朋友——這是真的——我發誓」

**規格**:全形 `——`(U+2014×2 連用),不用 `--`,不用單個 `—`,不
用 `-`。

### 5.2 全形省略號 ⋯⋯ 或 …… (≥ 1 處)

表餘韻、欲言又止、回憶綿長：

- 「在那一年的夏天⋯⋯我永遠記得⋯⋯」
- 「他走了⋯⋯一個人⋯⋯」

**規格**:全形 `⋯⋯`(U+22EF×2)或 `……`(U+2026×2),不用 `...`,
不用 `…`(單個)。

### 5.3 反覆強調(≥ 1 處)

譯製腔的舞台戲劇性來自反覆：

- 「我從未愛過任何人⋯⋯我從未⋯⋯」
- 「我發誓⋯⋯我向上帝發誓⋯⋯」
- 「走過去⋯⋯就是這樣⋯⋯走過去⋯⋯」

### 5.4 三層遞進句式(Soft, 建議出現)

「因為⋯⋯,因為⋯⋯,因為⋯⋯」三疊式；
「讓人⋯⋯,讓人⋯⋯,讓人⋯⋯」三疊式；
「每一棵樹、每一朵花、每一片草」式並列。

### 5.5 字面直譯誇張比喻(正典 ≥ 1 處，戲仿 ≥ 2 處)

| 樣式 | 範例 |
|---|---|
| 靴子類 | 我要用我的靴子，狠狠地踢你的屁股 |
| 動物比喻類 | 像隻被剝皮的兔子 / 乾癟得像一隻聖誕節的火雞 |
| 誇張誓言類 | 以我祖父的鬍子起誓 / 以我母親的名義 |
| 地獄類 | 願上帝讓他的靈魂在地獄裡烤上一千年 |
| 揍人類 | 我會把你揍得連你母親都認不出來 |

**戲仿檔**:這類比喻是 signature,堆滿才有迷因感。
**正典檔**:這類比喻收斂，出 1 處點到為止即可，過多會破壞莊重感。

### 5.6 多層定語(的的不休，Soft)

中文歐化的標誌之一：「那個穿著破舊大衣的可憐的年輕的人」、「站在門
口那個臉上掛著奇怪笑容的男人」。這種句子讀來吃力，但譯製腔保留它作
為翻譯腔指紋。

### 5.7 代詞氾濫

中文不必出現的「我/你/他/她/它/我們/你們/他們」,**一個不漏
地譯出**:

- 「他把他的手伸進他的口袋，拿出他的懷錶，看了它一眼」
- 「我感覺到我的心，正在我的胸膛裡，劇烈地跳動著」

### 5.8 副詞綴化(Soft)

「完整地擁有」「狠狠地踢」「深深地嘆息」「莫名地恐懼」——「⋯⋯地」
副詞綴化密度，每段 ≥ 1 處為佳。

## Step 6: 強度檢核

把寫好的稿子讀一遍，默念出來，自問：

1. **它像不像譯製片配音**?——閉上眼睛聽，能不能想像一位字正腔圓、
   舞台腔濃厚的配音演員在念這段台詞？如果讀起來像新聞播報、像論文、
   像 medium 文章，就破功
2. **強度檔位是否一致**?——正典檔不該堆滿「以我祖父的鬍子發誓」這
   種戲仿三件套；戲仿檔不該寫得太莊重抒情。檔位混了就破功
3. **指紋元素是否齊備**?——呼語、賭咒、歐化句式、破折號四元素至少
   出現三項；誇張比喻、反覆、三層遞進至少出現一項
4. **世界觀是否西洋**?——再掃一次有沒有殘留的中華專名/物件/地名
5. **是否模仿了具體配音演員**?——如果寫了「邱岳峰式的⋯⋯」「童自榮
   那種⋯⋯」,刪除

## Step 7: 標點清理 + 自檢指令

最後一道工序——標點清理：

| 半形(禁) | 全形(用) | Unicode |
|---|---|---|
| `,` | `,` | U+FF0C |
| `;` | `;` | U+FF1B |
| `:` | `:` | U+FF1A |
| `?` | `?` | U+FF1F |
| `!` | `!` | U+FF01 |
| `--` 或 `—` | `——` 全形破折號 | U+2014 × 2 |
| `...` 或 `…` | `⋯⋯` 或 `……` | U+22EF×2 / U+2026×2 |
| `"` `'` | 「」/『』 | U+300C/D, U+300E/F |
| `.` | 。 | U+3002 |

**寫完後必跑自檢指令**(指令名留作機械驗證，不可省略):

```bash
python3 -c "
import re, sys
text = open(sys.argv[1]).read()
# CJK 字後接半形 ,;:?! 一律違規(含行尾、引號前、段末等情境)
bad = re.findall(r'[一-鿿㐀-䶿][,;:?!]', text)
print(f'half-width punct after CJK: {len(bad)}')
for b in bad[:5]: print(repr(b))
" 輸出檔.md
```

結果必須為 `0`。本 skill 輸出為純 CJK 語體(無 PTT 推文暱稱式 ASCII
邊界例外),故採**單側 lookbehind 嚴格規則**——CJK 字後接半形
`,;:?!` 一律違規，不論後續是 CJK、空白、引號或行尾。非 0 表示輸出時
混入了 ASCII 半形，回到輸出檔逐字替換後重跑，直到歸零才算交付。

## Anti-patterns(常見失敗模式)

寫完一稿、自檢之前，先掃一眼這 10 條最容易踩的坑：

1. **點名具體配音演員** — 寫了「邱岳峰式的疲憊嗓」「童自榮般華麗
   的⋯⋯」「畢克那種冷峻」。本 skill 是集體語體致敬，不是配音家個人
   仿擬(違反 M-02)
2. **中華骨架殘留** — 寫了「縣令傳喚張三」「銀針探毒」「廟祝點頭」。
   譯製腔的世界觀**必為西洋**;源文是中華情境的話**整套位移**(違反
   M-01)
3. **正典/戲仿檔位混淆** — 想寫莊重的《簡愛》風，卻冒出「以我祖父
   的鬍子發誓」;想寫戲仿迷因，卻寫得抒情典雅。Step 2 已定就鎖死
   (違反 V-07)
4. **沒有呼語起手** — 全文沒有「哦，我親愛的⋯⋯」「先生」「閣下」
   一聲呼喚，讀起來就不是譯製腔(違反 C-01)
5. **沒有破折號 / 用 `--` 替代** — 譯製腔的舞台節奏建立在全形 `——`
   上，寫 `--` 或單個 `—` 一律違規(違反 S-02)
6. **沒有歐化句式** — 全篇都是漂亮的中文短句，讀起來像古龍體不像
   譯製片。要刻意保留「不僅⋯⋯而且⋯⋯」「為什麼我們不⋯⋯呢？」這
   類歐化(違反 V-01)
7. **字正腔圓被打破** — 把「我從未」寫成「我哪有」、把「我發誓」
   寫成「真的啦」。譯製腔不縮略，不省略主語(違反 V-05)
8. **半形標點混入內文 CJK 字之間** — 輸出時把 `,;:?!` 打成 ASCII
   半形而非全形 `,;:?!`。Step 7 自檢指令計數須歸零(違反 S-01、
   M-05)
9. **引政治台詞** — 寫了批美帝、歌革命、煽動階級鬥爭的台詞。譯製
   片背景跨意識形態陣營，風格本身中性，**內容須避意識形態對立**
   (違反 M-03)
10. **後設解說自我吹捧** — 改完之後寫「這就是上譯廠的精髓」「我用
    了字正腔圓的舞台腔來⋯⋯」。譯製腔的力量在於沉浸，後設解說即破
    功(違反 M-04)
11. **現代網路語混入** — 寫了「絕了」「emo」「破防」「下頭」「擺
    爛」「絕絕子」「YYDS」「內卷」「躺平」等 2015 後網路用語。譯製
    腔的時代鎖在 1950–90s,**戲仿檔也禁**(因為戲仿的是 1980s 上譯
    腔本身，不是 2020s 抖音梗)
12. **缺西洋日常語料** — 全篇只有物件詞，沒有度量衡(英鎊/英里)、
    沒有食物飲料(下午茶/雪利酒)、沒有西式罵人話(該死的笨蛋)、
    沒有道別問候(祝你晚安/早上好先生);失去西洋生活質感(違反
    C-05)

**地區範圍說明**:本 skill **專注大陸上譯/長譯/北影傳統**,**不涵
蓋**:

- **台灣國語配音**(老三台 1960–80s 卡通中配如《七龍珠》《北斗神
  拳》、本土在地化《我們這一家》《烏龍派出所》《蠟筆小新》);這條
  線走向「梗化、本土化、台語混用」,與大陸譯製腔分道揚鑣
- **香港 TVB 粵語配音**(《阿信》《東京愛情故事》《美少女戰士》粵
  配);粵語譯製腔有自身特徵(「咁啦呢」語氣詞 + 書面化「之也卻」)
- **2000 年後字幕翻譯腔**(字幕組「神翻譯」「接地氣」「網路語」);
  本 skill 模仿的是**配音譯製腔**,不是字幕譯製腔
- **動畫譯製腔**(1990s 後迪士尼動畫中配);具有童聲/唱腔/押韻特徵，
  本 skill 雖有「童話腔」子檔但聚焦上譯廠真人電影傳統

如果使用者要的是**真實譯製片台詞檢索**、**模仿某位配音演員的個人音
色**、**冷戰意識形態台詞致敬**,告訴使用者本 skill 是**集體語體致
敬**而非真實譯製片內容，且**禁模仿配音演員個人特徵、禁引政治台
詞**——不適合這三種需求。

## Important Notes

- 本 skill 是**集體語體致敬工具**,不是「配音演員仿擬」也不是「政治
  台詞生成器」。原文的核心張力必須被保留，以譯製腔的舞台戲劇腔重新
  承載
- **雙重位移是鐵律**——源文若為中華情境，世界觀層必整套移為 1850–
  1950 西洋世界，不可只換語氣留中華骨架
- **強度檔位 Step 2 就鎖死**——正典/戲仿兩檔擇一，後續每一步都以
  此檔位密度為準；混檔即破功
- **指紋四元素至少三項出現於每段**——呼語起手、賭咒嘆詞、歐化句式、
  全形破折號
- **字正腔圓不縮略**——譯製腔的舞台腔來自不省略主語/代詞、不寫口
  語縮略式
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
