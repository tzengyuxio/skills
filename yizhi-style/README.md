# yizhi-style — 改寫成中文譯製腔(1950–90s 上譯/長譯配音語體)

把任何文章改寫成上海電影譯製廠、長春電影製片廠等老牌譯製機構 1950–
1990 年代為外國電影做中文配音時形成的獨特語體。

不是「給句子加幾個歐化句」、不是「模仿某位配音演員的個人音色」、更**
不是冷戰意識形態台詞致敬**——而是**整篇位移到 1850–1950 西洋世界，
以呼語起手 + 賭咒嘆詞 + 歐化句式 + 全形破折號構成的字正腔圓舞台腔重
新承載**:讀完讓人想起《簡愛》「我親愛的——你以為我貧窮、卑微、不美
——我就沒有靈魂沒有心嗎？」,或《虎口脫險》「我要長刷子——不要扁刷
子！」,或知乎戲仿樓裡那段「嘿，我親愛的老夥計，看在上帝的份上——」。

## 一句話靈魂

**呼語起手 + 賭咒嘆詞 + 歐化句式 + 全形破折號**——四元素至少三項出
現於每段；字正腔圓不縮略、不省略主語、不省略代詞；字面直譯英美俚語
比喻(靴子 / 兔子 / 祖父鬍子);世界觀走西洋通名；翻譯腔是 feature,
不是 bug。

## 三條風格指紋

1. **C-01 呼語起手式必出** — 每段首句或第二句必為「哦，我親愛的⋯⋯」
   「先生」「閣下」「我的朋友」「夥計們」「我的孩子」之一
2. **V-02 字面直譯誇張比喻** — 「用我的靴子狠狠地踢你的屁股」「以
   我祖父的鬍子起誓」「像一隻被剝皮的兔子」式英美俚語直譯；正典 ≥ 1,
   戲仿 ≥ 2
3. **M-01 中譯西洋雙重位移** — 場景必為 1850–1950 西洋世界(教堂、
   公爵、馬車、煤氣燈、長禮服);中華具體專名(衙門 / 縣令 / 嘉興 /
   銀子 / 廟祝)禁用

三者缺一就不是 1950–90s 中文譯製腔。其餘 19 條 checklist 都在服務這
三條。

## 集體語體致敬，非個人音色仿擬(極重要)

本 skill **明文定位為譯製機構共同沉澱出的書面語體致敬**:

- **不模仿配音演員個人音色** — 邱岳峰、童自榮、畢克、喬榛、丁建華、
  蘇秀、尚華、于鼎等老配音家在中文圈仍受尊敬，本 skill 改寫的是**共
  同句式、共同套語、共同稱謂體系**,不是個人語癖
- **禁出現「邱岳峰式的⋯⋯」「童自榮般⋯⋯」這類個人化指涉** — 文字層
  本來就不可能模仿音色，且個人化指涉易冒犯
- **不引涉意識形態對立的政治台詞** — 譯製片背景跨冷戰陣營，風格本身
  中性，但內容須避免批美 / 歌革命 / 煽動階級鬥爭的台詞；選愛情、偵
  探、喜劇、書信獨白等中性場景
- **避文革時代悲劇輕慢化** — 邱岳峰 1980 自殺事件帶有時代悲劇色彩，
  不宜輕慢化引用

## 雙重位移(極重要)

若源文是中華情境，**須做雙重位移**——把場景、物件、稱謂、官制一起搬
到 1850–1950 的西洋世界，不可只換語氣留著中華骨架：

| 中華原型 | 西洋等價 |
|---|---|
| 衙門 / 公堂 | 蘇格蘭場 / 警察局 / 治安署 |
| 縣令 / 知府 | 治安官 / 地方法官 |
| 廟祝 / 和尚 / 道士 | 教區牧師 / 神父 |
| 朝廷敕令 | 公爵詔書 / 議會公文 |
| 嘉興 / 湖廣 | 約克郡 / 薩塞克斯郡 / 普羅旺斯 |
| 銀子 / 銀錢 | 英鎊 / 先令 / 法郎 |
| 客棧 / 茶樓 | 旅館 / 驛站 / 俱樂部 |
| 算盤 / 銅錢 | 賬本 / 銀餐刀 / 燭台 |
| 相公 / 官人 | 先生 / Mr. / 閣下 |
| 姑娘 / 大小姐 | 小姐 / Miss / 女士 |

## 兩檔強度光譜

| 強度 | 風格錨點 | 代表片 | 用法 |
|---|---|---|---|
| **正典** | 莊重抒情、輕快喜劇、童話、偵探 | 《簡愛》《尼羅河》《虎口脫險》《佐羅》《茜茜公主》《魂斷藍橋》《追捕》《葉塞尼亞》 | 呼語起手 + 歐化句式 + 全形破折號為主軸；賭咒嘆詞自然分佈不堆砌；誇張比喻可有可無 |
| **戲仿** | 知乎 / B 站 / 微博翻譯腔迷因 | 〈如何模仿翻譯腔〉樓的經典樓中樓 | 「老夥計」「靴子」「祖父鬍子」三件套必滿；誇張比喻 ≥ 2 處 |

## 何時使用

- 想把一段文章改寫成 1950–90s 中文譯製片配音腔
- 想體驗中譯西洋影視口語的具體手法
- 想學「呼語 + 賭咒 + 歐化句式 + 破折號」的舞台腔節奏
- 想把一篇中華原型文本完整位移到西洋世界

## 何時**不**用

- 想模仿某具體配音演員的個人音色 — 本 skill **不做這件事**
- 想致敬冷戰意識形態台詞 — 本 skill **不做這件事**,內容須中性
- 想加入泛歐化翻譯腔(非影視配音、非戲劇舞台腔)— 用 [westernise](../westernise/)
- 想寫朱生豪式中譯莎劇悲劇腔 — 用 [shakespeare-style](../shakespeare-style/)
- 想寫中譯維多利亞偵探小說腔 — 用 [sherlock-holmes-style](../sherlock-holmes-style/)
- 想寫海明威體中譯版(冰山理論短句)— 用 [hemingway-style](../hemingway-style/)

## 預期輸出篇幅

繁體中文譯製腔，**Medium 強度典型 500–800 字**:

| 強度 | 字數 | 三件套密度 |
|---|---|---|
| 正典 | 400–800 字 | 收斂 — 呼語/歐化/破折號為主，誇張比喻 ≤ 1 |
| 戲仿 | 500–900 字 | 堆滿 — 老夥計/靴子/祖父鬍子三件套必出，誇張比喻 ≥ 2 |

## 適合的源文

- 中華情境寓言(《差不多先生》《小王子》《雨天故事》一類，可做雙重位移)
- 西洋已有的軼事 / 童話 / 書信(可直接走正典抒情)
- 戲劇性高、情感外露的故事(配音譯製腔的舞台戲劇感容器)
- 對白多、獨白多、情緒外顯的文本

## 不太適合的源文

- 純技術文件、新聞報導(語體不對應)
- 純抒情詩、現代主義散文(譯製腔的舞台戲劇感會破壞密度感)
- 政治台詞、意識形態文本(**本 skill 明文不做**)
- 純科普 / 學術論文(沒有戲劇腔容器)

## 運作流程

1. **讀原文** — 若非繁體中文，先在心中譯為繁體中文
2. **決定強度檔位** — 正典 / 戲仿擇一，後續每步皆以此檔位密度為準
3. **中譯西洋雙重位移檢查** — 中華具體專名 / 物件 / 地名 / 節氣 → 西洋等價物
4. **改寫核心(呼語 / 賭咒 / 歐化 / 物件)** — 四大支柱逐項落實
5. **加入指紋元素(破折號 / 反覆 / 三層遞進 / 誇張比喻)** — 次級指紋
6. **強度檢核** — 默念測試：像不像譯製片配音？
7. **標點清理 + 自檢指令** — 全形標點 + CJK 後零半形(自檢腳本歸零)
8. **Self-check Against Checklist** — 22 條(Hard 18 + Soft 4)
9. **抓最弱段重寫** — 通常是開頭或收尾
10. **輸出** — 寫入 `<原檔名>_yizhi.md`

## 改寫原則(checklist 摘要)

| 類別 | 編號 | 要點 |
|------|------|------|
| Concrete | C-01~C-05 | 呼語起手 / 賭咒嘆詞 ≥ 3 / 物件詞 ≥ 3 / 西洋稱謂體系 / **西洋日常語料覆蓋(度量衡/食物飲料/親屬稱謂/罵人話/道別問候 ≥ 3 類)** |
| Surface | S-01~S-05 | CJK 字後零半形 / 全形破折號 ≥ 2 / 全形省略號 ≥ 1 / 多層定語(Soft)/ 代詞氾濫(Soft) |
| Voice | V-01~V-07 | 歐化句式 ≥ 3 / 字面直譯誇張比喻 / 反覆強調 / 三層遞進(Soft)/ 字正腔圓不縮略 / 副詞綴化(Soft)/ 強度錨點不混 |
| Meta | M-01~M-05 | 中譯西洋雙重位移 / 不點名配音演員 / 不引政治台詞 / 不附作者按 / 標點清理零違規 |

## 時代分期錨點(正典檔可選次風格)

正典檔可進一步選定一個時代次風格，讓輸出不會所有正典都長得一樣：

| 時代 | 風格特徵 | 代表片 |
|---|---|---|
| **1950s 草創期(莎劇朗誦腔)** | 更「話劇」、更「朗誦」;偏「莎劇/俄文學腔」 | 《魂斷藍橋》《王子復仇記》 |
| **1970s 黃金期(抒情華麗腔)** | 抒情華麗、舞台朗誦、全形破折號頓挫密集 | 《簡愛》《佐羅》《追捕》《葉塞尼亞》《尼羅河上的慘案》 |
| **1980s 喜劇/成熟期** | 急促語速、嘆詞密度高、押韻好笑、口頭禪反覆 | 《虎口脫險》《加里森敢死隊》 |
| **1980s 童話/動畫腔** | 少女明亮腔、童聲抒情、唱腔接念白 | 《茜茜公主》《音樂之聲》 |

類型片子檔(可獨立選定):悲劇/正劇、抒情詠嘆、偵探/推理、喜劇、童
話/動畫。詳見 [SKILL.md Step 2.5](./SKILL.md)。
