# yizhi-style — 示範

展示 `yizhi-style` 如何把短文改寫成中文譯製腔(1950–90s 上譯/長譯/北
影廠配音語體)。三個範例**各自的場景不同、敘事視角不同、發明骨架不
共用**:範例一是星球告別獨白、範例二是雨中歸家小喜劇、範例三是中華
情境完整雙重位移到法國鄉間的戲仿。

> **源文與引用說明**:範例一源文 [The Little Prince](../../examples/source-texts/little-prince.md)
> 為依 Saint-Exupéry 原作風格自編的短摘錄。範例二源文 [雨天故事](../../examples/source-texts/weather-rain.md)
> 為共用源文庫自編，無版權疑慮。範例三源文 [《差不多先生傳》(胡適，
> 1924)](../../examples/source-texts/mr-chabuduo.md) 來自共用源文庫，公
> 有領域。
>
> 對 1950–90 年代上海電影譯製廠/長春電影製片廠/北影廠等譯製機構作
> 品的指涉僅作風格座標說明，**未引用整段台本**;譯製機構與配音演員
> 的版權與名譽權歸各機構及當事人(或其後人)所有。
>
> **重要定位**:本 skill 為**集體語體致敬**而非**個人音色仿擬**——下
> 列三則示範不點名具體配音演員，不引涉意識形態對立的政治台詞；範例
> 三將原文的中華情境(直隸省/紅糖白糖/陝西山西)**雙重位移**為 1850s
> 法國鄉間情境(諾曼第省/糖粉麵粉/普羅旺斯布列塔尼)。

## 範例一：Little Prince → 譯製腔正典(抒情童話 / 訓誨腔)

源文：**自編〈Little Prince〉摘錄**,共用源文庫
[`examples/source-texts/little-prince.md`](../../examples/source-texts/little-prince.md)。

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 強度檔位 | 正典 |
| 風格錨點 | 《茜茜公主》長者訓誨腔 + 《簡愛》呼語三重遞進 + 《魂斷藍橋》「我從未」絕對化結構 |
| 時代 / 類型錨點 | 1980s 童話 / 動畫腔 + 抒情詠嘆類型(Step 2.5 子檔位)|
| 雙重位移 | 小王子已是西洋情境(法國童話),無需位移；保留星球/玫瑰/火山三件套 |
| 敘事視角 | 第二人稱「我的孩子」(地球敘述者對小王子的呼喚) |
| 結構 | 呼語起手 → 場景描寫(三座火山/一株玫瑰)→ 告別猶豫(反覆)→ 離別決心(三重遞進) |

### 改寫後

> 我的孩子——
>
> 你獨自住在那顆比一棟房子還要小的小行星上。
> 三座火山，一株玫瑰。
> 每一個清晨，你都要清掃你那三座火山，
> 你都要澆灌你那唯一深愛的玫瑰。
>
> 哦，我的孩子，我知道——
> 我知道這一日終將到來：
> 那一日，你要告別你的星球，
> 去往那無垠的、空寂的、佈滿了未知星辰的宇宙裡⋯⋯
>
> 你站在那扇透明的、被宇宙的微塵覆蓋著的小窗前，
> 望著你的玫瑰，
> 望了很久，很久。
> 你並不是不愛她——上帝啊，你從未，你從未這樣愛過任何一樣東西——
> 但你知道，你不得不去。
>
> 「再見了，我的玫瑰。」
> 你輕輕地、輕輕地說。
> 「再見了，我那三座可愛的、終日噴著薄煙的火山。」
> 你又輕輕地說了一次，
> 那聲音被風吹進了你的胸膛，
> 又從你的胸膛裡，被風吹了出來。
>
> 哦，我親愛的小傢伙——
> 因為你愛她，因為你必須走，因為你終究是要長大的，
> 所以你不得不，在這個清晨，
> 邁出那一步。
>
> 為什麼我們不能，只是停留在我們自己的小星球上呢？
> 為什麼我們不能，只是清掃我們的火山、澆灌我們的玫瑰呢？
> 然而你知道——
> 你是這樣的一種孩子，
> 在你的整個生命裡，
> 你終究是要去看一看那無垠的宇宙的。
>
> 走吧——
> 走過去⋯⋯就是這樣⋯⋯
> 走過去⋯⋯一直走⋯⋯不要朝兩邊看。
>
> 願上帝保佑你，我的孩子。

### 達標清單(22 條)

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 呼語起手：「我的孩子——」「哦，我的孩子」「哦，我親愛的小傢伙」三處 |
| C-02 | ✓ | 賭咒嘆詞：「上帝啊」「願上帝保佑你」≥ 3 處(含「哦」嘆詞密集) |
| C-03 | ✓ | 物件詞：星球、火山、玫瑰、小窗、清晨、星辰、宇宙、風 — 西洋童話自然意象 |
| C-04 | ✓ | 西洋稱謂：「我的孩子」「我親愛的小傢伙」;無中華稱謂 |
| C-05 | △ | 西洋日常語料覆蓋：親屬稱謂「我的孩子」「我親愛的小傢伙」+ 道別問候「願上帝保佑你」;v2 新規則 Hard 要求 ≥ 3 類，本 demo 為 v1 撰寫，部分達成，可補度量衡 / 食物飲料 |
| S-01 | ✓ | 全篇 CJK 字之間零半形標點 |
| S-02 | ✓ | 全形破折號 —— ≥ 5 處：「我的孩子——」「我知道——」「上帝啊⋯⋯」 |
| S-03 | ✓ | 全形省略號 ⋯⋯ ≥ 4 處：「宇宙裡⋯⋯」「走過去⋯⋯就是這樣⋯⋯」 |
| S-04 | ✓ | 多層定語(的的不休):「那扇透明的、被宇宙的微塵覆蓋著的小窗」 |
| S-05 | ✓ | 代詞氾濫：「你都要清掃你那三座火山，你都要澆灌你那唯一深愛的玫瑰」 |
| V-01 | ✓ | 歐化句式 ≥ 3:「為什麼我們不能⋯⋯呢？」×2、「你是這樣的一種孩子」、「在你的整個生命裡」 |
| V-02 | ✓ | 字面直譯誇張比喻(正典 ≥ 1):「在你的整個生命裡」絕對化表達(收斂於正典感) |
| V-03 | ✓ | 反覆強調：「你從未，你從未這樣愛過任何一樣東西」、「望了很久，很久」、「走過去⋯⋯就是這樣⋯⋯走過去⋯⋯」 |
| V-04 | ✓ | 三層遞進：「因為你愛她，因為你必須走，因為你終究是要長大的」 |
| V-05 | ✓ | 字正腔圓不縮略：「不得不去」、「我知道這一日終將到來」、「終究是要⋯⋯的」 |
| V-06 | ✓ | 副詞綴化：「輕輕地、輕輕地說」、「終日噴著薄煙的」 |
| V-07 | ✓ | 強度錨點不混：全篇走《茜茜公主》《簡愛》《魂斷藍橋》正典抒情；無戲仿三件套 |
| M-01 | ✓ | 雙重位移：源文已是西洋童話，無需位移；西洋意象群完整 |
| M-02 | ✓ | 不點名配音演員：無「邱岳峰式的⋯⋯」「童自榮般的⋯⋯」 |
| M-03 | ✓ | 不引政治台詞：純抒情告別，中性場景 |
| M-04 | ✓ | 不附作者按 |
| M-05 | ✓ | 標點清理通過(Step 7 自檢計數歸零) |

## 範例二：雨天故事 → 譯製腔正典(輕快喜劇 / 街坊調侃)

源文：**自編〈雨天故事〉**,共用源文庫
[`examples/source-texts/weather-rain.md`](../../examples/source-texts/weather-rain.md)。

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 強度檔位 | 正典(偏輕快喜劇) |
| 風格錨點 | 《虎口脫險》喜劇對白腔 + 《佐羅》街坊調侃 + 第一人稱自嘲回憶 |
| 時代 / 類型錨點 | 1980s 喜劇 / 成熟期 + 喜劇類型(Step 2.5 子檔位)|
| 雙重位移 | 中華現代城市 → 1880s 維也納(避開倫敦，與 sherlock-holmes-style 範例及範例三場景皆不同) |
| 對照 | 圖書館 → 霍夫堡圖書館；計程車 → 雙輪馬車；辦公室 → 事務所；鄰居 → 房東馮·施泰因夫人；鑰匙 → 鑰匙(西洋同名);錢包 → 錢包(西洋同名);先令(取代「錢」)|
| 視角 | 第一人稱「我」回憶 |
| 結構 | 雨突至 → 徒步歸家 → 鑰匙也忘 → 房東窗中打趣 → 自嘲收尾 |

### 改寫後

> 那一日的午後，我永遠記得——
>
> 維也納四月的天空，前一刻還是晴朗的，
> 後一刻竟突然下起了大雨！
> 大雨——哦，我的天哪，你能想像嗎？——
> 是那種把整條石板路都淋成一面鏡子的、
> 傾盆而下的、毫不留情的大雨。
>
> 我正在霍夫堡圖書館的閱覽室裡，
> 讀著一本封皮已經磨損了的、年代久遠的舊書，
> 完全沒有注意到窗外的變化。
> 等我合上書，走到大門前，卻發現——
> 我並沒有帶傘。
> 哦，該死的——我又一次，在這同一個季節，
> 犯了同一個錯誤。
>
> 街上的行人全都撐著傘奔走著，
> 馬車的車輪濺起的水花，
> 把石板路染得像是從多瑙河裡撈出來的一樣。
> 我那不爭氣的口袋裡，連一枚先令也沒有——
> 我向你發誓，先生——我忘了帶錢包。
>
> 「為什麼我們不雇一輛雙輪馬車呢？」
> 這念頭只在我腦中閃過一瞬，
> 便被現實狠狠地踢了出去。
>
> 我把外套的衣領豎起，
> 深深地嘆了一口氣，
> 邁開腳步，徒步走進那場——
> 那場屬於維也納的、屬於四月的、
> 屬於我這種忘帶錢包的可憐人的大雨裡。
>
> 等我終於拖著渾身濕透的身子，
> 回到我那聖斯德望廣場附近的小寓所，
> 摸遍每一個口袋，卻發現——
> 我那把該死的鑰匙，
> 也忘在事務所裡了。
>
> 三樓的窗子，這時竟「咯吱」一聲推開了一條縫。
> 那是住在我樓上的、年邁的、
> 總是穿著一身黑色喪服的房東——
> 馮·施泰因夫人。
> 她戴著她那副小巧的銀邊眼鏡，
> 從窗縫裡探出半張臉，笑著朝我喊道：
>
> 「先生！這樣的天氣，
> 閣下何以不雇一輛雙輪馬車？」
>
> 我抬起頭，擰乾袖口的水，
> 從口袋裡攤出兩隻空手——
> 「夫人見諒，」我說，
> 「我忘了帶錢包。」
>
> 哦，我親愛的——
> 我向上帝發誓，
> 這就是維也納四月的大雨，
> 帶給一個忘帶錢包、忘帶鑰匙的、
> 永遠粗心的可憐人的——
> 最完美的禮物。

| C-02 | ✓ | 賭咒嘆詞 ≥ 3:「哦，我的天哪」「該死的」「我向你發誓」「我向上帝發誓」 |

| C-05 | △ | 西洋日常語料覆蓋：度量衡「先令」+ 賭咒嘆詞「該死的——」;v2 新規則 Hard 要求 ≥ 3 類，本 demo 為 v1 撰寫，部分達成，可補食物飲料 / 親屬稱謂 / 道別問候 |

## 範例三：差不多先生 → 譯製腔戲仿(雙重位移 / 三件套堆滿)

源文：**胡適《差不多先生傳》(1924) 摘錄**,共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 強度檔位 | 戲仿(網路迷因「老夥計+靴子+祖父鬍子」三件套堆滿) |
| 風格錨點 | 知乎 / B 站 / 微博翻譯腔戲仿樓的典型句式組合 |
| 時代 / 類型錨點 | 戲仿檔不選次風格(Step 2.5 明示);戲仿的是 1980s 上譯腔的集體迷因本身 |
| 雙重位移 | 中華情境完整位移 → 1850s 法國諾曼第鄉間(避開倫敦/維也納，與 sherlock-holmes-style 範例及範例二場景皆不同) |
| 對照 | 中國 → 法蘭西；直隸省 → 諾曼第；陝西/山西 → 普羅旺斯/布列塔尼；紅糖/白糖 → 糖粉/麵粉；媽媽罵 → 母親 + 聖母瑪利亞之名；先生 → 教區牧師勒費弗爾；學堂 → 學堂(西洋亦有);名字「差不多」→ Monsieur À-Peu-Près(法文音意義近) |
| 視角 | 第三人稱敘述者(略帶嘲諷)+ 母親對白 + 牧師對白，皆套迷因戲仿三件套 |
| 結構 | 介紹其人 → 描述外貌 → 口頭禪 → 童年買糖事件 → 學堂地理糾正事件 → 預言式收尾 |

### 改寫後

> 嘿，我親愛的老夥計們——
>
> 看在上帝的份上，讓我告訴你——
> 在我們整個諾曼第的鄉間，有一位先生，
> 他的名字，人人皆曉，處處聞名。
>
> 他姓「À-Peu-Près」——也就是「差不多」。
> 我發誓——這真是見鬼的姓氏！——
> 但他的的確確就是這個名字，
> 而且他，以我祖父的鬍子起誓，
> 是這片土地上每一個郡、每一個村莊、每一座教堂前的廣場上，
> 都站著過的人。
>
> 哦，他長得是什麼樣子呢？
> 我向你保證，先生——他長得幾乎和你我都差不多。
> 他有一雙眼睛，但他看東西——你知道的——並不很清楚；
> 他有兩隻耳朵，但他聽事情——上帝啊——也並不很分明。
> 他的鼻子，他的嘴，他的腦子，他的記性——
> 全都像一隻被剝了皮的兔子那樣，
> 朦朦朧朧、含含糊糊地擺在那裡⋯⋯
>
> 他總是說——
> 他用他那不僅含混而且自鳴得意的腔調說：
> 「凡事啊，只要差不多就好了。
> 為什麼我們要這樣較真呢？」
>
> 他還是個小傢伙的時候，他那慈祥的、永不疲倦的母親，
> 叫他到鎮上的雜貨鋪去買一磅糖粉。
> 你能想像嗎？
> 哦，我親愛的老夥計——
> 他竟買了一磅麵粉回來！
>
> 「我的孩子！」他母親大喊，
> 「以聖母瑪利亞的名義——
> 糖粉和麵粉，你竟以為是同一種東西嗎？」
>
> 他搖了搖他那顆毛茸茸的小腦袋，
> 用一種——我發誓——
> 彷彿全世界都欠了他什麼似的口吻說：
> 「糖粉和麵粉，媽媽——它們不是差不多嗎？」
>
> 哦，該死的孩子——
> 他那可憐的母親，那一刻真想用她的木鞋，
> 狠狠地踢一下他的屁股，
> 像踢一隻聖誕節的火雞那樣。
>
> 而在學堂裡——願上帝憐憫他的老師——
> 教區牧師勒費弗爾先生問他：
> 「孩子，告訴我：諾曼第的西邊，是哪一片土地？」
>
> 他想了想，自信地、毫不猶豫地說：
> 「是普羅旺斯。」
>
> 「不！不！不！」
> 牧師敲著他那本黑皮的、邊角已經磨損了的舊筆記本，大喊——
> 「是布列塔尼！以我祖父的鬍子發誓——
> 是布列塔尼，不是普羅旺斯！」
>
> 而我們的 À-Peu-Près 先生，只是聳了聳他那單薄的肩膀，
> 用他那一貫的、令人髮指的、平靜的口吻說：
> 「普羅旺斯和布列塔尼——它們不是差不多嗎？」
>
> 哦，我親愛的——這個男孩——
> 我向你發誓，他將來，必定會成為——
> 整個法蘭西、整個歐羅巴、乃至整個基督教世界的——
> 最偉大的、最致命的、最沒有人能阻止的——
> 「差不多」先生。
