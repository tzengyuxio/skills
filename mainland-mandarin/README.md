# Mainland Mandarin — 中國大陸普通話

把任何文字改寫成中國大陸普通話日常 / 媒體 / 網路文體——詞彙以大陸現代用
法為準（視頻 / 質量 / 出租車 / 公交 / 軟件），網路流行語適度嵌入（內卷
／ 躺平 / yyds / 破防 / 家人們誰懂啊），句法走標準普通話（不台化、不港
化、不文言），平台文體可選（微博 / 朋友圈 / 抖音 / B 站 / 小紅書 / 知乎）。

## 什麼是中國大陸普通話？

PRC 普通話是中國大陸現代華語的**標準日常層**——既不是黨政公文體（那是
人民日報社論），也不是地域次方言（那是東北話、上海話、四川話）。它是
微信長文、微博推文、朋友圈日常、小紅書 caption、抖音文案、B 站動態、
知乎答題、澎湃新聞特稿那一層共同的語感地基。

文化錨點：微博熱搜、小紅書種草、B 站 UP 主、抖音爆款、知乎答題、微信
朋友圈、澎湃 / 三聯 / 經濟觀察報。

## 一句話靈魂

**PRC 普通話日常 / 媒體文體**——詞彙大陸化（視頻 / 質量 / 軟件）+ 網路用
語適度嵌入 + 句法標準普通話（不台化、不港化、不文言）。

## 三段強度

| Level | 密度 | 效果 |
|---|---|---|
| **Light** | 對台差異詞替換為主，0-1 處網路用語 | 澎湃新聞中性報導；大陸朋友寫的微信長文 |
| **Medium**（預設）| 流行語每段 1-2 處 + 微博 / 朋友圈體 | 小紅書 caption、微博日常、知乎輕鬆答題 |
| **Heavy** | 流行語密集 + 抖音 / B 站 文案 / 彈幕體 | 家人們誰懂啊體、爆款短視頻文案、B 站熱門動態 |

未指定時預設 **Medium**。

## 不會做的事

- 不寫黨政公文體（落實 / 推進 / 紮實 / 偉大復興）——那是 `prc-bureaucratese` 的事
- 不寫次方言（整 / 賊 / 嘎哈 / 巴適 / 儂）——那是 `dongbei-mandarin` / `sichuan-mandarin` / `shanghainese` 的事
- 不寫台灣國語標誌（啦 / 喔 / 齁 / 醬 / 偶 / 粉）
- 不寫意識形態羞辱詞（五毛 / 小粉紅 / 白左 / 美分）——大陸是現代華語標準變體，不是笑話素材
- 不附評論段、不附「我的改寫思路」

## 範例

| 原文（標準中文） | 大陸普通話（Medium）|
|---|---|
| 我影片看到一半當機。 | 我視頻看到一半卡了。|
| 這個品質有夠差。 | 這質量是真的差，破防了。|
| 我搭計程車去捷運站。 | 我打車去地鐵站。|
| 公司用的軟體很爛。 | 公司用的軟件真的很爛，每天上班就是內卷。|
| 我傳訊息給你。 | 我給你發個微信哈。|
| 大家好，今天分享⋯⋯ | 家人們誰懂啊，今天必須給友友們分享一個 yyds 的小館子！|
| 真的很好笑。 | 笑死，真的蚌埠住了😭 |

## 設計原則

- **標準日常層**：把「微博 / 朋友圈 / 小紅書 / 抖音 / B 站 / 知乎 / 中性媒體」共
  通的語感地基獨立呈現，不蹭公文、不沾次方言、不混台灣國語。
- **中性化**：大陸是現代華語的標準變體之一。不嘲弄、不政治羞辱、不放大對
  立。政治概念按源文中性轉述。
- **網路用語有節奏**：流行語密度隨強度 Light → Medium → Heavy 階梯式升高，
  Heavy 才會滿到「家人們誰懂啊 / 絕絕子 / yyds 拿捏了」這種飽和度。
- **簡繁體跟隨輸入**：大陸官方標準是簡體，但 skill 預設不強制轉換；明確要
  求「大陸地道版本」/「轉成簡體」時才轉。
