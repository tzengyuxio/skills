# Mainland Mandarin — 示範

展示 `mainland-mandarin` skill 在三段強度下的輸出效果，以及好的中國大陸普
通話寫作長什麼樣子。源文取自 [`examples/source-texts/`](../../examples/source-texts/) 共
用源文庫（範例三除外，自編）。

> **設計說明**：四個範例骨架彼此不共用——雨天 / 小王子 / 微信群裡的同事
> 八卦 / 差不多先生——以證明強度差異不是「同一篇文章加調味」，而是不同
> 平台、不同題材帶不同的詞彙密度與文體配置。範例一示範 Light、範例二示
> 範 Medium、範例三示範 Heavy（抖音體 + B 站彈幕體混合）、範例四是經典
> 〈差不多先生傳〉的 Medium 改寫對照。

---

## 範例一（Light）：雨天故事 — 微信長文 / 中性媒體層

源文：[weather-rain.md](../../examples/source-texts/weather-rain.md)

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### Light 改寫

> 昨天下午我在圖書館看書的時候，突然下起了大雨。我雖然沒帶傘，還是決定走回家。路上人挺多，到處都是打傘的行人。我全身都淋透了，回到家才發現鑰匙忘在辦公室了。鄰居看到我這個樣子，笑著說：「你怎麼不打個車啊？」我只好苦笑著回了一句：「我錢包也沒帶。」

### 達標解析

| 編號 | 達成 | 解析 |
|---|---|---|
| V-01 | ✓ | 「打車」（=叫車）、「鑰匙忘在辦公室」均為大陸口語 |
| G-01 | ✓ | 不用「有」+ V 完成體，純用「了」 |
| S-01 | ✓ | 「啊」單個語助詞，無台灣標誌 |
| M-04 | ✓ | 純粹日常敘事，無公文標誌 |
| M-05 | ✓ | 無次方言色彩，純標準層 |

**對照結論**：Light 模式不靠流行語博眼球，靠詞彙與句末助詞的微調讓
語感從「中性中文」轉到「大陸日常」。讀來像一個北京白領在朋友圈
記錄一天，不刻意，不浮誇。

## 範例二（Medium）：小王子（英文源 → 大陸普通話 / 微博體）

源文：[little-prince.md](../../examples/source-texts/little-prince.md)

> The little prince lived alone on a tiny planet, no bigger than a house. He had three volcanoes to clean, and a rose that he loved very much. Every morning, he would clean his volcanoes and water his rose. One day, he decided to leave his planet to explore the universe. He was sad to say goodbye, but he knew he had to go.

### Medium 改寫

> 小王子一個人住在一顆小小的星球上，比一間房子大不了多少。他有三座火山要打理，還有一朵特別愛的玫瑰。每天早上，他都會給火山做做清潔，再給玫瑰澆水——這就是他全部的日常。後來有一天，他突然決定離開這顆星球，去宇宙裡看看更大的世界。臨走的時候他真的破防了，但他知道，這一步必須得走。

### 達標解析

| 編號 | 達成 | 解析 |
|---|---|---|
| V-01 | ✓ | 「打理」「做做清潔」是大陸口語 |
| V-04 | ✓ | 「破防了」一處網路用語，落在情緒高峰 |
| G-04 | ✓ | 「他都會給火山做做清潔」——「給」字句口語擴張 |
| G-07 | ✓ | 「必須得走」——完成 / 決斷感末尾 |
| S-01 | ✓ | 結尾無語助詞堆疊；中段流暢 |
| M-07 | ✓ | 流行語只 1 處，不密集，不貼標籤 |

**對照結論**：Medium 不是把流行語往句子裡塞，而是讓「大陸詞彙基底
+ 一處情緒峰值的網路語」共同把語感頂上去。「破防了」放在小王子
告別玫瑰的瞬間，承載了原文 "sad to say goodbye" 的情緒——這是流行
語在文學翻譯裡最自然的用法。

## 範例三（Heavy）：自編軼事 — 抖音 / B 站 / 微博體混用

源文（自編）：

> 上週小張請我們部門一起吃火鍋慶祝拿到大客戶。結果他訂的店是網紅店，排了兩個小時還沒進去，大家都餓得不行。等終於坐下來，菜單一看人均三百，他臉色都變了。最後埋單時他默默掏出公司的招待費發票本。

### Heavy 改寫（抖音文案 + B 站彈幕雙拼）

> **抖音版（caption）**
>
> 家人們誰懂啊！！上週小張說請我們部門吃火鍋慶祝拿大客戶，結果直接給友友們整了個大的——網紅店排隊兩小時，當場破防😭 終於坐下，菜單一打開人均三百，小張臉色那叫一個精彩，整個包間瞬間安靜（）
>
> 重點來了：埋單的時候，這哥們兒從包裡默默摸出公司招待費發票本，xswl 真的拿捏了打工人的尊嚴 yyds 🤣 友友們有沒有過這種同事？評論區聊聊👇 #職場名場面# #打工人的快樂# #網紅店翻車#
>
> **B 站動態 + 彈幕版**
>
> u1s1 這故事屬實有點 city 了。小張屬於是把「請部門吃飯」這件事做成草台班子了，網紅店排倆小時、人均三百直接給他整破防——awsl，這埋單一刻發票本掏出來那畫面，xswl 我笑岔氣了，純路人都跟著繃不住（）
>
> 彈幕互動：「前方高能」「名場面」「爺青回 我們組也有這種人」「小張被內卷到了」「招待費 yyds」「鼠鼠我啊也想被請吃網紅店」「下次一定」「包的，下個月還這麼整」

### 達標解析

| 編號 | 達成 | 解析 |
|---|---|---|
| V-01 | ✓ | 「埋單」「人均三百」「招待費發票本」標準大陸語感 |
| V-04 | ✓ | 流行語飽和：家人們誰懂啊 / 友友們 / 破防 / 拿捏 / 翻車 / yyds / 草台班子 / city / 內卷 / 鼠鼠我啊 / 包的 / 爺青回 / 名場面 |
| V-05 | ✓ | 字母縮寫：xswl / awsl / u1s1；emoji：😭 🤣 |
| S-02 | ✓ | 微博 / 抖音話題標籤：#職場名場面# #打工人的快樂# #網紅店翻車# |
| S-03 | ✓ | 抖音文案體：「家人們誰懂啊」開場、「重點來了」鉤子、「評論區聊聊」收束 |
| S-04 | ✓ | B 站彈幕體：「（）」補刀笑點、「前方高能」「名場面」「爺青回」 |
| M-02 | ✓ | C-class 飽和度——每 2-3 句 1 處流行語 + 平台文體飽滿 |
| M-05 | ✓ | 雖密集但無「整 / 賊 / 嘎哈」東北標誌（「這哥們兒」是普通話北方口語，不是次方言標誌）|

**對照結論**：Heavy 不是把詞典背出來，是把**平台文體**整套搬進
來——抖音文案有抖音的鉤子節奏（家人們開場、評論區收束、話題標
籤），B 站動態有 B 站的彈幕互動（前方高能、爺青回、（）補刀）。
讀者一眼能認出「這是抖音」「這是 B 站」，這就成了。

## 範例四（Medium）：差不多先生傳（中文源 → 大陸普通話 / 微博 + 知乎混合）

源文：胡適《差不多先生傳》(1924) 摘錄，[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)，公有領域。

### 原文

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不多，是各省各縣各村人氏。⋯⋯他常常說：「凡事只要差不多，就好了。何必太精明呢？」他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：「錯了。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」

### Medium 改寫

> 你知道中國最有名的人是誰嗎？提起這位，那真是家人們誰懂啊——人人都熟，處處有他。他姓差，名不多，全國各省各縣各村都能找到他。差不多先生這名字，天天掛在大家嘴邊，畢竟他就是全中國人的代言人。
>
> 他經常掛在嘴邊一句話：「凡事只要差不多，就行了，何必那麼較真呢？」這句話的精神內核，放今天就是「躺平」+「擺爛」雙開——只要事情大差不差就好，誰耗誰呀。
>
> 上學那會兒，老師問他：「直隸省的西邊是哪個省？」他答：「陝西。」老師糾正：「錯了，是山西，不是陝西。」他理直氣壯地反問：「陝西跟山西，這不差不多嘛？」
>
> 真的，當代年輕人聽完這段直接破防——這位老哥拿捏了內卷時代「精神勝利」的精髓，比阿 Q 早了一百年，yyds。

### 達標解析

| 編號 | 達成 | 解析 |
|---|---|---|
| V-01 | ✓ | 「掛在大家嘴邊」「上學那會兒」「老哥」均為大陸口語 |
| V-02 | ✓ | 「躺平」「擺爛」「內卷」三個行政生活詞精準對位胡適原文「精神勝利」內核 |
| V-04 | ✓ | 流行語：家人們誰懂啊 / 大差不差 / 破防 / 拿捏 / yyds——每段 1-2 處 |
| G-04 | ✓ | 「誰耗誰呀」——口語提問式，拉近距離 |
| G-07 | ✓ | 「就行了」「就好」完成感末尾 |
| S-01 | ✓ | 「呢」「嘛」「呀」大陸語助詞集 |
| S-02 | ✓ | 末段「真的，⋯⋯直接破防」——微博式評論口吻收束 |
| M-03 | ✓ | 中性處理；不嘲弄、不政治化，只把「差不多哲學」與當代「躺平 / 擺爛」連接 |
| M-04 | ✓ | 全篇無公文標誌，純粹微博 + 知乎風格議論 |
| M-06 | ✓ | 無台灣標誌（不寫「啦」「喔」「機車」「歹勢」）|

**對照結論**：Medium 改寫的核心動作，是把胡適 1924 年的「諷刺寓言
體」翻譯成 2025 年的「微博 + 知乎輕議論體」——同樣的精神內核
（差不多哲學 = 反精明 = 國民性批判），用大陸當代人能直接接住的詞
彙系統（躺平 / 擺爛 / 內卷 / 破防 / 拿捏）重新講一遍。胡適看到大概
也會點個贊：他那年寫的就是這個意思。

## 強度速查

| 強度 | 特徵 | 典型場景 |
|---|---|---|
| **Light** | 對台差異詞 + 大陸句末助詞，0-1 處流行語 | 澎湃新聞、大陸朋友的微信長文、知乎中性答題 |
| **Medium**（預設）| 流行語每段 1-2 處 + 微博 / 朋友圈體 | 微博日常推文、小紅書 caption、知乎輕鬆答題 |
| **Heavy** | 流行語密集 + 抖音文案 / B 站 彈幕 / 微博熱搜 | 抖音爆款、B 站 熱門動態、家人們誰懂啊體 |

完整 21 條 checklist 與 9 步 workflow 見 [SKILL.md](../SKILL.md)。
