# Gulong-wuxia — 改寫成中後期古龍武俠

把任何文章改寫成中後期古龍流派的武俠敘事——極短句節奏、警句嵌入、對比張力，
讀完讓人停一拍，覺得江湖很遠，又覺得就在身邊。

風格參照：中後期古龍 (1969《多情劍客無情劍》之後的成熟期)。代表作：小李
飛刀系列、楚留香系列、陸小鳳系列、傅紅雪系列、《七種武器》、《歡樂英雄》、
《絕代雙驕》。

## 一句話靈魂

**極短句節奏 + 警句嵌入 + 對比張力**——三者構成古龍腔指紋，缺一就不是古龍。
其餘 checklist 都在服務這三條。

## Arguments

- `$0` —(選填)Markdown 或純文字檔案路徑。若省略，請使用者提供內文，
  或從對話上下文中找最近編輯的檔案。

## Step 1: Load the Text

- 若提供 `$0`，讀取該檔案。
- 若無引數，找對話中最近撰寫或編輯的 Markdown 檔，或請使用者提供文字。
- 若原文不是繁體中文，先在心中譯為繁體中文(不必輸出)，再做改寫。

## Step 2: Read Source and Extract One Tension

古龍體不是把原文壓縮成短句，而是**抽出一個核心張力，重新講一個江湖故事**。

讀完原文後，用一句話自答：

> 這篇文章裡的「**對立**」是什麼？「**錯失**」在哪？「**孤獨**」在哪？

可能的張力來源：殺與被殺、趕與趕不上、有與無、得與失、朋友與敵人、選擇與
不能選擇、自己與影子。原文若是議論文 / 學術文 / 新聞，**先抽核心張力，再為
它設計一個江湖場景**——不要把論點直接「翻譯」成短句。

若原文太長(超過 1500 字)，只取一個主題改寫，不要硬塞所有內容。

## Step 3: Decide Modern → 江湖 Theme Mapping

若原文涉及現代生活(科技、職場、政治、消費)，**把主題抽象化**為江湖等價物：

| 現代主題 | 江湖等價 |
|---|---|
| 職場霸凌 | 江湖圍剿、群雄逼一人 |
| 加班趕工 | 趕赴生死約 / 趕在月圓前到達 |
| 失戀 / 分手 | 江湖故人、相忘於江湖 |
| 升遷競爭 | 武林盟主之爭、刀法排行 |
| 演算法 / 系統 | 命格、宿命之網 |
| 通訊科技 | 信差、飛鴿、烽火 |
| 健康 / 病痛 | 暗傷、內傷、毒功反噬 |
| 學業 / 考試 | 入門考核、絕學試煉 |
| 政治派系 | 幫派、門派、明教正邪 |
| 都市寂寞 | 浪子、孤客、千里獨行 |

**例外**：若使用者明確要求保留某一現代詞作為刻意時代錯位，可保留 1–2 個。

## Step 4: Choose Character Configuration

從六種配置中**挑一種**。古龍最強的是「**對峙**」——兩人對視，往往不必動手。

| 配置 | 張力來源 | 範例 |
|---|---|---|
| 殺手 vs 殺手 | 同行對視、惺惺相惜 | 阿飛遇上荊無命、傅紅雪對葉開 |
| 浪子 vs 故人 | 相見不如不見 | 楚留香遇舊識 |
| 老者 vs 少年 | 經驗 vs 銳氣 | 老刀客遇少年劍客 |
| 主角 vs 影子 | 跟蹤、複製、自我懷疑 | 陸小鳳遇司空摘星 |
| 江湖人 vs 局外人 | 規矩 vs 情感 | 殺手與民女、刀客與小孩 |
| 主角 vs 自己 | 內在分裂 | 傅紅雪刀與本心的拉扯 |

**角色取響亮三字名**(傅紅雪 / 葉開 / 阿飛 / 西門吹雪 / 燕南飛)優於虛構姓名
(「李大俠」「王刀客」)。歷史名只能用於明確的史實引用。

## Step 5: Choose 對比張力與警句種子

從以下對比軸中**挑一組為主軸**，並起一句**警句芽**。在筆記裡明確寫下：
「主對比 = X，警句芽 = Y。」後續寫作圍繞這組收束。

| 對比軸 | 例 |
|---|---|
| 殺 / 被殺 | 「殺人不難，難的是不被殺。」|
| 快 / 慢 | 「太快的人，看不到太慢的事。」|
| 動 / 靜 | 「最快的刀，是不出鞘的刀。」|
| 生 / 死 | 「死不可怕。可怕的是知道自己會怎麼死。」|
| 趕上 / 趕不上 | 「趕不上的事，本來就比趕上的多。」|
| 自己 / 影子 | 「他殺死的，原來是自己的影子。」|

警句芽不必精到一稿就用上——它是寫作時的「靶」，會在 Step 6–8 之間打磨。

## Step 6: First Draft

寫一稿。原則：

- **語感**：白話偏雅，少量文言虛詞(乃 / 遂 / 竟 / 已 / 卻)點綴，不通篇文言
- **句長**：平均 ≤12 字，許多單句獨立成段
- **段落**：平均 1–3 句一段，超過 4 句的段落要警惕——古龍很少寫長段
- **對話**：可省略「誰說」指代，讓語氣自證
- **武打**：不寫過程，只寫結果或一個畫面(「刀光一閃」「那人就倒下了」)
- **景物**：取一二符號(風 / 雪 / 月 / 酒 / 刀 / 劍)，不鋪陳
- **篇幅**：原文短(< 200 字)寫 200–300 字；中(200–800)寫 300–450 字；
  長(800+)取單一主題寫 400–600 字
- **重複/變奏**：核心句可以細微差異重複 2–3 次(「他笑了。/ 他笑得很冷。/
  那笑像刀。」)，這是古龍最強的節奏裝置
- **結尾戛然而止**：警句嵌入收束的那一拍打完就停，不要解釋、不要再給場景

## Step 7: Self-check Against Checklist

逐條對照下面的 21 條 checklist。**任一條 [Hard] 違反就回 Step 6 重寫該段**。
[Soft] 違反需有理由(寫在筆記裡)，否則一併修。

### Checklist: Content(內容主題)

| 編號 | 強度 | 規則 |
|---|---|---|
| C-01 | Hard | **保留原文核心張力**——以「江湖人物相遇」框架重述。可換場景、可換角色，但「對立」與「錯失」要對得上原文 |
| C-02 | Hard | **必有對比張力組**(殺手/殺手、靜/動、生/死、年輕/年老、忠/叛、自己/影子擇一)——**靈魂條款之一** |
| C-03 | Hard | **不出現現代專名/物件**(品牌、產品、政治人物、現代地名、科技詞彙)。例外：用功能性指代替換(「東來的客商」「邑中人」) |
| C-04 | Soft | **主題抽象化**——時代性主題(經濟、政治、科技)在 Step 3 已轉化為江湖等價 |
| C-05 | Soft | **角色取響亮三字名**(傅紅雪 / 葉開 / 阿飛 / 燕南飛式)，避免「老李」「小張」這類平淡名 |

### Checklist: Structure(結構)

| 編號 | 強度 | 規則 |
|---|---|---|
| S-01 | Hard | **篇幅 200–600 字**(計入標點)，典型 350 字。低於 150 字無法承載對比張力，超過 700 字會偏散文化 |
| S-02 | Hard | **段落極短**——平均 1–3 句一段，長段是禁忌，**靈魂條款之二** |
| S-03 | Hard | **必有警句嵌入**敘事或對話中，不獨立成段成 cliché——**靈魂條款之三** |
| S-04 | Soft | **結構不機械**，可重複句變奏(同句以細微差異重複 2–3 次)，但不超過 3 次 |
| S-05 | Hard | **結尾留白或警句**，不下結論、不解釋。禁用「他終於明白⋯⋯」「於是 X 知道⋯⋯」這類訓誨句 |
| S-06 | Soft | **對白可省略「誰說」指代**，讓語氣自證身份 |

### Checklist: Voice(語言風格)

| 編號 | 強度 | 規則 |
|---|---|---|
| V-01 | Hard | **句子極短**，平均 ≤12 字。長複句是現代散文特徵，不是古龍的 |
| V-02 | Hard | **白話偏雅**，少量文言虛詞(乃 / 遂 / 竟 / 已 / 卻)，不通篇文言。古龍不是仿古，是以現代感的孤獨重寫江湖 |
| V-03 | Hard | **不寫武打過程**——只寫結果(「那人倒下了」)或一個畫面(「刀光一閃」)。古龍寫殺，不寫鬥 |
| V-04 | Soft | **環境描寫凝鍊**——風 / 雪 / 月 / 酒 / 刀 / 劍只取一二，不鋪陳 |
| V-05 | Soft | **重複/變奏節奏**——同句以細微差異重複 2–3 次，是古龍最強的節奏裝置，但不可濫用 |

### Checklist: Meta(後設)

| 編號 | 強度 | 規則 |
|---|---|---|
| M-01 | Hard | **不附評論段、不附作者按、不附「我的改寫思路」**——除非使用者明確要求 |
| M-02 | Hard | **警句不可孤立成段成 cliché**——必嵌入情境(對話收尾、場景定格、角色內在獨白)。獨立成段的警句是網路文青摘錄體，不是古龍 |
| M-03 | Soft | **角色取響亮名**而非平淡名 |
| M-04 | Hard | **不寫長段景物或情境鋪陳**——凝鍊是古龍鐵律。鋪陳是金庸的，古龍要的是符號 |
| M-05 | Hard | **若原文是議論文 / 抒情文 / 學術文**：必須先抽張力，再**設計江湖場景**承載——不要把論點直接「翻譯」成短句疊起 |

**總計**：21 條(Hard 14 + Soft 7)。

## Step 8: Find the Weakest Paragraph and Rewrite

通常**結尾**或**景物段**最弱：
- 若結尾下了結論，刪到只剩動作或畫面定格
- 若警句獨立成段過於漂亮，挪入對話或情境中嵌埋
- 若景物寫太滿(風雪月星全上)，砍到剩一二符號
- 若中段拖泥帶水，刪到節奏緊起來為止

「**能少一句就少一句**」是古龍體的鐵律——濃度來自節制，不是堆砌。

## Step 9: Output

1. **檔案輸入**：寫入 `<原檔名>_gulong.md`，保留原檔
2. **貼文輸入**：直接輸出古龍體
3. **不附說明、不附評論、不附「我的改寫思路」**
4. 若使用者明確要求，可額外輸出**改寫筆記**(列出 Step 3–5 的選擇)，但
   **主輸出永遠是古龍體本身**

## Anti-patterns(常見失敗模式)

寫完一稿、自檢之前，先掃一眼這 8 條最容易踩的坑：

1. **警句獨立成段**——「人生如刀，刀如人生」這類獨佔一段的警句立刻變網路
   文青摘錄體。警句必須**嵌入情境**(對話收尾、角色動作後的內心一閃)
2. **短句湊數無節奏**——把長句機械斷成短句不是古龍。古龍的短句有**呼吸感
   與意外**，每句都該推進或翻轉
3. **武打詳寫**——「他舉刀劃下三道，木屑紛飛」是金庸寫法不是古龍。古龍
   寫殺，不寫鬥
4. **缺對比張力**——只剩光禿短句堆疊，沒有殺/被殺、快/慢、動/靜的拉扯
5. **環境描寫鋪太滿**——風雪月星全上，破壞凝鍊感。古龍取一二符號就夠
6. **結尾下結論或解釋警句**——古龍永遠不解釋，讀者自己會懂
7. **角色名平淡**——「老李」「小張」失去江湖感。三字響亮名是古龍標配
8. **仿楚留香卻寫成偵探推理**——失去古龍核心的孤獨感。即使是楚留香的
   智謀篇，底色仍是浪子的寂寞

## Core Example: 木匠雕神像

源文(現代軼事)：一名工程師接到三日交專案的死線，連夜加班寫出醜陋程式
碼，事後重構，最後產品被取消。下方為改寫成功的版本——用節制的對立讓
孤獨自己長出來。

> 山下有個雕匠。
>
> 他接了一個活——三日內，為祠堂雕一尊神像。
>
> 第三日清晨，他走出工坊。
>
> 神像在他手上。
>
> 他走得很慢。
>
> 不是因為神像沉。
>
> 是因為他知道趕不上了。
>
> 廟祝在祠堂門前等著。
>
> 接過神像。
>
> 看了一眼。
>
> 放在桌上。
>
> 「祠堂前日已拆。」
>
> 雕匠沒有走。
>
> 廟祝也沒有再說。
>
> 風吹過山。
>
> 一個老人路過，看了他一眼。
>
> 「世上的事，趕不上的，本來就比趕得上的多。」
>
> 雕匠笑了。
>
> 那笑很苦。
>
> 然後他抱起神像，慢慢往山上走回去。
>
> 神像的眉眼，比第一日更偏了。
>
> 因為他走得太累。

**達標清單**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-02 | ✓ | 對比張力：年輕雕匠 vs 老者 / 趕上 vs 趕不上 |
| C-03 | ✓ | 無現代專名(雕匠、祠堂、神像皆前現代) |
| S-01 | ✓ | 約 240 字 |
| S-02 | ✓ | 平均 1–2 句一段，無長段 |
| S-03 | ✓ | 警句嵌入老人對話：「趕不上的，本來就比趕得上的多」(不獨立成段) |
| S-05 | ✓ | 結尾無結論——定格在「神像的眉眼比第一日更偏」「他走得太累」 |
| V-01 | ✓ | 平均句長 ~10 字 |
| V-03 | ✓ | 不寫雕刻過程，只寫「神像在他手上」「他走得很慢」這類定格 |
| V-04 | ✓ | 環境只取「風吹過山」一處 |
| V-05 | ✓ | 重複/變奏：「他走得很慢 / 不是因為神像沉 / 是因為他知道趕不上了」「沒有走 / 沒有再說」 |
| M-02 | ✓ | 警句嵌入老人對話，不孤立 |
| M-04 | ✓ | 無長段景物鋪陳 |

**對照結論**：古龍體不是把句子切短，而是**用節制的對立讓孤獨自己長出來**——
「神像的眉眼比第一日更偏」沒有解釋，但讀完整篇你會知道。短句是手段，
**對比張力與警句嵌入才是靈魂**。

## Important Notes

- 本 skill 是**體裁轉換工具**，不是「把句子切短」工具。原文的核心張力必須
  被保留，以江湖敘事的形式重新承載
- **對偶設計**：本 skill 與將來的 `jinyong-style` 互為對偶——古龍的短句
  留白 vs 金庸的章回招式。21 條 checklist 的每一條，jinyong-style 都會有
  反向對應條款
- **不要寫成空洞短句**——濃度來自對立與警句，不是把長句機械斷開
- **保留鋒利的細節**(刀、酒、風、雪、笑)，不要磨平成抽象的「他若有所思」
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
