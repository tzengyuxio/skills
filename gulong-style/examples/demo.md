# Gulong-wuxia — 示範

展示 `gulong-style` 如何把現代文章改寫成中後期古龍武俠敘事，以及好的古龍腔
長什麼樣子。

> **源文與引用說明**：範例一、範例二為依古龍中後期風格自編的「目標範例」，
> 用以示範靈魂條款怎麼落地，**非實際古龍作品**。範例三的源文(現代軼事)為
> 自編。範例四的源文 [《差不多先生傳》(胡適， 1924)](../../examples/source-texts/mr-chabuduo.md)
> 來自共用源文庫，公有領域。文中對中後期古龍代表作(《多情劍客無情劍》《天涯·
> 明月·刀》《楚留香傳奇》《七種武器》)的指涉僅作風格座標說明，未引用整段
> 原文。

---

## 範例一：風格目標 — 殺手對視

這是 gulong-style 的「品牌示範」——直接給出最純粹的中後期古龍腔：殺手 vs
殺手的配置、對比張力、警句嵌入對話、結尾不解釋。

### 自編目標範例

> 那人坐在窗邊。
>
> 已經坐了很久。
>
> 桌上一壺酒。
>
> 沒有動過。
>
> 阿飛走進來，看了他一眼。
>
> 「你在等人。」
>
> 「嗯。」
>
> 「等很久了？」
>
> 「三天。」
>
> 阿飛在他對面坐下。
>
> 「他不會來了。」
>
> 那人沒有回頭。
>
> 「我知道。」
>
> 「那你為什麼還等？」
>
> 那人終於看了他一眼。
>
> 「等不到，才是等。等得到，那叫赴約。」
>
> 阿飛沒有再說。
>
> 他把那壺酒拿過來，給自己倒了一杯。
>
> 酒已經涼了。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 段落極短，幾乎一句一段 | S-02 段落極短 | 古龍腔最直觀的視覺特徵 |
| 對白省略「誰說」 | S-06 省略指代 | 「你在等人。」「嗯。」讓語氣自證身份 |
| 警句嵌入對話：「等不到，才是等。等得到，那叫赴約。」 | S-03 + M-02 | 嵌入回答中，不獨立成段 |
| 對比張力：等 vs 等不到 / 主動 vs 被動 | C-02 對比張力 | 整段圍繞這組張力收束 |
| 角色名：阿飛(三字以下響亮短名) | C-05 響亮名 | 真正的中後期古龍標配 |
| 環境符號：窗邊、酒、涼酒 | V-04 凝鍊符號 | 不寫店名、不寫天候、不鋪陳 |
| 結尾「酒已經涼了」 | S-05 結尾留白 | 沒有結論，定格在涼酒上 |

**風格座標**：與《多情劍客無情劍》中阿飛與李尋歡對話片段的風格趨近——
**對視即敘事，沉默比話多**。

## 範例二：風格目標 — 浪子歸鄉

示範第二種配置——**浪子 vs 故人**。古龍腔不是只有殺手對峙，也有重逢的
寂寞。這個範例展現古龍的另一個重要面向：**返鄉、相忘、不認**。

### 自編目標範例

> 他回到了那個小鎮。
>
> 鎮口的酒幡還在。
>
> 老闆換了人。
>
> 他在角落坐下，叫了一壺酒。
>
> 喝了三杯，沒有醉。
>
> 鄰桌有人在喝酒。
>
> 喝得很慢。
>
> 喝得像認識他。
>
> 但沒有看他。
>
> 他也沒有看那人。
>
> 喝完酒，他付了錢，站起來。
>
> 走到門口，他停了一下。
>
> 沒有回頭。
>
> 「江湖上的人，最怕的不是仇家。」他低聲說。
>
> 「是還記得自己的人。」
>
> 然後他走了。
>
> 鄰桌那人把杯裡的酒喝完。
>
> 杯子放下時，桌面響了一下。
>
> 像很多年前的某個夜晚。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 對比張力：認 vs 不認 / 故人 vs 陌生 | C-02 對比張力 | 整篇核心張力 |
| 警句嵌入主角自言：「江湖上的人，最怕的不是仇家。是還記得自己的人。」 | S-03 + M-02 | 警句以對話形式嵌入，避免獨立成段 |
| 重複/變奏：「喝得很慢。/ 喝得像認識他。/ 但沒有看他。」 | V-05 重複變奏 | 同一動作的細微遞進，是古龍最強節奏 |
| 結尾「桌面響了一下。像很多年前的某個夜晚」 | S-05 結尾留白 | 沒有相認，沒有解釋，只一個聲音的回憶閃過 |
| 不寫武打 | V-03 不寫過程 | 通篇沒有打鬥 — 古龍中後期常如此 |
| 角色未取名 | M-03 響亮名(僅 Soft) | 兩人都沒名，反而強化「不必認」的氛圍 |

**風格座標**：類似《邊城浪子》《九月鷹飛》中故人重逢卻不相認的場景——
古龍寫人的孤獨，常勝過寫人的相遇。

## 範例三：改寫示範 — 現代軼事

源文(自編)──**現代軼事**：

> 一名工程師接到三天內交專案的死線，連夜加班寫出醜陋的程式碼，事後花更多
> 時間重構，最後產品被取消。

### 改寫

> 山下有個雕匠。
>
> 他接了一個活——三日內，為祠堂雕一尊神像。
>
> 第三日清晨，他走出工坊。
>
> 神像在他手上。
>
> 他走得很慢。
>
> 不是因為神像沉。
>
> 是因為他知道趕不上了。
>
> 廟祝在祠堂門前等著。
>
> 接過神像。
>
> 看了一眼。
>
> 放在桌上。
>
> 「祠堂前日已拆。」
>
> 雕匠沒有走。
>
> 廟祝也沒有再說。
>
> 風吹過山。
>
> 一個老人路過，看了他一眼。
>
> 「世上的事，趕不上的，本來就比趕得上的多。」
>
> 雕匠笑了。
>
> 那笑很苦。
>
> 然後他抱起神像，慢慢往山上走回去。
>
> 神像的眉眼，比第一日更偏了。
>
> 因為他走得太累。

**達標清單**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-02 | ✓ | 對比張力：年輕雕匠 vs 老者 / 趕上 vs 趕不上 |
| C-03 | ✓ | 無現代專名(雕匠、祠堂、神像皆前現代) |
| S-01 | ✓ | 約 240 字 |
| S-02 | ✓ | 平均 1–2 句一段，無長段 |
| S-03 | ✓ | 警句嵌入老人對話：「趕不上的，本來就比趕得上的多」 |
| S-05 | ✓ | 結尾無結論——定格在「神像的眉眼比第一日更偏」「他走得太累」 |
| V-01 | ✓ | 平均句長 ~10 字 |
| V-03 | ✓ | 不寫雕刻過程 |
| V-04 | ✓ | 環境只取「風吹過山」一處 |
| V-05 | ✓ | 重複/變奏：「他走得很慢 / 不是因為神像沉 / 是因為他知道趕不上了」 |
| M-02 | ✓ | 警句嵌入老人對話，不孤立 |

**對照結論**：古龍體不是把句子切短，而是**用節制的對立讓孤獨自己長出來**——
「神像的眉眼比第一日更偏」沒有解釋，但讀完整篇你會知道。短句是手段，
**對比張力與警句嵌入才是靈魂**。

## 範例四：改寫示範 — 《差不多先生傳》→ 古龍

源文：**胡適《差不多先生傳》(1924)摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 原文

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不多，
> 是各省各縣各村人氏。⋯⋯
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」
>
> 他小的時候，他媽叫他去買紅糖，他買了白糖回來。他媽罵他，他搖搖頭說：
>「紅糖白糖，不是差不多嗎？」
>
> 他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：
>「錯了。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」

(原文採取**諷刺寓言**體例。「差不多先生」是國民性的擬人化批判。)

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽張力 | 「差不多」是放棄區分的執著——表面隨和，實則消解一切判準。但江湖上有些「差不多」是會死人的 |
| 主題抽象化 | 把「差不多先生」放進江湖殺手體系，讓「差不多」遇上一個比他「快一寸」的對手 |
| 角色配置 | 殺手 vs 殺手(以「差不多」為名的殺手 vs 一個無名對手) |
| 主對比 | 差不多 vs 差一寸 |
| 警句芽 | 「差一寸，從來不是差不多」——藏在死前內心獨白裡，不獨立成段 |

### 改寫後

> 江湖上有個人，人稱「差不多」。
>
> 他用刀。刀法不算頂尖，也夠用。
>
> 紅糖白糖，他覺得差不多。
>
> 陝西山西，他覺得差不多。
>
> 殺一個和殺兩個，他也覺得差不多。
>
> 那一夜，他在小酒館裡。
>
> 對面坐了一個人。
>
> 那人說：「我刀比你快一寸。」
>
> 「差不多。」他回答。
>
> 然後他就死了。
>
> 死前他想：差一寸，從來不是差不多。
>
> 然後他什麼也沒再想。
>
> 對面那人收刀。
>
> 叫了一壺酒。
>
> 喝完。
>
> 站起來。
>
> 走出酒館。
>
> 外面風很大。
>
> 他沒有回頭。

(約 220 字)

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留「差不多」的核心張力；原文諷刺被轉化為江湖式的致命對比 |
| C-02 | ✓ | 對比：差不多 vs 差一寸 / 我 vs 對面那人 |
| C-03 | ✓ | 無現代專名 |
| C-05 | ✓ | 角色名：「差不多」是源文角色名(可保留)；對手以「對面那人」指代，符合古龍的不點名美學 |
| S-01 | ✓ | 約 220 字 |
| S-02 | ✓ | 段落極短，無長段 |
| S-03 | ✓ | 警句嵌入「死前他想」獨白：「差一寸，從來不是差不多」(不獨立成段) |
| S-04 | ✓ | 重複變奏：「紅糖白糖／陝西山西／殺一個和殺兩個」三疊式變奏 |
| S-05 | ✓ | 結尾「他沒有回頭」——殺手獨行收場，不下結論 |
| S-06 | ✓ | 對白省略指代，憑語氣自證身份 |
| V-01 | ✓ | 句長平均 ~9 字 |
| V-03 | ✓ | 不寫殺的過程，只「然後他就死了」 |
| V-04 | ✓ | 環境只取「酒、風」二符號 |
| M-02 | ✓ | 警句嵌入內心獨白，不孤立 |

**改寫的核心動作**：把胡適的「明寫的諷刺」轉為「江湖式的致命後果」。古龍
不講「差不多」的壞——讓「差不多」**在一個比他快一寸的人面前死去，對手
喝完酒就走，連名字都不問**。讀者會自己感到那份冷意。

## 速查：Checklist 重點

21 條中最常踩的：

| 編號 | 規則 | 怎麼用 |
|---|---|---|
| C-02 | 必有對比張力 | 寫之前明確寫下「主對比 = X」 |
| S-02 | 段落極短 | 平均 1–3 句一段，超過 4 句就要警惕 |
| S-03 | 警句嵌入 | 警句必須在對話、獨白、場景中，不獨立成段 |
| S-05 | 結尾留白 | 不下結論，把最後一句刪掉測試 |
| V-01 | 句子極短 | 平均 ≤12 字 |
| V-03 | 不寫武打過程 | 寫殺、不寫鬥；寫結果、不寫招式 |
| M-02 | 警句嵌入情境 | 獨立成段的警句是網路文青摘錄體，不是古龍 |

完整 21 項與 9 步流程見 [SKILL.md](../SKILL.md)。
