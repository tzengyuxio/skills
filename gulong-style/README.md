# Gulong-wuxia — 改寫成中後期古龍武俠

把任何文章改寫成中後期古龍流派的武俠敘事。

不是把句子切短，不是仿古文，而是**用節制的對立讓孤獨自己長出來**——
讀完讓人停一拍，覺得江湖很遠，又覺得就在身邊。

## 什麼是中後期古龍腔？

中後期古龍指 1969 年《多情劍客無情劍》之後的成熟期。代表作：

| 系列 / 作品 | 年代 | 風格特徵 |
|---|---|---|
| 《多情劍客無情劍》(小李飛刀) | 1969 | 確立短句留白派、警句嵌入 |
| 《楚留香傳奇》系列 | 1967–1978 | 智謀對話、浪子寂寞 |
| 《陸小鳳傳奇》系列 | 1972–1981 | 對峙美學、第三方視角 |
| 《天涯·明月·刀》 | 1972–1974 | 詩化散文、孤獨極致 |
| 《邊城浪子》 / 《九月鷹飛》 | 1972–1973 | 傅紅雪、葉開的對偶 |
| 《七種武器》系列 | 1974–1978 | 短篇武俠、警句密集 |
| 《歡樂英雄》 | 1971 | 朋友群像、笑的悲傷 |
| 《絕代雙驕》 | 1968 | 雙生對偶、命運糾結 |

`gulong-style` 鎖定這個時期的共同 DNA：**極短句節奏 + 警句嵌入 + 對比張力**。

## 風格參考

- **《天涯·明月·刀》**——重複變奏的詩化開頭(「天涯遠不遠？／不遠。／人就
  在天涯，天涯怎麼會遠？」)、孤獨意象的極致
- **《多情劍客無情劍》**——阿飛與李尋歡的對視美學、「酒與刀」的標誌符號
- **《七種武器》**——短篇結構、警句嵌入對話的密度
- **《邊城浪子》**——傅紅雪式的孤客心理、不認故人的回歸

## 不會做的事

- 不寫金庸式詳寫招式(那是 `jinyong-style` 的領域，本 skill 的對偶)
- 不寫平江不肖生 / 還珠樓主式的傳統武俠
- 不在結尾加「他終於明白⋯⋯」(古龍最大的禁忌)
- 不把警句獨立成段(會變網路文青摘錄體)
- 不寫長段景物或情境鋪陳(凝鍊是古龍鐵律)
- 不取「老李」「小張」這類平淡角色名(失去江湖感)

## 預期輸出篇幅

繁體中文白話偏雅，**200–600 字**(計入標點)，依原文長度決定：

| 原文長度 | 古龍體目標 |
|---|---|
| 短(< 200 字) | 200–300 字 |
| 中(200–800 字) | 300–450 字 |
| 長(800+ 字) | 400–600 字(只取單一主題) |

低於 150 字無法承載對比張力，超過 700 字會偏散文化。**原文短時就寫短**，
不為湊字數而稀釋節奏。原文超過 1500 字，只取一個主題改寫，不硬塞所有內容。

## 適合的源文

- 哲學散文 / 議論文(需先抽核心張力)
- 寓言 / 諷刺寓言(《差不多先生》《狂人日記》)
- 個人軼事(短篇散文、blog 文)
- 都市孤獨主題(尤其適合古龍腔)

## 不太適合的源文

- 充滿現代專名 / 科技 / 政治的新聞報導(去脈絡化代價太高)
- 純抒情詩(沒有可改寫的張力對立)
- 已經是武俠小說的源文(改寫意義不大)
- 純技術文件、程式碼說明(沒有可承載的江湖場景)

## 與 jinyong-style 的對偶設計

`gulong-style` 設計時刻意預留了與將來 `jinyong-style` 的對偶軸線：

| 軸線 | gulong-style | jinyong-style |
|---|---|---|
| 句長 | 極短句、單句成段 | 章回式長複句 |
| 結構 | 散文化詩意、節奏跳躍 | 章回對仗回目、線性史傳 |
| 武打 | 留白省略、只給結果 | 招式詳寫、招式有名 |
| 角色 | 殺手 / 孤客 / 浪子 | 大俠 / 情聖 / 門派傳人 |
| 主題 | 個人宿命、孤獨哲理 | 家國情義、江湖正邪 |
| 氛圍 | 現代感的孤寂與荒涼 | 古典史傳氣、歷史感 |
| 語感 | 白話偏雅 + 警句 | 半文白章回 + 套語 |
| 景物 | 凝鍊符號 | 詳實鋪陳 |

兩個 skill 的關係類似 `dewesternise` / `westernise`——是文體取捨的兩極。

## 運作流程

1. **讀原文 + 抽張力** — 一句話自答：「這篇的『對立』是什麼？『錯失』在哪？」
2. **主題抽象化** — 若是現代主題，換成江湖等價物(職場霸凌 → 江湖圍剿)
3. **角色設計** — 從六種配置選一(殺手/殺手、浪子/故人、老者/少年等)
4. **對比張力 + 警句芽** — 鎖定一組對比 + 起一句警句芽
5. **第一稿** — 短句節奏、段落極短、不寫武打
6. **Checklist 自檢** — 21 條(Hard 14 + Soft 7)
7. **抓最弱段重寫** — 通常是結尾或景物段
8. **輸出** — 寫入 `<原檔名>_gulong.md`，純古龍體、不附說明

## 改寫原則(checklist 摘要)

| 類別 | 編號 | 要點 |
|------|------|------|
| Content | C-01~C-05 | 保留核心張力、必有對比張力組、禁現代專名、主題抽象化、角色取響亮三字名 |
| Structure | S-01~S-06 | 篇幅 200–600 字、段落極短、警句嵌入、結構不機械、結尾留白、對白省略指代 |
| Voice | V-01~V-05 | 句子極短、白話偏雅、不寫武打過程、環境凝鍊、重複變奏節奏 |
| Meta | M-01~M-05 | 不附評論段、警句嵌入情境、響亮名、不長段鋪陳、議論文先抽張力 |

完整 21 項 checklist 與 9 步 workflow 見 [SKILL.md](./SKILL.md)。

## 三條靈魂條款

中後期古龍腔的指紋：

1. **C-02 對比張力組** — 殺手/殺手、靜/動、生/死、年輕/年老、忠/叛擇一
2. **S-02 段落極短** — 平均 1–3 句一段，長段是禁忌
3. **S-03 警句嵌入** — 警句必須嵌入對話/獨白/情境，不獨立成段成 cliché

三者缺一就不是古龍。其餘 18 條 checklist 都在服務這三條。
