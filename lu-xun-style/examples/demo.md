# Lu Xun-style — 示範

展示 `lu-xun-style` 如何把現代文章改寫成早期白話雜文，以及好的魯迅腔長
什麼樣子。四個範例**各自的「我」位置不同、各自的反諷對象不同**，不共用
骨架。

> **源文與引用說明**：範例一源文 [《差不多先生傳》（胡適， 1924)](../../examples/source-texts/mr-chabuduo.md)
> 來自共用源文庫，公有領域。範例二源文 [雨天故事](../../examples/source-texts/weather-rain.md)
> 為共用源文庫自編，無版權疑慮。範例三源文 [The Little Prince](../../examples/source-texts/little-prince.md)
> 為依 Saint-Exupéry 原作風格自編的短摘錄。範例四為自編現代軼事。
> 文中對魯迅代表作（《狂人日記》《阿 Q 正傳》《孔乙己》《野草》《華蓋集》）
> 的指涉僅作風格座標說明，未引用整段原文；魯迅 1936 年逝世，作品已進
> 入公共領域。
>
> **重要定位**：本 skill 為文體致敬，非立場模仿。下列示範皆以抽象／
> 普世的人性議題（自欺、苟且、看客、寂寞）為反諷對象，不涉及具體政
> 權、黨派、兩岸、宗教族群之爭。

## 範例一：改寫示範 — 《差不多先生傳》→ 魯迅體

源文：**胡適《差不多先生傳》(1924) 摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 原文

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名
> 不多，是各省各縣各村人氏。⋯⋯
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」⋯⋯
>
> 後來他得急病，趕快叫家人去請東街的汪先生。⋯⋯王大夫用醫牛之法給他
> 治病，差不多先生就此一命嗚呼。

（原文採取**諷刺寓言**體例。「差不多先生」是國民性的擬人化批判。）

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 反諷視角 | 同鄉舊識多年後寫的札記體，敘述者「我」是一個曾與差不多先生有過幾面之緣的書生 |
| 「我」位置 | 事後回望的我（多年後在上海弄堂閣樓寫下這段札記）|
| 場景錨定 | 縣城酒樓（差先生臨終延醫）+ 上海弄堂閣樓（敘述者寫札記之處）|
| 反諷對象 | 抽象：自欺、苟且、把毫釐當無關（不指向任何具體人事）|
| 結尾收法 | 動作收尾（敘述者合上札記）|

### 改寫後

> 差不多先生死了二十年，我才聽到這個消息。
>
> 那年我返鄉，住在縣城東頭的酒樓上。樓下有人喝酒，談起差先生。我聽得
> 一耳，便也只好放下筷子聽下去——他們說，差先生死那夜，雨下得很大，
> 家人慌了，跑到西街去請王大夫。王大夫是醫牛的，但鄰巷的汪先生那夜
> 正好不在，家人也未免太急，便就請了王大夫來。差先生躺在炕上，看見來
> 人不是汪先生而是王大夫，倒也沒怎麼掙扎，只笑了一下，說：「醫人醫
> 牛，不是差不多嗎？」
>
> 樓下的人說到這裡，都笑了。然而那笑也淡，倒像是笑給別人聽似的。
>
> 我那時想——差先生這一輩子，把毫釐當無關，把錯認當差不多，把生死當
> 兒戲，**究竟是看穿了世事，還是被世事看穿了**？想來他自己也未必說得
> 清。罷了，罷了，他既已葬在城南，墳頭上的草也不止三尺，再去問他也
> 是無謂。
>
> 後來我回了上海，在閣樓上整理舊筆記，翻到這一頁，才寫下這幾行字。
> 窗外電車鈴正響，鈴聲也淡，像是替誰響的。我擱筆起身，把札記合上，
> 蓋的塵不薄不厚——大抵也是差不多。
>
> （約 460 字）

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留「差不多」核心張力——把毫釐當無關，最後死於毫釐 |
| C-02 | ✓ | 冷峻反諷：敘述者只記下酒樓客人的笑與差先生臨終的話，不評斷 |
| C-03 | ✓ | 「我」字浮出三處：「我聽得一耳」「我那時想」「我擱筆起身」|
| C-04 | ✓ | 歷史距離：縣城酒樓 + 上海弄堂閣樓 + 民國交通（電車鈴）|
| C-05 | ✓ | 反諷對象抽象：自欺、苟且；不指向任何具體政權／群體 |
| C-06 | ✓ | 不代魯迅發言：無「中國人就是 X」式句子 |
| S-01 | ✓ | 約 460 字 |
| S-02 | ✓ | 五個短段落，每段 50–150 字 |
| S-03 | ✓ | 破折號思考停頓三處：「便也只好放下筷子聽下去——他們說」「我那時想——差先生這一輩子」「蓋的塵不薄不厚——大抵也是差不多」 |
| S-04 | ✓ | 動作收尾：「把札記合上，蓋的塵不薄不厚」，不下定論 |
| V-01 | ✓ | 標誌虛詞 ≥6：然而、未免、便、倒、只、罷了、罷了、究竟、想來、大抵、至於（隱）|
| V-02 | ✓ | 文言虛詞點綴：「無謂」「既已」「蓋」未強用，僅自然點綴 |
| V-04 | ✓ | 文化錨詞：酒樓、墳頭、炕、閣樓、電車鈴、墨／筆 |
| V-05 | ✓ | 冷觀：對差先生不嘲弄、不認同、不開脫；對酒樓客人的笑也只記錄不評斷 |
| M-02 | ✓ | 無現代政治指涉 |
| M-03 | ✓ | 不戲謔——差先生臨終的話寫得平淡，不抖機靈 |

**對照結論**：魯迅體不是把諷刺寓言寫得更尖銳，而是**把敘述者推遠一寸，
把場景挪到真實的酒樓裡，把笑寫成淡的笑**——讀者自己感受到差先生這一
輩子的可笑與可悲，敘述者並不出來說明。「**他既已葬在城南，墳頭上的草
也不止三尺，再去問他也是無謂**」這一句沒有評斷差先生，也沒有評斷酒樓
客人，但讀完整段你會知道：那座墳所在的，不只是一個人的縣城。

## 範例二：改寫示範 — 雨天故事 → 魯迅體

源文：**自編〈雨天故事〉**，共用源文庫
[`examples/source-texts/weather-rain.md`](../../examples/source-texts/weather-rain.md)。

### 原文

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是
> 決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回
> 到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫
> 計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 反諷視角 | 札記式的我，邊想邊寫，有自我懷疑 |
| 「我」位置 | 札記式的我（〈狂人日記〉式內省）|
| 場景錨定 | 縣城衙門外（看告示）+ 巷口（鄰人問話）|
| 反諷對象 | 抽象：自我尷尬時的微笑、為了體面而說謊的習性 |
| 結尾收法 | 問號收尾 |

### 改寫後

> 那日午後，我在衙門外看告示。告示是新貼的，墨還未乾。看了半晌，覺得
> 也未必有趣，便想轉身回去。剛轉身，雨就下來了。
>
> 雨下得很急。街上人多了起來，撐傘的撐傘，跑的跑，倒像是趕集。我沒帶
> 傘，也沒處躲，索性慢慢走。走到家門口，才想起鑰匙落在書齋——書齋距
> 衙門又有半條街。
>
> 鄰居王老頭從窗裡探出頭，看見我這副落湯雞的樣子，笑了一聲，說：「先
> 生為何不雇車？」
>
> 我那時竟也笑了。笑得很淡。我說：「忘了帶錢。」
>
> 然而我知道我並未忘。錢就在我袖口裡，三百個銅元，沉得很。我只是不願
> 說——說出來反倒像是炫耀，又像是辯解；不說呢，倒像是窮，倒像是疏忽，
> 王老頭便也笑得心安。我那一笑，**究竟是替自己笑，還是替王老頭笑**？
>
> 入夜，雨仍未停。我在油燈下寫這幾行字，寫到這裡便擱筆，想了想——其
> 實也想不出什麼。
>
> （約 380 字）

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-02 | ✓ | 冷峻反諷：對自己的「不願說」既不開脫也不控訴 |
| C-03 | ✓ | 「我」字浮出多處，札記式內省 |
| C-04 | ✓ | 歷史距離：衙門告示、銅元、書齋、油燈——舊中國縣城 |
| C-05 | ✓ | 反諷對象抽象：為體面而說謊的微妙心理，不指任何具體人事 |
| C-06 | ✓ | 無代魯迅發言句 |
| S-02 | ✓ | 六個短段落 |
| S-03 | ✓ | 破折號三處：「書齋距衙門又有半條街」（隱含停頓）、「想了想——其實也想不出什麼」、「不說呢，倒像是窮，倒像是疏忽」（逗號群造的停頓）|
| S-04 | ✓ | 問號收尾 + 動作收尾雙收：「究竟是替自己笑，還是替王老頭笑？」+「想了想——其實也想不出什麼」|
| V-01 | ✓ | 標誌虛詞 ≥6：便、倒、然而、只、究竟、罷（隱）、便也（重複）、倒像（多次）|
| V-02 | ✓ | 文言虛詞點綴：「半晌」「未必」（早期白話風格詞）|
| V-04 | ✓ | 文化錨詞：衙門、告示、銅元、書齋、油燈 |
| V-05 | ✓ | 冷觀：對自己的微笑也保持距離 |

**對照結論**：原文是一個小尷尬，魯迅體把它變成**一個敘述者對自己的微
觀內省**——「我那一笑，究竟是替自己笑，還是替王老頭笑？」這個問句沒有
答案，敘述者也不替讀者答；至於最後「想了想——其實也想不出什麼」，更
是把所有覺悟句的可能性一刀切斷。

## 範例三：改寫示範 — 小王子摘錄 → 魯迅體

源文：**自編〈Little Prince〉摘錄**，共用源文庫
[`examples/source-texts/little-prince.md`](../../examples/source-texts/little-prince.md)。

### 原文

> The little prince lived alone on a tiny planet, no bigger than a house.
> He had three volcanoes to clean, and a rose that he loved very much.
> Every morning, he would clean his volcanoes and water his rose. One
> day, he decided to leave his planet to explore the universe. He was
> sad to say goodbye, but he knew he had to go.

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 反諷視角 | 同代旁觀的我（街坊鄰居在童子離開時的視角）|
| 「我」位置 | 同代旁觀的我（〈藥〉式茶館視角）|
| 場景錨定 | 鄉間後園（童子的家）+ 河岸（送別處）|
| 反諷對象 | 抽象：對「不得不離開」這件事，旁人能說的話實在很少 |
| 結尾收法 | 靜默收尾 + 動作收尾 |

### 改寫後

> 我們村東頭有一戶人家，房子不大，比一般的茅屋稍大些罷了。屋後有個小
> 園子，種著三株矮樹，又一叢薔薇——那薔薇是童子養的。
>
> 童子年紀很小，沒有父母，獨自住在那園子裡。每天清晨，他便起來修剪矮
> 樹、給薔薇澆水。村裡人時常從牆外經過，看見他蹲在園裡，倒也不覺得
> 奇。
>
> 那年秋天，童子忽然要走了。他說要去看看別的地方。村裡人問他為什麼
> 走，他也答不出來，只是說：「不去也不行了。」說完便自己收拾包袱。
>
> 送行那日，我也去了。河岸上的風很涼，烏篷船停在淺灘邊。童子上船時，
> 回頭望了望那園子，望了很久。我那時想——他養了那薔薇許多年，臨走究
> 竟託付給誰呢？想來他也未必有人可託付。
>
> 然而我並未問。我只是站在岸上，看著船開走。船開得很慢，慢得像是不肯
> 走似的。村裡人陸陸續續散了，剩我一個。我也想說點什麼，**只是不知道
> 要說什麼好，便也只好不說了**。
>
> 河水流得很響。
>
> （約 430 字）

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-02 | ✓ | 冷峻反諷：童子要走，旁人能做的也只是站著；既不勸阻也不祝福 |
| C-03 | ✓ | 「我」字浮出：「我也去了」「我那時想」「我並未問」「剩我一個」|
| C-04 | ✓ | 歷史距離：茅屋、烏篷船、河岸、村東頭——民國初年江南鄉間 |
| C-05 | ✓ | 反諷對象抽象：送別時的無言、託付的不可能 |
| S-03 | ✓ | 破折號思考停頓：「我那時想——他養了那薔薇許多年」 |
| S-04 | ✓ | 靜默收尾 +「河水流得很響」動作收尾 |
| V-01 | ✓ | 標誌虛詞 ≥6：罷了、便、倒、只是、然而、究竟、想來、未必、也罷（隱）|
| V-04 | ✓ | 文化錨詞：茅屋、薔薇、烏篷船、河岸、包袱 |
| V-05 | ✓ | 冷觀：對童子的離開不抒情、不勸阻、不評斷 |

**對照結論**：小王子的原文是童話式的告別，魯迅體把它**搬到江南鄉村，
讓敘述者站在岸上看船開走**——「我也想說點什麼，只是不知道要說什麼
好，便也只好不說了」這一句把童話的詩意全部壓掉，剩下一個鄉村旁觀者
的沉默。「河水流得很響」作為孤立成段的收尾，是典型的動作收尾——它
沒有替誰發言，只是一個聲音。

## 範例四：改寫示範 — 自編現代軼事 → 魯迅體

源文（自編現代軼事）：

> 朋友老 K 最近換了第三份工作，說這次是真的找到天職了。我聽他說過
> 太多次「這次真的不一樣」，已經數不清是第幾回。三個月後他又離職了，
> 在群組發了一段話，說自己終於想清楚了，要去學陶藝。沒人回覆。

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 反諷視角 | 議論式的我（雜文體，邊敘邊評但評語短）|
| 「我」位置 | 議論式的我（《華蓋集》式雜文家自況）|
| 場景錨定 | 上海弄堂閣樓（雜文家的書桌）+ 縣城茶館（K 君當年談志向處）|
| 反諷對象 | 抽象：「終於想清楚」這四字的重複使用、群組沉默背後的人情 |
| 結尾收法 | 問號收尾 |

### 改寫後

> K 君近來又換了行業。
>
> 算起來這已是第三次了。第一次他從錢莊出來，去學了半年的醫；第二次又
> 從醫館出來，跟人合夥開了個書局；如今書局也散了，他寫信來說，這回是
> **真的**想清楚了，要去鄉下學做陶。
>
> 「真的」這兩個字，他寫得很重。
>
> 我那時正在閣樓上抄稿，看了信便擱在一邊，想笑也笑不出。倒不是不信他
> ——他說的「真的」每回都是真的，至少在他寫信的那一刻是真的。然而真
> 的也罷，假的也罷，三個月後便又有新的「真的」要來，至於上一個「真
> 的」如何收場，他似乎也未及細想。
>
> 想來十年前我在縣城茶館裡遇見他時，他也曾這樣說過——那時他要去考功
> 名，眼神也很亮。後來呢？後來自然也就那樣了。
>
> 信末他附了一句：「兄如何看？」
>
> 我提筆想回，寫了「兄之決心，未免⋯⋯」，下面便寫不下去。罷了，罷了，
> 兄之決心究竟如何，**也許連兄自己也未必知曉，何況我呢**？
>
> 我把信擱回原處，未即作覆。窗外有人在喊賣餛飩，喊了三聲，便沒了。
>
> （約 470 字）

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-02 | ✓ | 冷峻反諷：對 K 君的反覆既不嘲弄（不寫成段子）也不認同（不替他辯解）|
| C-03 | ✓ | 「我」字多處浮出，雜文家自況 |
| C-04 | ✓ | 歷史距離：錢莊、醫館、書局、縣城茶館、閣樓、餛飩擔——民國初期 |
| C-05 | ✓ | 反諷對象抽象：「真的」二字的反覆使用、人對自己決心的不可知 |
| C-06 | ✓ | 無代魯迅發言句 |
| S-02 | ✓ | 八個短段落 |
| S-03 | ✓ | 破折號思考停頓兩處：「倒不是不信他——他說的『真的』每回都是真的」「他也曾這樣說過——那時他要去考功名」|
| S-04 | ✓ | 問號收尾 + 動作收尾：「何況我呢？」+「喊了三聲，便沒了」|
| V-01 | ✓ | 標誌虛詞 ≥6：倒、然而、也罷（重複）、至於、想來、未免、罷了（重複）、究竟、便、也許、未必（多處）|
| V-02 | ✓ | 文言虛詞點綴：「兄之決心」「未即作覆」「何況」（議論性）|
| V-04 | ✓ | 文化錨詞：閣樓、茶館、錢莊、書局、餛飩、信、墨／筆（隱）|
| V-05 | ✓ | 冷觀：對 K 君的反覆變動、群組無人回覆，皆只記錄不評斷 |
| M-03 | ✓ | 不戲謔：沒有把 K 君寫成段子裡的笑料 |

**對照結論**：現代軼事的「群組沒人回覆」直接搬到民國，變成「閣樓上的
雜文家未即作覆」——同樣的沉默，但場景拉開了一百年。「**也許連兄自己
也未必知曉，何況我呢**？」這個問句不是嘲弄 K 君，而是讓敘述者把自己
也放進去：你不知道、我也不知道、誰都不知道。「窗外有人在喊賣餛飩，
喊了三聲，便沒了」是動作收尾——它不替信件作結，只是一個窗外的聲
音，叫了三聲就沒了，恰如那封信。
