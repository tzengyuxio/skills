# Lu Xun-style — 改寫成魯迅體（早期白話雜文）

把任何文章改寫成魯迅（1881–1936）式的早期白話雜文敘事。

不是「給句子加幾個古字」、不是「把段落加長加文」、更**不是借魯迅的口
吻發政見**——而是**讓敘述者站在事件旁邊冷觀，把事情的形狀寫下來**：
讀完讓人覺得敘述者就在那裡，但他不替你下判斷，至於對錯，他不替你斷。

## 一句話靈魂

**冷峻反諷的早期白話**——文白夾雜（早期白話為基底，文言虛詞點綴）+
標誌虛詞密集（然而 / 便 / 罷了 / 也罷 / 未免 / 實在 / 想來 / 只是 / 倒是）
+ 反諷距離（不嘲弄但不認同；敘述者站在事件之外冷觀）+「我」字第一人稱
不時出現（敘事者意識顯露）。

## 三條風格指紋

1. **C-02 冷峻反諷必現** — 敘述者站在事件之外冷觀，不嘲弄、不認同、
   不開脫、不控訴
2. **V-01 標誌虛詞密集** — 核心 12 詞至少 6 處出現
3. **S-04 結尾不下定論** — 問號／靜默／動作三擇一收尾

三者缺一就不是魯迅體。其餘 18 條 checklist 都在服務這三條。

## 政治中性化（極重要）

魯迅文體本身帶批判性，但本 skill **明文定位為文體致敬，不是立場模仿**：

- **不代魯迅發言** — 禁止「中國人就是 X」「魯迅當年會說」「我們的國民性
  就是 Y」式句子
- **反諷對象須抽象／普世** — 庸眾、看客、苟且、自欺可寫；具體政權、黨
  派、兩岸關係、宗教族群之爭一律不寫
- **歷史距離是安全範圍** — 舊中國的酒樓、茶館、墳場、後園是合法場景；
  現代政治指涉一律不寫

## 何時使用

- 想把一篇現代軼事改寫成 1920s 雜文家筆下的小品
- 想體驗早期白話「文白夾雜」的具體手法
- 想學「反諷距離」如何不嘲弄、不認同、不下定論
- 想把一個自欺式人物寫成阿 Q 式的旁觀對象

## 何時**不**用

- 想寫現代政治批判 — 本 skill **明確不做這件事**
- 想寫純文言短篇 — 早期白話為骨，文言只點綴
- 想寫戲謔段子 — 魯迅體即使對庸眾也保持距離，不戲謔
- 想寫熱血誓言、口號、覺悟句 — 本 skill 結尾**不下定論**

## 預期輸出篇幅

繁體中文早期白話雜文語感，**400–900 字**：

| 原文長度 | 魯迅體目標 |
|---|---|
| 短（< 200 字）| 400–600 字 |
| 中（200–800 字）| 500–800 字 |
| 長（800+ 字）| 600–900 字 |

## 適合的源文

- 寓言／諷刺寓言（《差不多先生》一類）
- 個人軼事（自欺、苟且、被冷落、被遺忘）
- 哲學散文（先抽核心張力再搬場景）
- 現代軼事（職場挫折、生活誤會、人情世故）
- 帶看客／旁觀視角的故事

## 不太適合的源文

- 純技術文件、新聞報導
- 純抒情詩
- 已經是雜文／魯迅作品的源文（改寫意義不大）
- 帶具體政治指涉、想借魯迅口吻發政見的文（**本 skill 不做這件事**）

## 運作流程

1. **讀原文 + 抽反諷視角** — 一句話自答：「敘述者站在哪裡看事件？」
2. **設計「我」的位置** — 事後回望／同代旁觀／札記式／議論式擇一
3. **場景錨定** — 搬到舊中國等價場景（酒樓、茶館、墳場、後園、小巷、
   衙門口、學堂、弄堂閣樓）
4. **草段** — 短句長句交替、逗號密度高、破折號做思考停頓
5. **加標誌虛詞** — 核心 12 詞 ≥6 處
6. **加文言虛詞點綴** — 1–3 處即可
7. **設計結尾（不收線）** — 問號／靜默／動作三擇一
8. **標點清理 + 朗讀** — 全形標點、破折號連寫、冷觀調性檢查
9. **Checklist 自檢** — 21 條（Hard 17 + Soft 4）
10. **抓最弱段重寫** — 通常是結尾段或評論段
11. **輸出** — 寫入 `<原檔名>_lu-xun.md`

## 改寫原則（checklist 摘要）

| 類別 | 編號 | 要點 |
|------|------|------|
| Content | C-01~C-06 | 保留核心張力、冷峻反諷必現、「我」字浮出、歷史距離錨定、反諷對象抽象、不代魯迅發言 |
| Structure | S-01~S-06 | 篇幅 400–900 字、短段落為主、破折號思考停頓、結尾不下定論、逗號密度高、重複造距離 |
| Voice | V-01~V-05 | 標誌虛詞密集、文言虛詞點綴、早期白話風格詞、文化錨詞、冷觀調性 |
| Meta | M-01~M-04 | 不附評論段、不寫現代政治批判、不戲謔嘲弄、不爆破不口號 |

完整 21 項 checklist 與 12 步 workflow 見 [SKILL.md](./SKILL.md)。

## 標誌虛詞清單

核心 12 詞：

| 類別 | 詞 |
|---|---|
| 轉折 | 然而、卻、倒是、只是 |
| 收束 | 罷了、也罷 |
| 推測 | 想來、未免 |
| 強調 | 實在、究竟、莫不 |
| 過渡 | 至於 |

延展與輔助詞另有：便、就、於是、似乎、彷彿、大抵、大約、近來、時常、
偶爾、纔、竟。
