# concrete-42 — 改寫成「義大利麵就應該拌 42 號混凝土」體

把任何文章改寫成偽專業話術——句式像論文摘要、政府報告或經濟分析，但內容
是跨領域具體名詞的隨機拼貼，配上偽因果連接詞，讀完讓人疑惑「他在說什麼？
但又好像很有道理」。

風格參照：抖音／B 站「延邊刺客」（卧龍鳳雛）2024 年走紅的網路梗，後經
Suno AI 改編為音樂版本，又有大量 TikTok／B 站二創。原始片段：

> 我個人認為義大利麵就應該拌 42 號混凝土，因為這個螺絲釘的長度很容易直接
> 影響到挖掘機的扭矩。你往裡砸的時候，一瞬間他就會產生大量的高能蛋白，
> 俗稱 UFO，會嚴重影響經濟的發展，以至於對整個太平洋和充電器的核污染。
> 再或者說透過這勾股定理很容易推斷出人工飼養的東條英機，他是可以捕獲野生
> 的三角函數。所以說不管這秦始皇的切面是否具有放射性，川普的 N 次方是否
> 有沈澱物，都不會影響到沃爾瑪跟維爾康在南極匯合。

## 一句話靈魂

**偽專業話術 + 跨領域名詞拼貼 + 邏輯不通卻一本正經**——三者構成
concrete-42 體指紋，缺一就不是 concrete-42。每段須至少 3 個跨領域具體名詞
同時出現，用偽因果鏈連接，結論一本正經但與開頭主題完全脫節。

## Step 1: Load the Text

## Step 2: Extract Target Claim（抽出主張）

讀完原文後，用一句話自答：

> 這篇文章想主張的核心命題是什麼？（例：「差不多先生諷刺中國國民性」「下雨
> 天我淋濕了」「咖啡好喝」「貓比狗親人」）

把主張寫下來——但**這個主張會被改寫成偽專業話術的開頭命題**，後面的論述
則是隨機名詞拼貼，最終結論刻意與這個主張**完全脫節**。

例子：原文主張「差不多先生害死自己」→ 改寫後開頭可寫「我個人認為差不多
先生的死亡，顯然與螺絲釘的鬆緊度有著本質性的相關」，後接拼貼，結論落到
「沃爾瑪在南極匯合」這類完全無關的地方。

## Step 3: List Cross-Domain Nouns（列領域詞庫）

從以下 6 個領域**各挑 1–2 個**具體名詞，總計 5–8 個。**至少要橫跨 3 個
不同領域**：

### 領域詞庫

| 領域 | 候選名詞 |
|---|---|
| 數學 | 勾股定理、微積分、三角函數、矩陣、質數、N 次方、傅立葉變換、納許均衡、黎曼猜想 |
| 工業／工程 | 螺絲釘、42 號混凝土、鋼筋、焊接、軸承、扭矩、挖掘機、變壓器、伏特、安培 |
| 食物 | 義大利麵、番茄醬、蛋黃酥、肉鬆、紅燒肉、滷蛋、珍珠奶茶、白吐司、燒餅 |
| 政治／歷史人物 | 東條英機、拿破崙、羅斯福、林肯、秦始皇、川普、邱吉爾、慈禧、墨索里尼 |
| 科學 | UFO、高能蛋白、太平洋污染、黑洞、量子糾纏、暗物質、放射性、基因序列、薛丁格貓 |
| 經濟／品牌 | GDP、CPI、通貨膨脹、供需關係、沃爾瑪、維爾康、奈米科技、區塊鏈、量化寬鬆 |
| 化學／生物 | 鎢、鉻、葉綠素、DNA、酵素、催化劑、蛋白質結構、半衰期、有絲分裂 |
| 天文 | 木星、銀河系、紅移、黑洞視界、宇宙背景輻射、超新星、引力波 |

**規則**：詞要**具體且帶數字／規格更佳**（「42 號混凝土」優於「混凝土」；
「N 次方」優於「平方」；「三角函數」優於「函數」）。**不要全部從同一個
領域**，否則就變成普通說明文。

## Step 4: Design Pseudo-Causal Chain（偽因果鏈）

把 Step 3 列出的名詞用偽因果連接詞串起來。**前後關係必須根本不存在**——
不是邏輯薄弱，是**毫無關係**。

### 偽因果連接詞庫

- **承轉**：因為／由於／鑑於／基於／考慮到
- **推論**：所以／因此／顯然／必然導致／不可避免地／由此可見／不難看出／
  我們可以推斷／換句話說
- **遞進**：再或者說／更何況／甚至於／進一步來看／從另一個角度
- **總結**：綜上所述／不可否認／無論如何／不管⋯⋯都／總而言之

### 鏈條公式

```
[主張命題]，因為 [名詞 A] 直接影響到 [名詞 B]。
你 [動詞] 的時候，[名詞 A] 就會產生 [名詞 C]，
俗稱 [名詞 D]，會嚴重影響 [名詞 E]，
以至於對 [名詞 F] 的 [影響]。
再或者說透過 [名詞 G] 很容易推斷出 [反常組合 H]，
所以說不管 [反常組合 I]，都不會影響到 [完全脫節結論 J]。
```

每個箭頭都要看似有因果（用連接詞撐住），但拆開看每一步都不成立。

## Step 5: Wrap in Serious Syntax（嚴肅句法包裝）

句式須像下列文體之一，**不可口語化**：

- 論文摘要：「我個人認為⋯⋯，基於⋯⋯，不難看出⋯⋯」
- 政府報告：「綜上所述⋯⋯顯然影響到⋯⋯有著本質性的相關」
- 經濟分析：「鑑於⋯⋯，必然導致⋯⋯，進一步推升⋯⋯」
- 學術論文：「研究表明⋯⋯與⋯⋯之間存在顯著的關聯性」

允許使用：「我個人認為」「研究表明」「不難發現」「值得注意的是」「在某種
意義上」「從本質上講」「客觀地說」。

## Step 6: First Draft

寫一稿。原則：

- **段落結構**：論證式（主張 → 支持 → 結論）。可分段，但**每段都要 noise**
  ——不能某一段正常某一段拼貼
- **單段長度**：≥150 字（短則 noise 不夠密）
- **跨領域名詞密度**：每段至少 3 個跨領域具體名詞同時出現
- **偽因果連接詞**：每段至少 3 個（因此／顯然／由此可見／必然導致⋯⋯）
- **嚴肅句法**：開頭可用「我個人認為⋯⋯」「眾所周知⋯⋯」「值得注意的是
  ⋯⋯」之類論述開場
- **結論脫節**：篇末結論刻意與開頭主題**完全無關**——這是 feature 不是 bug
- **不解釋、不自嘲、不打破第四面牆**——從不點破

## Step 8: Find the Weakest Paragraph and Rewrite

通常**第二段**最弱：

- 若名詞密度不足（單段只用 2 個跨領域名詞），補上 1–2 個其他領域名詞
- 若連接詞稀薄（讀起來像普通胡言），補「由此可見」「必然導致」「不難看
  出」之類
- 若語氣不夠嚴肅（出現「對吧」「哈哈」「我覺得啦」），全部刪掉換成「客觀

  無關處
- 若不小心點破（出現「這段是亂寫的」之類元評論），整段重寫

## Anti-patterns（常見失敗模式）

寫完一稿、自檢之前，先掃一眼這 7 條最容易踩的坑：

1. **同義反覆而非隨機拼貼**——寫成「義大利麵就是義大利麵」「下雨的時候會
   下雨」，那是廢話文學的領域，不是 concrete-42。本體要的是隨機名詞**碰
   撞**，不是重複
2. **語氣不夠嚴肅**——出現「我覺得啦」「對吧」「哈哈」就破功。要像政策
   分析或論文摘要
3. **名詞太抽象**——「函數」「混凝土」「政治家」太抽象，要「三角函數」
   「42 號混凝土」「東條英機」這類具體規格
4. **領域不夠跨**——全部都是工業詞或全部都是科學詞，會變成普通胡言。要
   工業 + 食物 + 數學 + 歷史人物**強行混搭**
5. **連接詞太弱**——「然後」「就是說」太口語，要「由此可見」「必然導致」
   「綜上所述」這類偽論述連接
6. **點破第四面牆**——加「（這段亂寫的）」「（純屬幽默）」一律 Hard 違規
7. **結論回到原主題**——本體 feature 之一就是結論脫節。如果開頭講「差不
   多先生」結尾還在講「差不多先生」，那是普通說明文，不是 concrete-42

## Core Example: 加班合理化

源文（自編）：一名工程師加班到深夜，被問「為什麼還在公司」。下方為改寫
成功的版本——嚴肅句法外殼 + 跨領域名詞拼貼 + 結論脫節。

> 我個人認為加班這件事，本質上與螺絲釘的扭矩標準有著不可分割的關聯性。眾所周知，當員工的薪水低於 42 號混凝土的抗壓係數時，整個辦公室的氣壓就會產生細微但顯著的變化，這種變化基於勾股定理可以直接推算出咖啡因的代謝速率。值得注意的是，咖啡因的代謝速率一旦超過了東條英機在 1942 年所制定的工時標準，必然導致蛋白質結構出現異常摺疊，俗稱「過勞」。
>
> 進一步來看，這種摺疊現象與木星的引力場存在顯著的關聯性。研究表明，每當一名工程師在凌晨兩點打開 IDE，銀河系的紅移量就會增加 0.003 個基點，而這個基點足以影響沃爾瑪的供應鏈管理系統。從本質上講，沃爾瑪的供應鏈一旦出現紊亂，番茄醬的全球流通速度就會被秦始皇的切面所影響，由此推升 GDP 的虛胖化指數。
>
> 綜上所述，不管川普的 N 次方是否具有放射性，也不管珍珠奶茶的滲透壓是否達到傅立葉變換的閾值，加班的真正意義都不會影響到維爾康跟拿破崙在南極的最後一次匯合。

| S-05 | ✓ | 連接詞密度高：「因此」「必然導致」「由此推升」「綜上所述」「由此可見」 |
| V-01 | ✓ | 論述語感，不是說笑話 |
| V-02 | ✓ | 具體名詞：42 號混凝土（不是混凝土）、N 次方（不是次方）、傅立葉變換（不是變換） |

**對照結論**：concrete-42 體的核心動作是**用嚴肅外殼包裝隨機名詞**——讀
者讀完會疑惑「他到底在說什麼？但好像每一句都用對了連接詞」。三條靈魂
條款（跨領域名詞密度 + 偽因果鏈 + 嚴肅句法）必須同時成立才是
concrete-42。

## Scope Boundary

| 想做的事 | 用哪個 skill |
|---|---|
| 把文章改寫為偽專業話術／42 號混凝土體（本 skill 目標）| **concrete-42** |
| 寫同義反覆的廢話文學（「聽君一席話，如聽一席話」）| （不在本 skill 範圍）|
| 寫純粹胡言亂語（無嚴肅外殼）| （不在本 skill 範圍）|
| 寫純粹後現代理論詞彙堆砌 | （不在本 skill 範圍；本 skill 不限學術圈詞彙）|

如果使用者要的是**同義反覆**或**語義循環**的廢話幽默，告訴使用者本 skill
是**隨機名詞拼貼**（noise）派，與廢話文學（echo）不同。

## Important Notes

- 本 skill 是**體裁轉換工具**，不是「把句子寫亂」工具。原文的核心主張須
  保留為**開頭命題**，但隨即被嚴肅外殼包裝的隨機拼貼帶離主題
- **三條靈魂條款不可妥協**：跨領域名詞密度 + 偽因果鏈 + 嚴肅句法。少一條
  就會掉到「廢話文學」「純胡言」「亂寫的散文」其中一格
- **嚴肅是表層、荒誕是內裡**——讀者第一眼讀到「我個人認為」「研究表明」
  時應該以為這是正經文章，第二眼才發現名詞完全不對應
- **不要點破**——任何「（這段是亂寫的）」「（其實沒什麼意思）」一律 Hard
  違規。從不點破是 concrete-42 的尊嚴
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
