# concrete-42 — 改寫成「義大利麵就應該拌 42 號混凝土」體

把任何文章改寫成偽專業話術——句式像論文摘要、政府報告或經濟分析，但內容
是跨領域具體名詞的隨機拼貼，配上偽因果連接詞，讀完讓人疑惑「他在說什麼？
但又好像很有道理」。

## 什麼是「義大利麵就應該拌 42 號混凝土」體？

源自抖音／B 站「延邊刺客」（卧龍鳳雛）2024 年走紅的網路梗，後經 Suno AI
改編為音樂版本，又有大量 TikTok／B 站二創。原始片段：

> 我個人認為義大利麵就應該拌 42 號混凝土，因為這個螺絲釘的長度很容易直接
> 影響到挖掘機的扭矩。你往裡砸的時候，一瞬間他就會產生大量的高能蛋白，
> 俗稱 UFO，會嚴重影響經濟的發展，以至於對整個太平洋和充電器的核污染。
> 再或者說透過這勾股定理很容易推斷出人工飼養的東條英機，他是可以捕獲野生
> 的三角函數。所以說不管這秦始皇的切面是否具有放射性，川普的 N 次方是否
> 有沈澱物，都不會影響到沃爾瑪跟維爾康在南極匯合。

該博主被網友戲稱為「水鏡先生」「知識攪拌機」——用一本正經科普的語氣，說
著毫無關聯的話。

`concrete-42` 鎖定這種風格的核心 DNA：**偽專業話術 + 跨領域名詞拼貼 + 邏輯
不通卻一本正經**。

## 與廢話文學的差異

| 軸線 | 廢話文學 | concrete-42 |
|---|---|---|
| 機制 | **同義反覆**（echo）| **隨機名詞拼貼**（noise）|
| 例句 | 「聽君一席話，如聽一席話」「西紅柿吃起來有番茄味」 | 「義大利麵就應該拌 42 號混凝土」 |
| 邏輯 | 語義上有迴圈、句式完整 | 故意打破邏輯、隨機名詞亂組合 |
| 笑點 | 你說了等於沒說 | 你說了我聽不懂但你看起來很懂 |

兩者都製造幽默，但走向相反——廢話文學是「重複」的藝術，concrete-42 是
「碰撞」的藝術。

## 一句話靈魂

**偽專業話術 + 跨領域名詞拼貼 + 邏輯不通卻一本正經**——三者構成 concrete-42
指紋，缺一就不是 concrete-42。每段須至少 3 個跨領域具體名詞同時出現，用偽
因果鏈連接，結論一本正經但與開頭主題完全脫節。

## 風格特徵

- **嚴肅外殼**：句式像論文摘要、政府報告、經濟分析，「我個人認為」「眾所
  周知」「研究表明」「值得注意的是」「綜上所述」
- **跨領域名詞**：數學定理、工業規格、食物、歷史人物、物理化學、經濟術語
  等跨領域強行混搭
- **具體規格**：「42 號混凝土」優於「混凝土」；「N 次方」優於「次方」；
  帶數字／型號／規格的名詞更佳
- **偽因果鏈**：用「因為／因此／顯然／必然導致／由此可見」連接，但前後關係
  根本不存在
- **結論脫節**：篇末結論刻意與開頭主題完全無關——這是 feature 不是 bug

## 不會做的事

- 不寫同義反覆的廢話文學（那是另一種幽默體系）
- 不寫純粹胡言亂語（concrete-42 必須有嚴肅外殼）
- 不口語化、不賣萌、不加 emoji
- 不點破第四面牆（不加「（這段亂寫的）」之類元評論）
- 不只用單一領域詞彙（必須跨領域）

## 預期輸出篇幅

繁體中文論述語感，依原文長度調整：

| 原文長度 | concrete-42 目標 |
|---|---|
| 短（< 200 字）| 200–400 字 |
| 中（200–800 字）| 400–800 字 |
| 長（800+ 字）| 取單一主張寫 600–1000 字 |

低於 150 字的單段無法承載足夠的跨領域名詞密度。

## 適合的源文

- 任何主張清晰的短文（議論、抒情、敘事都可以）
- 哲學散文／議論文（核心命題明確最佳）
- 寓言／諷刺寓言（《差不多先生》《狂人日記》）
- 個人軼事、生活敘事
- 任何「有觀點要表達」的文字

## 不太適合的源文

- 純技術文件、API 說明（已經很跨領域，效果不顯）
- 純抒情詩（沒有可拼貼的明確命題）
- 已經是廢話文學或胡言體的源文（改寫意義不大）

## 運作流程

1. **讀原文 + 抽主張** — 一句話自答：「這篇想主張的核心命題是什麼？」
2. **列領域詞庫** — 從 6+ 個領域挑 5–8 個具體名詞（橫跨 ≥3 領域）
3. **設計偽因果鏈** — 用偽因果連接詞串起，前後關係根本不存在
4. **嚴肅句法包裝** — 像論文摘要／政府報告／經濟分析
5. **第一稿** — 三段論證式，每段 ≥150 字，每段都要 noise
6. **Checklist 自檢** — 21 條（Hard 16 + Soft 5）
7. **抓最弱段重寫** — 通常是名詞密度不足或語氣不夠嚴肅
8. **檢查結論是否脫節** — 篇末必須與開頭主題完全無關
9. **輸出** — 寫入 `<原檔名>_concrete42.md`

## 改寫原則（checklist 摘要）

| 類別 | 編號 | 要點 |
|------|------|------|
| Content | C-01~C-05 | 三條靈魂俱全、跨領域名詞密度 ≥3、偽因果鏈、嚴肅句法、結論脫節 |
| Structure | S-01~S-05 | 篇幅依原文、論證式段落、單段 ≥150 字、嚴肅句法、連接詞密度 ≥3 |
| Voice | V-01~V-05 | 論述語感、具體名詞、論述開場詞、偽科普句式、不可口語化 |
| Meta | M-01~M-06 | 不附評論、從不點破、不揭示是胡言、不模仿廢話文學、不模仿純胡言 |

完整 21 項 checklist 與 9 步 workflow 見 [SKILL.md](./SKILL.md)。

## 三條靈魂條款

concrete-42 體的指紋：

1. **C-02 跨領域名詞密度** — 至少 3 種不同領域具體名詞同時出現
2. **C-03 偽因果鏈** — 用因果連接詞串，但前後關係根本不存在
3. **C-04 嚴肅句法包裝** — 像論文摘要／政府報告／經濟分析，不可口語化

三者缺一就不是 concrete-42。其餘 18 條 checklist 都在服務這三條。
