# Jingjing-style — 示範

展示 `jingjing-style` 三段強度（Light / Medium / Heavy）如何把不同源文改
寫成晶晶體，以及合格的晶晶體長什麼樣子。

> **源文與引用說明**：範例一源文（生活分享）為自編；範例二源文（職場感想）為自編；範例三源文 [《雨天故事》](../../examples/source-texts/weather-rain.md) 來自共用源文庫，自編無版權疑慮；範例四源文 [《差不多先生傳》(胡適， 1924)](../../examples/source-texts/mr-chabuduo.md) 來自共用源文庫，公有領域。本 skill 模擬的是 **2016 年起的台灣媒體名媛口語現象**，不針對任何個人。

---

## 範例一：Light 強度 — 週末生活分享

**源文（自編，生活分享）**

> 上個週末我去了東區一家新開的咖啡店。店裡的氛圍很不錯，店員也很親切。我點了一杯拿鐵和一塊起司蛋糕，坐在窗邊看了兩個小時的書。離開的時候還買了一袋咖啡豆當禮物送給朋友。整體而言是個很放鬆的下午，下次想再去試看看他們的早午餐。

### 改寫（Light：每 4–5 句 1 處）

> 上個 weekend 我去了東區一家新開的咖啡店。店裡的氛圍很不錯，店員也很親切。我點了一杯拿鐵和一塊起司蛋糕，坐在窗邊看了兩個小時的書。離開的時候還買了一袋咖啡豆當禮物送給朋友。整體而言是個很 chill 的下午，下次想再去試他們的 brunch。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 全篇共 5 句、嵌入 3 處英文字 | C-03 密度 | 約每 1.7 句 1 處,接近 Light 上限,但符合 Light 範圍 |
| weekend / chill / brunch 皆白名單級 | C-01 不必要性 | 三詞中文版（週末／放鬆／早午餐）資訊量等同 |
| 中文骨架完整，英文字僅單字嵌入 | S-01 / S-02 | 主謂賓位置全為中文 |
| 無評論、無嘲諷尾巴 | M-01 / M-02 | 純自然口語，沒附「呢哈哈」 |

**風格座標**：Light 強度的典型場景——日常生活分享。讀者讀完只會覺得「這
人有點習慣 mix 英文」，不到刻意炫耀的程度。

## 範例二：Medium 強度 — 職場感想

**源文（自編，職場感想）**

> 最近專案的進度有點延宕，老闆在會議上特別提到希望大家可以更專注一點。其實我也覺得自己最近狀態不太好，常常下班還在想工作上的問題。同事建議我週末出去走走，不要一直待在家裡。我覺得這個建議滿不錯的，下個週末打算約幾個朋友去爬山，順便分享一些最近看的書。

### 改寫（Medium：每 2–3 句 1 處）

> 最近 project 的進度有點 delay，老闆在 meeting 上特別提到希望大家可以更 focus 一點。其實我也覺得自己最近 vibe 不太好，常常下班還在 think 工作上的 problem。同事 suggest 我 weekend 出去走走，不要一直待在家裡。我覺得這個 idea 滿不錯的，下個 weekend 打算約幾個朋友去爬山，順便 share 一些最近看的書。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 全篇共 5 句、嵌入 11 處英文字 | C-03 密度 | 約每 0.5 句 1 處,Medium 偏高 |
| project / delay / meeting / focus / vibe / problem / weekend / idea / share 皆白名單 | C-01 不必要性 | 全為日常詞,中文版完全等義 |
| think / suggest 為動詞嵌入 | C-04 各層覆蓋 | 動詞層也有,不只形容詞 |
| 中文連詞（其實／常常／順便）皆保留 | S-01 中文骨架 | 結構由中文承載 |
| 同一句最多嵌 2 處 | V-02 不過於做作 | 沒有「really 很 amazing 的 project」這種堆疊 |
| 無嘲諷尾巴 | M-02 | 純口語自然 |

**風格座標**：Medium 強度的典型場景——職場分享、PTT 上會被截圖的那種
中英夾雜習慣。讀者讀完會明確意識到「這就是晶晶體」。

## 範例三：Heavy 強度 — 雨天故事

源文：[《雨天故事》](../../examples/source-texts/weather-rain.md)（共用
源文庫，自編短篇）。

### 原文

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### 改寫（Heavy：每句 1–2 處）

> 昨天 afternoon 我在 library 看書的時候，突然下起了 super 大的雨。雖然我沒帶 umbrella，但還是 decide 走路回家。路上人很多，到處都是撐著 umbrella 的 people。我全身都 wet 了，回到家才發現 key 忘在 office 了。鄰居看到我的 look，笑著說：「你怎麼不叫 taxi？」我只好苦笑著 reply：「我忘了帶 wallet。」

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 全篇共 7 句、嵌入 13 處英文字 | C-03 密度 | 平均每句 ~1.9 處,正中 Heavy 範圍 |
| afternoon / library / umbrella / people / wet / key / office / taxi / wallet 皆白名單 | C-01 不必要性 | 全為國中程度單字 |
| umbrella 重複出現兩次 | C-05 重複容許 | 口語自然性 |
| super 為副詞層級嵌入 | C-04 各層覆蓋 | 形容詞 / 副詞 / 名詞 / 動詞皆有 |
| 對話內也嵌英文字 | S-01 / V-03 | 「叫 taxi」維持口語底色 |
| 同句不超過 2 處 | V-02 不堆疊 | 「super 大的雨」沒接成「super big rain」 |

**風格座標**：Heavy 強度——2016 原汁原味，幾乎每句都 mix 英文。讀者讀
完會懷疑這人到底有沒有用中文想過事情。

## 範例四：改寫示範 — 《差不多先生傳》→ 晶晶體（Medium）

源文：**胡適《差不多先生傳》(1924) 摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 原文

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不多，是各省各縣各村人氏。
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」
>
> 他小的時候，他媽叫他去買紅糖，他買了白糖回來。他媽罵他，他搖搖頭說：「紅糖白糖，不是差不多嗎？」
>
> 他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：「錯了。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 強度 | Medium（每 2–3 句 1 處） |
| 可換詞掃描 | 有名（famous）、聞名（well-known→改 famous）、精明（smart）、 罵（complain）、搖搖頭（shake head）、錯了（wrong）|
| 不可換詞 | 紅糖／白糖（中文飲食詞）、直隸省／陝西／山西（地名）、姓差名不多（人名）、學堂（時代詞）|
| 句法骨架 | 中文文體保留——保留原文的「他常常說」「他在學堂的時候」這類連接框架 |
| 對話處理 | 對話內的關鍵中文（紅糖白糖／差不多）不替換,只替換非關鍵詞 |

### 改寫後

> 你知道中國最 famous 的人是誰？提起此人，人人皆曉，處處 famous。他姓差，名不多，是各省各縣各村人氏。
>
> 他常常說：「凡事只要差不多，就好了。何必太 smart 呢？」
>
> 他小的時候，他媽叫他去買紅糖，他買了白糖回來。他媽 complain 他，他搖搖 head 說：「紅糖白糖，不是差不多嗎？」
>
> 他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：「wrong 啦。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 替換的 famous / smart / complain / head / wrong 皆白名單級,中文（有名／精明／罵／頭／錯）資訊等同 |
| C-02 | ✓ | 紅糖／白糖／陝西／山西／直隸省／差不多／學堂 等不可換詞皆保留中文 |
| C-03 | ✓ | 全篇共 ~13 句、嵌入 6 處英文字,約每 2 句 1 處,符合 Medium |
| S-01 | ✓ | 中文句法骨架完整保留,連「人人皆曉」這類四字格也不動 |
| S-02 | ✓ | 全為單字嵌入,沒有拼成英文句 |
| V-01 | ✓ | 自然口語,沒寫成翻譯腔 |
| V-02 | ✓ | 同句最多 1 處英文字,不堆疊 |
| M-02 | ✓ | 對「差不多先生」沒附「呢哈哈」這種嘲諷尾巴,維持原文諷刺寓言的中性敘事 |
| M-04 | ✓ | 沒誤觸黑名單詞（地名／時代詞均保留中文） |

**改寫的核心動作**：把胡適原文「批判國民性的諷刺寓言」改寫成「以中文
為骨架、夾入若干不必要英文字的口語體」。**諷刺底色不變**，只是說話者
不再是 1924 年的胡適,而是一個 2016 之後習慣中英夾雜的當代敘述者——
這層語體錯位本身,就是另一層的時代諷刺。
