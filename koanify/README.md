# Koanify — 改寫成敘事禪宗公案

把任何文章改寫成「敘事故事型禪宗公案」(白隱「是這樣嗎?」流派)。

不是把文字塞進文言外殼,不是寫機鋒短答,而是**寫成一則有完整人物、場景、
動作的故事**——讀完讓人停一下,不知道要說什麼,但又像被輕輕點了一下。

## 什麼是敘事型公案?

公案(gōng'àn)源自唐宋禪宗,被結集為《無門關》《碧巖錄》《從容錄》《景德
傳燈錄》《五燈會元》等典籍,是禪師接引學人的對話與事件記錄。從文體角度公
案大致可分四類:

| 類型 | 特徵 | 範例 |
|---|---|---|
| 機鋒問答型 | 兩三句一問一答,字義斷裂 | 趙州狗子(無)、庭前柏樹子 |
| **敘事故事型** | 有場景、有動作、有過程 | 婆子燒庵、香嚴擊竹、白隱「是這樣嗎」 |
| 拈古頌古型 | 後人對前公案的詩偈評語 | 雪竇《頌古百則》 |
| 後世改寫型 | 近代禪師的擬作 | 鈴木大拙、Reps & Senzaki 收錄 |

`koanify` 鎖定第二類——**敘事故事型**。最具代表性的近代範本是白隱禪師
「是這樣嗎?」(Reps & Senzaki *101 Zen Stories* #3):被誣為孩子之父,
他只說「是這樣嗎?」獨自撫養孩子一年;真相大白後將孩子歸還,仍只說「是
這樣嗎?」——禪意全在那兩次重複的同一句話之間,沒有任何說理。

## 風格參考

- **白隱「是這樣嗎?」**(《101 Zen Stories》#3)— 重複句留白、平淡敘述、
  結尾不下結論
- **婆子燒庵**(《五燈會元》卷六)— 第三方裁決、僧-婦人配置、反角色設定
  (婆子比僧更高明)
- **南泉斬貓**(《無門關》第 14 則)— 無聲動作回應(趙州脫履安頭上而出)
- **香嚴擊竹**(《景德傳燈錄》)— 時間跳躍式結構、物理事件做悟的隱喻、
  瞬間開悟

## 不會做的事

- 不寫「狗子佛性」式的兩句機鋒(那是不同文體,不是 koanify 的目標)
- 不寫《古文觀止》式的優美駢文(過度文言反而失去禪味)
- 不在結尾加「這告訴我們⋯⋯」(禪宗最大的禁忌)
- 不把現代專名留下來(「賈伯斯問老僧」會讓整篇崩潰)
- 不把禪師寫成 AI 慈祥老人(禪師可以冷酷、暴躁、不答)

## 預期輸出篇幅

繁體中文白話偏雅,**150–400 字**,平均約 250 字。低於 80 字會落入機鋒型,
超過 500 字會偏散文化。

如果原文超過 1500 字,只取一個主題改寫,不硬塞所有內容。

## 適合的源文

- 哲學散文 / 議論文(需先抽核心張力)
- 寓言 / 童話(《小王子》《愛麗絲》)
- 個人軼事(短篇散文、blog 文)
- 學術論文摘要(進階用法)

## 不太適合的源文

- 充滿現代專名 / 科技 / 政治的新聞報導(去脈絡化代價太高)
- 純抒情詩(沒有可改寫的張力)
- 已經是公案 / 寓言 / 古典短篇的源文(改寫意義不大)

## 運作流程

1. **讀原文 + 抽張力** — 一句話自答:「這篇的『問』是什麼?『應』在哪裡?」
2. **主題抽象化** — 若是現代主題,換成前現代等價物(網路成癮 → 流連市集)
3. **角色設計** — 從六種配置選一(預設避開師-徒)
4. **結構選擇** — 三段式 / 雙段式 / 三疊式 / 時間跳躍式 / 倒裝式
5. **留白選擇** — 從留白八式中選一主一輔
6. **第一稿** — 目標 250 字、白話偏雅、敘述比 ≥50%
7. **Checklist 自檢** — 23 條(Hard 13 + Soft 10)
8. **抓最弱段重寫** — 通常是結尾(容易說教)
9. **輸出** — 寫入 `<原檔名>_koan.md`,純公案、不附說明

## 改寫原則(checklist 摘要)

| 類別 | 編號 | 要點 |
|------|------|------|
| Content | C-01~C-05 | 保留核心張力、禁現代專名、禁現代物件、角色多樣化、永恆主題優先 |
| Structure | S-01~S-06 | 篇幅 150–400 字、敘述比 ≥50%、用留白八式、避免機械三段、結尾不下結論、譬喻節制 |
| Voice | V-01~V-05 | 白話偏雅、禁心理描述、多具體名詞、句子簡短、不用第一人稱敘事 |
| Meta | M-01~M-05 | 不附評論段、保留禪師可不慈祥、角色取無名、三人稱限知、議論文必須先抽張力再設場景 |

完整 21 項 checklist 與 9 步 workflow 見 [SKILL.md](./SKILL.md)。

## 留白八式

敘事型公案的結尾收束手法:

| 編號 | 名稱 | 公案範例 |
|---|---|---|
| 1 | 重複句 | 是這樣嗎?(白隱) |
| 2 | 無聲動作 | 趙州脫履安頭(南泉斬貓) |
| 3 | 答非所問 | 庭前柏樹子、麻三斤 |
| 4 | 棒喝 | 俱胝斷指、德山棒、臨濟喝 |
| 5 | 笑 | 拈花微笑 |
| 6 | 走 | 趙州勘婆「便去」 |
| 7 | 場景轉移 | 香嚴擊竹後寫「動容揚古路」 |
| 8 | 第三方裁決 | 婆子燒庵、鄧隱峰妹妹推之而僕 |

每則改寫**必擇一式為主**,可加一輔助式,**不超過兩式**。
