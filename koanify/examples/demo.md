# Koanify — 示範

展示 `koanify` 如何把現代文章改寫成敘事禪宗公案，以及好的敘事公案長什麼樣
子。本 skill 沒有強度分層，單一目標：**敘事故事型公案**(白隱「是這樣嗎？」
流派)。

> **源文說明**：範例三的源文 [《差不多先生傳》(胡適， 1924)](../../examples/source-texts/mr-chabuduo.md) 
> 來自共用源文庫，公有領域。範例一、二為古典公案原典，作為「目標範例」展示
> 風格，不屬於本 skill 的輸出產物。範例四為自編現代軼事 + 對照改寫。

---

## 範例一：風格目標 — 白隱「是這樣嗎？」

這是 koanify 的「品牌公案」——直接示範敘事公案最純粹的樣態：重複句留白、
平淡敘述、結尾不下結論、永恆主題(名譽 vs 平等心)。

### 原典(Reps & Senzaki， *101 Zen Stories* #3，本研究自譯)

> 鄰里皆讚白隱禪師持戒清淨。
>
> 隔壁開食肆的人家，有個漂亮的女兒。某日她父母忽然發現她有了身孕，大為震
> 怒。逼問之下，女兒最後說出名字——白隱。
>
> 父母怒氣沖沖上門理論。白隱只說了一句：「是這樣嗎？」
>
> 孩子出生後被送到白隱那裡。他的聲譽已盡毀，但他不以為意，把孩子照顧得很
> 好——奶水四處去鄰居家化、孩子需要的一切也是托缽得來。
>
> 一年後，女兒終於忍不住，向父母吐實：孩子真正的父親，是魚市場的一個年輕人。
>
> 女兒父母立刻趕到白隱處，長跪請罪，要把孩子接回去。
>
> 白隱把孩子交還，只說了一句：「是這樣嗎？」

### 結構標註

| 段落 | 功能 | 字數(估) |
|---|---|---:|
| 鄰里皆讚⋯⋯ | 事起(背景：聲譽) | 約 30 |
| 隔壁⋯⋯逼問⋯⋯ | 事起(被誣) | 約 60 |
| 父母怒氣沖沖⋯⋯「是這樣嗎？」 | 第一次留白(重複句 之一) | 約 30 |
| 孩子出生後⋯⋯ | 對峙(獨自撫養) | 約 50 |
| 一年後⋯⋯吐實 | 反轉 | 約 30 |
| 父母趕到⋯⋯「是這樣嗎？」 | 第二次留白(重複句 之二) | 約 40 |

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 「是這樣嗎？」首尾呼應 | S-03 留白八式：**重複句** | 同一句話在「被誣」與「真相」兩種情境出現，迫使讀者比較 |
| 全篇沒有「白隱於是大悟」 | S-05 結尾不下結論 | 禪意全在那兩句重複裡，完全不解釋 |
| 「他不以為意」(無進一步描寫) | V-02 禁心理描述 | 只用「四處化奶水」「托缽」這些**動作**表現他的態度，不寫「他並不憤怒」 |
| 永恆主題：名譽 vs 平等心 | C-05 永恆主題優先 | 不涉時代，任何讀者皆可進入 |
| 角色配置：僧 - 俗(夫婦) | C-04 多樣化 | 不是師徒問答，是僧與一對父母 |

## 範例二：風格目標 — 婆子燒庵

示範「**反角色設定**」與「**第三方裁決**」——禪師(庵主)在這則公案裡
**犯錯**，而下判斷的是**沒有出家的老婦人**。這顛覆了「老和尚總是高明」的
套路，正是 koanify 的 M-02。

### 原典(《五燈會元》卷六，文言)

> 一婆子供養一庵主，凡二十年。常令一二八女子送飯給侍。一日令女子抱定，曰：
>「正恁麼時如何？」主曰：「枯木倚寒巖，三冬無暖氣。」女子歸舉似婆。婆曰：
>「我二十年只供養得個俗漢！」遂遣出，燒卻庵。

### 白話偏雅(本研究改譯)

> 有位老婆子供養一個出家人在自己土地上的小庵裡修行，前後二十年。她每日讓
> 一個十六歲的女子去送飯。
>
> 某日，婆子吩咐女子：「妳去，抱住他，問他：『此時如何？』」
>
> 女子照做。庵主答：「枯木倚寒巖，三冬無暖氣。」
>
> 女子回報。婆子勃然大怒：「我二十年來，竟然只養了個假道學！」當下趕走庵
> 主，把庵燒了。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 庵主「枯木倚寒巖」答得「太正確」 | C-01 核心張力 | 道學的正確 vs 慈悲的當下——二者在公案裡是對立的 |
| 婆子下判、燒庵作結 | S-03 留白八式：**第三方裁決 + 動作** | 不是禪師說「你錯了」，是婆子直接燒掉場所 |
| 沒有「庵主於是醒悟」 | S-05 結尾不下結論 | 庵主錯沒錯、錯在哪，讀者自己想 |
| 婆子勃然大怒(動作) | V-02 禁心理 vs 動作 | 「勃然大怒」是動作 + 表情，**不是內心戲**(沒寫「她感到失望」) |
| 角色配置：僧 - 婦人 - 少女(三角) | C-04 多樣化 | 不是師徒，是「庵主 - 老婦 - 送飯少女」三方張力 |
| 婆子比庵主更高明 | M-02 反慈祥 | 證明禪師可以**不**是公案裡最有道行的人 |

**關鍵技巧**：用「**第三方裁決者**」(婆子而非禪師)做評斷，顛覆師徒結
構——這是 koanify 對「師-徒」配置的反例，可作為改寫時跳脫套路的參考。

## 範例三：改寫示範 — 現代軼事(失敗版 vs 成功版對照)

源文(自編)──**現代軼事**：

> 一名工程師接到三天內交專案的死線，連夜加班寫出醜陋的程式碼，事後花更多時
> 間重構，最後產品被取消。

下面用同一段源文，做兩種改寫對照：**失敗版**犯了多項 [Hard] 規則；**成功
版**通過完整 checklist。

### 失敗版(Before)

> 從前有個叫小明的程式設計師，接到老闆要求要在三天內寫完一個專案。他**廢
> 寢忘食地敲打鍵盤**，終於在最後一刻交出。但程式碼又**亂又難維護**，他後悔
> 莫及，**心裡感到無限焦慮**。他花了更多時間重構，但兩個月後，**老闆告訴他
> 這個產品取消了**。
>
> **小明跪倒在地，終於明白：急於求成，反而失去了一切。從此以後，他學會了
> 慢工出細活的道理。** 這個故事告訴我們：**真正的快，是慢。真正的慢，是快。**

**犯規清單**

| 編號 | 違反 | 出處 |
|---|---|---|
| C-02 | 現代專名 | 「程式設計師」「鍵盤」「專案」「老闆」「重構」 |
| C-05 | 時代性主題沒抽象化 | 「截止日 / 加班」 |
| S-05 | 結尾下結論 | 「終於明白」「從此以後，他學會了⋯⋯」 |
| V-02 | 心理描述濫用 | 「廢寢忘食」「無限焦慮」「後悔莫及」 |
| M-01 | 評論段附在公案後 | 「這個故事告訴我們⋯⋯」 |

### 成功版(After)

> 山下村中，有個年輕木匠，受託在三日內為祠堂雕一尊神像。
>
> 他在燈下日夜不寐，刀痕急亂。第三日交出時，木屑滿地，神像的眉眼處有刀偏
> 的一道。村人接過，眾目相視。
>
> 木匠回到工坊，把神像借回，夜夜重雕，半月而成。再送至祠堂時，廟祝接過，
> 放在桌上，看了一眼，只說：「祠堂前日已拆。」
>
> 木匠抱著神像，沿原路走回村口。路邊一個老婦人正在曬芝麻，抬頭看了他一眼。
>
> 木匠在路邊坐下，把神像放在身旁。
>
> 風吹過，芝麻一粒一粒落到地上。

**達標清單**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-02 | ✓ | 無現代專名：木匠 / 祠堂 / 神像皆前現代 |
| C-04 | ✓ | 配置：工匠 - 廟祝 - 老婦人(僧-俗變體) |
| C-05 | ✓ | 主題抽象化：加班趕工 → 急於求成、名譽、失落 |
| S-01 | ✓ | 約 220 字，在 150–400 區間 |
| S-02 | ✓ | 敘述為主；對話只有「祠堂前日已拆」一句 |
| S-03 | ✓ | **主留白 = 場景轉移**(從工坊轉到路邊曬芝麻)；**輔留白 = 無聲動作**(老婦人看了一眼、木匠坐下、芝麻落地) |
| S-04 | ✓ | 「努力 - 重做 - 落空 - 路邊」四段不對稱結構 |
| S-05 | ✓ | 結尾無結論，純粹場景：「風吹過，芝麻一粒一粒落到地上」 |
| V-02 | ✓ | 無心理描述(沒寫「他感到絕望」「他幡然醒悟」) |
| M-01 | ✓ | 無評論段 |
| M-02 | ✓ | 老婦人不安慰、不開示——只是看了他一眼(反慈祥) |

**對照結論**：好的敘事公案不是把訓誨包在故事外殼裡，而是**讓事件本身承擔
語言無法承擔的東西**——「芝麻一粒一粒落到地上」沒有意義，但讀完整篇，你
會知道。

## 範例四：改寫示範 — 《差不多先生傳》→ 公案

源文：**胡適《差不多先生傳》(1924)摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 原文(Before)

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不多，
> 是各省各縣各村人氏。⋯⋯
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」
>
> 他小的時候，他媽叫他去買紅糖，他買了白糖回來。他媽罵他，他搖搖頭說：
>「紅糖白糖，不是差不多嗎？」
>
> 他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：
>「錯了。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」

(原文採取**諷刺寓言**體例，雖人物虛構，但結構直白、訓誨明顯——「差不多
先生」是國民性的擬人化批判。)

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽張力 | 「差不多」是一種放棄區分的執著——表面隨和，實則消解一切判準。死亡是這種執著的終局，但「差不多」會在他死後仍然繼續 |
| 主題抽象化 | 源文已是前現代設定(民初鄉土)，不需現代→古代的轉譯，但要去諷刺化、去訓誨化 |
| 角色配置 | 老者 - 村人 - 牛醫 - 鄉長(僧-俗變體，源文本有「牛醫」可保留) |
| 結構 | 三疊式(三次「差不多」對答)+ 反轉(死)+ **弔唁中三人 echo** + 場景轉移(兩糖罐) |
| 留白手法 | **主 = 重複句**(老者生前三次「差不多」，死後鄰人弔唁時又有三人 echo)；**輔 = 場景轉移**(月光下廳堂兩糖罐並列，無人記得開過哪個——直接 callback 開頭「紅糖白糖」之問) |

### 改寫後(After)

> 山下村中，有個老者，人稱「差不多公」。
>
> 凡有人問他：紅糖白糖差幾何？他答：「差不多。」
> 問：陝西山西差幾何？他答：「差不多。」
> 問：今日明日差幾何？他答：「差不多。」
>
> 一日老者得急病，家人急去請王大夫。王大夫適出。慌亂之間，從鄰巷請來牛醫。
> 牛醫至，老者氣喘曰：「王⋯⋯王大夫不在？」家人答：「牛醫已在門外。」老者
> 點頭：「醫人醫牛，差不多吧⋯⋯」
>
> 牛醫拿銀針，在老者身上扎了幾下。老者氣絕。
>
> 鄰里來弔。一童子問人群：「老者生前最常說什麼？」
>
> 一人答：「差不多。」
> 又一人答：「差不多。」
> 又一人答：「差不多。」
>
> 童子點頭，遂去。
>
> 月光照進廳堂。桌上紅糖罐、白糖罐並列，無人記得開過哪一個。

(約 240 字)

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留「差不多」作為核心張力；原文的諷刺被轉化為公案的留白 |
| C-02 | ✓ | 無現代專名 |
| C-04 | ✓ | 配置：老者 - 家人 - 牛醫 - 鄉長(僧-俗變體) |
| C-05 | ✓ | 永恆主題：對「分」的執著(或反向的：對「不分」的執著) |
| S-01 | ✓ | 約 240 字 |
| S-02 | ✓ | 敘述為主；對話為老者與家人的問答，簡短 |
| S-03 | ✓ | **主留白 = 重複句**(生前三次、弔唁三 echo)；**輔留白 = 場景轉移**(月光 + 兩糖罐 callback 開頭) |
| S-04 | ✓ | 三疊式 + 死亡反轉 + 弔唁餘響，非機械三段 |
| S-05 | ✓ | 結尾「無人記得開過哪一個」純粹場景，無結論 |
| V-01 | ✓ | 白話偏雅，有「曰」「鄰里」「老者」等少數雅字 |
| V-02 | ✓ | 無心理描述(沒有「老者感到滿足」這類) |
| V-03 | ✓ | 具體名詞：銀針、糖罐、月光、廳堂 |
| M-01 | ✓ | 無評論段——胡適原文的訓誨意味在此被收回 |
| M-02 | ✓ | 鄰里、童子均不是慈祥老和尚式的開示者——「差不多」在他死後依舊活著，無人從這個故事裡走出 |

**改寫的核心動作**：把胡適原文「明寫的諷刺」轉為「不寫但自現的批判」。
公案不講「差不多」的壞，只讓「差不多」**在他死後依舊有人接著說，糖罐也
依舊並列**——讀者會自己感到那份冷意。

## 速查：Checklist 重點

21 條中最常踩的：

| 編號 | 規則 | 怎麼用 |
|---|---|---|
| C-02 | 禁現代專名 | 「工程師」→「木匠」；「老闆」→「東家」；「公司」→「商號」 |
| C-05 | 永恆主題優先 | 「加班」→「趕工」；「滑手機」→「流連市集」 |
| S-03 | 留白八式擇一 | 寫之前明確寫下「主 = X、輔 = Y」 |
| S-05 | 結尾不下結論 | 把最後一句刪掉，看故事是否更完整 |
| V-02 | 禁心理描述 | 「他很憤怒」→ 寫他做了什麼動作 |
| M-01 | 不附評論段 | 寫完不要加「這個故事告訴我們⋯⋯」 |
| M-02 | 禪師可不慈祥 | 讓老者也是有缺陷的人，不要寫成全知開示者 |

完整 21 項與 9 步流程見 [SKILL.md](../SKILL.md)。
