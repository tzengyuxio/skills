# laogao-style — 改寫成老高與小茉(Mr & Mrs Gao)風格神秘解說體

把任何文章改寫成「老高與小茉」(Mr & Mrs Gao)這類華語 YouTube 上自
2010 年代後期定型的「神秘 / 都市傳說 / 失落古文明 / 未解之謎」口播
風格。

不是「給句子加幾個感嘆詞」、不是「把文章寫成假新聞」、更**不是真實
神秘事件考據**——而是**保留原文事實骨架，以 narrator 主軸推進 +
(可選)reactor 偶爾插話的口播結構重新承載**:讀完讓人覺得自己剛剛
看完一支 30 分鐘的影片，大腦塞滿了不知真假的「巧合」與「不為人知的
真相」,但每一個具體年代、人名、數字仍然是原文事實。

風格參照：**老高與小茉 / Mr & Mrs Gao 頻道**自 2018 年至今的影片結構
與口播節奏。相關華語 YouTube 同類型創作者：自說自話的總裁、馬臉姐、
腦洞烏托邦、曉涵哥來了等。

## 一句話靈魂

**標題情緒中括號 + N 分鐘講完承諾 + 兩到三層逗號層疊懸念 +
narrator 主軸推進(數字戲劇化 + 未解修辭 + 巧合修辭)+ 可選 reactor
偶爾插話 + 賣關子節奏 + 跳躍式關聯 + 個人觀點 + 免責子句 + 訂閱結尾
三件套 + 文末 disclaimer**——事實骨架不動，情緒拉滿四件套，但所有
權威必須是原文已有的，不可憑空偽造。

## 兩種輸出模式：Solo vs Duo

此 skill 支援兩種結構選擇，**Step 2.5 必選一**:

| 模式 | 結構 | 適用場合 | reactor 規則 |
|---|---|---|---|
| **Solo** | 純 narrator 說書腔 | 主題密度高、需專注推進的長篇 | reactor 不出現也合格 |
| **Duo** | narrator 主軸 + reactor 偶爾插話 | 文章長、有自然氣口可調節節奏 | reactor 反應 ≥ 5 處(Hard)|

**對話比例(Duo 模式)**:narrator 約佔 80–90%,reactor 約佔
10–20%——reactor 是**氣氛調節 + 話題轉換**用，不是平等對話。

## 四條鐵律(必讀)

1. **集體文類致敬，不模仿個人語癖** — skill 命名以致敬為框架，但具
   體個人化指紋(口誤迷因 / 會員團名 / 招呼語 / 主持人個人音色)**不
   可進入輸出**;reactor 命名走中性化(Alex/Sam/Mr.X 等)
2. **強制 disclaimer 維持文體層措辭** — 文末必加 blockquote 兩行中
   英並列「Stylistic rewrite in YouTube mystery-narration style;
   not a factual claim」,**禁改寫為「故事歸故事」式事實免責**
   (M-08)
3. **事實命題保留** — 核心事實(年代 / 人名 / 地名 / 數字)不可竄
   改；禁注入原文沒有的預言 / 外星人 / 平行宇宙
4. **禁偽造權威來源** — 不可加「某科學家發現」「日本研究員指出」這
   類虛指具名；只能用泛指「人們」「世人」「歷史記載」

## 三條風格指紋

1. **C-01 標題情緒中括號 + 承諾密度** — 【震撼】/【神人】/【目前最
   長影片】+「N 分鐘講完 XX」承諾；兩到三層全形逗號層疊懸念
2. **S-02 賣關子轉場 ≥ 2 處** — 「但這還不是最詭異的」「我們先把時
   間撥回到 OOO 年」式延遲揭曉
3. **M-01 文末 Disclaimer 固定句** — 兩行中英並列，缺一不交付，且
   M-08 補強禁假免責 — 靈魂條款

三者缺一就不是老高式神秘解說口播。其餘 20 條 checklist 都在服務這三
條。

## 不適用素材清單(極重要)

以下類型素材**不建議改寫**(改寫者應先提醒使用者):

- 醫療建議 / 法律建議 / 疫苗 / 藥物相關
- 突發新聞 / 災難現場 / 未證實刑案
- 政治敏感事實 / 選舉相關 / 族群敏感
- 涉及未成年人安全 / 性別暴力受害者

若使用者堅持改寫此類素材，本 skill 退守為**結構展示模式**:只套對白
外殼，**不加未解之謎修辭、不加巧合修辭、不加情緒副詞**,且
disclaimer 加碼為「本素材不適合此文體改寫，僅作結構示範」。

## 何時使用

- 想把一段事實 / 寓言 / 軼事改寫成 YouTube 神秘解說口播結構
- 想體驗「賣關子 + 跳躍關聯 + 巧合修辭」的口播節奏
- 想看一個普通故事如何被「震撼包裝」而不竄改事實
- 想分析此類節目的文體結構(教學 / 文體研究用途)

## 何時**不**用

- 想模仿某具體 YouTuber 的個人風格招呼語 — 本 skill **不做這件
  事**,集體文類致敬；個人語癖不挪用
- 想生成陰謀論 / 偽科學內容 — 本 skill **明文不做**,事實命題保留 +
  禁偽造權威
- 想寫單人 podcast 鬼故事說書腔(完全無神秘解說結構)— 暫無對應
  skill
- 想寫知音體煽情雜誌敘事 — 用 [zhiyin-style](../zhiyin-style/)
- 想寫廢話文學 — 用 [feihua-literature](../feihua-literature/)
- 想寫凡爾賽文學 — 用 [versailles-literature](../versailles-literature/)

## 預期輸出篇幅

繁體中文神秘解說口播體，**典型 800–1500 字**(含文末 disclaimer):

| 段落結構 | 字數估算 |
|---|---|
| 標題(含【情緒中括號】+ 承諾密度) | 15–50 字 |
| 開場(自介 + 預告題眼，Duo 加反應驚呼) | 80–150 字 |
| 主講推進 × 3–5 段(Duo 含 reactor 插話) | 600–1200 字 |
| 結尾(結語 + 互動勾子 + 訂閱三件套) | 80–150 字 |
| 文末 Disclaimer(固定句) | 30–50 字 |

## 適合的源文

- 軼事 / 寓言(《差不多先生》《小王子》一類)
- 中性事實素材(歷史人物、地理發現、文化現象)
- 含具體年代 / 數字 / 地點的故事(賣關子有錨點)
- 帶有「巧合」或「跨域關聯」可能性的素材

## 不太適合的源文

- 純抒情詩、現代主義散文(沒有事實命題可包裝)
- 純技術文件、API 文檔(無敘事容器)
- 上述「不適用素材清單」中的類型

## 運作流程

1. **讀原文**
2. **不適用素材篩檢** — 醫療 / 法律 / 突發新聞 / 政治敏感 / 未成年人
3. **Step 2.5 決定模式** — Solo / Duo 二擇一
4. **抽出核心事實 + 標題擬定** — 事實清單鎖定 + 中括號 + 承諾密度
5. **開場(自介 + 預告)** — 依模式分支
6. **主講推進** — 數字 + 未解 + 巧合 + 觀點 + 免責子句
7. **reactor 台詞**(僅 Duo 模式)— ≥ 5 處，六類字典
8. **賣關子節奏 + 跳躍式關聯** — ≥ 2 + ≥ 1
9. **結尾呼籲 + 文末 Disclaimer** — 三件套 + blockquote 兩行
10. **強度檢核** — 默念測試
11. **標點清理 + 自檢指令**
12. **Self-check Against Checklist** — 23 條(Hard 19 + Soft 3 +
    1 Conditional)
13. **抓最弱段重寫**
14. **輸出** — 寫入 `<原檔名>_laogao.md`

## 改寫原則(checklist 摘要)

| 類別 | 編號 | 要點 |
|------|------|------|
| Concrete | C-01~C-04 | 標題中括號 + 承諾密度 / 開場自介(依模式)/ reactor 反應(Duo Hard,Solo N/A)/ 訂閱結尾三件套 |
| Surface | S-01~S-05 | CJK 字後零半形 / 賣關子 ≥ 2 / 跳躍關聯 ≥ 1 / 破折號省略號(Soft)/ 兩到三層逗號層疊(Soft)|
| Voice | V-01~V-06 | 數字戲劇化(只用原文已有)/ 未解修辭 ≥ 2 / 巧合修辭 ≥ 2 / 個人觀點 / 免責子句 / reactor 六類字典(Soft) |
| Meta | M-01~M-08 | 文末 Disclaimer / 事實命題保留 / 禁偽造權威 / 禁注入未解 / 不挪用個人語癖 / 不適用素材篩檢 / 標點零違規 / **禁假免責(disclaimer 是文體聲明非事實免責)** |

完整 23 項 checklist 與 13 步 workflow 見 [SKILL.md](./SKILL.md)。

## 標題模式速查

| 中括號 | 用法 |
|---|---|
| 【震撼】 | 「以為的是真的」式翻案 |
| 【深挖】 | 「藏在 XX 背後的真相」 |
| 【神人】 | 「被埋沒 XX 年的⋯⋯」 |
| 【神作】 | 影視作品深度解讀 |
| 【目前最長影片】/【第三長影片】 | 自我宣傳長度 |
| 【庫存影片】 | 「拍攝於 XX 年封存至今」 |
| 【限時公開】 | 「會員特典 / 週年特別」 |
| 【你不知道的】/【顛覆認知】 | 知識落差 / 全盤翻轉 |
| 【實測】 | 「親自驗證」 |

**附加模式**:「N 分鐘講完巨大命題」承諾密度、「目前為止最 X」自我宣
傳、問句反詰、「⋯⋯」延伸式、數字精確化、跨域對比。

## reactor 反應字典摘要(僅 Duo 模式)

| 類別 | 樣式 |
|---|---|
| 驚呼 | 真的假的？ / 怎麼可能？ / 不會吧！ / 太可怕了 / 天啊 / 哇 |
| 質疑 | 我不信 / 這太誇張了吧 / 你確定？ / 等一下 |
| 引導 | 那後來呢？ / 然後呢？ / 那這跟前面有什麼關係？ / 所以呢？ |
| 補白 | 我懂了 / 所以是 XXX 的意思？ / 是這樣啊 |
| 重述 | 你的意思是說 XXX? / 也就是說 XXX? |
| **即興 punchline** | reactor 自誇 → narrator 順勢吐槽 |

## 賣關子變體摘要

| 變體 | 樣式 |
|---|---|
| 延遲揭曉 | 「先賣個關子」「這個我們等一下再說」 |
| 層層加碼 | 「但這還不是最詭異的」「然而真相遠不止於此」「接下來這段，你可能不信」 |
| 倒數提示 | 「請大家記住這個數字 / 名字，後面會用到」 |
| 章節跳接 | 「我們先放下這個，回到⋯⋯」 |
| 時間撥回 | 「我們把時間撥回到 OOO 年」 |
| **承諾倒數** | 「接下來的 N 分鐘，我會告訴你⋯⋯」 |

## 跨域關聯詞庫(在 narrator 段落中可呼名)

亞特蘭提斯 / 瑪雅 / 蘇美 / 古埃及 / 三星堆 / 諾查丹瑪斯 / 推背圖 /
百慕大三角 / 費城實驗 / 火星男孩 / 水晶頭骨 / 麥田圈 / UFO。

**鐵律**:跨域連接的「巧合」可以是修辭(把兩件事並陳),但**不可暗
示因果**(「所以這證明 XX 是真的」),只能停留在「你能想到嗎？這也
太巧了吧？」式的暗示。

## 結尾三件套(Duo 模式)

```
[H1] 結語(這就是今天的故事)
[H1] 互動勾子(你相信嗎？ / 歡迎在留言區告訴我們)
[H1] 訂閱呼籲(別忘了訂閱、按讚、開小鈴鐺)
[H1] 預告或道別(我們下次再見)
[H2] 拜拜——

> 本文為神秘解說口播體致敬，非事實陳述。
> Stylistic rewrite in YouTube mystery-narration style;
> not a factual claim.
```

**Solo 模式**:省略 H2 「拜拜」行；narrator 自己結尾呼籲。
