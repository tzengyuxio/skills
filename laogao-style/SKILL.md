# Laogao-style — 改寫成老高與小茉(Mr & Mrs Gao)風格神秘解說體

把任何文章改寫成「老高與小茉」(Mr & Mrs Gao)這類華語 YouTube 上自
2010 年代後期定型的「神秘 / 都市傳說 / 失落古文明 / 未解之謎」口播風
格。標題塞滿情緒中括號、開場拋出顛覆認知命題、narrator 不斷喊「整整
三千年前」「至今無法解釋」、reactor 偶爾驚呼「真的假的？」、中段一定
要賣關子、結尾不忘喊一聲「別忘了訂閱按讚開小鈴鐺」。讀完讓人覺得自
己剛剛看完一支 30 分鐘的影片，大腦塞滿了不知真假的「巧合」與「不為
人知的真相」,但每一個具體年代、人名、數字仍然是原文事實。

風格參照：**老高與小茉 / Mr & Mrs Gao 頻道**自 2018 年至今的影片結構
與口播節奏。相關華語 YouTube 同類型創作者：自說自話的總裁、馬臉姐、
腦洞烏托邦、曉涵哥來了等。

> **重要定位(必讀):四條鐵律 + 不適用素材清單**
>
> 1. **集體文類致敬，不模仿個人語癖** — skill 命名為 `laogao-style`
>    是因為**老高與小茉是此文類在華語圈的代表**,但具體個人化指紋
>    **不可進入輸出**:
>    - **禁出現具體迷因口誤** — 例如特定數字相關的口誤迷因、會員團
>      名、自我吹捧式口頭禪
>    - **禁直接照搬個別影片標題** — 用結構模板而非具體標題
>    - **禁模仿主持人個人音色 / 口頭禪 / 招呼套語**
>    - reactor 命名走中性化(Alex/Sam/Mr.X/Maya 等西洋名或泛化標籤
>      H1/H2),禁使用真實主持人姓名 / 暱稱
>
> 2. **強制 disclaimer** — 輸出文末**必加固定句**:
>
>    > 「本文為神秘解說口播體致敬，非事實陳述。
>    > Stylistic rewrite in YouTube mystery-narration style;
>    > not a factual claim.」
>
>    不可省略 / 不可改寫 / 不可移到文中其他位置。**且 disclaimer 是
>    文體聲明，不是「故事歸故事不必當真」式事實免責**——M-08 鐵
>    律，詳見後文。
>
> 3. **事實命題保留條款** — 情緒副詞(震撼 / 詭異 / 驚人 / 不可思
>    議 / 至今未解)可加，但**核心事實不可竄改**:
>    - **禁竄改**:年代 / 人名 / 地名 / 數字 / 具體事件
>    - **禁注入**:原文沒有的預言 / 外星人 / 時間旅行 / 平行宇宙元素
>    - **可加**:對既有事實的情緒包裝、賣關子節奏、reactor 對白(若
>      Duo 模式)、個人觀點(以「我個人覺得」框住的猜測)
>
> 4. **禁偽造權威來源** — 不可加「某某科學家發現」「日本研究員指
>    出」「最近有篇論文」「考古學家認為」這類**虛指**具名；若原文沒
>    提就**不能加**;只能用泛指「人們至今無法解釋」「世人普遍認為」
>    「歷史記載」(以複數泛指代替虛假具名)。
>
> **不適用素材清單** — 醫療 / 法律 / 突發新聞 / 政治敏感 / 未成年
> 人安全 / 性別暴力受害者素材**不建議改寫**;若使用者堅持，退守結構
> 展示模式(只套對白外殼，不加未解修辭、不加巧合修辭、不加情緒副
> 詞)。

## 兩種輸出模式：Solo vs Duo

| 模式 | 結構 | 適用場合 | reactor 規則 |
|---|---|---|---|
| **Solo** | 純 narrator 說書腔 | 主題密度高、需要專注推進的長篇；或源文不適合插話氣口 | reactor 不出現也合格 |
| **Duo** | narrator 主軸 + reactor 偶爾插話 | 文章長、有自然氣口可調節節奏；源文有對比 / 翻轉感 | reactor 反應 ≥ 5 處(Hard)|

**對話比例(Duo 模式)**:**narrator 約佔 80–90%**,**reactor 約佔
10–20%**——reactor 是**氣氛調節 + 話題轉換**用，不是平等對話。

**Solo / Duo 不是強度差異，而是結構選擇**。Step 2.5 必須明確選定一
種，後續所有 checklist 條目皆以此為準。

## 一句話靈魂

**標題情緒中括號 + N 分鐘講完承諾 + 兩到三層逗號層疊懸念 + narrator
主軸推進(數字戲劇化 + 未解修辭 + 巧合修辭)+ 可選 reactor 偶爾插話
+ 賣關子節奏 + 跳躍式關聯 + 個人觀點 + 免責子句 + 訂閱結尾三件套 +
文末 disclaimer**——事實骨架不動，情緒拉滿「震撼 / 詭異 / 巧合 / 至
今未解」四件套，但所有「科學家發現」「日本研究員指出」這類權威必須
是**原文已有的**,不可憑空偽造。

## 參照樣本(中性化口播範本)

完整參照清單見 [`references/source-passages.md`](./references/source-passages.md)。
此處摘三段示意：

**Solo 模式開場**:

> 「大家好，我是 Alex。今天要跟大家說的這個故事——可能會顛覆你對人
> 類歷史的整個認知。你準備好了嗎？別急，我們先從一個你絕對沒聽過的
> 數字開始⋯⋯」

**Duo 模式對白互動**:

> 「那個年代的人，可以做到現在做不到的事⋯⋯」
> 「等一下等一下——你是說那個年代的人，可以做到現在做不到的事？」
> 「對，而且這還不是最詭異的地方。」
> 「啊？那最詭異的是什麼？」
> 「別急，我們先把時間撥回到一萬兩千年前⋯⋯」

**結尾 + Disclaimer**:

> 「好，今天的故事就到這裡。你相信這個說法嗎？歡迎在留言區告訴我們你
> 的看法。喜歡這部影片的話，別忘了訂閱我們的頻道，按讚、開小鈴鐺，我
> 們下次再見。」
> 「拜拜——」(Duo 模式)
>
> > 本文為神秘解說口播體致敬，非事實陳述。
> > Stylistic rewrite in YouTube mystery-narration style;
> > not a factual claim.

## Step 2: 不適用素材篩檢

讀完原文後，逐項自答：

1. 是否涉及醫療建議 / 法律建議 / 疫苗 / 藥物？
2. 是否為突發新聞 / 未證實刑案 / 災難現場？
3. 是否涉及政治敏感 / 選舉 / 族群議題？
4. 是否涉及未成年人安全 / 性別暴力受害者？

**任一條為「是」**,**先提醒使用者**:「此素材不適合此文體改寫，我
建議⋯⋯」。若使用者堅持，改用**結構展示模式**(只套外殼，不加未解修
辭、不加巧合修辭、不加情緒副詞，disclaimer 加碼)。

**全部為「否」**,進 Step 2.5。

## Step 2.5: 決定輸出模式(Solo / Duo)

| 訊號 | 建議模式 |
|---|---|
| 源文有強烈翻轉、對比、揭曉感 | Duo(reactor 撐節奏轉換) |
| 源文邏輯密集、需專注推進 | Solo(避免 reactor 打亂) |
| 源文短(< 300 字)| Solo 或極輕量 Duo(reactor 僅 1–2 處)|
| 源文長(> 800 字)| Duo(reactor 調節氣息)|
| 不確定 | 預設 Duo(老高頻道的標準形態)|

選定後在內心或筆記中標注 `[Solo]` 或 `[Duo]`,後續每一步都以此為準。

## Step 3: 抽出核心事實 + 標題擬定

雙人口播體的特色是**事實骨架不動，情緒包裝拉滿**。先抽出原文的核心
事實清單：

- **時間 / 年代**(2024 年 / 三千年前 / 1969 年)
- **地點**(秘魯薩克塞瓦曼 / 亞馬遜雨林 / 北京故宮)
- **人物**(歷史人物 / 具體個人)
- **數字**(重達 200 噸 / 距今 5300 年 / 百分之九十九)
- **事件命題**(某人做了某事 / 某物有某特性)

**核心事實清單必須完整保留**,後續每一步都以此為錨點，不可竄改。

### 3.1 標題擬定

**格式**:**【情緒中括號】+ 違反直覺命題 + 兩到三層全形逗號層疊懸
念**(實證多為兩逗號)。

| 情緒中括號 | 用法 |
|---|---|
| 【震撼】 | 「以為你以為的是真的」式翻案 |
| 【深挖】 | 「藏在 XX 背後的真相」 |
| 【神人】 | 「被埋沒 XX 年的⋯⋯」 |
| 【神作】 | 「只有⋯⋯才能看出來的細節」/影視作品深度解讀 |
| 【目前最長影片】 | 自我宣傳長度為賣點 |
| 【第三長影片】 | 同上，精確排名 |
| 【庫存影片】 | 「拍攝於 XX 年，封存至今」 |
| 【限時公開】 | 「會員特典 / 一週年特別」 |
| 【你不知道的】 | 知識落差感製造 |
| 【顛覆認知】 | 全盤翻轉 |
| 【實測】 | 「親自驗證 / 親眼所見」 |

**標題附加模式**:

| 模式 | 範例骨架 | 用法 |
|---|---|---|
| **「N 分鐘講完巨大命題」承諾密度** | 「三十分鐘講完 XX 哲學」「四十三分鐘講完 XX 真相」「八個小時訪談 + XX」 | N 為精確數字 + 巨大命題；**承諾密度是此文類核心指紋之一** |
| **「目前為止最 X」自我宣傳** | 「目前為止最可信的 XX 證據」「目前為止最強的 XX」 | 自我評價最高級 |
| **問句反詰** | 「XX 究竟是 YY?」 | 製造好奇 |
| **「⋯⋯」延伸式** | 標題以省略號結尾 | 製造未完待續感 |
| **數字精確化** | 「整整三千年前」「97 個法則」「3906 年的未來」 | 拗口精確數字增強真實感 |
| **跨域對比** | 「比 XX 還誇張的 YY」「跟 XX 一樣 ZZ 的 WW」 | 用熟知參照物拉抬陌生命題 |

**範例骨架**(中性化):

> 【震撼】你以為的 XXX,其實是 YYY⋯⋯
> 【深挖】被掩蓋了 XX 年的真相，終於曝光⋯⋯
> 【神人】這個被遺忘的 XXX,改寫了我們對 YYY 的整個認知
> 【N 分鐘講完】XX 的全部秘密，看完你就懂了
> 【目前最長影片】XX,目前為止最完整的解讀

**禁止**:
- 直接照搬任何真實影片標題
- 標題出現具體醫療 / 法律 / 政治敏感事實判斷
- 標題使用主持人個人化口頭禪 / 會員團專名

## Step 4: 開場(自介 + 預告題眼)

### 4.1 開場結構(依模式分支)

**Solo 模式**:

```
[narrator] 大家好，我是 OOO。
[narrator] 今天要跟大家說的這個故事——
[narrator 預告題眼，賣關子]
[narrator 引導進入正文]
```

**Duo 模式**:

```
[H1 = 主講] 大家好，我是 OOO。
[H2 = 反應者] 我是 XXX。
[H1] 今天要跟大家說的這個故事——
[H1 預告題眼，賣關子]
[H2 反應驚呼]
[H1 引導進入正文，可加「資料快被刪除」危險聲明變體]
```

### 4.2 主講姓名 / 反應者姓名(中性化)

**鐵律**:**禁用活躍 YouTuber 真名 / 真稱呼**。從以下泛化模式擇取：

| 模式 | 範例 |
|---|---|
| 西洋名 | Alex / Sam / Mr.X / Mrs.Y / Eli / Maya |
| 角色稱呼 | 主講 / narrator / H1 / H2 |
| 泛化暱稱 | 老 X / 小 Y / X 哥 / Y 姐(其中 X、Y 為虛字母占位)|

**禁止**:任何接近真實活躍 YouTuber 的名字、暱稱、招呼套語、口誤迷
因。

### 4.3 預告題眼變體

| 變體 | 範例 |
|---|---|
| 顛覆認知式 | 今天要說的這個故事，可能會顛覆你對 XXX 的整個認知 |
| 危險聲明式 | 今天的話題，原始資料在網上幾乎都被刪除了，所以這部影片我也不知道能存活多久 |
| 觀眾準備式 | 在開始之前，我必須先提醒你——這個故事，你聽完可能會睡不著 |
| 數字賣關子式 | 一個百分之九十九的人都不知道的數字，我們今天就來解開它的秘密 |
| 承諾密度式 | 接下來 N 分鐘，我們講完 XX 的全部秘密 |

## Step 5: 主講推進(narrator 段落)

主講段落是文體的「資訊輸出」骨幹。每段須含以下元素之**至少二項**:

### 5.1 數字戲劇化(每段 ≥ 1 處)

- 「百分之九十九的人都不知道」「百分之九十九點九」
- 「整整三千年前」「距今一萬兩千年」「比埃及金字塔還早一千年」
- 拗口精確：「12.5 噸」「73 個石缸」「5300 歲」「3906 年的未來」
- **規則**:**只用原文已有的數字**;若原文沒給就不可憑空捏造「整整
  三千年前」。可加「整整」「足足」「竟然」這類情緒副詞包裝原文已有
  的數字。

### 5.2 未解之謎修辭(全篇 ≥ 2 處)

- 「至今科學家也無法解釋」「至今仍是人類未解之謎」
- 「考古學家發現了一個不可能存在的⋯⋯」
- 「現代科技無法復刻」「在當時的技術條件下完全做不到」

**鐵律(M-03)**:**禁偽造權威來源**——若原文沒有「某科學家」「某教
授」「日本研究員」這類人，**不可憑空加**;只能用泛指「人們」「世
人」「歷史學家普遍認為」(以複數泛指代替虛假具名)。

### 5.3 巧合修辭(全篇 ≥ 2 處)

- 「巧合的是⋯⋯」「無獨有偶⋯⋯」
- 「更詭異的是⋯⋯」「最讓人毛骨悚然的是⋯⋯」
- 「你能想到嗎？」「你猜怎麼著？」
- 「這也太巧了吧？」「這已經不能用巧合解釋了」

### 5.4 個人觀點插話(全篇 ≥ 1 處)

- 「我個人覺得⋯⋯」「我認為⋯⋯」「我感覺⋯⋯」
- 「這是我看過最⋯⋯的⋯⋯」
- 「如果你問我⋯⋯」「老實說⋯⋯」

### 5.5 免責子句(全篇 ≥ 1 處，Disclaimer 外)

- 「當然這只是傳說 / 一種說法 / 民間說法」
- 「真假大家自己判斷」
- 「以下內容僅供參考」

> **警示**:**免責子句不是 disclaimer**。免責子句是 narrator 在內文
> 中的退路話術(輕鬆語氣),disclaimer 是文末固定的文體聲明
> (見 Step 8)。兩者並存，不可互替。

## Step 6: 反應者(reactor)台詞[僅 Duo 模式]

**Solo 模式**:跳過此步。

**Duo 模式**:reactor 反應台詞 ≥ 5 處，均勻分佈於各 narrator 段落之
間。

### 6.1 反應字典(六類)

| 類別 | 樣式 |
|---|---|
| 驚呼 | 真的假的？ / 怎麼可能？ / 不會吧！ / 太可怕了 / 天啊 / 哇 |
| 質疑 | 我不信 / 這太誇張了吧 / 你確定？ / 等一下 |
| 引導 | 那後來呢？ / 然後呢？ / 那這跟前面有什麼關係？ / 所以呢？ |
| 補白 | 我懂了 / 所以是 XXX 的意思？ / 是這樣啊 |
| 重述 | 你的意思是說 XXX? / 也就是說 XXX? |
| **即興 punchline** | 「我覺得已經非常夠用了」「比一般人強很多」式自誇 → narrator 順勢吐槽「這個『一般人』是指代嗎？」 |

### 6.2 reactor 分佈規則

- 每個主講段落結束後，**至少有 1 句 reactor 反應**
- 反應台詞**短**(50 字內),不可寫成長篇大論
- **reactor 偶爾投出 punchline 自誇** → **narrator 順勢吐槽**,這是
  此文類的標誌互動模式(集體文類層級，可寫入；不可指涉具體頻道的個別
  名場面)

## Step 7: 賣關子節奏 + 跳躍式關聯

### 7.1 賣關子節奏(全篇 ≥ 2 處)

| 變體 | 樣式 |
|---|---|
| 延遲揭曉 | 「先賣個關子」「這個我們等一下再說」 |
| 層層加碼 | 「但這還不是最詭異的」「然而真相遠不止於此」「接下來這段，你可能不信」 |
| 倒數提示 | 「請大家記住這個數字 / 名字，後面會用到」 |
| 章節跳接 | 「我們先放下這個，回到⋯⋯」 |
| 時間撥回 | 「我們把時間撥回到 OOO 年」 |
| **承諾倒數** | 「接下來的 N 分鐘，我會告訴你⋯⋯」 |

### 7.2 跳躍式關聯(全篇 ≥ 1 處)

「這跟瑪雅文明 / 蘇美人 / 古埃及 / 亞特蘭提斯 / 諾查丹瑪斯預言 / 推背
圖 / 三星堆 / 火星男孩 / 百慕大三角 / 費城實驗又有什麼關係呢？」式跨
域連接——把不相關的時代 / 文明 / 數字 / 神話 / 預言放在同一段話裡，
只靠「巧合」黏合。

| 變體 | 樣式 |
|---|---|
| 跨文明 | 「這跟瑪雅文明又有什麼關係呢？」 |
| 跨地理 | 「無獨有偶，在地球的另一端⋯⋯」 |
| 跨時代 | 「為什麼這兩件事會這麼相似？」 |
| 跨預言 | 「巧合的是，某預言書也提到了同樣的數字」 |
| 數字巧合 | 「兩個從未接觸過的古文明，給出的數字只差了 12 年」 |

**詞庫**(可在 narrator 段落中以中性化方式呼名引用):亞特蘭提斯 /
瑪雅 / 蘇美 / 古埃及 / 三星堆 / 諾查丹瑪斯 / 推背圖 / 百慕大三角 /
費城實驗 / 火星男孩 / 水晶頭骨 / 麥田圈 / UFO。

**鐵律**:跨域連接的「巧合」可以是修辭(把兩件事並陳),但**不可暗
示因果**(「所以這證明 XX 是真的」),只能停留在「你能想到嗎？這也
太巧了吧？」式的暗示。

## Step 8: 結尾呼籲 + 文末 Disclaimer

### 8.1 結尾結構

**Solo 模式**:

```
[narrator] 結語(這就是今天的故事)
[narrator] 互動勾子(你相信嗎？ / 歡迎在留言區告訴我們)
[narrator] 訂閱呼籲(別忘了訂閱、按讚、開小鈴鐺)
[narrator] 預告或道別(我們下次再見)

> 本文為神秘解說口播體致敬，非事實陳述。
> Stylistic rewrite in YouTube mystery-narration style;
> not a factual claim.
```

**Duo 模式**:

```
[H1] 結語(這就是今天的故事)
[H1] 互動勾子(你相信嗎？ / 歡迎在留言區告訴我們)
[H1] 訂閱呼籲(別忘了訂閱、按讚、開小鈴鐺)
[H1] 預告或道別(我們下次再見)
[H2] 拜拜——

> 本文為神秘解說口播體致敬，非事實陳述。
> Stylistic rewrite in YouTube mystery-narration style;
> not a factual claim.
```

### 8.2 Disclaimer 規格(靈魂條款 M-01)

- **位置**:文末，結尾呼籲之後
- **格式**:blockquote(`>` 開頭)兩行，中英文並列
- **不可省略**、**不可改寫**、**不可移位**
- **缺 disclaimer 即不交付**

### 8.3 禁假免責條款(M-08,鐵律補強)

**Disclaimer 是文體聲明，不是事實免責**。

**禁出現**:
- 「以上純屬說書」/「故事歸故事，不必當真」
- 「資料都是匯集的，真假不負責」
- 「我只是個說書人，事實請自行查證」

這類話術把 disclaimer 從**文體層**(stylistic rewrite)拉到**事實免
責層**(洗清傳播假訊息責任),是此文類最常見的爭議源。本 skill 的
disclaimer 必須維持文體層位置，只能用「Stylistic rewrite in YouTube
mystery-narration style; not a factual claim」這個明確措辭。

## Step 9: 強度檢核

把寫好的稿子讀一遍，默念出來，自問：

1. **它像不像一支 YouTube 影片的逐字稿**?——能不能想像主講(及 Duo
   模式下的反應者)坐在攝影機前對著鏡頭講這些話？
2. **事實骨架是否被竄改**?——逐項對比 Step 3 抽出的核心事實清單，
   有沒有偷偷把年代 / 人名 / 數字改了？有沒有偽造「某某科學家發
   現」?
3. **disclaimer 在不在 + 措辭是否文體層**?——文末有沒有那行
   blockquote?措辭是「Stylistic rewrite」還是寫成「故事歸故事」?
4. **指紋元素是否齊備**?——數字戲劇化 / 未解修辭 / 巧合修辭 / 個人
   觀點 / 免責子句 / 賣關子 / 跳躍關聯七大件(Duo 加 reactor 反應)
   缺哪幾項？
5. **是否點名了具體 YouTuber 或挪用個人語癖**?——出現了真實活躍
   YouTuber 的名字、暱稱、口頭禪、招呼語、會員團名、迷因化口誤就刪
6. **是否混入現代具體事件 / 醫療 / 法律 / 政治判斷**?——退守結構展
   示模式

## Step 10: 標點清理 + 自檢指令

最後一道工序：

| 半形(禁) | 全形(用) | Unicode |
|---|---|---|
| `,` | `,` | U+FF0C |
| `;` | `;` | U+FF1B |
| `:` | `:` | U+FF1A |
| `?` | `?` | U+FF1F |
| `!` | `!` | U+FF01 |
| `--` 或 `—` | `——` 全形破折號 | U+2014 × 2 |
| `...` 或 `…` | `⋯⋯` 或 `……` | U+22EF×2 / U+2026×2 |
| `"` `'` | 「」/『』 | U+300C/D, U+300E/F |
| `.` | 。 | U+3002 |

**寫完後必跑自檢指令**:

```bash
python3 -c "
import re, sys
text = open(sys.argv[1]).read()
# CJK 字後接半形 ,;:?! 一律違規(含行尾、引號前、段末等情境)
bad = re.findall(r'[一-鿿㐀-䶿][,;:?!]', text)
print(f'half-width punct after CJK: {len(bad)}')
for b in bad[:5]: print(repr(b))
" 輸出檔.md
```

結果必須為 `0`。

## Step 11: Self-check Against Checklist

逐條對照下面的 21 條 checklist。**任一條 [Hard] 違反就回前面對應的
步驟重寫該段**。

### Checklist: Concrete(標題 / 開場 / reactor / 結尾)

| 編號 | 強度 | 規則 |
|---|---|---|
| C-01 | Hard | **標題情緒中括號必出**——標題開頭為【震撼】/【深挖】/【神人】/【神作】/【目前最長影片】/【第三長影片】/【庫存影片】/【限時公開】/【你不知道的】/【顛覆認知】/【實測】之一，或附「N 分鐘講完巨大命題」承諾密度模式 |
| C-02 | Hard | **開場自介**——Solo 模式：narrator 一句自介；Duo 模式：主講 + 反應者各一句並列開場；命名走中性化(西洋名 / 泛化暱稱),禁活躍 YouTuber 真名 |
| C-03 | **Conditional** | **reactor 反應台詞**——Duo 模式：**≥ 5 處 [Hard]**,均勻分佈，六類字典皆可用；Solo 模式：此條 N/A — **Duo 模式靈魂條款** |
| C-04 | Hard | **訂閱結尾呼籲**——文末須有「歡迎在留言區告訴我們」「別忘了訂閱、按讚、開小鈴鐺」「我們下次再見」三件套(Duo 模式可加反應者「拜拜——」) |

### Checklist: Surface(節奏 / 標點 / 賣關子)

| 編號 | 強度 | 規則 |
|---|---|---|
| S-01 | Hard | **CJK 字後零半形標點**——`,;:?!` 出現於 CJK 字後一律違規；Step 10 自檢指令計數須為 0 |
| S-02 | Hard | **賣關子轉場 ≥ 2 處**——「但這還不是最詭異的」/「先賣個關子」/「我們先把時間撥回到 OOO 年」/「接下來這段你可能不信」等延遲揭曉句 ≥ 2 處 — **靈魂條款** |
| S-03 | Hard | **跳躍式關聯 ≥ 1 處**——「這跟瑪雅 / 亞特蘭提斯 / 蘇美 / 三星堆 / 諾查丹瑪斯 / 推背圖 / 火星男孩又有什麼關係呢？」「無獨有偶，在地球的另一端⋯⋯」式跨域連接 ≥ 1 處 |
| S-04 | Soft | 全形破折號 `——` 與省略號 `⋯⋯` 自然分佈，各 ≥ 1 處 |
| S-05 | Soft | **兩到三層全形逗號層疊懸念**——標題或內文中至少出現一處「A,B,C」式三句連發疊加 |

### Checklist: Voice(數字 / 未解 / 巧合 / 觀點 / 免責)

| 編號 | 強度 | 規則 |
|---|---|---|
| V-01 | Hard | **數字戲劇化 ≥ 1 處**——「整整 X 年前」「百分之九十九的人都不知道」「重達數百噸」式；**只用原文已有的數字**,可加情緒副詞包裝，禁憑空捏造 |
| V-02 | Hard | **未解之謎修辭 ≥ 2 處**——「至今科學家也無法解釋」「至今仍是人類未解之謎」「現代科技無法復刻」式 |
| V-03 | Hard | **巧合修辭 ≥ 2 處**——「巧合的是」「無獨有偶」「更詭異的是」「你能想到嗎？」「這也太巧了吧？」式 |
| V-04 | Hard | **個人觀點插話 ≥ 1 處**——「我個人覺得」「老實說」「如果你問我」「我認為」式 |
| V-05 | Hard | **免責子句 ≥ 1 處(Disclaimer 外)**——「當然這只是一種說法」「真假大家自己判斷」「以下內容僅供參考」式 |
| V-06 | Soft | reactor 字典使用(Duo 模式)——驚呼 / 質疑 / 引導 / 補白 / 重述 / 即興 punchline 六類至少各 1 處 |

### Checklist: Meta(disclaimer / 事實 / 避雷 / 標點)

| 編號 | 強度 | 規則 |
|---|---|---|
| M-01 | Hard | **文末 Disclaimer 固定句**——blockquote 兩行中英並列「本文為神秘解說口播體致敬，非事實陳述。Stylistic rewrite in YouTube mystery-narration style; not a factual claim.」;不可省略 / 改寫 / 移位 — **靈魂條款** |
| M-02 | Hard | **事實命題保留**——核心事實(年代 / 人名 / 地名 / 數字)不可竄改；對比 Step 3 抽出的事實清單，逐項保留 — **靈魂條款補強** |
| M-03 | Hard | **禁偽造權威來源**——不可加「某某科學家發現」「日本研究員指出」「考古學家認為」「最近有篇論文」這類虛指具名；只能用泛指「人們」「世人」 |
| M-04 | Hard | **禁注入新未解之謎**——不可憑空加上原文沒有的預言 / 外星人 / 時間旅行 / 平行宇宙元素 |
| M-05 | Hard | **不挪用個人語癖**——禁出現主持人個人化口頭禪、迷因口誤、會員團專名、招呼套語；reactor 命名走中性化 |
| M-06 | Hard | **不適用素材篩檢**——醫療 / 法律 / 疫苗 / 突發新聞 / 政治敏感 / 未成年人事實已於 Step 2 篩出；若混入，退守結構展示模式並加碼 disclaimer |
| M-07 | Hard | **標點清理零違規**——Step 10 自檢指令計數歸零 |
| M-08 | Hard | **禁假免責**——disclaimer 是文體聲明不是事實免責；禁出現「以上純屬說書」「故事歸故事不必當真」「資料都是匯集的真假不負責」這類洗清事實責任話術 — **靈魂條款補強** |

**總計**:23 條(Hard 19 + Soft 3 + 1 Conditional)。

## Step 12: Find the Weakest Section and Rewrite

通常**主講推進段**或**reactor 反應分佈**最弱：

- 若主講段沒有未解之謎修辭，回 Step 5.2 補
- 若主講段沒有巧合修辭，回 Step 5.3 補
- 若 Duo 模式 reactor < 5 處，回 Step 6 補
- 若沒有賣關子，回 Step 7.1 補
- 若沒有跳躍關聯，回 Step 7.2 補
- 若偽造了「某科學家發現」,回 Step 5.2 改泛指
- 若竄改了原文事實，回 Step 3 對比核心事實清單，還原回去
- 若文末沒 disclaimer 或 disclaimer 寫成「故事歸故事」,立刻補 / 改
- 若挪用了主持人個人語癖，刪除並換用中性化版本

## Step 13: Output

1. **檔案輸入**:寫入 `<原檔名>_laogao.md`,保留原檔
2. **貼文輸入**:直接輸出口播體
3. **不附說明、不附評論、不附「我的改寫思路」**(除非使用者明確要求)
4. **文末 Disclaimer 必出**——靈魂條款，缺一不可交付

## Anti-patterns(常見失敗模式)

1. **缺文末 Disclaimer**(違反 M-01)
2. **Disclaimer 寫成「故事免責」**(違反 M-08)
3. **偽造權威來源**「日本研究員 XXX 指出」(違反 M-03)
4. **竄改原文事實**或注入新未解之謎(違反 M-02、M-04)
5. **挪用主持人個人語癖**(違反 M-05)
6. **Duo 模式缺 reactor 反應**(違反 C-03 條件式)
7. **Solo 模式硬塞 reactor**(模式應一以貫之)
8. **缺賣關子**(違反 S-02)
9. **半形標點混入內文 CJK 字後**(違反 S-01、M-07)
10. **不適用素材硬上**(違反 M-06)
11. **沒有跳躍關聯**(違反 S-03)
12. **訂閱結尾缺三件套**(違反 C-04)
13. **照搬具體影片標題**(違反 M-05 個人語癖延伸)

## Important Notes

- **為何這個文體需要四條鐵律**:致敬對象長期陷於「假權威 + 抄襲 + 知
  識生產定位混淆」三重爭議，本 skill 透過(1)中性化命名(reactor /
  個人語癖層級)、(2)強制文體 disclaimer、(3)事實命題保留、
  (4)禁偽造權威——四項規則把這個語體從爭議實踐中切割出純語體致
  敬。**這四條缺一不可。**
- **文末 Disclaimer 是鐵律，且須維持文體層措辭** — 禁改寫為「故事歸
  故事」式事實免責
- **事實命題保留** — 年代 / 人名 / 地名 / 數字不可改；原文沒提到的權
  威人物不可憑空加；原文沒提到的預言 / 外星人 / 時間旅行元素不可注入
- **Solo / Duo 二擇一** — Step 2.5 鎖定後不可再混；Solo 模式 reactor
  不出現是 OK 的，不是缺陷
- **個人語癖避雷** — 中性化命名、結構模板替代具體標題、不挪用主持人
  口頭禪 / 招呼語 / 會員團專名 / 迷因口誤
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
