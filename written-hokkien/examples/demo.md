# Written Hokkien — 示範

展示 `written-hokkien` 把文章改寫成台語 / 閩南語書面化的兩種強度——
**Light（純漢字）** 與 **Heavy（漢羅混寫）**。

> **源文與引用說明**：範例一源文為 [`weather-rain.md`](../../examples/source-texts/weather-rain.md)（自編，無版權疑慮）；範例二為自編現代生活情境；範例三源文為 [《差不多先生傳》（胡適，1924)](../../examples/source-texts/mr-chabuduo.md) 公有領域；範例四為自編台文短詩（仿陳明仁、李勤岸的漢羅詩體，僅作風格座標說明，未引用整段原文）。

---

## 範例一：雨天故事 — Light（純漢字版）

源文：[weather-rain.md](../../examples/source-texts/weather-rain.md)

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### 台文 Light（純漢字）

> 昨昏下晡我佇圖書館看冊的時陣，雄雄落大雨。雖然我無紮雨傘，毋過猶是決定行路轉去厝。路裡人真濟，四界攏是攑雨傘的人。我規身軀攏澹糊糊矣，轉到厝才發見鎖匙袂記咧辦公室。厝邊看著我這款形，笑笑仔講：「你哪會無叫計程車？」我只好苦笑共伊應：「我袂記紮錢袋仔。」

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 「我」「我」 | G1 | 第一人稱保留，未改阮 / 咱（單數情境） |
| 「無紮 / 毋過 / 袂記」 | G2 | 否定系統：無（沒）、毋過（不過）、袂記（忘記） |
| 「雄雄落大雨」 | V1 | 「雄雄（hiông-hiông）= 突然」本字 |
| 「四界攏是」 | V1 | 攏（lóng）= 都 |
| 「轉去厝 / 轉到厝」 | V1 | 「轉（tńg）= 回」本字 |
| 「澹糊糊矣」 | G3 | 矣 = 變化貌（已濕） |
| 「共伊應」 | G6 | 共（kā）+ 賓語 + 動詞，台語特有功能詞 |
| 「哪會無叫」 | G4 | 「哪會」= 怎麼會，台語問句結構 |
| 「錢袋仔」 | V3 | 文化詞：錢包的台語說法 |
| 全篇純漢字、無羅馬字 | W1 | 一致性：Light 模式不混入台羅 |

**詞彙表**：昨昏（昨天）、下晡（下午）、佇（在）、冊（書）、雄雄（突然）、紮（帶）、規身軀（全身）、澹糊糊（濕透）、厝邊（鄰居）、袂記（忘記）、錢袋仔（錢包）。

## 範例二：辦公室對話 — Heavy（漢羅混寫版）

源文（自編）：

> 早上同事走進辦公室，看我臉色不太好，問我怎麼了。我說昨晚熬夜趕報告，現在頭很痛，想回家睡覺。他笑了笑說：「你也太拚了，我去幫你倒杯熱水。」我說謝謝，覺得有這樣的同事真好。

### 台文 Heavy（漢羅混寫）

> 透早同事行入來辦公室，看我面色 bē sui，問我是按怎。我講昨暝拚熬夜趕報告，這馬頭真痛，beh 轉去厝睏。I 笑笑 á 講：「Lí mā siuⁿ phah-piànn ah，góa 去鬥 kā lí 倒一杯燒水。」我講多謝，感覺有這款同事真好 leh。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 「透早 / 昨暝 / 這馬」 | V3 | 時間文化詞：透早（清晨）、昨暝（昨晚）、這馬（現在） |
| 「行入來」 | V1 | 「行（kiâⁿ）」走的本字 |
| 「面色 bē sui」 | V4 + W2 | 「bē sui」（不漂亮）寫台羅；無對應穩定漢字 |
| 「按怎」 | G6 | 疑問詞「怎麼樣」 |
| 「beh 轉去厝睏」 | V4 + W2 | 「beh（想要）」用台羅；「轉、厝、睏」三本字漢字 |
| 「I」「Lí」「góa」 | W2 | Heavy 模式人稱可用台羅，與 i / lí / góa 一致 |
| 「siuⁿ phah-piànn ah」 | V4 + W2 | siuⁿ（太）+ phah-piànn（拚）+ ah（變化貌） |
| 「鬥 kā lí 倒」 | G6 | 鬥（鬥相共）+ 共（kā）= 「幫忙替你倒」 |
| 「真好 leh」 | G5 + W2 | leh（句末強調）寫台羅 |
| 漢字 / 羅馬字之間半形空格 | W4 | 「我 beh 食」不寫成「我beh食」 |

**詞彙表**：透早（thàu-tsá / 清晨）、昨暝（tsa-mê / 昨晚）、這馬（tsit-má / 現在）、按怎（án-tsuáⁿ / 怎樣）、beh（想要 / 將要）、kā（把 / 替）、siuⁿ（太）、phah-piànn（拚命）、鬥（鬥相共 / 幫忙）、leh（句末助詞）。

## 範例三：差不多先生傳 — Light + Heavy 並陳

源文：[mr-chabuduo.md](../../examples/source-texts/mr-chabuduo.md)（胡適 1924，公有領域）

### 原文（節錄）

> 你知道中國最有名的人是誰？他姓差，名不多，是各省各縣各村人氏。差不多先生的名字天天掛在大家的口頭，因為他是中國全國人的代表。
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」
>
> 他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：「錯了。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」

### 台文 Light（純漢字）

> 你敢知影中國上有名的人是啥人？伊姓差，名不多，逐省、逐縣、逐庄攏有伊。差不多先生的名字逐工攏掛佇逐家的喙裡，因為伊就是中國全國人的代表。
>
> 伊不時咧講：「逐項代誌只要差不多，就好矣。何必傷精明咧？」
>
> 伊佇學堂的時陣，先生問伊：「直隸省的西爿是佗一省？」伊講是陝西。先生講：「毋著矣。是山西，毋是陝西。」伊講：「陝西佮山西，敢毋是差不多？」

### 台文 Heavy（漢羅混寫）

> Lí kám 知影中國 siōng 有名 ê 人是 siáⁿ-人？I 姓差，名不多，逐省、逐縣、逐庄 lóng 有 i。差不多先生 ê 名字逐工 lóng 掛 tī 逐家 ê 喙裡，因為 i 就是中國全國人 ê 代表。
>
> I m̄-bat 停 leh 講：「逐項代誌只要差不多，就好 ah。何必 siuⁿ 精明 leh？」
>
> I tī 學堂 ê 時陣，先生問 i：「直隸省 ê 西 pîng 是 tó 一省？」I kóng 是陝西。先生 kóng：「毋著 ah。是山西，m̄ 是陝西。」I kóng：「陝西 kah 山西，kám m̄ 是差不多？」

### 結構標註

| 條目 | 對照規則 | Light / Heavy 對應 |
|---|---|---|
| 第一句「你敢知影」 vs 「Lí kám 知影」 | G1 + G4 | Light 漢字「你敢」；Heavy 用 Lí kám 同義切換 |
| 「上有名」 / 「siōng 有名」 | V2 | 上（siōng）= 最；訓用字 vs 台羅 |
| 「逐省、逐縣、逐庄」 | V1 | 逐（ta̍k）= 每，台語高頻字 |
| 「掛佇喙裡」 / 「掛 tī 喙裡」 | G6 | 佇 / tī = 在 |
| 「不時咧講」 / 「m̄-bat 停 leh 講」 | G3 | 進行貌：咧 / leh |
| 「矣」 / 「ah」 | G5 | 變化貌：Light 用矣，Heavy 用 ah |
| 「佮」 / 「kah」 | G6 | 和：Light 用佮（本字）；Heavy 改寫 kah（俗音變體） |
| 「敢毋是」 / 「kám m̄ 是」 | G2 + G4 | 「敢 + 否定」= 難道不；台語特有反詰 |
| 通篇人稱「伊」/「i」 | G1 | 伊 = 他 / 她 |
| 不混入兩種強度於同段 | W1 + W2 | Light、Heavy 各自一致 |

**改寫的關鍵動作**：胡適原文是雜文體諷刺，台文版未動其情節結構，只把句法
改造為台語序、把功能詞換為本字。Heavy 版進一步把 ê / siáⁿ / kah / kám / leh
等難以漢字化的高頻虛詞寫成台羅，這是現代台文文學（陳明仁、李勤岸、胡長松
等）的主流書寫慣例。

**詞彙表**：知影（tsai-iáⁿ / 知道）、上（siōng / 最）、逐（ta̍k / 每）、喙
（tshuì / 嘴）、不時（put-sî / 經常）、代誌（tāi-tsì / 事情）、佗（tó / 哪）、
傷（siunn / 太過）、爿（pîng / 邊）。

## 範例四：台文短詩 — Heavy（漢羅）

仿陳明仁、李勤岸的漢羅詩體，自編短詩示範文學語境的書寫一致性。

### 自編目標範例

> **〈夜車〉**
>
> 透暝 ê 火車 leh 走
>
> 阮 ê 心思 mā tī 邊仔
>
> 看 phah 著窗 á ê 雨水
>
> Sī 故鄉 leh 哭，á-sī 我 leh 哭
>
> 月娘 m̄ 知影
>
> Hiah-nī 遠 ê 厝
>
> Kám 猶有人 leh 等

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 詩題「〈夜車〉」單一場景意象 | M2 | 文體靈活：詩 |
| 全篇分行不加句號，遵詩體慣例 | M2 | 台文詩多採白話分行 |
| 「ê」「leh」「mā」「sī」「m̄」「kám」 | V4 + W2 | 漢羅核心：高頻虛詞用台羅 |
| 「透暝 / 月娘 / 故鄉 / 厝」 | V1 + V3 | 本字漢字承載意象 |
| 「á-sī」 | V4 | 抑是 / 或是的台羅形式 |
| 「Hiah-nī 遠 ê 厝」 | V4 + W2 | hiah-nī（那麼）+ ê 連結典型台羅句構 |
| 「Kám 猶有人 leh 等」 | G4 + G3 | 敢（kám）反詰 + leh 進行貌 |

**風格座標**：陳明仁《路樹下 ê t³-peh-á》與李勤岸詩集大量以漢羅寫鄉愁、夜景
與時間流逝；本範例承襲此書寫慣例——**本字承載意象，台羅承載呼吸與節奏**。
