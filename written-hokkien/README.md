# Written-hokkien — 改寫成台語／閩南語書面化

把任何文章改寫成台語（閩南語、台灣閩南語）書面化文體——句法走台語
而非中文翻譯，標誌語法詞用本字（阮／咱／怹／ê／beh／攏／毋／莫），
依強度選擇純漢字或漢羅混寫。

## 什麼是台語書面化？

台語（閩南語、台灣閩南語）有完整的書寫傳統，分三大書寫方案：

1. **全漢字**——使用教育部《臺灣閩南語推薦用字》（2007 起公布 700
   字詞，分本字／訓用字／新造字三類）。
2. **漢羅混寫**——本字漢字 + 不可漢字化的詞（如屬性助詞「ê」、
   意願動詞「beh」）用台羅。台語文文學主流。
3. **全羅**——白話字（POJ，1832 起，巴克禮 1873 完成首部 POJ 新約
   聖經）或台羅（教育部 2006 公布）；本 skill 不採此模式。

文化錨點：賴和、楊逵、鄭清文、王禎和、宋澤萊、陳明仁《路樹下 ê
tó͘-peh-á》、李勤岸詩集、向陽、教會聖經巴克禮譯本、布袋戲與歌仔戲
腳本、台語流行歌詞。

## 一句話靈魂

**句法走台語、不是中文翻譯**——關鍵語法詞用本字，依強度選書寫系統，
讓讀者一眼看出這是台語文而不是「翻譯後的中文」。

## 兩段強度

| Level | 漢字 | 羅馬字 | 適用場景 |
|---|---|---|---|
| **Light**（純漢字）| 100% | 0% | 教科書、報刊、一般讀者；沿用教育部推薦字 |
| **Heavy**（漢羅混寫）| ~70% | ~30% | 文學作品、詩、學術；本字漢字 + 虛詞或不可漢字化詞用台羅 |

未指定時預設 **Light**（純漢字）。

## 不會做的事

- 不採政治意識形態立場（「中國方言」 vs 「獨立語言」之爭不在本 skill
  範圍）；定位為**語言學現象**
- 不附評論段、不附「我的改寫思路」
- 不混用兩種強度（同一文段內須一致）
- 不翻譯成「台灣腔的普通話」——那是 `taiwan-mandarin` 的事，不是台語
- 不用全羅（POJ／台羅單獨書寫）——本 skill 採漢字優先

## 並列稱呼說明

本 skill 文件內並列使用「閩南語」「台語」「台灣閩南語」三種稱呼，
不偏一方。教育部官方規範稱「臺灣閩南語」，學界另有「台語」「Hokkien」
等用法，社會語境選詞各有偏好。本 skill 不對命名爭議表態。
