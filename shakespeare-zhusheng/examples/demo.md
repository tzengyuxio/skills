# Shakespeare-zhusheng — 示範

展示 `shakespeare-zhusheng` 如何把現代文章改寫成朱生豪式中譯莎劇腔，以及
好的莎翁譯腔長什麼樣子。

> **源文與引用說明**：範例一、範例二為依朱生豪式風格自編的「目標範例」，
> 用以示範靈魂條款怎麼落地，**非實際莎翁譯本**。範例三的源文（現代軼事）
> 為自編。範例四的源文 [《差不多先生傳》(胡適， 1924)](../../examples/source-texts/mr-chabuduo.md)
> 來自共用源文庫，公有領域。文中對四大悲劇（Hamlet / King Lear /
> Othello / Macbeth）的指涉僅作風格座標說明，未引用整段原譯。

---

## 範例一：風格目標 — 老者獨白（譬喻＋文白＋戲劇性情感）

這是 shakespeare-zhusheng 的「品牌示範」——展示**獨白＋譬喻系統＋文白
夾雜**最純粹的樣態。仿 Hamlet 哲學獨白的節奏，但角色換為老者面對時光的
悲嘆。

### 自編目標範例

> 〔幕啟〕暗室，燭光半枯。老者持鏡而坐，鏡中映出他白髮的影子。
>
> **老者（獨白）**：
>
> 噫！這把鏡——它映過我的青春，映過我的盛年，如今映得只是一團將熄
> 的燭影。命運，啊命運！你最殘忍的並非把我帶到此境，而是讓我於此境
> 之中，仍記得彼境之色。
>
> 玫瑰於青春之園盛開，玫瑰亦於老年之園盛開——然而前者之芬芳是希望，
> 後者之芬芳是悼念。我曾誓言：此生不向時光低頭。然則時光不曾與我交
> 手——他只在每個清晨悄悄取走我的一根白髮，直到我的鏡中已無黑髮可
> 取。啊！豈非這般取勝最為可怖？
>
> 縱使有人於此刻闖入，持劍指我說：「老者，將你之餘年交我！」我亦不
> 必驚——因為時光早已先他一步，將我的餘年取得乾乾淨淨。
>
> 〔將鏡覆於膝上〕
>
> 我來自塵土，終歸塵土；唯有這一柄燭，陪我度過這從盛年到塵土的旅程。
>
> 〔燭光忽暗，幕落〕

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 戲劇格式：〔幕啟〕＋〔幕落〕＋角色名前綴＋〔舞台說明〕 | S-04 戲劇格式 | 此例約 280 字屬 Soft 邊界但仍採完整格式 |
| 獨白佔 100% | S-02 獨白 ≥30% | 老者獨自一人的哲學獨白 |
| 譬喻系統：鏡／燭／玫瑰／塵土 | S-03 譬喻密度 + V-05 文藝復興詞彙 | 自然意象（鏡/燭/玫瑰）+ 抽象概念（命運/青春/盛年）並置 |
| 文白夾雜：噫／然則／豈非／縱使／焉得 | V-01 文白點綴 | 點綴而非通篇文言 |
| 戲劇性情感：「啊命運！」「啊！豈非⋯⋯最為可怖？」 | V-02 情感外露 | 強烈呼告與反問 |
| 結尾「我來自塵土，終歸塵土」 | S-05 戲劇性收束 | 譬喻收場＋〔幕落〕 |
| 角色：老者（抽象稱）| C-05 抽象稱 | 不取現代姓名 |

**風格座標**：與 Hamlet 「To be or not to be」段、Macbeth 「Tomorrow,
and tomorrow, and tomorrow」段的哲學獨白氣質相承——**用譬喻系統承載人類
共通的時間焦慮**。

## 範例二：風格目標 — 鬼魂與公子對話（譬喻＋戲劇性對白）

示範第二種配置——**王子／鬼魂**。仿 Hamlet 父親鬼魂登場的場景結構，但
台詞為原創。展示**戲劇對白＋押韻雙行詩**的搭配。

### 自編目標範例

> 〔幕啟〕城堡平台。三更時分，寒風凜冽。
>
> **公子（獨於台前，望遠方）**：
> 父王⋯⋯父王！汝若聞我之聲，請現身。
>
> **鬼魂（自陰影中緩出，白衣）**：
> 吾兒——
>
> **公子（顫慄）**：
> 啊！噫嘻！此聲——此聲十年未聞，然每一字皆如刀，刻於我心之最深處！
>
> **鬼魂**：
> 吾兒，聽我言——縱使我已歸於彼岸之國，我之冤仍滯於此岸之風中。
>
> **公子**：
> 父王，何冤？
>
> **鬼魂**：
> 那為我斟最後一杯酒之人，即為奪我王冠之人。那笑迎我入棺之人，即為
> 使我入棺之人。
>
> **公子（怒，拔劍）**：
> 啊！我願以此劍——
>
> **鬼魂（舉手，色靜）**：
> 不，吾兒。劍，是奪命之物；而你需做的，是給命運一個方向。汝之手若
> 顫，則此劍已敗。
>
> **公子**：
> 父王，何時⋯⋯何時方為其時？
>
> **鬼魂（漸隱）**：
> 當你能於微笑中持劍——而非於怒火中持劍——其時自至。
>
> 〔鬼魂消失，風更急〕
>
> **公子（獨自，輕誦）**：
> 縱使天上有星，亦不及此刻之黑；
> 縱使地下有眠，亦不及此心之裂。
>
> 〔幕〕

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 戲劇格式：完整劇本格式 | S-04 戲劇格式 | 角色前綴＋〔舞台說明〕＋〔幕〕 |
| 對白＋公子獨白雙重結構 | S-02 獨白與對白並重 | 結尾段為公子獨自輕誦 |
| 譬喻：酒／棺／劍／星／眠／微笑與怒火 | S-03 譬喻密度 | 每段至少 1 處譬喻 |
| 戲劇性情感：「啊！噫嘻！」「父王！」 | V-02 情感外露 | 顫慄、怒、悲交織 |
| 押韻雙行詩：「縱使天上有星，亦不及此刻之黑／縱使地下有眠，亦不及此心之裂」 | S-06 押韻雙行 | 黑／裂尾韻（仄聲），對仗工整 |
| 文白夾雜：吾兒／汝／縱使／何時／焉得 | V-01 文白點綴 | 對白中自然出現 |
| 角色：公子／鬼魂（抽象稱）| C-05 抽象稱 | 不取音譯名也不取現代姓名 |

**風格座標**：與 Hamlet 第一幕第五景父親鬼魂揭示謀殺真相的場景結構相
承——**鬼魂指引方向，公子承擔命運**。

## 範例三：改寫示範 — 現代軼事

源文（自編）──**現代軼事**：

> 一名工程師接到三天內交專案的死線，連夜加班寫出醜陋的程式碼，事後花更多
> 時間重構，最後產品被取消。

### 改寫

> 〔幕啟〕場景：嘉興城外，山下木匠工坊。燭光昏黃，木屑遍地。
>
> **木匠（獨白，撫刀而立）**：
>
> 啊！這把刻刀在我手中，已二十春秋。它曾在玫瑰木上刻過愛情，在檀香
> 木上刻過誓言，亦曾在松木上刻過墓銘——然今夜，它要在這塊敕命之木
> 上，刻下我此生最後的虛榮。
>
> 三日之約，三日！縱使日月可借，何以能借？縱使星辰可摘，何以能摘？
> 此木非木，乃我之命；此像非像，乃我之名。我若雕成，則名動九州；我
> 若失手⋯⋯啊，焉得失手！焉得失手！
>
> 〔燭光忽暗，門外風起〕
>
> **弟子（持燭入）**：師父，夜深了。
>
> **木匠**：夜深？卿不知麼，今夜之燭，照的是我之心；今夜之木，雕的是
> 我之骨。汝且去歇——縱使天上有星，亦不及這刀光之亮；縱使地上有土，
> 亦不及這木屑之重。
>
> 〔弟子退〕
>
> 〔三日後，廟祝登場〕
>
> **廟祝（接像，置之桌上）**：祠堂前日已圮。
>
> **木匠（怔立）**：⋯⋯
>
> **廟祝**：朝廷棄此祠改築它處，敕令未及收回。
>
> **木匠（緩緩跪下，手撫神像之眉眼）**：
>
> 啊！命運！你這既盲且聾的劊子手！你以三日之約縛我心，卻以拆祠之斧
> 斷我夢！這神像之眉，偏了一分；我之心，偏了千里！我以塵土之手，雕
> 了塵土之像，獻給已成塵土之祠⋯⋯
>
> 〔將神像置於懷中，緩起，長嘆〕
>
> 罷了。塵歸於塵，土歸於土。
>
> 〔押韻雙行詩〕
>
> > 三日如刀劃此心，
> > 一像如夢葬煙塵。
>
> 〔幕落〕

**達標清單**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留「急工→失敗→自悔」核心張力 |
| C-02 | ✓ | 悲劇軸：野心（留名）vs 命運（祠堂已拆）|
| S-01 | ✓ | 約 480 字（含舞台說明），戲劇格式 Soft 規則邊界 |
| S-02 | ✓ | 獨白佔比 ≥50%（開場獨白＋接旨後獨白＋臨終獨白）|
| S-03 | ✓ | 譬喻密度：玫瑰木／檀香木／松木／墓銘、三日如刀、一像如夢、塵歸於塵土歸於土等多處 |
| S-04 | ✓ | 戲劇格式：角色前綴＋〔舞台說明〕＋押韻雙行詩＋〔幕落〕|
| S-05 | ✓ | 結尾押韻雙行詩「三日如刀劃此心，一像如夢葬煙塵」＋〔幕落〕|
| S-06 | ✓ | 押韻雙行詩成立（心／塵 通押）|
| V-01 | ✓ | 半文白：「嗚呼」「奈何」「縱使」「焉得」「卿」自然點綴 |
| V-02 | ✓ | 戲劇性呼告：「啊！焉得失手！」「命運！你這既盲且聾的劊子手！」 |
| V-03 | ✓ | 容納歐化翻譯感（「啊！」「焉得失手！」呼告），同時保留戲劇詩意與譬喻 |
| V-05 | ✓ | 文藝復興詞彙：命運、塵土、星辰、王冠 |
| M-02 | ✓ | 譬喻嵌入情感：「三日如刀劃此心」呼應急工煎熬，「塵歸塵土歸土」呼應失落終局 |

**對照結論**：朱生豪腔不是「給故事加感嘆詞」，而是**讓人物在悲劇命運前
獨白**——「命運！你這既盲且聾的劊子手！」沒有解釋為何如此呼喊，但讀完
整段你會知道：那是一個工匠面對「自己的成就被命運直接抹除」的瞬間，唯一
能做的事就是把這個瞬間提升為人類共通的悲劇。

## 範例四：改寫示範 — 《差不多先生傳》→ 莎士比亞悲劇

源文：**胡適《差不多先生傳》(1924)摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 原文

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不
> 多，是各省各縣各村人氏。⋯⋯
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」⋯⋯
>
> 後來他得急病，趕快叫家人去請東街的汪先生。一面慌一面跑，人急了，東西
> 兩街，汪王不分，跑到西街牛醫王大夫家裡。⋯⋯王大夫用醫牛之法給他治病，
> 差不多先生就此一命嗚呼。

（原文採取**諷刺寓言**體例。「差不多先生」是國民性的擬人化批判。）

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽張力 | 「差不多」是消解判準的執著——平日無事，臨終之際才發現「差一寸」即是生死之別 |
| 主題抽象化 | 把差不多先生升格為悲劇主角，「差不多」是他的悲劇之鑰——以差不多為冠、為劍、為印，最終以差不多殞命 |
| 角色配置 | 主角／合唱團（Chorus）— 仿希臘悲劇式合唱旁白評論 |
| 譬喻系統 | 印／冠／劍 vs 鏽／塵／裂；星辰／距離 |
| 戲劇格式 | 完整劇本格式（≥500 字必加）|
| 收場 | 臨終獨白（譬喻收場：「我以差不多，作我一生之印」）+ 合唱旁白 + 押韻雙行詩 + 〔幕落〕 |

### 改寫後

> 〔幕啟〕場景：湖廣山下小鎮酒肆。陋室一間，差不多公臥於榻上，氣若游絲。
> 鄉人立於榻側，持燭。窗外明月初升。
>
> **差不多公（臨終獨白，氣弱）**：
>
> 啊！死亡！你來得真快——快得像一支射偏的箭。可是我這一生射偏的箭，
> 豈非比你更多？紅糖，白糖，我不分；陝西，山西，我不察；醫人，醫
> 牛，我不辨。
>
> 我以「差不多」三字，作我一生之印，作我一生之冠，作我一生之劍——
> 而今，差不多三字，卻成了我印上之裂、我冠上之塵、我劍上之鏽。
>
> 啊！命運啊命運！你既盲且聾，可你的銀針卻刺得這般精準！我以差不多
> 遊戲世間，世間以差一寸殺我以還。差一寸——豈非差不多？然這一寸，
> 卻是我之生與死的距離。
>
> 〔向眾人，氣弱〕
>
> 諸君，當我合眼之時，記得——差不多者，終必差不多；然此「終」之差
> 不多，豈是當初之差不多哉！
>
> 〔氣絕。眾鄉人垂首〕
>
> 〔合唱旁白 / Chorus（自舞台兩側緩出）〕：
>
> 看哪，這位差不多公——
> 他生時差不多，死時亦差不多；
> 然他臨終那一刻，方才明白了那一寸：
> 那一寸，即是他與我們、與命運、與星辰之間的距離。
>
> 縱有星辰可問，星辰不答；
> 縱有銀針可索，銀針已歸鞘。
> 唯有此公之屍，獨臥於月下，
> 提醒著世人：毫釐不可差，差一寸即生死。
>
> 〔押韻雙行詩〕
>
> > 願爾之差，終於毫釐之巔；
> > 願爾之眠，長過寒星之年。
>
> 〔月光忽明，幕落〕

（約 550 字）

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留「差不多」核心張力；原文諷刺被轉化為悲劇命運感 |
| C-02 | ✓ | 悲劇軸：差不多／差一寸——含混度日 vs 毫釐之差為生死 |
| C-03 | ✓ | 無現代專名 |
| C-05 | ✓ | 角色：差不多公（保留源文角色名）+ 合唱旁白（Chorus，仿希臘悲劇）|
| S-01 | ✓ | 約 550 字，超過 500 字必加完整戲劇格式 |
| S-02 | ✓ | 獨白佔比 ≥60%（臨終獨白 + 合唱旁白）|
| S-03 | ✓ | 譬喻密度：箭、印、冠、劍、鏽、塵、裂、銀針、星辰、距離、月下、寒星——多重交疊 |
| S-04 | ✓ | 完整戲劇格式：〔幕啟〕＋角色前綴＋〔舞台說明〕＋〔幕落〕|
| S-05 | ✓ | 結尾：押韻雙行詩＋〔月光忽明，幕落〕 |
| S-06 | ✓ | 押韻雙行：巔／年（平水韻 一先 通押）|
| V-01 | ✓ | 半文白：嗚呼、噫、縱使、豈非、焉得、奈何、此情自然點綴 |
| V-02 | ✓ | 戲劇性情感：「啊！死亡！」「啊！命運啊命運！」呼告密度高 |
| V-03 | ✓ | 容納歐化翻譯感（「啊！」「焉得失手！」呼告），同時保留戲劇詩意與譬喻 |
| V-05 | ✓ | 文藝復興詞彙：命運、星辰、距離、月下 |
| M-02 | ✓ | 譬喻嵌入情感：印／冠／劍 vs 鏽／塵／裂 整組譬喻呼應「差不多」三字的命運轉折 |

**改寫的核心動作**：把胡適原文「明寫的諷刺」轉為「莎翁式的悲劇命運感」。
原文是雜文體諷刺，莎翁版讓「差不多公」成為一個有譬喻系統、有戲劇格式、
有合唱旁白、有押韻收場的悲劇主角——**他不是因牛醫而死，是因『差不多』
這個哲學自身的命運邏輯而死**——而這個道理由合唱旁白（Chorus）的詠嘆
與押韻雙行詩共同承擔。

## 速查：Checklist 重點

21 條中最常踩的：

| 編號 | 規則 | 怎麼用 |
|---|---|---|
| C-02 | 必有悲劇張力軸 | 寫之前明確寫下「悲劇衝突 = X」（野心／嫉妒／復仇／瘋狂／命運擇一）|
