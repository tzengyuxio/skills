# Feihua-literature — 改寫成廢話文學

把任何文章改寫成廢話文學——表面上一本正經地說了話，實際上一個字的新資訊
都沒給。讀完以後，讀者知道的事不會比讀之前多；讀者沒被告知什麼，但也不會
意識到自己沒被告知什麼，因為每一句聽起來都像在傳達道理。

風格參照：2021 年下半年從 B 站彈幕（用戶「那就叫王師傅吧」的視頻）起家、
經饒舌歌《官方回答》與奧運期間運動員採訪 BGM 二次發酵後，於微博
#廢話文學大賽#（總閱讀量 1.1 億）、抖音 #廢話文學#(7.5 億播放）爆紅的
網路文體。

## 一句話靈魂

**零信息密度**——表面說了一整段話，實際每一句的後半都被前半「抵銷」、
「重述」或「等價代換」，讀完之後讀者知道的事不比讀之前多。三大公式
（同義替換 / 首尾矛盾 / 問答轉換）是達成零信息的工具，**至少二發**。

文學史錨點：魯迅〈秋夜〉「在我的後園，可以看見牆外有兩株樹，一株是棗樹，
還有一株也是棗樹」是公認的祖師句；朱自清〈論廢話〉是早期理論化嘗試。
2021 年的廢話文學是這條傳統在短視頻時代的爆發。

## Arguments

- `$0` —（選填）Markdown 或純文字檔案路徑。若省略，請使用者提供內文，
  或從對話上下文中找最近編輯的檔案。

## Step 1: Load the Text

- 若提供 `$0`，讀取該檔案。
- 若無引數，找對話中最近撰寫或編輯的 Markdown 檔，或請使用者提供文字。
- 若原文不是繁體中文，先在心中譯為繁體中文（不必輸出），再做改寫。

## Step 2: Extract the Real Message (target)

廢話文學不是亂寫，是**精確地把該說的事情用廢話把它說沒**。先把原文要傳達
的核心訊息抽出來，寫成一條不超過二十字的明白話，例如：

- 原文：工程師連夜寫醜程式碼，事後重構，產品被取消
- target：急著做出來的東西最後沒用

target 越清楚，改寫時才知道哪些「資訊」要被廢話化掉。

## Step 3: Choose Wrapper Combinations

從三大公式裡選 wrapper,**整篇至少二發**（可同類重複也可混搭）:

### 公式一：同義替換 / 同義反覆

後半重複前半關鍵詞，或用同義詞、單位換算、近義改寫做表面變化：

- 「聽君一席話，如聽一席話」（關鍵詞同字重複）
- 「七日不見，如隔一周」（單位換算）
- 「人每呼吸 60 秒，生命就會減少一分鐘」（數值換算）
- 「俗話說得好：俗話說得好」（原樣回收）
- 「我長話短說，但說來話長」（同義並陳）

### 公式二：首尾矛盾 / 套套邏輯

用反義詞讓句子前後互相否定，或用同義詞讓句子前後永真：

- 「這個西瓜很甜，因為它不苦」（反義永真）
- 「能力越大，能力就越大」（同義永真）
- 「看似很危險，其實一點也不安全」（反向繞回）
- 「但凡你有點本事，也不至於一點本事都沒有」（雙重否定回到原點）

### 公式三：問答轉換 / Q-keyword echo

回答抽取問題的關鍵詞改寫成答，使答案完全包含於問題之內：

- 「Q: 你為什麼遲到？ A: 因為我沒有準時。」
- 「Q: 你從哪裡來？ A: 從我來過的地方來。」
- 「Q: 你要吃什麼？ A: 吃我該吃的東西。」

短文（< 200 字）用 2 發即可；中長篇（200+ 字）建議 3–5 發，並讓三種公式
都至少出現一次。

## Step 4: Insert Wrappers Around the Target

把 target 拆成幾個小命題，每個命題外面包一層 wrapper。例如：

- target 命題：「他寫得很快」 → 廢話化：「他寫得很快，因為他並沒有慢下來」
- target 命題：「最後沒用」 → 廢話化：「最後它沒派上用場——畢竟用不上的
  東西本來就用不上」

關鍵是：**廢話的語氣必須一本正經**，語法要穩、句讀要對，不可以露出
「我知道我在說廢話」的破綻。

## Step 5: Add 廢話 Wrapper Vocabulary

選用以下 wrapper 詞當黏著劑，讓全文有「在做學問」的口氣：

- 「聽 / 如 / 不過是 / 而已 / 其實就是 / 換句話說 / 也就是說」
- 「據我所知 / 如果我沒猜錯 / 一般來說 / 通常情況下」
- 「凡是 / 但凡 / 只要 / 只有」
- 「眾所周知 / 不言自明 / 顯而易見」

但 wrapper 詞**只是潤滑劑，不是公式本身**。少了三大公式，光堆 wrapper
詞只會變成空洞，不會變成廢話文學。

## Step 6: Self-check Against Checklist

逐條對照下面的 21 條 checklist。**任一條 [Hard] 違反就回 Step 4 重寫
該段**。

### Checklist: Content（內容）

| 編號 | 強度 | 規則 |
|---|---|---|
| C-01 | Hard | **零信息密度**——讀完後讀者知道的事不比讀之前多。每一句的後半被前半抵銷、重述或等價代換。**靈魂條款**。 |
| C-02 | Hard | **三大公式至少二發**（同義替換 / 首尾矛盾 / 問答轉換，可同類重複也可混搭） |
| C-03 | Hard | **禁止傳遞任何真新訊息**。原文裡的事實、數字、地名、原因鏈，改寫後不可被讀者「學到」 |
| C-04 | Hard | **禁止反諷自嘲**。不可出現「我這是不是在說廢話」「我也覺得這話沒意義」這類後設破綻——廢話文學要假裝自己在傳達真理 |
| C-05 | Soft | 中長篇可三公式各出現一次；短篇至少二發即可 |

### Checklist: Structure（結構）

| 編號 | 強度 | 規則 |
|---|---|---|
| S-01 | Hard | 篇幅：短源（< 200 字）寫 100–250 字；中源（200–800）寫 200–500 字；長源（800+）寫 300–700 字。**廢話不該被拉長到讓讀者疲倦** |
| S-02 | Hard | **句長宜短**——以短句為主（平均 ≤20 字），兩句一組形成 wrapper 對。長複句會稀釋廢話的爽脆感 |
| S-03 | Soft | **節奏可重複、段落可循環**——廢話文學適合對偶、排比、回環句式 |
| S-04 | Soft | 整篇可分段也可單段，但每段內部必須至少有一個完整的廢話發數 |
| S-05 | Hard | **禁止「失敗版/成功版」「對照範例」「主題：⋯⋯」式 meta header**。輸出本體就是廢話本身，不要解釋 |

### Checklist: Voice（語感）

| 編號 | 強度 | 規則 |
|---|---|---|
| V-01 | Hard | **一本正經**——語氣平靜、措辭得體，像在做學問或寫公告。**靈魂條款之一**：廢話文學的笑點來自「正經臉說廢話」的反差，語氣一旦變調（嘲弄、戲謔、誇張）就破功 |
| V-02 | Hard | **不嘲弄、不自嘲**——既不嘲弄話題，也不嘲弄自己 |
| V-03 | Soft | 善用 wrapper 詞：「聽 / 如 / 不過是 / 而已 / 其實就是 / 換句話說 / 也就是說 / 據我所知 / 但凡 / 眾所周知」 |
| V-04 | Soft | 可加「俗話說得好 / 古人云 / 老話講 / 民間常說」這類偽引用，只要被引用的「俗話」本身也是廢話 |
| V-05 | Soft | 可用問答體穿插，但每個答必須是 Q-keyword echo |

### Checklist: Meta（後設）

| 編號 | 強度 | 規則 |
|---|---|---|
| M-01 | Hard | 不附評論段、不附作者按、不附「我的改寫思路」 |
| M-02 | Hard | **不可出現破功句**——任何形式的「我知道這是廢話」「以上純屬廢話」「請勿當真」都違規 |
| M-03 | Hard | 不可摻入真知灼見——即使原文有金句，改寫後也要把它廢話化掉，不可原句保留 |
| M-04 | Soft | 標點全形、句讀清晰——廢話的形式必須端正，內容才有資格空洞 |
| M-05 | Soft | 篇末可留一個「最廢」收束句，讓讀者意識到自己什麼都沒被告知 |

| 編號 | 強度 | 規則 |
|---|---|---|
| X-01 | Soft | **零信息密度**是這個 skill 的存在理由。其他 20 條都在服務這一條 |

**總計**:21 條（Hard 12 + Soft 9）。

## Step 7: Punctuation & 朗讀 Cleanup

- CJK 標點全形（`,`→`,`、`.`→`。`、`:`→`:`、`!`→`!`、`?`→`?`、
  `(`→`(`)
- 全形標點與 CJK 之間零空格
- 大聲朗讀一遍——若任何一句聽起來像「在傳達真資訊」，改掉
- 若有句子需要讀者花腦筋才能確認它是廢話，改成更直白的廢話

## Step 8: Output

1. **檔案輸入**：寫入 `<原檔名>_feihua.md`，保留原檔
2. **貼文輸入**：直接輸出廢話文學
3. **不附說明、不附評論、不附「我的改寫思路」**
4. 若使用者明確要求，可額外輸出**改寫筆記**（列出 target 與三大公式
   發數），但**主輸出永遠是廢話本身**

## Step 9: Final Sanity Pass

最後一道檢查——讀完輸出，問自己一句：

> 如果讀者只看了我的輸出、沒看原文，他能知道原文在講什麼嗎？

**理想答案是「不能」**。如果他能，那是還沒寫夠廢。回 Step 4 加 wrapper。

## Anti-patterns（常見失敗模式）

寫完一稿、自檢之前，先掃一眼這 8 條最容易踩的坑：

1. **wrapper 詞堆疊但沒公式**——只放「眾所周知」「換句話說」卻沒做同義
   替換或矛盾，變成空洞而非廢話
2. **語氣變嘲弄**——一句「你說呢」「我也是醉了」就破功
3. **真資訊洩漏**——把原文的數字、人名、地名留下來，讀者學到了東西
4. **反諷自嘲**——出現「我是不是在說廢話」「以上是廢話」就違規
5. **公式只一發**——只做同義替換不做矛盾或問答，密度不夠
6. **句子太長**——廢話愈長愈像論文，失去爽脆感
7. **太用力造金句**——廢話文學是「平靜的零信息」，不是「機智的悖論」
8. **加 meta header**——「失敗版」「成功版」「主題：⋯⋯」一律違規

## Important Notes

- 本 skill 是**體裁轉換工具**。原文真要傳達的訊息（target）必須先抽出來，
  改寫的工作是「把它包進廢話裡讓讀者學不到」
- **語氣是核心**——平靜、得體、像做學問。一旦變嘲弄就不是廢話文學，是
  別的東西
- **三大公式至少二發**是密度底線，低於這個就只是廢話，還沒到廢話文學
- **不要解釋自己**——廢話文學的笑點在於它假裝自己有意義。一旦解釋就破功
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
