# Feihua-literature — 改寫成廢話文學

把任何文章改寫成廢話文學——表面上一本正經地說了話，實際上一個字的新資訊
都沒給。

不是把句子寫得難懂，不是把段落寫得冗長，而是**讓零信息密度成為文體**——
讀完之後，讀者知道的事不比讀之前多。

## 什麼是廢話文學？

廢話文學是 2021 年下半年從 B 站彈幕（用戶「那就叫王師傅吧」的視頻）起家、
經饒舌歌《官方回答》與奧運期間運動員採訪 BGM 二次發酵後爆紅的網路文體。

2021 年 9 月起在微博 #廢話文學大賽# 話題下集中爆發（總閱讀量 1.1 億、
4.8 萬人參與、多次登上熱搜），抖音 #廢話文學# 話題播放量突破 7.5 億次，
迅速成為現象級網路語言。

文學史錨點：

- **魯迅〈秋夜〉（1924）**——「在我的後園，可以看見牆外有兩株樹，一株是
  棗樹，還有一株也是棗樹」是公認的祖師句
- **朱自清〈論廢話〉**——早期理論化嘗試
- **2021 廢話文學爆發**——這條傳統在短視頻時代的集中爆發

`feihua-literature` 鎖定的是 2021 年成熟期的爆款公式：**三大句式 + 一本
正經的口氣 + 零信息密度**。

## 一句話靈魂

**零信息密度**——表面說了一整段話，實際每一句的後半都被前半「抵銷」、
「重述」或「等價代換」，讀完之後讀者知道的事不比讀之前多。

## 三大公式

廢話文學的爆款句式可歸納為三類，改寫時**至少二發**（可同類重複也可混搭）：

### 公式一：同義替換 / 同義反覆

後半重複前半關鍵詞，或用同義詞、單位換算、近義改寫做表面變化。

- 「聽君一席話，如聽一席話」
- 「七日不見，如隔一周」
- 「人每呼吸 60 秒，生命就會減少一分鐘」
- 「俗話說得好：俗話說得好」
- 「我長話短說，但說來話長」

### 公式二：首尾矛盾 / 套套邏輯

用反義詞讓句子前後互相否定，或用同義詞讓句子前後永真。

- 「這個西瓜很甜，因為它不苦」
- 「能力越大，能力就越大」
- 「看似很危險，其實一點也不安全」
- 「但凡你有點本事，也不至於一點本事都沒有」

### 公式三：問答轉換 / Q-keyword echo

回答抽取問題的關鍵詞改寫成答，使答案完全包含於問題之內。

- 「Q: 你為什麼遲到？ A: 因為我沒有準時。」
- 「Q: 你從哪裡來？ A: 從我來過的地方來。」
- 「Q: 你要吃什麼？ A: 吃我該吃的東西。」

## 不會做的事

- 不寫機智的悖論（廢話文學是「平靜的零信息」，不是「Wilde 式機智」）
- 不寫嘲弄、自嘲（一旦變嘲弄就破功——「我這是不是廢話」是違規句）
- 不在文末「揭穿」自己（「以上純屬廢話」一類後設破綻）
- 不保留原文金句（即使原文有真知灼見，改寫後也要廢話化掉）
- 不堆 wrapper 詞而沒有實質公式——光放「換句話說」「眾所周知」沒有
  同義替換 / 矛盾 / 問答，只會變空洞，不會變廢話文學

## 預期輸出篇幅

繁體中文，語氣平靜得體：

| 原文長度 | 廢話文學目標 |
|---|---|
| 短（< 200 字）| 100–250 字，公式至少二發 |
| 中（200–800 字）| 200–500 字，公式 3–5 發 |
| 長（800+ 字）| 300–700 字，三公式各至少一發 |

廢話不該被拉長到讓讀者疲倦。**密度而非長度**才是這個文體的指標。

## 適合的源文

- 政府公告、官方聲明（本身已偏冗，廢話化效果好）
- 自傳體散文、寓言（有明確 target 可被廢話化）
- 新聞稿、會議通知（實用資訊豐富，廢話化反差大）
- 心靈雞湯、職場名言（原本就半廢，徹底廢話化反而清晰）
- 童話、短篇敘事（像《小王子》這類細節豐富的，可被穩穩包住）

## 不太適合的源文

- 純抒情詩（沒有明確 target 可廢話化）
- 已經是廢話文學的源文（改寫意義不大）
- 純技術文件、程式碼說明（廢話化後完全無法傳遞，但讀者也學不到任何
  東西——這倒是符合靈魂條款，但實用價值低）
- 笑話、段子（廢話文學的笑點在「正經」，先有笑點反而干擾）

「tautology talk」

## 運作流程

1. **讀原文** — 載入內文
2. **抽 target** — 用一句不超過二十字的話寫出「原文真要傳達什麼」
3. **選 wrapper 公式** — 從三大公式選組合，整篇至少二發
4. **包進廢話** — 把 target 的小命題逐個 wrapper 化
5. **加 wrapper 詞** — 「換句話說」「眾所周知」「但凡」這類黏著劑
6. **Checklist 自檢** — 21 條（Hard 12 + Soft 9）
7. **標點與朗讀清理** — 全形標點、句讀清晰、朗讀檢查
8. **輸出** — 寫入 `<原檔名>_feihua.md`，不附說明
9. **Final sanity** — 自問：讀者讀完能知道原文在講什麼嗎？ 不能才及格

## 改寫原則（checklist 摘要）

| 類別 | 編號 | 要點 |
|------|------|------|
| Content | C-01~C-05 | 零信息密度、三大公式至少二發、禁止傳遞真新訊息、禁止反諷自嘲 |
| Structure | S-01~S-05 | 篇幅短至中、句長宜短、節奏可重複、禁止 meta header |
| Voice | V-01~V-05 | 一本正經、不嘲弄、wrapper 詞、可偽引用、可問答體 |
| Meta | M-01~M-05 | 不附評論、不可破功句、不摻真知灼見、標點端正、最廢收束句 |

完整 21 項 checklist 與 9 步 workflow 見 [SKILL.md](./SKILL.md)。

## 三條靈魂條款

廢話文學的指紋：

1. **C-01 零信息密度** — 讀完後讀者知道的事不比讀之前多
2. **C-02 三大公式至少二發** — 同義替換 / 首尾矛盾 / 問答轉換
3. **V-01 一本正經** — 平靜、得體、像做學問，語氣變調就破功

三者缺一就不是廢話文學。其餘 18 條 checklist 都在服務這三條。
