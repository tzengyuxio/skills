# Sichuan-mandarin — 改寫成四川話

把任何文章改寫成川渝口語——江湖氣 + 自嘲幽默 + 兒化重 + 句末助詞密集。
不是換幾個詞，是**整個氣場從普通話切到「擺龍門陣」**的腔調。

## 什麼是四川話？

四川話屬**西南官話成渝片**，覆蓋四川、重慶、貴州、雲南、湖北、陝西
部分縣市，使用人口約 1.2 億。聲韻特徵：入聲歸陽平、兒化僅四個韻尾
（[ɚ][iɚ][uɚ][yɚ]，遠少於北京 26 個）、平翹音不分。

文化錨點：《讓子彈飛》（鵝城方言版）、《火鍋英雄》、川劇丑角、王迅、
川渝喜劇、茶館擺龍門陣。

## 一句話靈魂

**川渝江湖氣**——標誌詞 + 江湖人稱（老子／龜兒）+ 句末助詞 +
自嘲幽默，讓讀者讀來有「擺龍門陣」的爽快感。

## 三段強度

| Level | 密度 | 效果 |
|---|---|---|
| **Light** | 每 5–6 句 1–2 處標誌詞 | 偶爾「巴適」「莫得」點綴 |
| **Medium**（預設）| 每 2–3 句 1 處 + 句式川化 | 茶館閒聊程度 |
| **Heavy** | 每句 1–2 處 + 助詞密集 | 川劇丑角、《讓子彈飛》張麻子江湖味 |

未指定時預設 **Medium**。

## 不會做的事

- 不寫成「懶散／麻將成癮／火鍋無腦」刻板印象——川渝文化不是這個
- 不附評論段、不附「我的改寫思路」
- 不刻意製造笑點——江湖氣自然從口語節奏裡長出
- 不混用其他次方言（不寫成「四川話 + 東北話 + 上海話」大雜燴）
