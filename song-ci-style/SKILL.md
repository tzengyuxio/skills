# Song Ci-style — 改寫成宋詞（依詞牌格律填詞）

把任何現代散文壓縮、重組、押韻、合律，填入五個經典宋代詞牌之一,
產出一首字數合譜、句長合譜、押韻位置合譜的完整詞作。輸出帶有派別標
籤([豪放派]或[婉約派]),全篇只用古典意象，現代詞彙一律不入詞。

## 一句話靈魂

**選對牌、合對律、用對意象**——詞不是把散文拆短句加古字，而是先**為文章
情緒挑一個詞牌**,再依該牌的字數 / 句長 / 押韻 / 平仄譜把意義重壓進去;
古典意象群是詞的肌理，現代專名是詞的死敵。豪放婉約只能擇一，不可混。

> **重要定位(必讀)**:本 skill 是**體裁致敬**,不是字句模仿。學的是
> 詞牌格律、上下闋結構、派別意象，而不是抄蘇辛李煜的句子。輸出須是**新
> 寫**的詞作，不可借用古人原句；古人原句僅作風格座標，放在參照樣本段。

## 詞牌格律表(SIGNATURE)

五個詞牌，記下總字數、上下闋句長序列、押韻位置、平仄譜。**填詞前必先選
定一牌，並把該牌的格律抄在草稿頂端**,逐句對照填寫。

平仄符號:**平** = 必平聲、**仄** = 必仄聲、**中** = 可平可仄。

### 1. 水調歌頭(95 字，雙調，中長調)

- **總字數**:95;**上闋** 9 句 48 字;**下闋** 10 句 47 字
- **押韻**:四平韻為主，中間可間入兩仄韻(蘇軾體)
- **句長序列**(蘇軾體):
  - 上闋:5 / 5 / 6 / 5 / 6 / 6 / 5 / 5 / 5
  - 下闋:3 / 3 / 3 / 4 / 7 / 6 / 6 / 5 / 5 / 5
- **平仄譜要點**:上闋首句「中仄仄平仄」、次句「中仄仄平平(韻)」、第 3 句六字「中平中仄平仄」、第 4 句「中仄仄平平(韻)」、第 5-6 句兩句六字一仄一仄(可間入兩仄韻);下闋以「轉朱閣，低綺戶，照無眠」式三字三句啟，接四字 + 七字奇句後再續六字對仗，結句五字三句收
- **代表作**:蘇軾〈水調歌頭·明月幾時有〉(對照原作逐句：明月幾時有 / 把酒問青天 / 不知天上宮闕 / 今夕是何年 / 我欲乘風歸去 / 又恐瓊樓玉宇 / 高處不勝寒 / 起舞弄清影 / 何似在人間 — 上闋 5/5/6/5/6/6/5/5/5;轉朱閣 / 低綺戶 / 照無眠 / 不應有恨 / 何事長向別時圓 / 人有悲歡離合 / 月有陰晴圓缺 / 此事古難全 / 但願人長久 / 千里共嬋娟 — 下闋 3/3/3/4/7/6/6/5/5/5)
- **適合題材**:中秋、思念、仕途感慨、宇宙人生宏大題

### 2. 念奴嬌(100 字，雙調，長調)

- **總字數**:100;**上闋** 11 句 49 字;**下闋** 11 句 51 字
- **押韻**:**全篇仄韻**(常用入聲韻),上下闋各四仄韻在第 3、6、9、11 句末；一韻到底
- **句長序列**(蘇軾體):
  - 上闋:4 / 3 / 6 / 4 / 3 / 6 / 4 / 4 / 5 / 4 / 6
  - 下闋:6 / 5 / 4 / 4 / 3 / 6 / 4 / 5 / 4 / 4 / 6
- **平仄譜要點**:上闋以「四 / 三 / 六」三句一節重複兩次，後接「四 / 四 / 五 / 四 / 六」收；下闋首句六字過片(「遙想公瑾當年」式),次句五字 + 四字相承，中段又以「四 / 三 / 六」一節呼應上闋，結句以「人生如夢」四字句 + 「一尊還酹江月」六字句作結；氣勢開闔大
- **代表作**:蘇軾〈念奴嬌·赤壁懷古〉(對照原作逐句：大江東去/浪淘盡/千古風流人物 — 4/3/6 韻；故壘西邊/人道是/三國周郎赤壁 — 4/3/6 韻；亂石穿空/驚濤拍岸/捲起千堆雪 — 4/4/5 韻；江山如畫/一時多少豪傑 — 4/6 韻；遙想公瑾當年/小喬初嫁了/雄姿英發 — 6/5/4 韻；羽扇綸巾/談笑間/檣櫓灰飛煙滅 — 4/3/6 韻；故國神遊/多情應笑我/早生華髮 — 4/5/4 韻；人生如夢/一尊還酹江月 — 4/6 韻)
- **適合題材**:懷古、史詠、豪邁、英雄人物、江山感慨

### 3. 虞美人(56 字，雙調，小令)

- **總字數**:56;**上闋** 28 字 4 句;**下闋** 28 字 4 句
- **押韻**:**平仄韻交替**——每片內兩仄韻 + 兩平韻，押韻方式甲乙丙丁(每兩句換一次韻)
- **句長序列**(李煜體):
  - 上闋:7 / 5 / 7 / 9
  - 下闋:7 / 5 / 7 / 9
- **平仄譜要點**:首句「中平中仄平平仄(仄韻)」，次句「中仄中平仄(仄韻同部)」，三句「中平中仄平平仄(換平韻)」，末句九字「中平中仄仄平平(平韻)」一氣呵成
- **代表作**:李煜〈虞美人·春花秋月何時了〉
- **適合題材**:悲愴、失去、亡國、短嘆、追憶

### 4. 如夢令(33 字，單調，小令)

- **總字數**:33;**單調** 7 句(不分上下闋，但意義上有自然轉折)
- **押韻**:**五仄韻 + 一疊韻**(第 5、6 句二字疊句押同一仄韻)
- **句長序列**:6 / 6 / 5 / 6 / 2 / 2 / 6
- **平仄譜要點**:
  - 1:中仄中平平仄(韻)
  - 2:中仄中平平仄(韻)
  - 3:中仄仄平平
  - 4:中仄中平平仄(韻)
  - 5:中仄(韻，二字疊句首)
  - 6:中仄(韻，二字疊句，通常與 5 同字或近義字)
  - 7:中仄中平平仄(韻)
- **代表作**:李清照〈如夢令·常記溪亭日暮〉
- **適合題材**:瞬間印象、細膩、戲劇感、追憶一個小場景

### 5. 西江月(50 字，雙調，中調)

- **總字數**:50;**上闋** 25 字 4 句;**下闋** 25 字 4 句(完全對稱)
- **押韻**:**平仄通叶格**——上下闋各 2 平韻 + 1 仄韻(末句押仄，須與平韻同部)
- **句長序列**:
  - 上闋:6 / 6 / 7 / 6
  - 下闋:6 / 6 / 7 / 6
- **平仄譜要點**:
  - 1:中仄中平平仄(不押)
  - 2:中平中仄平平(平韻)
  - 3:中平中仄仄平平(平韻)
  - 4:中仄中平中仄(仄韻，須同部)
  - 下闋同上
- **代表作**:辛棄疾〈西江月·夜行黃沙道中〉
- **適合題材**:田園、議論、旁觀、夜行、節氣感

## 詞牌選擇邏輯

讀完原文,**先判定情緒主軸與篇幅張力**,再對照下表挑牌。**選牌須在輸出
時用一兩句說明理由**(放於正文之前的 metadata)。

| 文章特徵 | 推薦詞牌 | 派別建議 |
|---|---|---|
| 宏大、思念、仕途感慨、中秋、宇宙意識 | 水調歌頭 | 豪放（偏蘇式） |
| 懷古、英雄、江山、史事、慷慨豪邁 | 念奴嬌 | 豪放（必） |
| 悲愴、失去、亡國、人生短嘆、追憶往事 | 虞美人 | 婉約（必） |
| 瞬間印象、戲劇小場景、細膩、女性視角 | 如夢令 | 婉約（偏李清照式） |
| 田園、夜行、議論、節氣、旁觀感、農村風光 | 西江月 | 豪放或閒淡（辛棄疾兼擅） |

選牌**錯位**最常見的失敗：用如夢令寫赤壁懷古(篇幅不夠)、用念奴嬌寫
雨後散步(篇幅太大)、用虞美人寫田園豐年(調性不合)。

## 豪放派 vs 婉約派

| 維度 | 豪放派(蘇辛) | 婉約派(李煜柳永李清照) |
|---|---|---|
| **氣勢** | 開闔大、奔放、不拘音律 | 含蓄、纏綿、嚴守音律 |
| **句法** | 詩句法入詞、宏博、議論 | 細膩白描、形象柔和 |
| **意象** | 大江、孤鴻、千古、英雄、酹月、長劍、鐵馬、寒鴉(寬鏡頭) | 春花、秋月、梧桐、細雨、斜陽、煙柳、紅樓、燕子(近景) |
| **主題** | 懷古、史事、家國、宇宙 | 男女、離愁、閨情、亡國個人哀傷 |
| **代表** | 蘇軾、辛棄疾、陳亮 | 李煜、柳永、李清照、晏殊 |

**派別擇一，不可混**。一首詞內若同時出現「鐵馬冰河」與「梧桐細雨」，大
抵就破了。輸出時**標註 [豪放派] / [婉約派] 作為 metadata**。

## 參照樣本(五牌真實原作)

放此段以證明已 web research,並作為填詞時的格律座標。**禁抄錄原句**,
學的是骨架不是字句。

**蘇軾〈水調歌頭·明月幾時有〉(1076)**:

> 明月幾時有？把酒問青天。不知天上宮闕，今夕是何年。我欲乘風歸去,
> 又恐瓊樓玉宇，高處不勝寒。起舞弄清影，何似在人間。
>
> 轉朱閣，低綺戶，照無眠。不應有恨，何事長向別時圓？人有悲歡離合,
> 月有陰晴圓缺，此事古難全。但願人長久，千里共嬋娟。

**蘇軾〈念奴嬌·赤壁懷古〉(1082)**:

> 大江東去，浪淘盡，千古風流人物。故壘西邊，人道是，三國周郎赤壁。亂石
> 穿空，驚濤拍岸，捲起千堆雪。江山如畫，一時多少豪傑。
>
> 遙想公瑾當年，小喬初嫁了，雄姿英發。羽扇綸巾，談笑間，檣櫓灰飛煙滅。
> 故國神遊，多情應笑我，早生華髮。人生如夢，一尊還酹江月。

**李煜〈虞美人·春花秋月何時了〉(978)**:

> 春花秋月何時了，往事知多少。小樓昨夜又東風，故國不堪回首月明中。
>
> 雕闌玉砌應猶在，只是朱顏改。問君能有幾多愁，恰似一江春水向東流。

**李清照〈如夢令·常記溪亭日暮〉(約 1099)**:

> 常記溪亭日暮，沉醉不知歸路。興盡晚回舟，誤入藕花深處。爭渡，爭渡,
> 驚起一灘鷗鷺。

**辛棄疾〈西江月·夜行黃沙道中〉**:

> 明月別枝驚鵲，清風半夜鳴蟬。稻花香裏說豐年，聽取蛙聲一片。
>
> 七八個星天外，兩三點雨山前。舊時茅店社林邊，路轉溪橋忽見。

特徵分析:
- **水調歌頭**:長調氣勢、上闋仰問下闋鋪敘、結句必收於人事普世
- **念奴嬌**:仄韻一氣、四字短句疊出、「人生如夢」式收
- **虞美人**:上下闋格式完全對稱、九字長句作收、平仄韻交替造往復感
- **如夢令**:單調七句、「爭渡爭渡」式二字疊句是命門
- **西江月**:6676 句式整齊、上下闋鏡像、夜景田園感最自然

## Arguments

- `$0` —(選填)Markdown 或純文字檔案路徑。若省略，請使用者提供內文,
  或從對話上下文中找最近編輯的檔案。

## Step 1: Load the Text

- 若提供 `$0`,讀取該檔案。
- 若無引數，找對話中最近撰寫或編輯的 Markdown 檔，或請使用者提供文字。
- 若原文不是繁體中文，先在心中譯為繁體中文(不必輸出),再做改寫。

## Step 2: 判斷情緒主軸與篇幅

讀完原文，用一句話自答:

> 這篇的**情緒核心**是什麼?(豪邁 / 悲愴 / 細膩瞬間 / 田園議論 / 思念
> 宏大?)**篇幅張力**是密集如一個瞬間，還是綿長如一段史事?

把答案寫在草稿頂端：「情緒 = X;篇幅張力 = Y」。

## Step 3: 選牌(必輸出選牌理由)

依 Step 2 與「詞牌選擇邏輯」對照表，挑一個詞牌。**輸出時必須包含一兩
句選牌理由**(放於詞作之前):

> 「選牌：虞美人。原文寫一段失去後的追憶，情感壓得低，九字結句正好
> 一氣帶出沉痛——故選此牌。」

選牌時須同時定派別:**[豪放派]** 或 **[婉約派]**,寫進 metadata。

## Step 4: 抄譜在草稿頂端

把所選詞牌的**句長序列、押韻位置、平仄譜**抄下來，逐句留白。例如選虞美人:

```
[平仄] 中平中仄平平仄 (仄韻 A) — 7
[平仄] 中仄中平仄 (仄韻 A) — 5
[平仄] 中平中仄仄平平 (平韻 B) — 7
[平仄] 中平中仄仄平平 (平韻 B) — 9
[過片]
[平仄] 中平中仄平平仄 (仄韻 C) — 7
[平仄] 中仄中平仄 (仄韻 C) — 5
[平仄] 中平中仄仄平平 (平韻 D) — 7
[平仄] 中平中仄仄平平 (平韻 D) — 9
```

**無此譜不可動筆**。譜抄錯了，後面全錯。

## Step 5: 提取核心意象(古典化)

把原文的核心元素**翻譯成古典意象**。現代專名一律換成詞庫中的等價物:

| 現代 | 古典等價 |
|---|---|
| 城市 / 街道 | 長安 / 京華 / 金陵 / 古道 / 通衢 |
| 火車 / 飛機 | 舟楫 / 鐵騎 / 征鞍 / 孤帆 |
| 咖啡 / 茶 | 酒 / 茶 / 觴 / 杯 |
| 燈光 | 燭 / 燈 / 月光 |
| 朋友 / 親人 | 故人 / 知交 / 兄弟 / 良朋 |
| 工作 / 職場 | 宦遊 / 功名 / 仕途 / 塵勞 |
| 手機 / 訊息 | 尺素 / 魚雁 / 鴻書 / 紙鳶 |
| 季節變化 | 春花 / 秋月 / 冬雪 / 夏蟬 |

挑出 3-5 個**核心古典意象**,先寫在草稿邊欄，再分配上下闋。

## Step 6: 寫上闋——景 / 起興

上闋多以**景**或**起興**開篇，鋪設場景與情緒底色。長調(水調歌頭、念
奴嬌)上闋寫景空間大，小令(虞美人、如夢令)上闋直接切入物象。

寫上闋時**逐句對照 Step 4 抄下的譜**,字數對、平仄盡量對(中字位置可
鬆)、押韻位置不可錯。

> **格律寬嚴**:現代填詞**字數與押韻位置必嚴**(這是不可妥協的);**平
> 仄譜可寬**(允許「中」位自由，主韻位儘量合；若實在難合，優先保意義
> 與押韻，平仄微誤可接受)。但「字數錯」「韻位錯」「該平處全仄」三大
> 違規會直接破譜。

## Step 7: 過片轉折

雙調詞(水調歌頭、念奴嬌、虞美人、西江月)上下闋之間有「**過片**」——
意義或角度的轉折點。常見過片手法:
- **景轉情**(上闋寫景，下闋抒情):虞美人「雕闌玉砌應猶在」承上啟下
- **物轉人**(上闋詠物，下闋詠人):念奴嬌「遙想公瑾當年」
- **遠轉近**(上闋遠景，下闋近景):水調歌頭「轉朱閣，低綺戶」

如夢令是單調，無過片，但第 4-5 句之間常有**意義跳接**(從敘述跳到呼
喊，如「誤入藕花深處。爭渡，爭渡」)。

## Step 8: 寫下闋——情 / 議論 / 收束

下闋承接過片，通常**以情或議論作結**。每個詞牌的**收束慣常情調**不同:

| 詞牌 | 收尾調性 |
|---|---|
| 水調歌頭 | 普世收(「但願人長久」式),從個人推及眾人 |
| 念奴嬌 | 蒼茫收(「人生如夢」「一尊還酹」式),英雄到頭仍空 |
| 虞美人 | 沉痛收(「一江春水向東流」式),九字一氣帶出悲 |
| 如夢令 | 戲劇收(「驚起一灘鷗鷺」式),動作收尾留聲響 |
| 西江月 | 豁然收(「路轉溪橋忽見」式),旁觀者一個轉身發現 |

**收尾須符合所選牌的慣常調性**——虞美人不可豁然收、如夢令不可普世收。

## Step 9: 押韻檢查 + 平仄譜檢查

寫完一稿,**逐句點檢**:

1. **字數**:每句字數對不對?(用阿拉伯數字數，不要憑感覺)
2. **韻位**:該押韻的句子有沒有押？同片內韻是否同部？平仄韻交替的
   牌，平韻句押平、仄韻句押仄?
3. **平仄譜**:主韻位平仄對不對？「中」位以外的字，大致合譜?
4. **派別一致**:豪放派句子裡有沒有混入婉約派典型意象(梧桐細雨)?反
   之亦然?

任一條失守，回到 Step 6/7/8 重寫該句或該闋。

## Step 10: 標點清理 + 自檢指令

最後一道工序:

- **全形標點(鐵律)**:CJK 文本中所有標點一律全形。**ASCII 半形 `, ; : ? !` 在 CJK 字之間出現一律是 bug**,必須換成全形 `,;:?!`。對照表:

  | 半形(禁) | 全形(用) | Unicode |
  |---|---|---|
  | `,` | `,` | U+FF0C |
  | `;` | `;` | U+FF1B |
  | `:` | `:` | U+FF1A |
  | `?` | `?` | U+FF1F |
  | `!` | `!` | U+FF01 |
  | `(` `)` | `(` `)` | U+FF08 / U+FF09 |

- **句末標點**:詞作每句以全形「，」或「。」收；上下闋分段以空行分隔
- **引號**用「」/『』，不用 `"` `'`
- **破折號**用「——」(兩個全形),不用 `--`
- **全形標點與 CJK 之間零空格**

- **寫完後必跑自檢指令**(機械驗證，不可省略):

  ```bash
  python3 -c "
  import re, sys
  text = open(sys.argv[1]).read()
  bad = re.findall(r'[^\x00-\x7f][,;:?!][^\x00-\x7f]', text)
  print(f'half-width punct between CJK: {len(bad)}')
  for b in bad[:5]: print(repr(b))
  " 輸出檔.md
  ```

  結果必須為 `0`。非 0 表示輸出時混入 ASCII 半形，回到輸出檔逐字替換後重跑，直到歸零才算交付。

## Step 11: Self-check Against Checklist

逐條對照下面 21 條 checklist。**任一條 [Hard] 違反就回對應步驟重寫**。

### Checklist: Concrete(意象 / 物件)

| 編號 | 強度 | 規則 |
|---|---|---|
| C-01 | Hard | **古典意象密度**——詞中至少出現 3 個經典意象(月 / 風 / 江 / 樓 / 酒 / 笛 / 燕 / 梅 / 雁 / 柳 / 簫 / 鶴 / 舟 / 苔 / 砌)|
| C-02 | Hard | **現代詞彙零違規**——禁出現電腦 / 飛機 / 咖啡 / 手機 / 公司 / 捷運 / 地鐵 / Wi-Fi / email 等任何現代專名;Step 5 對照表必走 |
| C-03 | Hard | **核心意象與情緒對位**——若是悲詞，意象須走凋零系(殘月 / 落葉 / 寒蟬);若是豪詞，意象須走宏闊系(大江 / 鐵馬 / 千古)|
| C-04 | Soft | 意象組合不堆砌——每句不超過 2 個並列意象，避免「梅蘭竹菊月風花雪」式拼湊 |

### Checklist: Surface(句法 / 標點 / 格律)

| 編號 | 強度 | 規則 |
|---|---|---|
| S-01 | Hard | **字數合譜**——所選詞牌總字數須完全相符(水調歌頭 95 / 念奴嬌 100 / 虞美人 56 / 如夢令 33 / 西江月 50)|
| S-02 | Hard | **句長序列合譜**——逐句字數須與所選詞牌的句長序列完全對應 |
| S-03 | Hard | **押韻位置合譜**——該押韻的句子必押，不押的句子不押；同片內同韻部 |
| S-04 | Hard | **平仄類型合譜**——念奴嬌全仄韻、水調歌頭主平韻、虞美人平仄交替、西江月平仄通叶、如夢令五仄一疊；此類型不可錯 |
| S-05 | Soft | **平仄譜主位合**——韻腳字平仄須對；非韻腳字「中」位寬，實字位儘量合譜(允許小違) |
| S-06 | Hard | **如夢令二字疊句**——若選如夢令，第 5、6 句須為二字疊句(如「爭渡，爭渡」「知否，知否」),這是該牌命門 |
| S-07 | Hard | **全形標點零違規**——CJK 字之間的 ASCII 半形 `, ; : ? !` 計數須為 0;以 Step 10 自檢指令驗證 |

### Checklist: Voice(派別 / 語感)

| 編號 | 強度 | 規則 |
|---|---|---|
| V-01 | Hard | **派別必擇一**——[豪放派] 或 [婉約派] 標籤須出現於 metadata,且全篇意象與句法統一於該派，不混 |
| V-02 | Hard | **句法與派別一致**——豪放派允許詩句法、議論句、宏博用事；婉約派須細膩白描、纏綿、含蓄，禁宏博議論 |
| V-03 | Soft | **文白比例**——詞體本是文言為骨，允許少量白話虛字(也、了、卻、便),但不可大量現代白話 |
| V-04 | Soft | **不抄古人原句**——禁直接挪用「明月幾時有」「大江東去」「春花秋月」等名句；化用可，挪用不可 |

### Checklist: Meta(結構 / 後設)

| 編號 | 強度 | 規則 |
|---|---|---|
| M-01 | Hard | **選牌理由必出**——詞作前須有一兩句說明為什麼選這個詞牌(對位文章情緒與篇幅)|
| M-02 | Hard | **標題格式**——「詞牌名·副題」格式(例：〈水調歌頭·秋夜偶感〉),副題須與內容對位 |
| M-03 | Hard | **上下闋分段**——雙調詞須以空行分隔上下闋；單調(如夢令)不分段 |
| M-04 | Hard | **收尾合該牌調性**——虞美人收沉痛、念奴嬌收蒼茫、如夢令收戲劇動作、水調歌頭收普世、西江月收豁然；不可錯位 |
| M-05 | Hard | **不附評論段**——不附「這首詞展現了 X」式自評，不附「我的填詞思路」；詞作即終點，留餘韻 |
| M-06 | Hard | **不代蘇辛李煜發言**——禁「蘇軾若在會說」「正如稼軒當年」式句子；體裁致敬，非作者代言 |

**總計**:21 條(Hard 17 + Soft 4)。

3. **輸出格式**:

## Anti-patterns(常見失敗模式)

寫完一稿、自檢之前，先掃這 9 條最容易踩的坑:

1. **字數不合詞牌** — 水調歌頭寫成 92 字、念奴嬌寫成 95 字。**Step 9 第
   1 條逐句點數**,缺一不可(違反 S-01、S-02)
2. **押韻位置錯** — 該押韻的句子沒押，不該押的硬塞韻；或同片內換韻
   部。**Step 4 抄譜時把韻位標出**(違反 S-03)
3. **平仄類型大幅違譜** — 念奴嬌寫成平韻、虞美人通篇仄韻不換。**Step
   2 選牌時就要對齊類型**(違反 S-04)
4. **上下闋失衡** — 上闋鋪了 60 字，下闋只剩 35 字；或反之。**雙調詞上
   下闋字數須各依譜分配**(違反 S-01、M-03)
5. **現代詞彙混入** — 把「捷運」「咖啡」「電腦」直接寫進詞裡，即使其
   他都合律也整篇破。**Step 5 對照表必走**,禁原樣保留現代專名(違反
   C-02)
6. **豪放婉約混雜** — 同一首詞既有「鐵馬冰河」又有「梧桐細雨」、既懷
   古又閨怨，派別精神分裂。**Step 3 選牌時定派別，全篇貫徹**(違反
   V-01、V-02)
7. **如夢令缺二字疊句** — 寫了七句卻無「爭渡，爭渡」式疊句；或疊句寫
   成三字、四字。**S-06 是如夢令的命門**(違反 S-06)
8. **抄古人原句** — 直接寫「明月幾時有」「大江東去」當自己的句子。**化
   用可，挪用不可**(違反 V-04)
9. **半形標點混入** — 輸出時把 `,;:?!` 打成 ASCII 半形而非全形。常見
   原因是 IME 切換失誤或從英文 prompt 複製字串。寫完務必跑 Step 10 自
   檢指令，計數歸零(違反 S-07)

如果使用者要的是**唐詩**或**元曲**或**現代新詩**,告訴使用者本 skill 鎖
定**宋代詞牌格律填詞**,不適合那些體裁——本 skill 第一版只覆蓋五個經典
詞牌，其他詞牌(如蝶戀花、鵲橋仙、滿江紅、永遇樂、菩薩蠻)未來版本或可
擴充。

## Important Notes

- 本 skill 是**體裁致敬工具**,不是「給文章加幾個古字」工具，更不是「代
  蘇辛李煜發言工具」。原文的核心情緒與張力必須以該詞牌的格律重新承載
- **格律是門檻，不是裝飾**——字數、句長、押韻位置三項合譜是 Hard;平仄
  譜的「中」位以外允許小違，但主韻位平仄必對
- **派別擇一，不可調和**——豪放婉約是兩種美學，不是兩種顏色可以調色
- **意象是肌理**——古典意象不是裝飾品，是詞的肌膚；現代專名一進詞就死
- **選牌即半成功**——錯選詞牌(用如夢令寫赤壁懷古),後面再合律也救不
  回來;Step 2-3 是最重要的兩步
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
