# Song Ci-style — 改寫成宋詞(依詞牌格律填詞)

把任何現代散文重寫為宋詞——一首字數 / 句長 / 押韻 / 平仄譜全都合譜的完
整詞作，並帶有派別標籤([豪放派] / [婉約派])。

不是「把段落拆短句加幾個古字」、不是「換幾個文言虛詞」，而是**先為文章
情緒選一個詞牌，再依該詞牌的格律把意義重壓進去**。古典意象是詞的肌
理，現代專名一進詞就死。

## 一句話靈魂

**選對牌、合對律、用對意象**——詞牌格律是門檻、派別美學是基調、古典
意象群是肌膚；三者缺一就不是詞。

## 三條風格指紋

1. **S-01~S-04 格律合譜** — 字數、句長序列、押韻位置、平仄類型四項全
   對；主韻位平仄不可錯
2. **C-02 現代詞彙零違規** — 電腦、咖啡、捷運、Wi-Fi 一律不入詞;Step
   5 對照表把現代專名翻譯成古典等價物
3. **V-01 派別擇一** — [豪放派] / [婉約派] 標籤必出，意象與句法統一於
   該派，不混

三者缺一就不是詞。其餘 18 條 checklist 都在服務這三條。

## 何時使用

- 想把一篇現代散文壓縮為一首合譜的宋詞
- 想體驗「填詞」這件事的格律約束(字數、句長、押韻、平仄)
- 想把日常情緒以蘇辛或李煜李清照的詞牌結構重新承載
- 想看豪放派 vs 婉約派的句法 / 意象差異具體長什麼樣子

## 何時**不**用

- 想寫唐詩 — 本 skill 鎖定宋詞詞牌，不做近體詩格律
- 想寫元曲 / 現代新詩 — 體裁不同，韻部與格律不同
- 想寫純文言短篇散文 — 用 `wenyan-guwen` 或 `liaozhai-tale`
- 想寫蘇軾本人代言 — 本 skill 是體裁致敬，不是作者代言

依所選詞牌而定,**字數須與該詞牌完全一致**:

| 如夢令 | 33 字 |

加上選牌理由與標題約 30-50 字 metadata。

## 適合的源文

- 抒情散文(思念、追憶、節氣感)
- 旅行札記(夜行、田園、登高)
- 史評懷古(讀史心得、古蹟感懷)
- 個人軼事(失去、聚散、瞬間印象)

## 不太適合的源文

- 純技術文件、新聞報導
- 已經是詩詞的源文
- 帶大量現代政治指涉的文(古典意象難以承載)
- 對話 / 戲劇腳本(詞體不適合多人對白)

## 運作流程

1. **讀原文 + 判定情緒主軸與篇幅張力** — 一句話自答「情緒 = X;篇幅 = Y」
2. **選牌(輸出選牌理由)** — 五牌對照表，定派別 [豪放派] / [婉約派]
3. **抄譜在草稿頂端** — 句長序列、押韻位置、平仄譜逐句留白
4. **提取核心意象並古典化** — 現代專名翻譯成古典等價物(對照表)
5. **寫上闋：景 / 起興** — 逐句對譜
6. **過片轉折** — 雙調詞的承上啟下
7. **寫下闋：情 / 議論 / 收束** — 收尾須符合該牌慣常調性
8. **押韻檢查 + 平仄譜檢查** — 字數、韻位、平仄、派別四點逐一查
9. **標點清理 + 自檢指令** — 全形標點機械驗證計數歸零
10. **Checklist 自檢** — 21 條(Hard 17 + Soft 4)
11. **輸出** — 寫入 `<原檔名>_song-ci.md`

## 改寫原則(checklist 摘要)

| 類別 | 編號 | 要點 |
|------|------|------|
| Concrete | C-01~C-04 | 古典意象密度、現代詞彙零違規、意象與情緒對位、不堆砌 |
| Surface | S-01~S-07 | 字數合譜、句長合譜、押韻合譜、平仄類型合譜、主韻位平仄合、如夢令二字疊句、全形標點 |
| Voice | V-01~V-04 | 派別必擇一、句法與派別一致、文白比例、不抄古人原句 |
| Meta | M-01~M-06 | 選牌理由必出、標題格式、上下闋分段、收尾合調性、不附評論、不代古人發言 |

完整 21 項 checklist 與 12 步 workflow 見 [SKILL.md](./SKILL.md)。

## 派別差異速查

| 維度 | 豪放派(蘇辛) | 婉約派(李煜柳永李清照) |
|---|---|---|
| 氣勢 | 開闔大、不拘音律 | 含蓄、纏綿、嚴守音律 |
| 意象 | 大江、孤鴻、千古、鐵馬 | 春花、秋月、梧桐、煙柳 |
| 主題 | 懷古、家國、宇宙 | 男女、離愁、閨情、亡國個人傷 |
