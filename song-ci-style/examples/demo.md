# Song Ci-style — 示範

展示 `song-ci-style` 如何把現代散文壓縮為合譜的宋詞。三個範例**各用不同
詞牌、不同派別、不同情緒主軸**,不共用骨架——每個詞牌長出自己的篇。

> **源文與引用說明**:範例一源文 [《雨天故事》](../../examples/source-texts/weather-rain.md)
> 為共用源文庫自編，無版權疑慮。範例二源文 [《差不多先生傳》(胡適,
> 1924)](../../examples/source-texts/mr-chabuduo.md) 來自共用源文庫，公
> 有領域。範例三源文 [The Little Prince](../../examples/source-texts/little-prince.md)
> 為依 Saint-Exupéry 原作風格自編的短摘錄。文中對蘇軾、辛棄疾、李煜、
> 李清照詞作的引用僅作格律座標說明，皆為公有領域。
>
> **重要定位**:本 skill 為體裁致敬，非作者代言。下列示範皆是依詞牌
> 格律新填的詞作,**不挪用古人原句**;化用詞牌結構與意象群，但句子須
> 自鑄。

---

## 範例一：改寫示範 — 雨天故事 → 如夢令

源文:**自編〈雨天故事〉**,共用源文庫
[`examples/source-texts/weather-rain.md`](../../examples/source-texts/weather-rain.md)。

### 原文

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是
> 決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回
> 到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫
> 計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### 選牌與派別

**[婉約派] 選牌：如夢令。** 原文是一個瞬間印象——午後驟雨、空街、忘鑰、
鄰人問話、自欺微笑——情緒密集、戲劇感強、宜短不宜長。如夢令 33 字單
調七句，正好一筆收住一場雨，二字疊句「知否，知否」可以承擔最後那個自
己對自己的無聲質問。

### 詞作

#### 〈如夢令·驟雨〉

> 忽報西窗雨驟,
> 倉皇空街徑走。
> 鑰落舊書齋,
> 鄰叟憑窗回首。
> 知否。
> 知否。
> 袖底分明銅鈕。

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 古典意象 ≥3:西窗、空街、書齋、銅鈕、雨 |
| C-02 | ✓ | 無現代詞彙；「圖書館」轉「書齋」、「計程車」隱去、「錢包/鈔票」轉「銅鈕」(古銅錢) |
| C-03 | ✓ | 意象與情緒對位：雨驟 / 空街 / 鑰落 / 銅鈕——皆細微落寞，合婉約調 |
| S-01 | ✓ | 共 33 字(6+6+5+6+2+2+6),合譜 |
| S-02 | ✓ | 句長序列 6/6/5/6/2/2/6,完全對譜 |
| S-03 | ✓ | 押韻位置:1、2、4、5、6、7 句押仄韻;3 句不押 |
| S-04 | ✓ | 五仄韻 + 一疊韻——驟 / 走 / 首 / 否 / 否 / 鈕，皆詞林正韻第十二部(有 / 厚 / 宥) |
| S-06 | ✓ | 二字疊句「知否，知否」，正合李清照式命門 |
| S-07 | ✓ | 全形標點，計數歸零 |
| V-01 | ✓ | [婉約派] 標籤，意象走細膩落寞系 |
| V-04 | ✓ | 「知否，知否」化用李清照〈如夢令·昨夜雨疏風驟〉句法，但全篇情境自鑄，非挪用原句 |
| M-02 | ✓ | 標題格式：〈如夢令·驟雨〉 |
| M-04 | ✓ | 戲劇收尾：「袖底分明銅鈕」——錢就在袖中，卻說沒帶，自欺剎那以一個物件動作收住 |

## 範例二：改寫示範 — 《差不多先生傳》→ 水調歌頭

源文:**胡適《差不多先生傳》(1924) 摘錄**,共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

### 原文

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名
> 不多，是各省各縣各村人氏。⋯⋯
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」⋯⋯
>
> 後來他得急病，趕快叫家人去請東街的汪先生。⋯⋯王大夫用醫牛之法給他
> 治病，差不多先生就此一命嗚呼。

### 選牌與派別

**[豪放派] 選牌：水調歌頭。** 原文諷刺寓言收於生死大義——「差不多」
四字蓋住一生，從買糖到延醫到墳塚。情緒不是悲愴一聲就收得住的，須一個
從仰問到鋪陳到普世的長調來承載。水調歌頭 95 字，上闋寫差先生在世的
苟且，下闋寫死後墳塚的空闊與千古普世；結句「但願」式，正合此調慣常
收法。

### 詞作

#### 〈水調歌頭·差不多先生〉

> 浮世千般事,
> 何處不糊塗。
> 我見縣城東畔,
> 一客姓差夫。
> 凡事一概差矣,
> 諸般且自隨喜,
> 笑罷捋長鬚。
> 但聽炊煙斷,
> 落日掛城隅。
>
> 轉茅店,
> 過石巷,
> 訪殘墟。
> 醫牛醫主,
> 一笑何分廢與初。
> 春去秋來無數,
> 月落星沉如故,
> 一塚枕荒蕪。
> 莫問差人意,
> 此意古今俱。

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 古典意象 ≥3:縣城、炊煙、落日、茅店、石巷、殘墟、月落星沉、荒蕪、塚 |
| C-02 | ✓ | 無現代詞彙；「醫生 / 大夫」轉「醫牛醫主」、「死了」轉「炊煙斷 / 一塚枕荒蕪」 |
| C-03 | ✓ | 意象與情緒對位：塚 / 荒蕪 / 月落星沉——蒼茫感，合豪放派長調 |
| S-01 | ✓ | 共 95 字(上闋 48 + 下闋 47),完全合譜 |
| S-02 | ✓ | 上闋句長 5/5/6/5/6/6/5/5/5,下闋 3/3/3/4/7/6/6/5/5/5,完全對譜 |
| S-03 | ✓ | 平韻在句 2/4/7/9(上闋)及句 3/5/8/10(下闋),仄韻在上闋句 5/6 |
| S-04 | ✓ | 主平韻(虞韻第四部：塗 / 夫 / 鬚 / 隅 / 墟 / 初 / 蕪 / 俱),間入兩仄韻(止韻：矣 / 喜),合蘇軾體 |
| S-07 | ✓ | 全形標點，計數歸零 |
| V-01 | ✓ | [豪放派] 標籤；氣勢從個人推至千古普世 |
| V-02 | ✓ | 句法走豪放議論：「醫牛醫主，一笑何分廢與初」「莫問差人意，此意古今俱」皆議論句 |
| V-04 | ✓ | 不抄蘇軾原句；「但聽⋯⋯」「莫問⋯⋯」是化用句法，非挪用 |
| M-02 | ✓ | 標題：〈水調歌頭·差不多先生〉 |
| M-03 | ✓ | 上下闋以空行分隔 |
| M-04 | ✓ | 普世收尾：「莫問差人意，此意古今俱」——從差先生一人推及千古眾人，合水調歌頭慣常情調 |

## 範例三：改寫示範 — 小王子摘錄 → 虞美人

源文:**自編〈Little Prince〉摘錄**,共用源文庫
[`examples/source-texts/little-prince.md`](../../examples/source-texts/little-prince.md)。

### 原文

> The little prince lived alone on a tiny planet, no bigger than a house.
> He had three volcanoes to clean, and a rose that he loved very much.
> Every morning, he would clean his volcanoes and water his rose. One
> day, he decided to leave his planet to explore the universe. He was
> sad to say goodbye, but he knew he had to go.

### 選牌與派別

**[婉約派] 選牌：虞美人。** 原文是一個小王子告別小行星的離別敘事——
所失甚輕(一朵薔薇、三座小山),情卻甚深；李煜亡國體之輕重不對稱正合
此境。虞美人 56 字，上下闋對稱，九字結句一氣帶出沉痛，正適合「不得不
走」這種無解的告別。

### 詞作

#### 〈虞美人·童子別星〉

> 三峰小苑無人到,
> 一朵薔薇老。
> 童心欲問九重霄,
> 卻怕扁舟一去更迢迢。
>
> 故園春色留難住,
> 別緒空回顧。
> 相思幾度過長安,
> 但見孤帆一葉入雲端。

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 古典意象 ≥3:三峰、薔薇、九重霄、扁舟、故園、春色、孤帆、雲端 |
| C-02 | ✓ | 無現代詞彙；「planet」轉「小苑 / 三峰 / 故園」、「rose」轉「薔薇」、「universe」轉「九重霄」、「leave」轉「扁舟一去」 |
| C-03 | ✓ | 意象與情緒對位：薔薇老 / 別緒 / 孤帆——皆告別系細微意象，合婉約 |
| S-01 | ✓ | 共 56 字(上闋 28 + 下闋 28) |
| S-02 | ✓ | 句長序列上下闋皆 7/5/7/9,完全對譜 |
| S-03 | ✓ | 押韻位置每句皆押 |
| S-04 | ✓ | 平仄韻交替：上闋仄韻(到 / 老，皓號韻部第八部)→ 平韻(霄 / 迢，蕭韻第八部);下闋換仄韻(住 / 顧，遇韻第四部)→ 換平韻(安 / 端，寒桓韻第七部);四韻相互不同，合虞美人格 |
| S-07 | ✓ | 全形標點，計數歸零 |
| V-01 | ✓ | [婉約派] 標籤；意象柔和、情感壓住 |
| V-02 | ✓ | 句法細膩白描，無宏博議論 |
| V-04 | ✓ | 不抄李煜原句；「故園」「別緒」是李煜詞庫常見字眼，但組合自鑄 |
| M-02 | ✓ | 標題：〈虞美人·童子別星〉 |
| M-03 | ✓ | 上下闋以空行分隔 |
| M-04 | ✓ | 沉痛收尾：「但見孤帆一葉入雲端」——九字一氣帶出告別感，合虞美人慣常情調 |

## 速查：格律與選牌重點

| 詞牌 | 字數 | 派別建議 | 收尾調性 | 何時該選 |
|---|---|---|---|---|
| 如夢令 | 33 | 婉約 | 戲劇動作 | 一個瞬間印象、強戲劇感小景 |
| 西江月 | 50 | 豪放或閒淡 | 豁然轉身 | 田園、夜行、議論、節氣感 |
| 虞美人 | 56 | 婉約 | 沉痛九字 | 失去、亡國、告別、追憶 |
| 水調歌頭 | 95 | 豪放(偏蘇式) | 普世推及 | 中秋、思念、宇宙、仕途 |
| 念奴嬌 | 100 | 豪放(必) | 蒼茫如夢 | 懷古、史事、英雄、家國 |
