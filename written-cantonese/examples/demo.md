# Written Cantonese — 示範

展示 `written-cantonese` 把文章改寫成完整粵語書面語的三段強度——**Light /
Medium / Heavy**——以及好的粵語書面長什麼樣。

> **源文與引用說明**：範例一源文為 [`weather-rain.md`](../../examples/source-texts/weather-rain.md)（自編，無版權疑慮）；範例二為自編生活情境；範例三為自編 LIHKG / 連登式論壇貼文，純為展示 Heavy 強度的網絡語體；範例四源文為 [《差不多先生傳》（胡適，1924）](../../examples/source-texts/mr-chabuduo.md) 公有領域。本 demo 不引用任何政治題材；連登詞範例僅作語體標記用途，無政治立場。

---

## 範例一：雨天故事 — Light（普及型粵語書面）

源文：[weather-rain.md](../../examples/source-texts/weather-rain.md)

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### 粵語 Light（TVB 字幕風）

> 琴日下晝我喺圖書館睇書嘅時候，突然落起大雨嚟。雖然我冇帶遮，不過都決定行路返屋企。條路好多人，周圍都係撐住遮嘅人。我全身濕晒，返到屋企先發覺鎖匙唔記得喺寫字樓。隔籬鄰居見到我咁樣，笑住問：「你做咩唔叫的士啊？」我唯有苦笑答佢：「我唔記得帶銀包。」

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 「我喺 / 我冇 / 唔記得 / 都係」 | G1 | 核心虛詞全替換：在→喺、沒→冇、不→唔、是→係 |
| 「行路返屋企」 | V1 + V2 | 行（走）+ 屋企（家） |
| 「濕晒」 | G3 | 動補後置「晒」= 完盡貌 |
| 「先發覺」 | G2 | 副詞後置變體：先 + V |
| 「做咩唔叫的士啊」 | G7 + G5 | 反問句式 + 句末助詞「啊」 |
| 「答佢」 | G4 | 直接接賓語「佢」 |
| 「琴日 / 下晝 / 寫字樓 / 隔籬」 | V2 | 文化詞：昨日 / 下午 / 辦公室 / 鄰居 |
| 「銀包 / 鎖匙 / 遮」 | V2 | 港式生活詞替換 |

**達標檢核**

- G1 核心虛詞：✓（喺 / 冇 / 唔 / 嘅 / 咗 / 佢 / 啲）
- G2 副詞後置 / G3 動補後置：✓（濕晒、先發覺）
- G5 句末助詞：✓（嚟、啊）
- 朗讀：粵語自然落地

**詞彙表**：琴日（昨日）、下晝（下午）、屋企（家）、寫字樓（辦公室）、銀包（錢包）、鎖匙（鑰匙）、遮（雨傘）、隔籬（鄰居）、做咩（為什麼）、的士（計程車）。

## 範例二：辦公室片段 — Medium（Apple Daily / WhatsApp 風）

源文（自編）：

> 早上同事走進辦公室，看我臉色不太好，問我怎麼了。我說昨晚熬夜趕報告，現在頭很痛，想回家睡覺。他笑了笑說：「你也太拚了，我去幫你倒杯熱水。」我說謝謝，覺得有這樣的同事真好。

### 粵語 Medium（中度 code-mixing + 完成貌密集）

> 朝早個 colleague 行入嚟 office，望我塊面色唔多好，問我搞咩事。我話琴晚捱通宵趕個 report，而家頭痛到爆，想返屋企瞓覺喎。佢笑笑口話：「你真係拼得太緊喇，等我幫你倒杯滾水先啦。」我同佢講多謝，覺得有咁嘅同事真係好彩。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 「行入嚟 office」 | G2 + V6 | 副詞後置（入嚟）+ code-mixing |
| 「望我塊面色」 | V1 + S3 | 望（看）+ 塊（量詞） |
| 「搞咩事」 | G7 | 反問結構（=怎麼回事） |
| 「捱通宵 / 而家 / 痛到爆」 | V1 + V3 | 粵語動詞 + 程度詞「到爆」 |
| 「想返屋企瞓覺喎」 | V1 + G5 | 瞓（睡）+ 句末「喎」 |
| 「拼得太緊喇」 | G3 + G5 | 完成貌「喇」 |
| 「等我幫你倒杯滾水先啦」 | G2 + G5 | 「先」副詞後置 + 「啦」 |
| 「同佢講」 | G6 | 「同 + 對象 + V」表「跟…說」 |
| 「真係好彩」 | V3 + G1 | 真係（真是）+ 程度詞 |

**達標檢核**

- G1：✓（係 / 唔 / 嘅 / 佢 / 喺）
- G2 副詞後置：✓（行入嚟、倒杯滾水先）
- G3 動補後置：✓（拼得太緊喇）
- G5 句末助詞：✓（喎 / 喇 / 啦）
- V6 code-mixing：✓（office / colleague / report）

**詞彙表**：朝早（早上）、塊面（臉）、搞咩事（怎麼了）、琴晚（昨晚）、捱通宵（熬夜）、而家（現在）、瞓覺（睡覺）、滾水（熱水）、好彩（幸運 / 真好）。

## 範例三：連登貼文 — Heavy（LIHKG / 高登式論壇文體）

源文（自編，描述一則加班抱怨；無政治題材）：

> 公司又叫我加班趕報告，週末都不能休息。我覺得很累，但又不敢開口拒絕，怕老闆不高興。同事說我太老實，應該學會推。我想了想，覺得他說的也對。

### 粵語 Heavy（連登 / LIHKG 風）

> 巴打絲打救命啊，間公司又 call 我 OT 趕個 report，連 weekend 都唔畀休息，係咪當我牛㗎？我真係攰到 on9，但又唔敢出聲推，驚個 boss 唔開心，遲啲炒我魷魚啦。隔籬個同事話我太老實，應該學識 say no，唔好咩都應晒。我諗咗陣，又覺得佢講得啱喎。LM 個世界係咁㗎啦，做到死先係好打工仔咩？

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 「巴打絲打」 | V4 | 連登開場語（中性版本，純語體標記） |
| 「call 我 OT / boss / weekend / report / say no」 | V6 + S4 | 密集 code-mixing |
| 「係咪當我牛㗎」 | G7 + G5 | 反問「係咪」+ 句末「㗎」 |
| 「攰到 on9」 | V4 + V3 | 連登詞「on9」+ 程度補語「到 X」 |
| 「炒我魷魚啦」 | V2 + G5 | 港式社區詞 + 句末「啦」 |
| 「應晒」 | G3 | 完成貌「晒」（全部都應） |
| 「諗咗陣」 | G3 | 完成貌 + 量詞片語 |
| 「LM 個世界」 | V4 | 連登俚語縮寫（中性處理：純語體記號） |
| 「做到死先係好打工仔咩」 | G2 + G5 | 副詞後置（先）+ 反詰「咩」 |
| 句末助詞群 | G5 | 啊 / 㗎 / 啦 / 喎 / 咩 / 㗎啦 連發 |

**達標檢核**

- G1：✓
- G2 / G3：✓（諗咗陣、應晒、做到死先）
- G4 雙賓語：「炒我魷魚」（V + 對象 + 內容）
- G5：每 1-2 句一個粒子，密度極高
- V4 連登：✓
- V6 code-mixing：每 2-3 句一個英文插入
- M3 政治詞：✓（無黃絲 / 藍絲 / 國安等具體政治詞）

**詞彙表**：巴打 / 絲打（兄弟 / 姊妹，論壇用語）、OT（加班）、weekend / report / boss、攰（累）、on9（戇 / 笨，連登俚語）、諗（想）、講得啱（說得對）、打工仔（上班族）。

## 範例四：差不多先生傳 — Light + Medium 並陳

源文：[mr-chabuduo.md](../../examples/source-texts/mr-chabuduo.md)（胡適 1924，公有領域）

### 原文（節錄）

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不多，是各省各縣各村人氏。差不多先生的名字天天掛在大家的口頭，因為他是中國全國人的代表。
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」
>
> 他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：「錯了。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」

### 粵語 Light（普及型，可作課室誦讀）

> 你知唔知中國最出名嗰個人係邊個？講起呢個人，人人都識，周圍都聽過。佢姓差，名不多，係各省各縣各村嘅人氏。差不多先生個名日日掛喺大家嘴邊，因為佢就係中國全國人嘅代表。
>
> 佢成日講：「凡事只要差不多，就得啦。使乜咁精明喎？」
>
> 佢喺學堂嘅時候，先生問佢：「直隸省西邊係邊一省呀？」佢答話係陝西。先生話：「錯咗喇，係山西，唔係陝西。」佢話：「陝西同山西，唔係差唔多咩？」

### 粵語 Medium（Apple Daily 專欄風，加密度與口吻）

> 你估中國最出名嗰條友係邊個？講起呢條友，個個都聽過佢個名，周圍都搵到佢。佢姓差，名不多，係各省各縣各村嗰啲人氏嚟㗎。差不多先生個名日日掛喺大家把口度，因為佢就係 whole China 嘅代表喎。
>
> 佢成日講嘅一句嘢：「乜嘢都差不多就得嘅啦，使乜咁精明㗎？」
>
> 佢喺學堂讀書嗰陣，個 teacher 問佢：「直隸省西邊係邊一省啊？」佢答陝西。Teacher 話：「錯咗囉，係山西，唔係陝西。」佢即刻駁：「陝西同山西，唔係差唔多咩？」

### 結構標註（並陳對比）

| 條目 | 對照規則 | Light / Medium 對應 |
|---|---|---|
| 「你知唔知」/「你估」 | G7 | Light 用 V-唔-V；Medium 改用「估」更口語 |
| 「邊個 / 嗰個 / 邊一省」 | G1 | 疑問與指示詞 |
| 「日日掛喺嘴邊」 | G1 + G2 | 喺（在）+ 整句口語化 |
| 「就得啦」/「就得嘅啦」 | G5 | Light 單粒子；Medium 雙粒子 |
| 「使乜」 | V1 | 何必 → 使乜 |
| 「錯咗喇 / 錯咗囉」 | G3 + G5 | 完成貌 + 不同情緒粒子 |
| 「whole China / teacher」 | V6 | 僅 Medium 加 code-mixing |
| 「個 name / 把口度 / 嗰條友」 | V2 + S3 | Medium 採更口語的量詞 |
| 「即刻駁」 | G2 | 副詞 + V |

**改寫的關鍵動作**：胡適原文的諷刺結構保留（差不多先生的口頭禪 = 全國代表），只把 syntax 改成粵語、把功能詞換成本字。Light 版仍可朗讀為「正常粵語」，Medium 版多兩層港報專欄味（code-mixing + 密集句末助詞 + 更口語的指人量詞「條友」）。

**達標檢核（兩版皆滿足）**

- G1：✓（係 / 唔 / 嘅 / 咗 / 佢 / 喺 / 呢 / 嗰 全部出現）
- G2 副詞後置 / G3 動補：✓（錯咗、即刻駁）
- G5 句末助詞：✓（喎 / 啦 / 㗎 / 咩 / 囉 / 嚟㗎 連發）
- M3 政治詞：✓（原文中性，改寫亦中性）

**詞彙表**：知唔知（知道嗎）、邊個（誰）、嗰條友（那個人，口語）、成日（常常）、使乜（何必）、學堂（學校）、錯咗（錯了）、咩（嗎，反詰）。

## 強度速查

| 強度 | 特徵 | 典型場景 |
|---|---|---|
| **Light** | G1 全用 + G2 副詞後置 + 偶用句末助詞，無 code-mixing 或極少 | TVB 字幕、課室朗讀、普及型對白 |
| **Medium**（預設） | + G3 完成貌 + G4 雙賓語 + G7 反問 + 中度 code-mixing + 密集句末助詞 | Apple Daily 專欄、WhatsApp、blog |
| **Heavy** | + V4 連登詞 + S4 連登文體 + 密集 code-mixing + 顏文字 | LIHKG / 高登 / 周星馳式插科打諢 |
