# Written-cantonese — 改寫成粵語書面語 / 廣東話書面化

把任何文章改寫成完整粵語書面語——不是把幾個港式詞彙塞進普通話骨架，
而是 syntax 也粵語化：核心虛詞（係 / 唔 / 嘅 / 咗 / 佢 / 喺）、句末助詞
（喎 / 啦 / 㗎 / 咩 / 咯 / 啩 / 嘛 / 咧）、粵語語序（副詞後置 / 動補後置
/ 直接賓語先於間接賓語）。

## 什麼是粵語書面語？

粵語 / 廣東話是有完整書寫傳統的漢語語言，書面化形式可見於：

1. **TVB 劇 / 港產片字幕** — 對白型粵語書面化
2. **Apple Daily / 蘋果日報專欄** — 普及型粵語書面化（Apple Daily 1995
   創刊起大量採用）
3. **連登 LIHKG / 高登討論區** — 網絡論壇文體（巴打 / 絲打 / on9 等
   詞彙）
4. **周星馳對白 / 港產片台詞** — 帶喜劇節奏的粵語書寫
5. **粵語流行歌詞**（黃霑、林夕、林振強） — 文學型粵語書寫

文化錨點：HKSCS（香港增補字符集，1999 起，2016 最新版）涵蓋約 4,700 字；
維基百科「粵語書面語」與 Robert S. Bauer 等研究文獻；Apple Daily、TVB
字幕、連登日常書寫慣例。

## 一句話靈魂

**完整粵語書面語**——syntax 也粵語化，不只詞彙。核心虛詞（係 / 唔 / 嘅
/ 咗 / 佢 / 喺）+ 句末助詞 +  粵語語序（食先 / 食晒 / 畀錢佢）三者皆
必備，缺一即非粵語書面。

## 三段強度

| 強度 | 特徵 | 典型場景 |
|---|---|---|
| **Light** | G1 全用（係 / 唔 / 嘅 / 佢 / 嗰 / 啲）+ 副詞後置 + 偶用句末助詞 | TVB 字幕 / 普及型對白 |
| **Medium**（預設） | + 完成貌（咗 / 晒 / 緊）+ 雙賓語 + 反問 + 中度 code-mixing + 密集句末助詞 | Apple Daily 專欄 / WhatsApp |
| **Heavy** | + 連登 / LIHKG 詞彙（巴打 / 絲打 / on9）+ 密集 code-mixing + 顏文字 | LIHKG / 高登 / 周星馳式插科打諢 |

未指定時預設 **Medium**。

## 不會做的事

- 不對「方言 vs 獨立語言」之類爭議表態；定位為**語言學現象**
- 不附評論段、不附「我的改寫思路」
- 政治敏感詞（黃絲 / 藍絲 / 五大訴求 / 國安法）避免帶具體立場使用
- 不嘲弄香港文化、不做 caricature
- 不適合改寫法律條文 / 政府公告 / 學術論文（這類文體傳統上用標準書面中文）
