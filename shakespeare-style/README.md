# Shakespeare-style — 改寫成朱生豪式中譯莎劇腔

把任何文章改寫成朱生豪式（1940s–50s）的中譯莎劇悲劇腔。

不是給文章加感嘆詞，而是**讓人物在悲劇命運前獨白**——讀完讓人覺得這不
只是一段敘述，而是一場小型的人類悲劇，且帶著「這是西洋文學中譯」的閱讀
印象。

## 什麼是朱生豪式中譯莎劇腔？

朱生豪（1912–1944）是中文世界最重要的莎劇譯者之一。1935 年起翻譯莎翁全
集，1944 年因肺結核早逝，留下 31 部已譯劇本。其譯本以**濃情半文白、譬喻
密集、戲劇性外露**為特徵，是中文世界最熟悉的「莎劇腔」。

| 特徵 | 朱生豪式 | 對照 |
|---|---|---|
| 文白比例 | 文言虛詞點綴白話基底 | 梁實秋偏淺白 |
| 譬喻密度 | 平均每段 ≥1 處 | 散文化譯本偏低 |
| 戲劇性 | 強烈呼告／感嘆／反問 | 學術譯本偏陳述 |
| 翻譯感 | 適度保留（強化「中譯」印象） | caricature 翻譯腔（westernise 領域） |

`shakespeare-style` 鎖定這個風格的共同 DNA：**譬喻密度 + 文白夾雜 +
戲劇性情感外露**。

## 風格參考

- **《哈姆萊脫》（Hamlet）** 朱生豪譯——「To be or not to be」的著名哲學
  獨白，朱譯「生存還是毀滅，這是一個值得考慮的問題」是中文世界最熟悉的
  莎劇句
- **《李爾王》（King Lear）** 朱生豪譯——老王分國的悲劇獨白與弄臣對話，
  譬喻系統最為密集
- **《奧瑟羅》（Othello）** 朱生豪譯——嫉妒主題的層層遞進，戲劇性情感最
  為強烈
- **《麥克白斯》（Macbeth）** 朱生豪譯——「Tomorrow, and tomorrow, and
  tomorrow」式哲學獨白，命運感最為宏大

## 譯本選擇與版權

- **朱生豪（1912–1944）** 為**主要參照**——朱譯 1944 完成，1995 起在台
  灣公有領域；中國大陸 2014 起公有領域。本 skill 預設朱生豪腔
- **梁實秋（1903–1987）** 譯本較精準淺白，作為次要對照。梁譯 2037 起公
  有領域；現階段引用片段做教學示範屬合理使用範圍
- 莎翁原作 1616 年作者去世，全球公有領域

若使用者明確要求梁實秋風格，可在輸入時註明「採梁實秋風」。日後若需要可
另開 `shakespeare-liangshiqiu` skill。

## 不會做的事

- 不寫莎翁原作 Early Modern English（本 skill 限中文輸出）
- 不寫梁實秋式淺白譯腔（預設朱生豪式）
- 不寫**只剩**機械翻譯腔而無戲劇詩意（歐化句法 OK，但要有譬喻＋情感＋獨白；純翻譯腔 caricature 是 `westernise` 的領域）
- 不寫現代恐怖戲劇（莎翁悲劇有命運感、有神性、有英雄式尊嚴，不只是黑暗）
- 不在結尾加白話結論（「他終於明白⋯⋯」是莎翁悲劇大忌）
- 不在短文（<500 字）強制加完整劇本格式（S-04 是 Soft 規則）

## 預期輸出篇幅

繁體中文半文白戲劇腔，**300–1000 字**（計入標點）：

| 原文長度 | 莎劇腔目標 | 戲劇格式 |
|---|---|---|
| 短（< 200 字）| 300–500 字 | 散文化譯出劇作腔（保留「他長嘆道」式舞台敘述）|
| 中（200–800 字）| 500–800 字 | ≥500 字必加完整劇本格式 |
| 長（800+ 字）| 700–1000 字 | 必加完整劇本格式，可考慮多場景 |

低於 200 字無法承載獨白＋譬喻的重量，超過 1200 字會偏連續舞台劇章。**戲
劇格式**（角色名前綴＋舞台說明＋旁白）是 Soft 規則：≥500 字必加，<500
字可散文化譯出。

## 適合的源文

- 哲學散文／議論文（需先抽核心張力）
- 個人軼事中含悲劇張力者（野心／復仇／嫉妒／命運）
- 寓言／諷刺寓言（《差不多先生》《狂人日記》—— 可悲劇化處理）
- 失落主題（失戀／離別／衰老／死亡）
- 道德困境的紀實或評論

## 不太適合的源文

- 純喜劇／純滑稽材料（朱生豪腔本身偏悲劇）
- 充滿現代專名／科技／政治的新聞報導（去脈絡化代價太高）
- 純技術文件、程式碼說明（沒有可承載的悲劇場景）
- 已經是莎翁原作或譯本（改寫意義不大）

## 與 westernise 的差異

兩者**都**會帶有歐化翻譯感——這是中譯西洋文學的本質，本 skill 不視為
違規。差別在**美學目標**：

| | shakespeare-style | westernise |
|---|---|---|
| 美學目標 | **戲劇詩意 + 翻譯感** 並存 | **caricature 式的彆扭翻譯腔** |
| 翻譯感 | 強化「西洋文學中譯」的閱讀印象 | 刻意凸顯翻譯的彆扭感、異質感 |
| 譬喻／情感 | 必須有（譬喻 + 戲劇性情感為 Hard 規則） | 不要求 |
| 體裁定位 | 嚴肅文學體裁改寫 | 風格實驗、寫翻譯感本身 |

**判斷標準**：歐化句法（「噢！多麼⋯⋯啊」「對他來說⋯⋯」）在兩個 skill
中都可以出現。本 skill 的失敗模式不是有翻譯感，而是**只剩**翻譯感而無
譬喻、無情感、無戲劇詩意。

## 運作流程

1. **讀原文 + 抽張力** — 一句話自答：「這篇的『悲劇衝突』在哪？」
2. **主題抽象化** — 若是現代主題，換成悲劇普世主題（職場野心 → 王權之
   慾；失戀 → 嫉妒猜疑）
3. **角色設計** — 從六種配置選一（君王/弄臣、王子/鬼魂、戀人/父親、嫉
   妒者/無辜者、巫女/命運、傻子/智者）
4. **譬喻系統 + 戲劇結構** — 鎖定主譬喻軸（玫瑰/塵土/星辰/海洋/鏡/鐘擇
   一）+ 決定獨白/對白比例
5. **第一稿** — 譬喻密集 + 文白夾雜 + 戲劇性情感
6. **Checklist 自檢** — 21 條（Hard 14 + Soft 7）
7. **抓最弱段重寫** — 通常是譬喻段（過密／離題）或結尾段（戲劇性不足）
8. **輸出** — 寫入 `<原檔名>_shakespeare.md`，含戲劇格式（若 ≥500 字）

## 改寫原則（checklist 摘要）

| 類別 | 編號 | 要點 |
|------|------|------|
| Content | C-01~C-05 | 保留核心張力、必有悲劇張力軸、禁現代專名、悲劇主題抽象化、角色取莎劇式音譯名或抽象稱 |
| Structure | S-01~S-06 | 篇幅 300–1000 字、必有獨白(≥30%)、譬喻密度、戲劇格式（Soft）、戲劇性結尾、可選押韻雙行 |
| Voice | V-01~V-05 | 半文半白、戲劇性情感外露、可保留歐化翻譯感、句長變化、文藝復興詞彙 |
| Meta | M-01~M-05 | 不附評論段、譬喻嵌入情感、響亮名、必有戲劇詩意（不可只剩直譯）、議論文先抽張力 |

完整 21 項 checklist 與 9 步 workflow 見 [SKILL.md](./SKILL.md)。

## 三條靈魂條款

朱生豪式中譯莎劇腔的指紋：

1. **C-02 悲劇性張力軸** — 野心／王權、嫉妒／猜疑、復仇／猶豫、瘋狂／清
   醒、命運／抉擇擇一
2. **S-03 譬喻密度** — 平均每段 ≥1 處譬喻，自然意象 + 抽象概念並置
3. **V-01 半文半白** — 文言虛詞點綴於現代白話基底

三者缺一就不是朱生豪腔。其餘 18 條 checklist 都在服務這三條。

戲劇格式（角色名前綴＋舞台說明）為 Soft 規則（≥500 字才必加），但**戲劇
性情感**（呼告、感嘆、反問、誓言）為 Hard——即使散文化譯出，仍需保留
戲劇腔。

## 相關技能

- [westernise](../westernise/) — 加翻譯腔（兩者都有翻譯感，但美學目標不同：
  westernise 是 caricature 翻譯腔，本 skill 是「戲劇詩意 + 翻譯感」並存）
- [koanify](../koanify/) — 改寫為敘事禪宗公案（同樣文學體裁改寫，但東方
  禪宗 vs 西方戲劇）
- [liaozhai-tale](../liaozhai-tale/) — 改寫為聊齋體文言短篇（同樣文學體裁
  改寫，但東方志怪 vs 西方悲劇）
- [qiongyao-style](../qiongyao-style/) — 改寫為瓊瑤式愛情敘事（同樣
  文學體裁改寫，但現代愛情 vs 古典悲劇）
- [gulong-style](../gulong-style/) — 改寫為中後期古龍武俠（同樣文學體裁
  改寫，但短句留白 vs 長段獨白）
- [jinyong-style](../jinyong-style/) — 改寫為金庸式章回武俠（同樣文學體
  裁改寫，但東方家國 vs 西方命運）
