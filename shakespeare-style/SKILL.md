# Shakespeare-style — 改寫成朱生豪式中譯莎劇腔

把任何文章改寫成朱生豪式（1940s–50s）的中譯莎劇悲劇腔——譬喻濃密、文白
夾雜、戲劇性情感外露，讀完讓人覺得這不只是一段敘述，而是一場小型的人類
悲劇。

風格參照：**朱生豪（1912–1944）譯本為主**——朱譯偏濃情半文白，是中文
世界最熟悉的「莎劇腔」。代表譯作：《哈姆萊脫》《李爾王》《奧瑟羅》《麥
克白斯》（即四大悲劇）。**梁實秋（1903–1987）譯本**較精準淺白，作為
次要對照。

> **譯本選擇說明**：朱譯本 1944 完成，1995 起在台灣公有領域；中國大陸2014 起公有領域。本 skill 預設朱生豪腔；若使用者明確要求梁實秋風格，可在輸入時註明「採梁實秋風」。

## 一句話靈魂

**譬喻密度 + 文白夾雜 + 戲劇性情感外露**——三者構成朱生豪腔指紋，缺一就
不是莎劇譯腔。其餘 18 條 checklist 都在服務這三條。

戲劇格式（角色名前綴 + 舞台說明）為 Soft 規則（≥500 字才必加），但**戲
劇性情感**（呼告、感嘆、反問、誓言）是 Hard——即使散文化譯出，仍需保留
戲劇腔。

## Arguments

- `$0` —（選填）Markdown 或純文字檔案路徑。若省略，請使用者提供內文，
  或從對話上下文中找最近編輯的檔案。

## Step 1: Load the Text

- 若提供 `$0`，讀取該檔案。
- 若無引數，找對話中最近撰寫或編輯的 Markdown 檔，或請使用者提供文字。
- 若原文不是繁體中文，先在心中譯為繁體中文（不必輸出），再做改寫。

## Step 2: Read Source and Extract One Tension

朱生豪腔不是把原文翻譯成感嘆句，而是**抽出核心張力，重新講一個有悲劇命運
感的小故事**。

讀完原文後，用一句話自答：

> 這篇文章的「**悲劇衝突**」在哪？是**野心 vs 良知**？**復仇 vs 猶豫**？**嫉妒 vs 信任**？**瘋狂 vs 清醒**？**命運 vs 抉擇**？

可能的張力來源：權力之慾、復仇之火、嫉妒之毒、命運之網、瘋與醒的邊界、
父子之裂、戀人之誤、忠與叛之選。原文若是議論文／學術文／新聞，**先抽出
核心張力，再為它設計一個悲劇場景**——不要把論點直接「翻譯」成獨白。

若原文太長（超過 1500 字），只取一個主題改寫，不要硬塞所有內容。

## Step 3: Decide Modern → Tragic Theme Mapping

若原文涉及現代生活（科技、職場、政治、消費），**把主題抽象化**為悲劇普世
主題：

| 現代主題 | 莎劇悲劇等價 |
|---|---|
| 職場野心 | 王權之慾（Macbeth）|
| 加班趕工 | 命運的鞭策、時間的暴政 |
| 失戀／分手 | 嫉妒（Othello）／戀人誤會（Romeo & Juliet）|
| 升遷競爭 | 兄弟相殘、父位之爭（King Lear）|
| 公司倒閉 | 王朝傾覆、王國崩塌 |
| 健康／病痛 | 命運的詛咒、身體的背叛 |
| 家庭責任 | 父子之裂（Hamlet）／姐妹之裂（Lear）|
| 政治派系 | 宮廷陰謀、忠奸之辨 |
| 演算法／系統 | 命運／三女巫的預言 |
| 通訊科技 | 信差、密信、誤傳 |

**例外**：若使用者明確要求保留某一現代詞作為刻意時代錯位，可保留 1–2 個。

## Step 4: Choose Character Configuration

從六種配置中**挑一種**。莎劇悲劇的力量來自**人與命運的對撞**——

| 配置 | 張力來源 | 莎劇對應 |
|---|---|---|
| 君王 / 弄臣 | 權力 vs 智慧 | King Lear / Fool |
| 王子 / 鬼魂 | 復仇之命 | Hamlet / Ghost |
| 戀人 / 父親 | 愛 vs 家世 | Romeo / Capulet |
| 嫉妒者 / 無辜者 | 猜疑摧毀真實 | Othello / Desdemona |
| 巫女 / 命運 | 預言 vs 自由 | Macbeth / Three Witches |
| 傻子 / 智者 | 表面瘋癲，其實清醒 | Lear's Fool / Hamlet's pretended madness |

**角色名取莎劇式音譯名**（哈姆雷特／羅密歐／奧菲麗亞）或抽象稱（公子／
王后／老者／少年）。避免太現代姓名（「王經理」「小李」會破壞悲劇感）。

## Step 5: Choose 譬喻系統 + 戲劇結構

從以下譬喻軸中**挑一組為主軸**，並決定獨白／對白比例。在筆記裡明確寫下：
「主譬喻 = X，獨白比例 = Y%。」

### 譬喻軸選擇

| 譬喻軸 | 自然意象 | 抽象概念 |
|---|---|---|
| 玫瑰 / 凋零 | 玫瑰、薔薇、花瓣、芬芳 | 美貌、青春、情慾、毀滅 |
| 塵土 / 王冠 | 塵、土、陶土、石、屍骨 | 王權、榮耀、虛榮、終局 |
| 星辰 / 命運 | 星辰、月亮、夜空、彗星 | 命運、預兆、神意、宿命 |
| 海洋 / 風暴 | 大海、波浪、風暴、船 | 動盪、激情、無常、心緒 |
| 鏡 / 影子 | 鏡子、倒影、影子、雙生 | 真實、虛偽、自我、瘋狂 |
| 鐘 / 時間 | 鐘、漏壺、晝夜、季節 | 時間、命運、生死、急迫 |

### 獨白／對白比例

- 短獨白為主（300–500 字）：對白 ≤30%、獨白 ≥70%
- 對白為主（500–800 字）：對白 50%、獨白 30%、舞台說明 20%
- 五幕長段（800+ 字）：完整戲劇結構，可以 Act 分段

## Step 6: First Draft

寫一稿。原則：

- **語感**：半文半白，文言虛詞點綴（嗚呼／噫／卿／汝／爾／奈何／縱使／
  此情／果真／豈非／焉得）於現代白話基底，不通篇文言
- **譬喻**：平均每段 ≥1 處譬喻，自然意象 + 抽象概念並置
- **戲劇性情感**：強烈呼告（啊！／噢！／天哪！）、誓言、反問、感嘆——
  非陳述句為主
- **戲劇格式**：≥500 字必加完整劇本格式（角色名前綴對白 + `〔舞台說明〕`
  + `(旁白)`）；<500 字可散文化譯出劇作腔（保留「他長嘆道」「她暗自思
  忖」這類舞台化敘述）
- **句長變化**：短促命令句 + 長層遞獨白並用，節奏對比強
- **押韻雙行詩**：場景／幕收場可選用 7+7 字或 5+5 字押韻雙行收尾
- **篇幅**：原文短（< 200 字）寫 300–500 字；中（200–800）寫 500–800
  字；長（800+）取單一主題寫 700–1000 字
- **結尾**：戲劇性收束——臺詞收場、定格動作、或押韻雙行詩，**不戛然
  而止、不下白話結論**

## Step 8: Find the Weakest Paragraph and Rewrite

通常**譬喻段**或**結尾段**最弱：
- 若譬喻過密變堆砌（每句都譬喻），刪到「平均每段 1 處」
- 若譬喻離題（與角色當下情緒脫節），換成貼合情境的譬喻
- 若結尾下了白話結論，改寫成臺詞收場或押韻雙行詩
- 若押韻不工失工，改用定格動作收場（不要硬押）
- 若戲劇格式硬塞變不像短文也不像劇本，散文化譯出（保留「他長嘆道」式
  舞台化敘述）

「**情感推著譬喻走，不是譬喻推著情感走**」是朱生豪腔的鐵律。

## Step 9: 標點清理

最後一道工序：

- **全形標點（鐵律）**：CJK 文本中所有標點一律全形。**ASCII 半形 `, ; : ? !` 在 CJK 字之間出現一律是 bug**，必須換成全形 `，；：？！`。對照表：

  | 半形（禁） | 全形（用） | Unicode |
  |---|---|---|
  | `,` | `，` | U+FF0C |
  | `;` | `；` | U+FF1B |
  | `:` | `：` | U+FF1A |
  | `?` | `？` | U+FF1F |
  | `!` | `！` | U+FF01 |
  | `(` `)` | `（` `）` | U+FF08 / U+FF09 |

- **破折號**用兩個全形「—」連寫成「——」，不寫成 `--` 也不寫成單個「—」
- **引號**用「」與『』，不用 `"` `'`
- **句號**用「。」，不用 `.`
- **全形標點與 CJK 之間零空格**

> **注意**：莎劇譯腔保留歐化翻譯感（V-03），但**全形標點是 CJK 排版鐵律與翻譯感無關**——朱生豪原譯亦用全形標點。歐化是句法層面的選擇，不是標點層面的妥協。

- **寫完後必跑自檢指令**（指令名留作機械驗證，不可省略）：

  ```bash
  python3 -c "
  import re, sys
  text = open(sys.argv[1]).read()
  bad = re.findall(r'[^\x00-\x7f][,;:?!][^\x00-\x7f]', text)
  print(f'half-width punct between CJK: {len(bad)}')
  for b in bad[:5]: print(repr(b))
  " 輸出檔.md
  ```

  結果必須為 `0`。非 0 表示輸出時混入了 ASCII 半形，回到輸出檔逐字替換後重跑，直到歸零才算交付。

1. **檔案輸入**：寫入 `<原檔名>_shakespeare.md`，保留原檔
2. **貼文輸入**：直接輸出莎劇譯腔
3. **不附說明、不附評論、不附「我的改寫思路」**
4. 若使用者明確要求，可額外輸出**改寫筆記**（列出 Step 3–5 的選擇），但

## Anti-patterns（常見失敗模式）

寫完一稿、自檢之前，先掃一眼這 9 條最容易踩的坑：

1. **譬喻濫用** — 每句都譬喻變堆砌；應「平均每段 ≥1 處」而非「每句」。
   譬喻是燈光，不是路面
2. **文言過度** — 寫成《古文觀止》失去戲劇感；朱生豪是文白「夾雜」，不
   是文言為主。判斷標準：讀來像「現代戲劇對白點綴文言」，不是「文言夾
   雜白話」
3. **只剩翻譯腔而無戲劇詩意** — 歐化句法本身不是違規（這是「中譯」的本質），
   但若**只剩**機械直譯（沒有譬喻、沒有情感、沒有獨白哲學），就失去朱生豪
   腔的精髓。判斷標準：去掉歐化痕跡後還有戲劇詩意嗎？沒有就是失敗
4. **戲劇格式硬塞** — 短文（< 500 字）也加角色名前綴變成不像短文也不像
   劇本；S-04 是 Soft 規則
5. **缺乏獨白** — 全是對白沒有獨白，失去莎劇靈魂；S-02 要求獨白佔比 ≥30%
6. **悲劇張力不足** — 沒有「無解」或「命運感」，變成普通敘事。莎劇的
   悲劇核心是「命運推著人走，人卻仍要選擇」
7. **押韻雙行詩失工** — 收場詩若押韻不工反而尷尬；不會押就別硬押，定格
   動作收場一樣有效
8. **角色名太現代** — 「王經理」「李醫師」失去戲劇感；應用「公子」「王
   后」「老者」抽象稱或音譯名
9. **半形標點混入** — 輸出時把 `,;:?!` 打成 ASCII 半形而非全形 `，；：？！`。
   常見原因是 IME 切換失誤或從英文 prompt 複製字串。歐化句法是 V-03 允許的
   feature，但全形標點是 CJK 排版鐵律與翻譯感無關。寫完務必跑 Step 9 自檢
   指令，計數歸零才算交付（違反 M-06）

## Core Example: 木匠雕神像

源文（現代軼事）：一名工程師接到三日交專案的死線，連夜加班寫出醜陋程式
碼，事後重構，最後產品被取消。下方為改寫成功的版本——讓人物在悲劇命運
前獨白，把瞬間提升為人類共通的悲劇。

> **〔幕啟〕場景：古城西側，老木匠工坊。燭光昏黃，木屑遍地。**
>
> **木匠（獨白，撫刀而立）**：
>
> 啊！這把刻刀在我手中，已二十寒暑。它曾在玫瑰木上刻過愛情，在檀香木上刻過誓言，亦曾在松木上刻過墓銘——然今夜，它要在這塊王命之木上，刻下我此生最後的虛榮。
>
> 三日之約，三日！縱使日月可借，何以能借？縱使星辰可摘，何以能摘？此木非木，乃我之命；此像非像，乃我之名。我若雕成，則名動寰宇；我若失手⋯⋯啊，焉得失手！焉得失手！
>
> **〔燭光忽暗，門外風起〕**
>
> **弟子（持燭入）**：師父，夜深了。
>
> **木匠**：夜深？卿不知麼，今夜之燭，照的是我之心；今夜之木，雕的是我之骨。汝且去歇——縱使天上有星，亦不及這刀光之亮；縱使地上有土，亦不及這木屑之重。
>
> **〔弟子退〕**
>
> **〔三日後，使者登場〕**
>
> **使者（接像，置之桌上）**：王上敕建之堂，前日已圮。
>
> **木匠（怔立）**：⋯⋯
>
> **使者**：王上棄此堂改築他處，王諭未及收回。
>
> **木匠（緩緩跪下，手撫聖像之眉眼）**：
>
> 啊！命運！你這既盲且聾的劊子手！你以三日之約縛我心，卻以拆堂之斧斷我夢！這聖像之眉，偏了一分；我之心，偏了千里！我以塵土之手，雕了塵土之像，獻給已成塵土之堂⋯⋯
>
> **〔將聖像置於懷中，緩起，長嘆〕**
>
> 罷了。塵歸於塵，土歸於土。
>
> **〔押韻雙行詩〕**
>
> > 三日如刀劃此心，一像如夢葬煙塵。
>
> **〔幕落〕**

**達標清單**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 保留「急工→失敗→自悔」核心張力 |
| C-02 | ✓ | 悲劇軸：野心（留名）vs 命運（王上之堂已圮）|
| C-03 | ✓ | 無現代專名；世界觀走西洋通名（古城／王命／使者／聖像／王諭），不退進中華具體專名 |
| C-05 | ✓ | 角色配置：木匠 / 弟子 / 使者（使者帶來命運判決，相當於 messenger / herald）|
| S-01 | ✓ | 約 480 字（含舞台說明），戲劇格式 Soft 規則邊界 |
| S-02 | ✓ | 獨白佔比 ≥50%（開場獨白＋接旨後獨白＋臨終獨白）|
| S-03 | ✓ | 譬喻密度：玫瑰木／檀香木／松木／墓銘、三日如刀、一像如夢、塵歸於塵土歸於土等多處 |
| S-04 | ✓ | 戲劇格式：角色名前綴對白 + 〔舞台說明〕 + 押韻雙行詩 + 〔幕落〕 |
| S-05 | ✓ | 結尾押韻雙行詩「三日如刀劃此心，一像如夢葬煙塵」+ 〔幕落〕|
| S-06 | ✓ | 押韻雙行詩成立（心／塵收尾，平水韻 13 元 / 12 真通押）|
| V-01 | ✓ | 半文白：「嗚呼」「奈何」「縱使」「焉得」「卿」自然點綴 |
| V-02 | ✓ | 戲劇性呼告：「啊！」「焉得失手！」「命運！你這既盲且聾的劊子手！」 |
| V-03 | ✓ | 容納歐化句法（「啊！」「焉得失手！」之類戲劇感嘆），但不是只剩翻譯腔 |
| V-05 | ✓ | 文藝復興詞彙：命運、塵土、星辰 |
| M-02 | ✓ | 譬喻嵌入情感：「三日如刀劃此心」呼應急工煎熬，「塵歸塵土歸土」呼應失落終局 |

**對照結論**：朱生豪腔不是「給故事加感嘆詞」，而是**讓人物在悲劇命運前
獨白**——「命運！你這既盲且聾的劊子手！」沒有解釋為何如此呼喊，但讀完
整段你會知道：那是一個工匠面對「自己的成就被命運直接抹除」的瞬間，唯一
能做的事就是**把這個瞬間提升為人類共通的悲劇**。

## Scope Boundary

| 想做的事 | 用哪個 skill |
|---|---|
| 把文章改寫為朱生豪式中譯莎劇腔（本 skill 目標）| **shakespeare-style** |
| 寫莎翁原作 Early Modern English | （不在本 skill 範圍）|
| 寫梁實秋式譯本腔（較精準淺白）| （日後可開 `shakespeare-liangshiqiu`）|
| 寫敘事公案（東方禪宗）| `koanify` |
| 寫志怪短篇（東方文言）| `liaozhai-tale` |
| 寫瓊瑤體愛情敘事 | `qiongyao-style` |
| 寫古龍／金庸武俠 | `gulong-style` / `jinyong-style` |
| 加翻譯腔（歐化中文）| `westernise`（兩者**都**有翻譯感但美學目標不同：westernise 追求 caricature 式的彆扭翻譯腔；本 skill 是「戲劇詩意 + 翻譯感」並存）|

如果使用者要的是**英文莎翁原作風**或**現代恐怖戲劇**，告訴使用者本 skill
是**朱生豪式中譯腔**，限於中文輸出。

## Important Notes

- 本 skill 是**體裁轉換工具**，不是「給文章加感嘆詞」工具。原文的核心
  張力必須被保留，以悲劇敘事的形式重新承載
- **歐化翻譯感是 feature 不是 bug**：本 skill 的本質是「中譯」莎劇腔，
  歐化句法（多重從句、抽象主語、感嘆句前置）能強化「西洋文學中譯」的
  閱讀印象。與 `westernise` 的差異不在「有無翻譯感」，而在**美學目標**：
  westernise 是 caricature 式的彆扭翻譯腔；本 skill 是戲劇詩意 + 翻譯感
  並存。失敗模式是**只剩**翻譯腔而無譬喻／情感／戲劇詩意
- **譬喻服務情感**——每個譬喻都要回答「為什麼是現在出現」「呼應角色當下
  什麼情緒」
- **不要寫成現代恐怖戲劇**——莎翁悲劇有命運感、有神性、有英雄式的尊嚴，
  不只是黑暗
- **押韻雙行詩不可硬押**——失工的押韻反而尷尬。不會押就用定格動作收場
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
