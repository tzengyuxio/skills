# Versailles-literature — 示範

展示 `versailles-literature` 如何把不同題材改寫成凡爾賽文學，以及好的
凡學腔長什麼樣子。

> **源文與引用說明**：範例一、範例二、範例三的源文皆為自編貼文。範例四
> 的源文 [《差不多先生傳》(胡適， 1924)](../../examples/source-texts/mr-chabuduo.md)
> 來自共用源文庫，公有領域。文中對「凡爾賽文學」的指涉本於 2020 年
> 5 月豆瓣「凡爾賽學研習小組」（@小奶球）所提的三要素，以及同年 11 月
> 微博博主蒙淇淇77 引爆的範本句式，僅作風格座標說明，未引用整段原文。

## 範例一：物質炫耀 — 包堆不下了

**炫耀類別**：物質（包款數量）。

### 源文（自編）

> 衣帽間最近真的快爆炸了，老公又買了一個禮物給我，說是看到限量款覺得我會喜歡。我已經請設計師重新規劃櫥櫃了，但短期內看來還是放不下。

### 改寫

> 真的好煩，我家衣帽間又被塞滿了，連門都關不太起來。
>
> 上禮拜跟老公說過很多次別再買了，他就是不聽，這次又不小心訂了一隻新色的 Birkin 回來，櫃姐說是這季亞洲限量配額，他順手就拿了。結果我還沒打開盒子，他週末又從巴黎帶了一條 Cartier 給我，說是逛街隨便挑的。我已經跟設計師約下個月重做衣帽間了，可是這樣下去就算重做也放不下啊。
>
> 朋友都笑我「這種煩惱誰不想要」，可我是真的覺得困擾耶，為什麼會這樣呢？

**為什麼這版有效**

- 第一段純抱怨「衣帽間爆炸」，第一秒讀者會共情（誰沒有東西放不下的時候）
- 第二段才透過「不小心」「順手」「隨便挑的」滲出 Birkin、Cartier、巴黎、亞洲限量配額
- 第三段以「為什麼會這樣呢」反問收尾，不揭穿
- **餘韻**：讀者讀完幾秒後才驚覺——啊她剛剛是在說 Birkin 限量配額對吧？

## 範例二：關係炫耀 — 老公太招搖

**炫耀類別**：關係（配偶優秀）。

### 源文（自編）

> 老公開新買的車送我去機場，路上引來一些路人注意。我覺得低調一點比較好，但他總是說既然買了就要用。

### 改寫

> 我們家先生實在拿他沒辦法，明明說過很多次出門低調點，他就是不聽。
>
> 今天早上送我去機場，他偏要開那輛上個月剛入手的瑪莎拉蒂——說是經銷商朋友幫忙留的客制色，亞洲只有兩台。一路上我都把臉藏在口罩後面，等紅燈的時候還是被旁邊摩托車騎士拍照，旁邊高中生一直探頭看。我都跟他說過很多次了，這樣很不方便，他卻說「車就是要開的」，又笑著說下個月還要去提那輛保時捷。
>
> 我也很想低調啊，可是他怎麼總是這樣？

**炫耀梯度**

- 第一段：純抱怨「先生不聽勸」——任何配偶有點固執的人都能共情
- 第二段「不小心」鬆動，露出瑪莎拉蒂、亞洲僅兩台、客制色、保時捷預購
- 第三段反問「我也很想低調啊」——典型凡爾賽收尾句
- 弱化詞密度：明明、上個月剛、偏要、又、總是

## 範例三：經歷炫耀 — 飛太頻繁

**炫耀類別**：經歷（國際旅行頻率）。

### 源文（自編）

> 最近因為工作經常飛來飛去，時差調不過來，朋友邀約都常常推掉。

### 改寫

> 真的好累，連續第三個月時差都還沒調回來。
>
> 上週才從蘇黎世開完合夥人會議飛回台北，飛機降落還沒兩天，公司又安排我下週一直接飛紐約路演，明明跟祕書說過儘量不要排紅眼班，可是這個案子規模太大，合夥人那邊堅持要我親自過去。我朋友這個月生日，已經是我第二次缺席她的派對了，她還傳訊息說「妳的人生比我的精彩多了」，我看著真的有點哭笑不得，又不能告訴她其實我只是想睡個整覺而已。
>
> 為什麼總是這樣呢？我也好想當個普通的上班族啊。

**炫耀梯度**

- 第一段：純抱怨「時差」——任何上班族都能共情
- 第二段：蘇黎世合夥人會議、紐約路演、案子規模、祕書、紅眼班——身份
  地位資訊全靠弱化詞「明明」「只是」滲出
- 第三段：「我也好想當個普通的上班族啊」——典型反問收尾，留下「等等
  她剛剛是在抱怨還是？」的餘韻

## 範例四：改寫示範 — 《差不多先生傳》→ 凡爾賽

源文：**胡適《差不多先生傳》(1924) 摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

**炫耀類別**：關係（配偶事業太成功）。

### 原文

> 你知道中國最有名的人是誰？提起此人，人人皆曉，處處聞名。他姓差，名不多，是各省各縣各村人氏。⋯⋯
>
> 他常常說：「凡事只要差不多，就好了。何必太精明呢？」
>
> ⋯⋯後來他得急病，趕快叫家人去請東街的汪先生。一面慌一面跑，人急了，東西兩街，汪王不分，跑到西街牛醫王大夫家裡。⋯⋯王大夫用醫牛之法給他治病，差不多先生就此一命嗚呼。

（原文採取**諷刺寓言**體例。「差不多先生」是國民性的擬人化批判。）

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽資源 | 把「差不多先生」改寫成「凡爾賽太太的老公」——主角的事業成功、配偶的私人醫生資源 |
| 困擾包裝 | 「老公事業心太重、連看醫生都隨便」 |
| 弱化詞策略 | 「明明」「只是」「順便」「不過是」 |
| 第二段細節 | 蘇黎世跨國併購、百億估值、私人醫生上門、祕書 |
| 第三段反問 | 「到底要我怎麼辦才好？」 |

### 改寫後

> 真的好煩，我家先生最近又把我惹生氣了。
>
> 上禮拜他突然胸口悶痛，我急得不行，明明跟他說過很多次身體比什麼都重要，他卻只是擺擺手說「差不多就好」，連醫生都不肯多看兩眼。後來還是他祕書幫忙安排私人醫生上門，他才順便讓人看了看——結果連藥都沒吃完，第二天就飛去蘇黎世開那場跨國併購的會了，明明他公司光今年那個案子估值就過百億，少他一場會議真的會怎麼樣嗎？
>
> 我每次跟閨蜜抱怨，她們都笑我說「妳老公這種男人才難得啦」。可是我真的不懂耶，他連看病都這麼差不多，到底要我怎麼辦才好？

（約 280 字）

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 表面抱怨「老公差不多態度」，實則炫耀「跨國併購／百億案／私人醫生／祕書」|
| C-02 | ✓ | 三段齊：抱怨開端（被惹生氣）+ 細節暴擊（蘇黎世／百億／私人醫生）+ 反問收尾 |
| C-03 | ✓ | 無「我老公很有錢」直白句；資源訊息全靠弱化詞滲出 |
| C-04 | ✓ | 無「凡爾賽一下」「我知道這聽起來像炫耀」這類自覺破格 |
| S-01 | ✓ | 約 280 字，正中典型範圍 |
| S-02 | ✓ | 第一段純抱怨，未露任何具體細節 |
| S-03 | ✓ | 第二段細節暴擊：蘇黎世、百億、私人醫生上門、祕書 |
| S-04 | ✓ | 第三段以「我真的不懂耶」「怎麼辦才好」反問收尾 |
| S-06 | ✓ | 餘韻：讀完才驚覺「等等，她說的是百億跨國併購？」|
| V-01 | ✓ | 弱化詞密度：明明、只是、順便、真的、不過、又 |
| V-02 | ✓ | 關係詞與細節：祕書、私人醫生、百億、蘇黎世、跨國併購、老公 |
| V-03 | ✓ | 第一人稱社群口語腔 |
| V-05 | ✓ | 自問自答：「真的會怎麼樣嗎？」「怎麼辦才好？」|
| M-02 | ✓ | 主角誠摯相信自己在抱怨，無自嘲破格 |

**改寫的核心動作**：把胡適原文「明寫的諷刺」轉為「凡爾賽式的婚姻
抱怨」。原文是雜文體諷刺，凡爾賽版讓「差不多」從國民性的批評變成
「老公事業太成功，連健康都差不多帶過」的虛擬困擾——讀者第一秒共情
婚姻挫折，第二秒驚覺主角是在炫耀她的丈夫掌管百億跨國案。**抱怨完全
淹沒炫耀，這就是凡爾賽**。

## 速查：Checklist 重點

21 條中最常踩的：

| 編號 | 規則 | 怎麼用 |
|---|---|---|
| C-01 | 抱怨包裝的炫耀（soul）| 寫之前明確寫下「可炫資源 = X」「困擾包裝 = Y」 |
| C-03 | 不可直接炫富 | 直白句「我家很有錢」即屬違規 |
| C-04 | 不可有自我意識 | 「凡爾賽一下」「我知道這聽起來像炫耀」即破格 |
| S-02 | 第一段純抱怨不露細節 | 第一段出現品牌名即違規 |
| S-03 | 第二段必有細節暴擊 | 至少 1 個品牌／價格／地點，由弱化詞掩護 |
| S-04 | 第三段必為反問 | 不可下結論、不可揭穿 |
| V-01 | 弱化副詞至少 2 個 | 不小心、隨便、又、明明、只是、剛好、順便 |

完整 21 項與 9 步流程見 [SKILL.md](../SKILL.md)。
