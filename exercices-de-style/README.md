# Exercices de Style — 同源異體 Gallery

致敬 Raymond Queneau 1947 年《Exercices de Style》——同一個故事，
以 99 種文體重述。

本 gallery 用**同一篇源文**（胡適《差不多先生傳》, 1924）配本 repo 多種 skill
改寫，作為「換 skill 看效果」的最直接 showcase。

## 預計擴充

本 gallery 預計逐步擴充到覆蓋每個分類至少 1-2 個 skill 的同源改寫，使單一文章
能看出全部 47 個 skill 各自的指紋差異。**目前 10 件已覆蓋 8 個分類中的全部 8 個**
（01×1、02×1、03×1、04×2、05×2、06×1、07×1、08×1）。8 軸地圖完整。

進一步擴充方向（同分類內加 1-2 件，看異形對比）：
- **04 文學作家體**：`qiongyao-style`（愛情版差不多）、`gulong-style`（武俠版）、
  `hemingway-style`（中譯海明威版）、`sherlock-holmes-style`（雙重位移成福爾摩斯案）、
  `yu-guangzhong-style`（散文版）
- **05 中文古典體式**：`haiku-style`（俳句版）、`chinese-sonnet-style`（十四行詩版）、
  `wenyan-xianqin/hanwei/guwen/huaben`（四個文言時代版，可成完整歷時光譜）
- **02 中文地域變體**：`taiwan-mandarin` / `mainland-mandarin` / `dongbei-mandarin`
  等其他八件（差不多先生在台北 / 北京 / 東北 / 上海 / 四川的同文不同腔）
- **01 文本操作工具**：`westernise`（加歐化）/ `postmodern-lens`（後現代版）/
  `humanize`（雖然差不多先生本就很 human,可做反向練習）
- **06 應用與結構文類**：`prc-bureaucratese` / `roc-bureaucratese-classic`（公文版）、
  `koanify`（禪宗公案版）、`bagu-essay`（八股版差不多）
- **07 影視口播**：`laogao-style`（神秘解說雙人口播版）
- **08 網路文體**：`feihua-literature` / `zhiyin-style` / `versailles-literature` /
  `concrete-42`（不同 meme 機制改寫差不多）

## 為什麼用差不多先生

胡適 1924 年〈差不多先生傳〉是公有領域、長度適中（約 700 字）、有清楚的角色與
情節、含多個可改寫的單元（紅 / 白糖、山西 / 陝西、東西街、王大夫醫牛），對各種
skill 都是好用的試金石。

> 「凡事只要差不多，就好了。何必太精明呢？」——差不多先生
