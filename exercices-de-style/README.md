# Exercices de Style — 同源異體 Gallery

致敬 Raymond Queneau 1947 年《Exercices de Style》——同一個故事，
以 99 種文體重述。

本 gallery 用**同一篇源文**（胡適《差不多先生傳》, 1924）配本 repo 多種 skill
改寫，作為「換 skill 看效果」的最直接 showcase。

## 預計擴充

本 gallery 預計逐步擴充到覆蓋每個分類至少 1-2 個 skill 的同源改寫，使單一文章
能看出全部 47 個 skill 各自的指紋差異。**目前 7 件已覆蓋 5 個分類**(04 文學作家
體 ×2、05 中文古典體式 ×2、06 應用與結構文類 ×1、07 影視口播 ×1、08 網路文體 ×1)。

候選擴充方向（尚未覆蓋的分類）：
- **01 文本操作工具**：差不多先生若先 dewesternise → 看看歐化版會被去成什麼樣
- **02 中文地域變體**：用 `taiwan-mandarin` / `mainland-mandarin` / `written-cantonese`
  換地寫，看「差不多先生在台北 / 北京 / 香港」三地的同文不同腔
- **03 中英混搭**：用 `chinglish` 改寫成英語腔（會變什麼樣的世界？）
- **04 文學作家體擴充**：`qiongyao-style`（愛情版差不多）、`gulong-style`（武俠版）、
  `hemingway-style`（中譯海明威版）、`sherlock-holmes-style`（雙重位移成福爾摩斯案）
- **05 中文古典體式擴充**：`haiku-style`（俳句版）、`chinese-sonnet-style`（十四行詩版）、
  `wenyan-xianqin/hanwei/guwen/huaben`（四個文言時代版）
- **06 應用與結構文類擴充**：`prc-bureaucratese` / `roc-bureaucratese-classic`（公文版）、
  `koanify`（禪宗公案版）、`bagu-essay`（八股版）
- **07 影視口播擴充**：`laogao-style`（神秘解說雙人口播版）

## 為什麼用差不多先生

胡適 1924 年〈差不多先生傳〉是公有領域、長度適中（約 700 字）、有清楚的角色與
情節、含多個可改寫的單元（紅 / 白糖、山西 / 陝西、東西街、王大夫醫牛），對各種
skill 都是好用的試金石。

> 「凡事只要差不多，就好了。何必太精明呢？」——差不多先生
