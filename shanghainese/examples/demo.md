# Shanghainese — 示範

展示 `shanghainese` skill 如何把現代文章轉為上海話 / 滬語三段強度的書面語。源文取自 [`examples/source-texts/`](../../examples/source-texts/)，含自編與公有領域素材。

> **書面慣例說明**：上海話書寫尚未完全統一（不如粵語穩定）。本示範以《繁花》、錢乃榮《上海話大詞典》、教育部本字為優先，遇到 訓用字 / 借音字 並行的情況採最常見印刷形態。對形容某些聲調或入聲字無理想漢字者，沿用普通話寫法以求可讀。

---

## 範例一：雨天故事（中文源）

源文：[weather-rain.md](../../examples/source-texts/weather-rain.md)

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### Light

> 昨天下半天我在圖書館看書呃辰光，忽然下起大雨。我蠻笨呃，沒帶傘，但是還是決定走路回去。路上人老多，到處都是撐傘呃行人。我全身濕透，回到屋裡才發現鑰匙忘在辦公室嘞。隔壁阿婆看到我搿副霞氣樣子，笑著講：「儂哪能弗叫部出租車？」我只好苦笑回：「皮夾子忘記帶嘞。」

### Medium（預設）

> 昨天下半天，阿拉在圖書館看書呃辰光，忽然下起大雨。我嘸沒帶傘，弗過還是決定走路轉去。路上人老多，到處撐傘呃行人。我渾身濕得霞氣，到屋裡才發現鑰匙忘伊辦公室嘞。隔壁阿婆看到我搿副樣子，笑著講：「儂哪能弗叫部差頭？」我只好苦笑：「哦呦，皮夾子也忘脫嘞。」

### Heavy

> 昨日下半天呃辰光，阿拉在圖書館看書，忽然下起大雨。我朆帶傘，覅緊，腳一抬，走路轉去。路浪人老多，伊拉撐傘撐得霞氣。我渾身淋得透濕，到屋裡才曉得鑰匙忘伊辦公室嘞，搿樁事體真結棍。隔壁阿婆望著阿拉搿副樣子，嘎三胡兩句：「儂哪能弗叫部差頭？」我嘸講啥，只好苦笑撥伊聽：「哦呦，皮夾子忘脫了，戇來。」

### 達標清單（Medium）

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 阿拉、儂、伊（兼地點代詞）|
| C-02 | ✓ | 嘸沒、弗 |
| C-03 | ✓ | 標誌詞 ≥ 3：霞氣、嘎、老、哦呦、辰光 |
| C-04 | ✓ | 句末助詞：嘞、呃、講 |
| C-05 | ✓ | 鄰居只是親切詢問，非刻板「上海人精明」 |
| G-04 | ✓ | 老多、嘎遠 |
| V-04 | ✓ | 辰光（時候）、轉去（回家）、差頭（出租車）、忘脫（忘掉）|

## 範例二：弄堂裡的小爭執（自編）

自編情境，鎖定海派文化詞與評價語。源文（自編）：

> 老李退休後搬進新弄堂，鄰居張大爺每天清早就在窗下練二胡。老李受不了，敲門理論。張大爺聽完笑說：「我家祖傳三代都是這個時間練。」老李沒辦法，只好買了副耳塞。第二天清早，他發現窗外靜了——張大爺感冒，今天不練了。

### Heavy（《繁花》式）

> **《新弄堂裡呃事體》**
>
> 老李退休嘞，搬進新弄堂。隔壁張爺叔，天天清老早窗下拉二胡。老李吃勿消，敲門上去講：「儂搿副派頭，阿拉嘸沒辦法睏覺。」
>
> 張爺叔笑笑，講：「儂洋盤呃伐？阿拉屋裡三代人，都是搿個辰光拉呃。」
>
> 老李一句閒話也接弗上，門關呃時候摔得邪氣響。
>
> 第二日清老早，老李一覺醒過來，望望窗門外頭——靜悄悄。隔了一歇，伊曉得嘞：張爺叔感冒，今朝弗拉。
>
> 老李坐在床浪，手裡攥著昨日剛買呃耳塞，嘎三胡也嘎三胡弗出來，只好對自家輕聲講一句：「霞氣。」

### 結構標註（Heavy）

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 「《新弄堂裡呃事體》」單一書名 | M-03 | Heavy 模式可加書名標題 |
| 爺叔、弄堂 | V-02 | 《繁花》核心文化詞 |
| 派頭、洋盤、嘎三胡 | V-03 / V-01 | 海派評價語 + 標誌詞 |
| 一覺醒過來、隔了一歇 | G-06 | 短時體 |
| 阿拉嘸沒辦法睏覺、阿拉屋裡 | G-01 / G-02 / V-04 | 代詞 + 否定 + 詞彙替換 |
| 「霞氣」收尾 | C-03 + 結尾餘韻 | 單字結句，不點明老李心境 |
| 結尾 | M-02 | 「嘎三胡也嘎三胡弗出來」由動詞反折成靜默 |

**敘事重點**：兩位老人不是衝突的代表，是弄堂式日常的兩面——抱怨、和解、然後一個小病讓所有的計較失焦。結尾不寫老李是否原諒張爺叔，留給讀者自己想。

## 範例三：差不多先生傳（公有領域）

源文：[mr-chabuduo.md](../../examples/source-texts/mr-chabuduo.md)（胡適 1924）

> 你知道中國最有名的人是誰？他姓差，名不多，是各省各縣各村人氏。差不多先生的名字天天掛在大家的口頭，因為他是中國全國人的代表。他常常說：「凡事只要差不多，就好了。何必太精明呢？」他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：「錯了。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」

### Medium（預設）

> 儂阿曉得中國頂頂有名呃人是啥人？伊姓差，名不多，各省各縣各村都有伊。差不多先生呃名字，天天掛勒大家嘴邊，因為伊就是阿拉中國人呃代表。
>
> 伊老歡喜講一句閒話：「凡事只要差不多就好嘞，何必嘎精明呢？」
>
> 伊讀小學呃辰光，先生問伊：「直隸省西邊是啥省？」伊講陝西。先生講：「弗對，是山西，弗是陝西。」差不多先生眨眨眼睛，回一句：「陝西山西，阿弗是差不多伐？」
>
> 後首伊長大嘞，依舊一副差不多派頭——買紅糖買回白糖，寫八字寫成捌字。鄰居都講：「搿個人拎勿清呃。」伊聽嘞反而笑笑：「拎得清，拎勿清，差不多。」
>
> 一直到伊臨終嘞，醫生來遲一刻鐘，差不多先生擠著最後一口氣，望著天花板，輕輕講：「活同死，差不多……」聲氣斷脫。爺叔嬸嬸哭呃哭，圍著床浪商量身後事，講得正鬧猛，忽然一個爺叔開口：「葬一日和葬兩日，反正——」屋裡一時沒人接話。

### 達標清單（Medium）

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 儂 / 阿拉 / 伊 完整 |
| C-02 | ✓ | 弗、勿 |
| C-03 | ✓ | 標誌詞：派頭、拎勿清 / 拎得清、嘎、辰光、鬧猛 |
| C-04 | ✓ | 句末助詞：呃、嘞、伐、呢 |
| C-05 | ✓ | 不寫差大爺「上海人式精明」，強調認知放棄 |
| G-04 | ✓ | 老歡喜、嘎精明、頂頂有名 |
| G-08 | ✓ | 阿曉得、阿弗是 |
| V-04 | ✓ | 辰光、講、歡喜、後首、聲氣 |
| 結尾餘韻 | ✓ | 收在另一個爺叔接腔「反正——」屋裡無人接話；「差不多」病傳給了下一個人，但點到為止 |

**改寫筆記**：胡適原文是寓言體諷刺。轉滬語時，把「差不多」這句口頭禪用海派的「拎勿清 / 拎得清」二項對比放大，再讓結尾另一個爺叔開口接腔——讓讀者自己意識到「差不多」並非死於差不多先生本人，而是流傳於整間屋。

## 範例四：小王子（英文源 → 上海話）

源文：[little-prince.md](../../examples/source-texts/little-prince.md)

> The little prince lived alone on a tiny planet, no bigger than a house. He had three volcanoes to clean, and a rose that he loved very much. Every morning, he would clean his volcanoes and water his rose. One day, he decided to leave his planet to explore the universe. He was sad to say goodbye, but he knew he had to go.

### Light

> 小王子一個人住在一粒老小呃星球浪，弗比一間屋大多少。伊有三座火山要打理，還有一朵伊老歡喜呃玫瑰花。每日清老早，伊就去清理火山，再撥玫瑰澆水。一日，伊決定離開星球，出去看看宇宙。要走呃辰光伊心裡蠻難過，弗過伊曉得自家是非走弗可。

### Medium

> 小王子自家一個人住在一粒老小呃星球浪頭，搿粒星球弗比一間石庫門大多少。伊有三座火山要打理，還有一朵心愛呃玫瑰花。每日清老早，伊先去清理火山，再撥玫瑰澆一記水。後首伊想想，覺得搿樣呃日子嘸啥意思，就決定離開星球，出去看看宇宙呃別呃地方。要講再會呃辰光，伊心裡邪氣難過——弗過伊曉得，自家無論哪能也是要走呃。

### Heavy

> 小王子是一個人，住在一粒老小老小呃星球浪頭，弗比一間石庫門大多少。伊養了三座火山，還有一朵伊頂頂歡喜呃玫瑰花。每日清老早，伊照例搿三座火山掃一記，再撥玫瑰澆水。
>
> 一日，伊忽然想離開搿粒星球嘞，去外頭軋軋鬧猛，看看宇宙是啥腔調。
>
> 講再會呃辰光，伊望著玫瑰，眼睛裡有點濕。伊心裡曉得呃——人總歸要走，玫瑰也總歸要等。
>
> 玫瑰嘸沒講閒話。伊也嘸沒講閒話。天上呃風吹過，火山口頭一道煙緩緩升起來。

### 達標清單（Heavy）

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 伊（小王子 / 玫瑰）、阿拉（隱於敘述）|
| C-02 | ✓ | 弗、嘸沒 |
| C-03 | ✓ | 老小老小、頂頂歡喜、軋鬧猛、腔調、辰光、講閒話 |
| C-04 | ✓ | 嘞、呃、頭 |
| G-04 | ✓ | 老小老小、頂頂歡喜 |
| G-06 | ✓ | 掃一記、澆一記水 |
| V-02 | ✓ | 石庫門（替換 house）|
| V-03 | ✓ | 軋鬧猛、腔調 |
| 結尾餘韻 | ✓ | 不直寫離別，以「火山口頭一道煙緩緩升起來」收 |

**翻譯動作**：英文原文的"a tiny planet, no bigger than a house"用「弗比一間石庫門大多少」轉錨——用海派文化詞替換 house，是一種 cultural domestication；末段不再原文翻譯，借「玫瑰嘸沒講閒話」表達告別場景的沉默。

## 強度速查

| 強度 | 特徵 | 典型場景 |
|---|---|---|
| **Light** | 普通話骨幹 + 儂 / 阿拉 / 弗 + 蠻 / 老 + 3-5 個標誌詞。普通話讀者完全讀得懂。| 新民晚報副刊、半正式部落格 |
| **Medium**（預設） | 全套人稱與否定 + 句末助詞（伐 / 嘞 / 哦呦）+ 部分句式吳語化（拿伊撥我 / 困覺去 / 阿是）+ 海派評價詞 | 周立波清口書面化、《愛情神話》對白 |
| **Heavy** | 全篇滬語書寫，G1-G8 全用、V1-V5 自由替換；趨向《繁花》小說式書面語，普通話讀者讀來會有閱讀阻力 | 金宇澄《繁花》風格小說 |

## 重要區別：和粵語的界線

| 助詞 / 字 | 粵語 | 上海話 |
|---|---|---|
| 是 | 係 | 是（書寫常作「是」，不用「係」）|
| 不 | 唔 | 弗 / 勿 |
| 沒 | 冇 | 嘸沒 / 嘸 |
| 的 | 嘅 | 呃 / 個 |
| 了 | 咗 | 嘞 |
| 他 | 佢 | 伊 |
| 這 | 呢 | 搿 / 迭 |
| 那 | 嗰 | 伊（遠指）|

混用粵字（嘅 / 咗 / 佢）會立即破壞滬語感，要避免。
