# Shanghainese — 上海話 / 滬語

將文字轉為上海話 / 滬語——吳語太湖片蘇滬嘉小片的代表方言。涵蓋吳語人稱代詞（儂 / 阿拉 / 伊 / 伊拉）、吳語否定詞（弗 / 勿 / 覅）、句末助詞（呃 / 嘞 / 伐 / 哦呦）、海派標誌詞（結棍 / 霞氣 / 嗲 / 戇 / 洋盤 / 淘漿糊 / 軋鬧猛 / 噶三胡）、弄堂文化詞（弄堂 / 石庫門 / 爺叔 / 小囡）以及海派評價語（派頭 / 有腔調 / 紮台型 / 拎得清）。

## 功能

依照 21 條 checklist 將文字轉為上海話風格，涵蓋以下模式：

| 類別 | 項目 |
|------|------|
| **靈魂條款** (C-01–C-05) | 人稱代詞 / 否定詞 / 標誌詞密度 / 句末助詞 / 中性化 |
| **語法模式** (G-01–G-08) | 代詞系統、弗/覅、句末助詞、蠻/老/嘎、拿/撥、V 一記、困覺去、阿是 |
| **詞彙模式** (V-01–V-05) | 標誌詞、文化詞、海派評價、常用詞替換、外來語 |
| **Meta** (M-01–M-03) | 標點、不混粵語、Heavy 對白格式 |

支援三段強度：

| 強度 | 說明 |
|------|------|
| **輕** | 普通話骨幹 + 儂 / 阿拉 / 弗 / 蠻 + 3-5 個標誌詞。普通話讀者完全讀得懂。像新民晚報副刊或半正式部落格。 |
| **中**（預設） | 全套人稱與否定 + 句末助詞（伐 / 嘞 / 哦呦）+ 部分句式吳語化（拿伊撥我 / 困覺去 / 阿是）+ 海派評價詞。像周立波清口的書面化或《愛情神話》對白。 |
| **重** | 全篇滬語書寫，G1-G8 全用、V1-V5 自由替換；趨向《繁花》式書面語，普通話讀者讀來會有阻力。 |

## 使用方式

```
/shanghainese path/to/article.md
```

**觸發詞：** `/shanghainese`、「寫成上海話」、「滬語化」、「翻成上海話」、「上海話」、「滬語」、「吳語」、「儂」、「阿拉」、「海派」、「周立波」、「繁花」

支援任何語言輸入，轉為上海話輸出。

## 運作流程

1. **載入** — 讀取檔案或行內文字
2. **轉換** — 依 checklist 逐項套用滬語模式，先人稱與否定，再句末助詞，再標誌詞
3. **輸出** — 另存為 `_shanghainese` 後綴新檔，附 3-5 組前後對比與標誌詞 glossary

## 設計原則

- **吳語不是普通話次方言**：吳語與官話在漢語譜系內為姊妹語族，上海話有自己的代詞、否定、聲調與詞彙系統，不是「壞掉的普通話」。
- **書面標準仍未統一**：本字 / 訓用字 / 借音字三套並行；本 skill 以《繁花》、錢乃榮《上海話大詞典》、教育部本字為優先，避免自造字。
- **避免地域刻板印象**：不寫「上海人精明 / 排外 / 拜金」類戲仿；本 skill 定位為吳語太湖片地域文化現象。
- **Heavy 模式有閱讀阻力**：完整滬語書寫對普通話讀者是有挑戰的——這是 authenticity tradeoff。Medium 是安全預設。
- **不混粵語字**：嘅 / 咗 / 佢 / 嗰 是粵語，不是上海話；上海話用 呃 / 嘞 / 伊 / 搿。
