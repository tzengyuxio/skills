# Psychoanalytic-lens — 用精神分析的眼光重寫敘事

把一篇文章改寫成「**它自己用精神分析的眼光看自己**」的版本。事件不動，但
文章內部對動機、意義、心理活動的敘述，改用精神分析的語彙與切片展開。

這是一個 **lens skill**——它不像體裁／風格 skill 那樣改變句法、節奏或詞
彙表面，而是改變**詮釋框架**：同一個事件，被當作症狀、慾望的迂迴、或大
他者凝視之下的演出來敘述。讀完讓人覺得：這篇文章從一開始就是用分析師的
耳朵在聽自己的故事。

## 一句話靈魂

**事件保留、概念自然發生、替代敘述義務**——三條核心條款並列，缺一就會掉
回兩個失敗模式：要嘛事件被竄改成另一個故事（變創作而非詮釋），要嘛變成
論文式評論貼在原文後面。

> **關鍵分辨**（請務必讀完）：
>
> - **A 路線（本 skill）**：重寫**主敘述**——把「他簽了那份合約」改寫為「他在父親死後第三年，終於替亡魂蓋上那枚他從沒被允許觸碰的章」。事件（簽合約）保留，意義被替代。 - **B 路線（嚴禁）**：原文不動，後面接「拉康會說⋯⋯」「佛洛伊德指出⋯⋯」這類論文式評論。這是分析評論，不是分析改寫。

本 skill 永遠走 A 路線。

## 流派選擇（只走一派，不混血）

精神分析有三個主要血脈，概念之間**不能任意互換**（尤其是 Freud 與 Jung,
他們在 1913 後分裂，世界觀差異甚大）。動筆前先決定主走哪派：

- **[F] Freud 經典精神分析**——壓抑、伊底帕斯、本我自我超我、夢的工作
  （壓縮 Verdichtung / 置換 Verschiebung）、症狀作為妥協形成、替代形成
  (Ersatzbildung）、被壓抑者的回返（Wiederkehr des Verdrängten)
- **[L] Lacan 結構主義精神分析**——鏡像階段（Imaginary）、想像/象徵/
  真實三界、大他者（le grand Autre）、父之名（Nom-du-Père）、慾望 vs
  享樂（jouissance）、能指鏈、目的因（objet petit a）、症狀作為對某個
  他者的訊息、隱喻（能指替換）/ 換喻
- **[J] Jung 分析心理學**——集體無意識、原型、陰影、阿尼瑪/阿尼姆斯、
  個體化。**Jung 不在本 skill 預設工具箱中**——他與 Freud/Lacan 的世
  界觀不相容，要走 Jung 路線請整篇從頭走 Jung 框架，別與 [F][L] 混用

預設**主走 [F] 或 [L](或兩者銜接,因 Lacan 自稱「回到 Freud」)**。
Žižek 式的當代寫法基本上是 Lacan + Freud 共構，可作 A 路線標竿——他在
《Looking Awry》《Enjoy Your Symptom！》中把希區考克、《阿拉丁》、恐怖
小說等改寫成精神分析敘事，沒有一句「拉康會說」，而是讓事件本身自己變
成分析。

## Step 1: Load the Text

- 若提供 `$0`，讀取該檔案。
- 若無引數，找對話中最近撰寫或編輯的 Markdown 檔，或請使用者提供文字。
- 若原文不是繁體中文，先在心中譯為繁體中文（不必輸出），再做改寫。

## Step 2: Mark Up the Source — Three Kinds of Sentences

讀完原文後，把每一句歸類成三種：

- **事件句**：誰做了什麼、結果如何。**這些句子的事實內容不可動**。
- **動機句 / 意義句**：解釋「為什麼」、「象徵什麼」、「他覺得⋯⋯」。
  這些是改寫的主戰場。
- **敘述者插話**：作者的評論、總結、寓意。可以全部重寫。

實作上：在心中（或筆記中）替每個動機句寫下「表面動機 → 可能的潛意識
動機」的對照。不是每一條都會用上，挑出最有戲的 2–4 條。

## Step 3: Pick One Master Concept（只挑一個，不要全用）

從概念工具箱中**挑一個**作為這篇改寫的主軸。其他概念可以零星出現，但
必須有一個是貫穿全文的「鏡頭焦距」。

> **C-class Hard 條款（概念自然發生）**：概念須從事件自然長出，不可貼標籤式塞入，不可把工具箱的概念全部用上。一篇文章能用 1 個主軸 + 1–2 個副概念已是極限。

### 概念工具箱

每條後方標 [F]=Freud / [L]=Lacan（無 [J] 條目；Jung 路線整篇另走）。
括弧內為德/法原文或標準術語。

| 概念 | 派 | 一行解釋 | 自然使用範例（怎麼長進敘事裡） |
|---|---|---|---|
| **壓抑 (Verdrängung)** | [F] | 不可承認之物被推到意識之下，卻從別處返回 | 「他每次經過那條街都加快腳步，自己也沒注意到」（不要寫「他壓抑了 X」）|
| **被壓抑者的回返 (Wiederkehr des Verdrängten)** | [F] | 被壓抑之物以扭曲的形式從別的地方冒出來——夢、口誤、症狀 | 「那個名字他從來不在白天說出口，但每一份報告的第三段都不知為何會多一個 typo，落在那個字母上」 |
| **症狀作為妥協形成 (compromise formation)** | [F] | 症狀同時滿足慾望與防禦——既說出又遮住 | 「他遲到的方式很有規律——每次都晚十二分鐘，像在守一個只有他自己知道的、不能準時也不能太晚的契約」 |
| **替代形成 (Ersatzbildung)** | [F] | 不能承認的對象/想法被替換成另一個——症狀、夢、口誤都是替代品 | 「他擦那輛車的方式，像擦一個他從來不敢觸碰的人的肩膀」（車站到了那個人的位置）|
| **壓縮 (Verdichtung) / 置換 (Verschiebung)** | [F] | 夢的工作：多個元素疊成一個（壓縮）、情感從原對象挪到無關對象（置換） | 「他對辦公室那盆枯掉的盆栽生氣得不成比例——那盆栽承接了一整個禮拜他不能對任何具體的人說的話」（置換）|
| **伊底帕斯情結 (Oedipus complex)** | [F] | 對同性親長的競爭與對異性親長的依戀；法、禁制、認同的原始現場 | 「他知道母親在等他選某一條路。他選了相反的那條，然後在那條路上，把每件事都做成只有母親會看得懂的版本」 |
| **閹割焦慮 (Kastrationsangst)** | [F] | 失去能力/完整性/陽具（象徵性）的恐懼 | 「電腦螢幕一暗，他的手就不聽使喚地伸向重開機鍵——像怕什麼會永遠關掉」 |
| **死亡驅力 (Todestrieb)** | [F] | 朝向毀滅、重複、回到無張力之點的力量 | 「他第七次重寫那段程式，刪掉再寫，刪掉再寫——好像不是要寫好，是要把它寫到不存在」 |
| **移情 (Übertragung / transference)** | [F] | 把舊關係的位置投射到新對象身上 | 「他第一次見到新主管，就不由自主地用他十八歲時對父親的那種沉默回應」 |
| **投射 / 認同 (Projektion / Identifizierung)** | [F] | 把自己不能承受的歸給別人 / 把別人的位置據為己有 | 「他罵下屬粗心，聲音卻越來越像當年罵他的主管」 |
| **鏡像階段 (stade du miroir)** | [L] | 嬰孩透過鏡像認出一個比自身更完整的「我」——這個我從一開始就是誤認、是異化 | 「他在會議室的玻璃倒影裡看見自己，挺直了腰——彷彿那個倒影才是真的他，而他要努力的，是不要讓真的他露出來」 |
| **想像/象徵/真實三界 (RSI)** | [L] | Imaginary（影像、誤認）/ Symbolic（語言、法）/ Real（無法被符號化之物） | （整篇主軸而非單句）|
| **大他者 (le grand Autre) / 大他者的凝視** | [L] | 不是某個具體的人，是一個無名的「應該」在看；無意識是「大他者的話語」 | 「他在無人的辦公室還是把姿勢調正——彷彿牆角有一雙永不眨眼的眼」 |
| **父之名 (Nom-du-Père)** | [L] | 父親作為法/禁制的象徵位置（不是某位具體的父親）| 「他簽下名字時，握筆的方式和那個位置一模一樣——他自己沒察覺」 |
| **慾望 (désir) / 慾望是他者之慾** | [L] | 慾望永遠指向他者所慾；不可被任何具體對象滿足 | 「他要的從來不是那份工作，他要的是父親會怎麼看他拿到那份工作」 |
| **目的因 / 對象 a (objet petit a)** | [L] | 不是慾望追的對象，是讓慾望啟動的剩餘物——一個被符號化過程切割掉的殘渣 | 「他真正在意的不是那塊錶，是錶背面那個他從來看不見、卻知道父親每天會擦的位置」 |
| **享樂 (jouissance)** | [L] | 超出快樂原則、痛中之爽、飲鴆之樂 | 「他罵自己罵得越狠，越覺得有什麼東西被滿足了」 |
| **症狀作為訊息 (le symptôme comme message)** | [L] | 症狀是說給某個他者聽、寄到大他者那裡的訊息，而非要被治癒之物 | 「他的失眠不是病，是夜裡留給某個他白天不能對話的人的時段」 |
| **能指替換（隱喻）/ 能指鏈（換喻）** | [L] | 一個能指替換另一個能指（隱喻）/ 在能指鏈上滑動（換喻）；Lacan 的「替代」就在這層運作 | 「他每次經過那盞紅綠燈，都會在綠燈前先停一秒——那一秒在替另一個他十六歲時沒有停下來的瞬間立著」 |

每一條的「自然使用範例」**不是學術定義**，而是怎麼把概念**寫進敘事**而
不是貼在敘事旁邊。

> **關於「替代敘述」的學術根據**：本 skill 的「替代敘述義務」對應的是 Freud 的 **Ersatzbildung（替代形成）** 與 Lacan 的 **能指替換（隱喻）** ——兩派都認為：不能直接被說出口的東西，會以另一個東西「站到它的位置上」的方式說出來。本 skill 的改寫動作，就是把敘述本身做成這種替代。

## Step 4: Plan the Substitute Narration（替代敘述義務 — 靈魂條款）

選好主概念後，**至少挑一處**表面行為，把它的主敘述換成它的象徵性根源。

> **C-class Hard 條款（替代敘述義務）**：不是加一句「這是壓抑」，而是把主敘述本身改寫。
>
> ❌ 「他簽了合約。這其實是一種壓抑的展演。」（B 路線：評論貼在事件旁）
>
> ✓ 「他在父親死後第三年，終於替亡魂蓋上那枚他從沒被允許觸碰的章。」 （A 路線：事件保留——確實是簽合約 / 蓋章——但敘述本身就是分析）

替代敘述至少 1 處，理想 2–3 處。多了會變成過度詮釋，失去克制。

## Step 5: First Draft

寫一稿。原則：

- **事件骨架不動**：時間順序、誰做了什麼、結果如何，全部保留
- **動機句重寫**：把「他想要 X」改成「他要的並不是 X，他要的是 X 在某
  個目光下變成的那個東西」這類句式——但不要每句都這樣，會變說教
- **心理切片插入**：在事件之間插入 1–3 處短切片，描述潛意識層面正在發
  生什麼（不是評論，是場景）
- **敘述者揣測句**：可以用「他自己不會這樣說，但他的手已經這樣做了」
  「他以為他在 X，他其實在 Y」這類克制的揣測句——但密度不可過高
- **語氣**：分析的冷靜 + 文學敘述的克制。**不亢奮、不戲謔、不評判**
- **篇幅**：大致與原文相當或略長（+0–30%）。不要膨脹

## Step 6: Self-check Against Checklist

逐條對照下面的 21 條 checklist。**任一條 [Hard] 違反就回 Step 5 重寫該段**。

### Checklist: Core（核心三條 — 並列靈魂條款）

| 編號 | 強度 | 規則 |
|---|---|---|
| C-01 | Hard | **事件保留**——不可竄改敘事事實（誰做了什麼、結果如何、時間順序、人物關係）。只能重寫動機句、意義句、心理活動句、敘述者插話 |
| C-02 | Hard | **概念自然發生**——核心概念須從事件自然長出，不可貼標籤式塞入（不可寫「這就是伊底帕斯情結」）。**禁止全部概念出場**,1 個主軸 + 1–2 個副概念為極限 |
| C-03 | Hard | **替代敘述義務**——至少 1 處（理想 2–3 處）把表面行為的主敘述替換為其象徵性根源。**不是加註，是改寫主敘述本身** |
| C-04 | Hard | **不走 B 路線**——禁止「拉康會說⋯⋯」「佛洛伊德指出⋯⋯」「依據精神分析理論⋯⋯」這類 cite 式句子。分析必須**內化**進敘述 |
| C-05 | Hard | **不評判**——精神分析不做道德評判。不可寫「他這樣是錯的」「他應該⋯⋯」 |

### Checklist: Structure（結構）

| 編號 | 強度 | 規則 |
|---|---|---|
| S-01 | Hard | 篇幅大致與原文相當，允許 ±30% 浮動。不可膨脹為論文 |
| S-02 | Hard | **保留原文段落骨架**——大段落順序與事件對齊，不可隨意重組時間軸 |
| S-03 | Soft | 動機句重寫位置：優先處理「他想/他要/他覺得/他認為」開頭的句子 |
| S-04 | Soft | 心理切片可在關鍵事件**前後**插入（不打斷事件本身），每篇 1–3 處 |
| S-05 | Soft | 敘述者揣測句（「他不會這樣說，但⋯⋯」）每篇 ≤2 處，過密則失克制 |
| S-06 | Hard | **不寫論文格式**——禁用「摘要 / 前言 / 結論 / 參考文獻」式結構；不分節標題化 |
| S-07 | Hard | **不加招牌標題**——禁止「精神分析解讀：XXX」「拉康視角下的 XXX」這類 meta 標題 |

### Checklist: Vocabulary（詞彙）

| 編號 | 強度 | 規則 |
|---|---|---|
| V-01 | Hard | **概念詞自然嵌入**——用「壓抑」「慾望」「象徵」「父親的位置」「他者的凝視」這類詞時，要當作敘述語言的一部分，不是引用術語 |
| V-02 | Soft | 5–10 個核心概念詞可在文中出現，但**不集中堆疊**（同一段不要超過 2 個概念詞） |
| V-03 | Hard | **禁用 cite 式短語**——「根據佛洛伊德」「拉康認為」「精神分析告訴我們」整類句式禁止 |
| V-04 | Soft | 可用學派典故的物件比喻（鏡像、舞台、面具、信件未達其目的地⋯⋯）但不點名來源 |
| V-05 | Soft | 留意「象徵」「投射」「移情」這類詞的中文日常義與精神分析義的差別，語境清楚才用 |
| V-06 | Hard | **不混 Jung 與 Freud/Lacan**——一篇文章選定 [F]/[L](或兩者銜接)就不冒出「陰影」「原型」「集體無意識」「阿尼瑪/阿尼姆斯」「個體化」；走 Jung 就整篇 Jung |

### Checklist: Mood（調性）

| 編號 | 強度 | 規則 |
|---|---|---|
| M-01 | Hard | **冷靜**——分析師耳朵的距離感，不哀嘆、不驚呼、不替人物代言情緒 |
| M-02 | Hard | **克制**——一篇文章不要把所有概念用完。留白比說滿更接近本 skill 精神 |
| M-03 | Hard | **不亢奮**——禁止「這正是⋯⋯的絕佳體現」「不正是⋯⋯嗎」這類論證口吻 |

## Step 7: Verify the Three Core Clauses（核心三條複查）

寫完後**單獨再走一次這三條**——它們是這個 skill 的命脈：

1. **事件保留**：把改寫稿的事件順序列出來，逐一對照原文。任何被改動的
   事實（誰做了什麼、結果如何），都要回 Step 5 改回去。
2. **概念自然**：全文用了幾個概念？如果超過 3 個，刪掉最弱的。任何一處
   讀起來像「貼標籤」（可以替換成「這就是 X 概念」而不損失資訊），改寫
   該句直到它看起來像場景而不是診斷。
3. **替代敘述義務**：有沒有至少一處把表面行為的主敘述替換為象徵性根源？
   如果只有「加註」沒有「改寫主敘述」，回 Step 4。

## Step 8: Punctuation & Spacing Cleanup

- 中文用全形標點（，。；：「」『』——⋯⋯）
- 數字與英文與中文之間留半形空格（視專案慣例）
- 破折號用「——」（兩字）而非「—」（一字）或「-」

## Forbidden in Output

寫完一稿、自檢之前先掃一眼這 6 條最容易踩的坑：

1. **招牌標題** ❌ —「精神分析解讀：XXX」「拉康視角下的 XXX」「佛洛伊德
   讀 XXX」這類給文章貼大字標籤的標題，絕對禁止
2. **Cite 式句子** ❌ —「拉康會說」「佛洛伊德指出」「依據精神分析理論」
   這類引用句，屬於 B 路線
3. **概念全家桶** ❌ — 一篇文章把工具箱的概念都用一遍。1 個主軸 +
   1–2 個副概念為極限
4. **論文格式** ❌ — 摘要 / 前言 / 結論 / 章節標題；分析摘要表；括號註釋
5. **道德評判** ❌ —「他這樣是錯的」「他應該⋯⋯」「這種人格不健康」。
   精神分析不評判
6. **事件竄改** ❌ — 為了讓詮釋更順，把原文的事件順序、人物關係、結果
   悄悄改掉。這是創作不是詮釋
7. **流派混血** ❌ — 在 Freud / Lacan 框架裡突然冒出「陰影」「原型」
   「集體無意識」「阿尼瑪」這類 Jung 詞；或反之。Freud↔Lacan 可銜接
   (Lacan 自稱回到 Freud),Jung 必須整篇另走

## Core Example: 木匠雕神像

源文（現代軼事）：一名工程師接到三日交專案的死線，連夜加班寫出醜陋程式
碼，事後重構，最後產品被取消。下方為改寫成功的版本——事件全保留（三日
死線 / 醜陋程式 / 重構 / 產品取消），但動機句、心理切片、敘述者插話全部
換成精神分析的眼光。**主軸概念**：症狀作為訊息 [L](他寫醜的程式不是失
誤,是寫給某個他者看的訊息)。**副概念**：大他者的凝視 [L]。整篇走純
Lacan 路線。

> 那個三日死線到的時候，他並沒有想「我要把它寫好」。他想的是另一句話，但那句話他自己不會這樣說——他的手已經這樣做了：他要把它寫到讓某個人看見他寫得多糟。第一天的程式碼是給時間看的，第二天的是給主管看的，第三天清晨那段——那段沒有縮排、變數名一個字母的程式——是給一個從來沒在這個辦公室裡出現過的人看的。
>
> 他自己以為他在趕工。他其實在簽名。他每寫下一段不該這樣寫的程式，就像在牆上又劃了一道：**看，我做到了。看，你還是沒有來看**。
>
> 死線過了。產品上線了。那段醜陋的程式碼運作正常。然後他開始重構——花了比死線本身還久的時間，一行一行地把它擦掉。他以為他在補救當初的潦草，他其實在抹除那個訊息。他不能讓那段程式留下，因為那段程式是他寫給一個不在場的目光的信，而那封信現在開始讓他自己讀到了。
>
> 重構到一半，產品被取消。
>
> 他坐在那裡，沒有立刻關掉編輯器。他發現自己鬆了一口氣——這口氣他不願意承認。產品取消的那一刻，他不必再決定要不要把那段醜的程式留下還是擦掉。決定被替他做了。那個從未到場的目光，終於以「整件事不存在」的方式回應了他。
>
> 他關上電腦，走出辦公室。隔天他照常上班。他沒有想這件事。他只是在那之後一段時間，寫程式的習慣變了：他開始非常仔細地寫每一個變數名，每個都要對得起一個他不會說出名字的人。

**達標複查**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 事件保留：三日死線、寫醜程式、重構、產品取消、之後變得仔細——全部對齊 |
| C-02 | ✓ | 主軸：症狀作為訊息（寫醜的程式 = 訊息）；副：大他者的凝視（那個從未到場的目光）；總共 2 個概念 |
| C-03 | ✓ | 替代敘述至少 3 處：「趕工 → 簽名」、「補救潦草 → 抹除訊息」、「鬆一口氣 → 不必再決定要不要留下訊息」 |
| C-04 | ✓ | 全文無 cite 式句子，無學派名稱出現 |
| C-05 | ✓ | 不評判他「不該」如此，只描述心理結構 |
| S-01 | ✓ | 約 480 字，原文 60 字概要——但事件骨架對齊 |
| S-06 | ✓ | 無摘要 / 結論 / 標題 |
| S-07 | ✓ | 無「精神分析解讀」式招牌標題 |
| V-01 | ✓ | 「目光」「訊息」「不在場」自然嵌入，不引術語 |
| V-03 | ✓ | 無「拉康認為」「佛洛伊德指出」 |
| M-01 | ✓ | 冷靜：不為他哀嘆，不為他辯護 |
| M-04 | ✓ | 結尾不收線：他「在那之後變得仔細」——這個習慣的改變本身是新症狀，沒有解決 |

**對照結論**：精神分析改寫不是把故事翻譯成術語，而是**讓故事的內部敘
述本身變成分析**——「他自己以為他在趕工。他其實在簽名。」這一句替代敘
述，把整個事件從「工作壓力下的失常表現」重新組織為「給一個不在場目光的
訊息」。事件沒有變，意義被重組了。

## Scope Boundary

| 想做的事 | 用哪個 skill |
|---|---|
| 把文章用精神分析的眼光重寫敘事（本 skill）| **psychoanalytic-lens** |
| 寫一篇精神分析論文式的評論 | （不在本 skill 範圍 — 那是 B 路線）|
| 翻譯精神分析經典文本 | （不在本 skill 範圍）|

如果使用者要的是**論文式分析**或**對作者下精神分析診斷**，告訴使用者本
skill 的目標是**重寫敘事**而非**寫評論**，並請對方確認是否仍要繼續。

## Important Notes

- 本 skill 是**詮釋框架轉換工具**，不是「給文章加術語」工具。事件骨架
  必須完整保留，只重組意義
- **替代敘述是靈魂**：沒有至少一處主敘述被替換為象徵性根源，就不是這
  個 skill 的成品。加註不算
- **克制 > 說滿**：概念用得少而準，比用得多而散更接近本 skill 精神。
  一個好的精神分析改寫，讀者不會覺得「這篇在分析」，而會覺得「這篇文
  章自己在聽自己」
- **不評判**：精神分析的倫理是不評判。任何道德結論（他應該 / 不該 / 健
  康 / 不健康）都是違規
- **不收線**：症狀永遠未解決。結尾允許懸而未決——事實上理想結尾就該
  如此。寫一個「他從此釋懷了」的結尾，等於背叛這個 skill
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
