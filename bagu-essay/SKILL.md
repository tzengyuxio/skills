# Bagu-essay — 改寫成明清八股文

把任何文章改寫成明清科舉的八股文（經義文 / 制藝）——八段結構齊備、四股
兩兩對仗、代聖人立言，讀完讓人覺得這篇現代議題已經被裝進了一副明清經義
的鐵架子裡。

風格參照：**明清科舉八股文**（自明憲宗成化年間定型，至光緒三十一年廢科
舉）。代表選本：《欽定四書文》（方苞編）、《制義叢話》（梁章鉅輯）、《明文海》
（黃宗羲編）中的時文卷。代表名家：王鏊、唐順之、歸有光、艾南英、方苞。

## 一句話靈魂

**八段結構齊備 + 四股兩兩對仗 + 代聖人立言**——三者構成八股文指紋，缺
一就不是八股文。八段為：破題、承題、起講、入手、起股、中股、後股、束
股；其中起股、中股、後股、束股稱為「四股」，**每股必須由兩個對偶分句
組成**，字數相同、句式相對、虛實相對、平仄相對。全篇須以聖人（孔孟程朱）
的口吻立論，**禁用第一人稱「我」**。其餘 18 條 checklist 都在服務這三條。

## 段落異名對照（各派稱呼差異）

明清制藝歷時數百年，各家對段落的稱呼略有差異。本 skill 採以下主名，讀
者若在他處見到異名請對照：

| 主名（本 skill 用） | 異名 / 別稱 |
|---|---|
| 破題 | （無常用異名） |
| 承題 | （無常用異名） |
| 起講 | 原起、小講 |
| 入手 | 入題、領題、出題 |
| 起股 | 起比、提比、題比、提股、前股 |
| 中股 | 中比 |
| 後股 | 後比 |
| 束股 | 束比、小結 |
| 大結 | 收結、落下 |

「股」與「比」可互換（「比」即對偶之意），故四股亦稱「四比」或「八比」
（每股含上下兩比，合計八比，即八股文之名所由）。本 skill 內文一律用「股」。

## Step 2: Read Source and Find a 經書式題目

八股文的題目**必出自四書**（《論語》《孟子》《大學》《中庸》），少數出自
五經。改寫現代議題時，須**虛擬一句經書式題目**——一句像四書斷章取義出
來的話。讀完原文後，自答：

> 這篇文章可以歸結為一句什麼樣的「經書式短語」？它能像「學而時習之」「不患人之不己知」那樣被斷章獨用嗎？

虛擬題目的方法：
1. **直接挪用**——若原文已有近似四書句式的金句，稍作節縮即可
   （「凡事差不多」→「論凡事差不多」）
2. **化俗為雅**——把現代詞翻為文言對等詞
   （「LinkedIn 經營」→「君子當有 LinkedIn」）
3. **斷章取義**——從原文抽一句最濃縮的命題，套上「論⋯⋯」「⋯⋯之道」
   「⋯⋯不可⋯⋯」格式
   （「請假事宜」→「論請假之道」、「子曰加班」、「不患加班之不至」）

題目須像經書斷句：**短、有歧義空間、可發議論**。

## Step 3: Choose a 四書範本（經書骨架）

從以下四種經書骨架挑一種為主軸，影響全篇用詞、典故、議論方式：

| 骨架 | 重點德目 | 慣用句式 | 適合議題 |
|---|---|---|---|
| 《論語》派 | 仁、學、君子小人 | 「子曰」「君子」「小人」「夫子之道」 | 修身、學習、人際 |
| 《孟子》派 | 義、性善、王道 | 「孟子曰」「天下」「民」「不忍人之心」 | 政事、價值、抉擇 |
| 《大學》派 | 格致誠正、修齊治平 | 「物有本末」「先後之序」「明明德」 | 流程、目標、自律 |
| 《中庸》派 | 中、庸、誠 | 「不偏不倚」「致中和」「誠者天之道」 | 平衡、節度、長期 |

**多 demo 不共用同一骨架**——選定後在筆記裡寫：「骨架 = X 派，主德目 = Y。」

## Step 4: 草破題二句

破題是八股文最關鍵的一段——**用 2 句點破題目核心，不可說破到底，留懸
念**。破題若失，全篇皆失。原則：

- **必為兩句**（不可一句、不可三句）
- **不可直引題目原字**（明清「冒題」「犯題」之忌）——須繞著題意說
- **要有命題感**——點出此題的「分量」何在，但不解題到底

> 範例（題：「學而時習之」）：破題：「聖人示學，以時為要。蓋時習者，學之命脈也。」 ——點出「時習」之分量，未說破「悅」字，留待下文。

## Step 5: 承題、起講、入手

- **承題**（3–5 句）：承接破題，稍展開，點出題目的脈絡與本義。**散行**
  （不對仗）
- **起講**（1 段）：**以聖人（或題目所屬經書原作者）口吻發議論**，慣用
  起首套語見下表；語氣莊重，設下全篇議論的調性。**散行**（不對仗）
- **入手**（1–2 句）：過渡到正文八股，引出議題的兩面或三面，為起股鋪路。
  亦稱「入題」「領題」「出題」

### 起講起首套語（擇一）

明清制藝起講開頭多用「揣摩語氣」的虛字或代言式發語詞。可用範圍比想像
中寬，擇一即可：

- **代言式**：「意謂」「若曰」「以為」「蓋謂」「嘗謂」「嘗思」「請即
  所云」（以聖人口吻揣摩語意）
- **發語式**：「夫」「蓋」「且夫」「今夫」「甚矣」「想夫」（承上啟下，
  發起議論）
- **複合式**：「子曰⋯⋯今夫」「君子以為」「有若深言⋯⋯蓋謂」（先點明
  代言對象再展開）

> 王鏊〈百姓足君孰與不足〉起講原文：「**有若深言**君民一體之意，以告哀公。**蓋謂**公之加賦，以用之不足也；欲足其用，盍先足其民乎？」 ——先以「有若深言」標出代言對象，再以「蓋謂」承接展開，是明代制藝起講的標準工法。

起講最易踩坑——**不可用「我」「我們」「筆者」**，必以上述套語之一起。

## Step 6: 寫四股（每股兩兩對仗）

四股是八股文的議論主體。每股結構：

```
某股
  上比(分句一)——XX 字,某句式
  下比(分句二)——XX 字,結構相同,虛實相對
```

**對仗要求**（每一股內部，清代律賦的標準）：

| 軸 | 上比 | 下比 |
|---|---|---|
| 字數 | N 字 | **必為 N 字**（嚴格相同） |
| 句式 | 主謂賓某結構 | **完全對應結構**（句讀、語法位置同） |
| 虛實 | 實字位 / 虛字位 | **實對實、虛對虛**，不可錯位 |
| 詞性 | 名 / 動 / 形 / 副 | **對應名 / 動 / 形 / 副** |
| 平仄 | 句末某聲（平 / 仄） | **與上比相對**（平對仄、仄對平） |
| 意義 | 正 / 反 / 並列 | 與上比形成正對、反對或並列對 |

明清論者總括四股對仗大要為：**「一反一正、一虛一實、一淺一深」**——
四股之間既要兩兩對偶工整，也要在義理上分層遞進。

**四股之分工**:

| 股 | 功能 | 比例 |
|---|---|---|
| 起股 | 正論之始，提出立場 | 1 段，兩兩對仗 |
| 中股 | 正論深入，通常為論述重心 | 1 段，字數最豐 |
| 後股 | 反論或補論，從另一面說 | 1 段，兩兩對仗 |
| 束股 | 收結議論，氣勢收束 | 1 段，字數可較短 |

> 範例（題：「學而時習之」，起股）：
>
> 上比：「方其童蒙，問字於塾師，則學在乎啟其智。」下比：「迨其壯歲，讀書於燈下，則學在乎進其德。」
>
> ——上比講童蒙啟智，下比講壯年進德，虛實相對，字數對等。

**寫法建議**：先把上比寫好，再對著上比逐字逐位寫下比；若下比寫不出，
回頭調整上比讓它好對。

## Step 7: （選填）大結

**大結**（1 段）：束股之後可加一段總結升華，**散行不對仗**。

歷史脈絡：
- **明代**：大結是士子借題發揮、表達己意之處，可稍離經義講時務，篇幅
  較長
- **清代**：功令收緊，大結改為「**三、四句收束，不能發揮己意**」，只能
  照應全篇、不得議論朝政。亦稱「收結」「落下」

本 skill 取其寬——**有就有，沒有也行**。若束股已收得乾淨，毋須畫蛇添
足；若加，以清代格為宜：三、四句點題收束，不另起爐灶。

> 王鏊〈百姓足君孰與不足〉大結原文：「**吁！徹法之立，本以為民，而國用之足，乃由於此，何必加賦以求富哉！**」——四句收束，呼應破題，不離題，不對仗。

## 參照樣本：王鏊〈百姓足君孰與不足〉（明・成化年間）

下方為明代弘治三鼎甲、後入《欽定四書文》的王鏊代表作全文。題出《論語・
顏淵》「百姓足，君孰與不足？百姓不足，君孰與足？」——是制藝範本中最常
被引用的一篇。寫八股時，**句式氣息與虛字節奏可參照此篇**。

> **破題**：民既富於下，君自富於上。
>
> **承題**：蓋君之富，藏於民者也。民既富矣，君豈有獨貧之理哉？
>
> **起講**：有若深言君民一體之意，以告哀公。蓋謂公之加賦，以用之不足也；欲足其用，盍先足其民乎？
>
> **起股**（起比 / 提比）：誠能百畝而徹，恆存節用愛人之心；什一而征，不為厲民自用之計；則民力所出，不困於征求；民財所有，不盡於聚斂。閭閻之內，乃積乃倉，而所謂仰事俯育者，無憂矣；田野之間，如茨如梁，而所謂養生送死者，無憾矣。
>
> **入手 / 虛股**：百姓既足，君何為而獨貧乎？
>
> **中股**：藏諸閭閻者，君皆得而有之，不必歸之府庫，而後為吾財也；蓄諸田野者，君皆得而用之，不必積之倉廩，而後為吾有也。取之無窮，何憂乎有求而不得；用之不竭，何患乎有事而無備！
>
> **後股**：犧牲粢盛，足以為祭祀之供；玉帛筐篚，足以資朝聘之費。借曰不足，百姓自有以給之也，其孰與不足乎？饔飧牢醴，足以供賓客之需；車馬器械，足以備征伐之用。借曰不足，百姓自有以應之也，又孰與不足乎？
>
> **大結**：吁！徹法之立，本以為民，而國用之足，乃由於此，何必加賦以求富哉！

（出處：王鏊《震澤集》；轉引自方苞《欽定四書文》。維基文庫、百度百科
「民既富于下，君自富于上」條皆有全文。）

**可學習之處**:
1. 起講以「有若深言⋯⋯蓋謂⋯⋯」開頭——代言對象先點名，套語接議論
2. 起股對仗：「百畝而徹⋯⋯什一而征⋯⋯」「閭閻之內⋯⋯田野之間⋯⋯」字數
   對等、虛實對位
3. 中股對仗：「藏諸閭閻者⋯⋯蓄諸田野者⋯⋯」交錯複沓，虛字「不必⋯⋯
   而後為吾⋯⋯也」前後對應
4. 後股以兩組「⋯⋯足以為⋯⋯」「借曰不足，百姓自有以⋯⋯，其孰與不足
   乎？」反詰收束，氣勢遞進
5. 大結僅四句，呼應破題「民既富於下，君自富於上」，不離題、不對仗

### Checklist: Meta（後設）

| 編號 | 強度 | 規則 |
|---|---|---|
| M-01 | Hard | 不附評論段、不附作者按、不附「我的改寫思路」 |
| M-02 | Hard | **平仄錯綜**——上比若以平聲收，下比以仄聲收（或反之）；整篇平仄不可單調 |
| M-03 | Hard | **虛實相對**——對仗時實字對實字、虛字對虛字，不可以虛對實 |
| M-04 | Soft | 避免重複句式——四股之間句式不可全然雷同，須有變化（主謂並列、賓語前置、設問互答等） |
| M-05 | Hard | 不嘲弄、不搞笑、不刻意拗口——嚴肅認真做，讓讀者自行感受古今反差 |

**總計**:22 條（Hard 16 + Soft 6）。

## Step 9: 朗讀檢查對仗與氣勢

寫完後**默讀一遍**，逐項檢查：

1. 八段是否齊備、是否以空行區隔（沒有「破題：」標籤）
2. 四股每一股的上比、下比字數是否對等
3. 對仗點：虛實是否相對、平仄是否錯綜
4. 起講是否以「夫 / 蓋 / 嘗謂」開頭
5. 通篇是否一個「我」字也無
6. 束股是否氣收，沒有戛然而止
7. 起股、中股、後股、束股之間，句式是否有變化（不全是「方其⋯⋯則⋯⋯;
   迨其⋯⋯則⋯⋯」這種同一模板）

若任何一項不過，回到 Step 4–6 重寫該段。

## Step 10: Output

1. **檔案輸入**：寫入 `<原檔名>_bagu.md`，保留原檔
2. **貼文輸入**：直接輸出八股文
3. **不附說明、不附評論、不附「我的改寫思路」、不附「達標清單」**
4. 若使用者明確要求，可額外輸出**改寫筆記**（列出 Step 2–6 的選擇），但

5. **段落格式**：整篇置於 blockquote(`>`）中，**段落單行不換行**(CJK
   blockquote 慣例），段落間以 blockquote 空行（`>`）區隔

## Anti-patterns（常見失敗模式）

寫完一稿、自檢之前，先掃一眼這 8 條最容易踩的坑：

1. **嘲弄式仿八股**——刻意拗口、刻意誇大、加註解開玩笑。本 skill 是嚴肅
   體；古今反差感由「八股結構 + 現代議題」自然產生，不必添油加醋
2. **缺一股或對仗失工**——四股有一股缺對仗（只是長句而非兩兩），即視為
   違反靈魂條款 C-03
3. **用 markdown 子標題切八段**——「## 破題」「## 承題」會徹底破壞八股
   整體性。空行區隔即可
4. **「破題：⋯⋯」「承題：⋯⋯」標籤式開頭**——同樣破壞整體性。讓讀者自
   己看出八段
5. **第一人稱「我」漏網**——「我認為」「我們知道」是最常見的失誤。代聖
   人立言不可有「我」
6. **起講不以「夫 / 蓋 / 嘗謂」開頭**——起講語氣決定全篇議論調性，起手
   錯則全篇散
7. **現代口語雜入**——「真的很重要」「滿不錯的」「欸這就是」破壞文言節
   奏。可以雜現代議題詞（KPI / 健身房），但不可雜現代口語
8. **束股戛然而止或轉現代散文**——束股須以「斯⋯⋯而已矣」「⋯⋯也夫」式
   氣收，不可斷在轉論上、不可改用現代散文收尾

## Core Example: 論凡事差不多

源文（現代寓言）：胡適《差不多先生傳》（1924）摘錄——差不多先生凡事差
不多，最終誤請牛醫而死。下方為改寫成功的版本——以《論語》派為骨架，
題目「論凡事差不多」，代聖人（孔子）立言。

> 凡事而曰差不多者，聖人之所深戒也。蓋差不多者，亂仁義之分，失是非之辨也。
>
> 夫天下之事，精者其本，粗者其末；明者其體，昧者其用。差之毫釐，謬以千里——古之聖賢，所以兢兢於此者也。今有差不多先生焉，以差不多自處，以差不多遊世，終亦以差不多自喪其身。是以君子聞其風而懼，小人聞其風而樂，蓋君子知其禍，而小人不知也。
>
> 嘗謂聖人之教，在於辨。辨在此，則仁與不仁判；辨不立，則義與不義混。子曰「君子和而不同」，非謂差不多也；又曰「過猶不及」，非許差不多也。今之人乃以差不多自譽，是聖人之憂也。
>
> 試以其行考之：
>
> 紅糖白糖，色雖近而味異；陝西山西，字雖鄰而境殊。色雖近而味異，則甘苦淆於口；字雖鄰而境殊，則東西迷於途。
>
> 醫人以人之術，則疾退而身全；醫牛以牛之方，則療施而生危。施之於人也當其體，故活；誤之於牛也失其類，故殞。
>
> 不察者以為差不多，而察者見其差萬里；不明者笑其辨之苛，而明者懼其忽之深。蓋忽其差，則是非渾；辨其差，則仁義立。
>
> 故差不多者，非小過也，實大病也。一世以為小，而一身終以此亡；一人以為易，而天下終以此亂。斯所以聖人之戒，終古而不可廢也夫。

（約 480 字）

**改寫的核心動作**：把胡適原文「明寫的諷刺」轉為「明清制藝的莊重議
論」。原文是雜文體諷刺，八股版讓「差不多」成為一個被孔子之徒鄭重批判
的德目失格——**差不多者，亂仁義之分，失是非之辨**。這個道理由起講設下
基調（「差之毫釐，謬以千里」）、由四股兩兩對仗鋪開（色味、字境、活殞、
辨忽）、由束股以「斯所以聖人之戒，終古而不可廢也夫」收束。

## Important Notes

- 本 skill 是**體裁轉換工具**，不是「把文章加文言」工具。八股文有極嚴格
  的結構規範，必須八段齊備、四股兩兩對仗，缺一不可
- **嚴肅體是底色**——八股文在歷史上飽受詬病（「束縛思想」「八股取士」），
  但本 skill 不嘲弄這個體裁，而是認真用其鐵架子處理現代議題，讓讀者自
  行感受反差喜感。**刻意拗口、刻意誇張的 caricature 八股不是目標**
- **代聖人立言**是八股文的靈魂——通篇須以孔孟程朱口吻發議論，**禁用
  第一人稱**。這條最容易踩坑，寫完務必逐字檢查
- **對仗服務議論**——對仗不是炫技，是把議論的兩面用最對稱的形式擺出來。
  若對仗工而議論空，仍是失敗
- **不要用 markdown 子標題切八段**——那破壞八股整體性。空行區隔，讓讀
  者自己看出八段
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
