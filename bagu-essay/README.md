# Bagu-essay — 改寫成明清八股文

把任何文章改寫成明清科舉的八股文(經義文 / 制藝)。

不是把文章加文言,不是仿古文散文,而是**把現代議題裝進明清經義的鐵架
子裡**——八段齊備、四股對仗、代聖人立言,讀完讓人自然感受到古今反差。

## 什麼是八股文?

八股文是明清科舉考試指定的應試文體,自明憲宗成化年間定型,至光緒三十
一年(1905)廢科舉。題目必出自四書五經,考生須以指定的八段結構、嚴格
的對仗格律、**代聖人立言**的口吻寫出一篇議論文。

八段結構:
1. **破題**(2 句)——點破題目核心,不可說破到底
2. **承題**(3–5 句)——承接破題,稍展開
3. **起講**(1 段)——以聖人口吻發議論,慣用「夫 / 蓋 / 嘗謂」開頭
4. **入手**(1–2 句)——過渡到正文
5. **起股**(1 段,兩兩對仗)——正論之始
6. **中股**(1 段,兩兩對仗)——正論深入
7. **後股**(1 段,兩兩對仗)——反論或補論
8. **束股**(1 段,兩兩對仗)——氣勢收束

可選 **大結**——升華但不離題,不再對仗。

## 三條靈魂條款

1. **C-02 八段齊備** — 八段不可缺一
2. **C-03 四股兩兩對仗** — 起股、中股、後股、束股每股內含上比下比
3. **C-04 代聖人立言** — 以孔孟程朱口吻發議論,禁用第一人稱「我」

## 何時使用

- 想把現代議題(KPI / 開會 / 健身 / 社群媒體)裝進明清經義的莊重框架
- 想用八股結構處理一段哲學散文或諷刺寓言
- 想體驗「鐵架子裡的現代命題」的反差閱讀感

## 不適用情境

- 想要古文散文(韓柳歐蘇)——用 `wenyan-guwen`
- 想要志怪短篇——用 `liaozhai-tale`
- 想要章回武俠——用 `jinyong-style` / `gulong-style`
- 想要嘲弄式仿八股(本 skill 是嚴肅體,不嘲弄)
- 想要說書腔話本——用 `wenyan-huaben`

## 預期輸出篇幅

繁體中文文言為主,**400–900 字**,典型 600 字。

## 使用方式

```
/bagu-essay path/to/article.md
```

也可以直接貼一段文字進來。

**觸發詞:** `/bagu-essay`、「改寫成八股文」「八股文改寫」「經義文」
「明清制藝」「破題承題」「代聖人立言」「Eight-legged essay」
