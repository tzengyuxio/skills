# 影視口播 / Voice-over & Broadcast

**鎖死的是「口語媒介」**——這些 skill 模擬影視 / 廣播口播的語感，輸出讀起來
像被人念出來的講稿，而非被人讀的書面文字。

媒介限定使其與其他 skill 區隔——`hemingway-style` 是中譯文學風格，可讀可念但
為書面散文；`laogao-style` / `yizhi-style` 則明確以「念出來才對」為設計核心。

| [yizhi-style](../yizhi-style/) | 1950-90s 中譯影視配音腔（上譯廠 / 長譯廠正典 + 中譯西洋雙重位移） | 正典 / 戲仿 | [demo](../yizhi-style/examples/demo.md) |

## 對偶與光譜

- **影視口播 vs 配音翻譯**：兩件 skill 都是「念出來才對」，但機制不同
  - `laogao-style`：**創作者口播**（中文原創影音內容，神秘解說 / 玄學雙人口播）
  - `yizhi-style`：**譯製配音**（中譯西洋影視的翻譯腔配音傳統）
- **與「文學作家體」中譯西洋三件套**（shakespeare / hemingway / sherlock-holmes）
  的差別：那三件是書面譯本傳統，`yizhi-style` 是口語譯製傳統 — 同為中譯西洋
  但媒介不同
- **與「網路文體」的差別**：`laogao-style` 雖是網路時代產物，但結構是「雙人口播
  影音」，不是純文字 meme；歸入此類

## 設計原則

- 「念出來通順」是核心驗證：完成稿須能想像被某主播 / 配音員念出來
- 媒介標誌詞必須出現（影視配音的「噢」「哎」「啊」、口播的賣關子停頓詞「然後」
  「不過呢」）
- `laogao-style` 是 repo 首例「致敬活躍創作者」(設四條鐵律組切割語體與爭議實踐)
