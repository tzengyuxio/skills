# 中文地域變體 / Regional Chinese

把中文改寫為**某地的中文**——標準官話的地理 / 社會語體變體，外加漢字方言書寫
（粵語、台語）。**鎖死的是「在哪裡 / 屬於哪個語言社群的人在寫」**。

本類採真實語言學研究為據（邵敬敏、Jerry Norman、何大安等），**排除 caricature**
——把每個變體當真實的語言系統對待，而非嘲諷對象。

## 對偶與光譜

- **地理對偶**：taiwan ↔ mainland（兩岸標準語對位）、hongkong ↔ singapore（境外華語
  雙城）、dongbei ↔ sichuan（南北次方言）
- **書面 vs 標準層**：`written-cantonese` 與 `hongkong-chinese` 是同一語言的兩層
  輸出（前者全粵語句法、後者中文骨架夾粵詞）；`written-hokkien` 與 `taiwan-mandarin`
  同理（前者全台語、後者國語含台味）

## 設計原則

- 每個 skill 都有真實語料來源、語言學研究參照
- 輕 / 中 / 重三段：詞彙密度 → 句法滲透 → 全面方言化
- **不寫成卡通腔**：每個變體都是真實使用者每天在用的中文，不是電視喜劇裡的誇張版

## 邊界案例

- 與「跨語混搭」分類差別：本類是**中文內部的變體**；跨語混搭（如 chinglish）是
  **跨語言系統的接觸**，已自成一類
- 與「網路文體」分類差別：mainland-mandarin 含網路語但屬地域變體；`feihua-literature`
  等是 meme 句法，屬網路文體
