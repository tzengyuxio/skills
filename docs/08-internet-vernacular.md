# 網路文體 / Internet Vernacular

**鎖死的是「網路 meme 句法 / 修辭套路」**——這類 skill 收錄被網路社群放大形成
可辨識套路的次文化文體。每件 skill 把該 meme 的句法、套式、典型修辭系統化為
checklist。

涵蓋台灣本土 BBS 體與大陸網路四大 meme。

## 對偶與光譜

- **台灣 vs 大陸**：`ptt-bbs-style` 一件代表台灣本土網路體；其他 4 件代表大陸網路
  meme。同為網路文體但社群與機制不同
- **meme 機制四大類**:
  - **零信息**(feihua-literature)— 空話的形式藝術
  - **煽情**(zhiyin-style)— 雜誌時代延伸到網路的悲情敘事
  - **反差**(versailles-literature)— 用抱怨包裝炫耀
  - **答非所問**(concrete-42)— 偽專業話術噴霧
- **ptt-bbs 結構完整度高**:含**貼文 + 推文堆疊**兩段，其他 4 件只改寫文本本身

## 設計原則

- 諷刺對象限抽象普世(集體心態 / meme 機制本身),不指涉具體真實人物或事件
- `ptt-bbs-style` 暱稱使用泛化 ID(rookie123 / fatdog2024 等),不點名真實鄉民
- 每件 skill 引用 meme 學術研究或起源考據(例如 versailles 的 Mu et al. 2021
  學術定位為 humblebrag 文體)
