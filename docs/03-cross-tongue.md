# 中英混搭 / Cross-Tongue Mixed

兩種語言系統接觸 / 混搭所產生的特殊書寫形態。**鎖死的是「兩語的接觸機制」**——
與「中文地域變體」不同，這些是**跨語言系統**的混搭，base language 與裝飾語可能
互換。

## 收錄 skill（4 件）

| skill | 一句話功能 | 強度 | demo |
|---|---|---|---|
| [chinglish](../chinglish/) | 中式英語（中文母語干擾下的系統性英文變異） | 輕 / 中 / 重 | [demo](../chinglish/examples/demo.md) |
| [singlish](../singlish/) | 新加坡英語（含粵、閩、馬來語的英語克里奧爾） | 輕 / 中 / 重 | [demo](../singlish/examples/demo.md) |
| [hanjify](../hanjify/) | 英文漢字化（保留英文句法，內容詞替換為 CJK 漢字） | — | [demo](../hanjify/examples/demo.md) |
| [jingjing-style](../jingjing-style/) | 晶晶體（中文骨架夾不必要簡單英文字，名媛口語現象） | 輕 / 中 / 重 | [demo](../jingjing-style/examples/demo.md) |

## 兩種 base language 機制

| base | skill | 說明 |
|---|---|---|
| **英文 base + 中文影響** | chinglish, singlish | 英語使用者的中文 / 多語母語干擾英語 |
| **中文 base + 英文裝飾** | jingjing-style | 中文寫作者刻意夾入英文字凸顯身分 |
| **英文 base + 漢字替換** | hanjify | 實驗性 — 用漢字取代英文內容詞，句法不動 |

## 對偶與光譜

- **chinglish vs hanjify**：兩者都是「英文受中文影響」，但機制不同 —
  chinglish 是**句法 / 語意層**的干擾（語法錯位 / 直譯片語），hanjify 是**書寫
  系統層**的替換（保留英文句法、替換內容詞為漢字）
- **singlish 是 chinglish 的鄰居**：兩者都是英語克里奧爾化，但 singlish 含粵 /
  閩 / 馬來語成分，地理上限定新加坡 / 馬來西亞
- **jingjing-style 與其他三者方向相反**：本 skill 寫**中文**輸出，只是夾入英文字；
  其他三者寫**英文**輸出

## 設計原則

- 每個 skill 引用真實語言接觸研究（Kachru, Platt, Bautista 等）
- 不寫成卡通腔 — 把這些跨語形態當真實的語言系統對待
- jingjing-style 因為承載「身分標籤 / 名媛口語」的社會學意涵，特別注意諷刺對象限
  於文體現象本身，不指涉真實名媛
