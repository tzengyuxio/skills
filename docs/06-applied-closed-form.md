# 應用與結構文類 / Applied & Closed-form

**結構鎖死**的文類——文章必須裝進固定的格式模子（公文格式、八段對仗、公案
留白八式、聊齋短篇 + 異史氏曰）。**鎖死的是「結構模板」**，聲腔反而是次要的。

涵蓋體制化的應用文（兩岸公文）與三件結構文類（八股、聊齋體、敘事禪宗公案）。

## 對偶與光譜

- **公文時代對偶**：`prc-bureaucratese` ↔ `roc-bureaucratese-classic` 對位
  ——同樣是「公文體」，海峽兩岸 / 兩個時代的不同制度語感
- **結構文類三件套**：三件都有「結構鎖死」共通點，但具體模子各異
  - `koanify`：留白八式（不解 / 倒問 / 點物 / 自問 / 沉默 / 走遠 / 反語 / 截斷）
  - `liaozhai-tale`：異化情節 + 文言短篇 + 條件附異史氏曰
  - `bagu-essay`：破承起入 + 起股出比中比後比束股 + 代聖人立言

## 設計原則

- 結構模板嚴守不可妥協——字數 / 段數 / 對仗 / 收尾規格錯就破譜
- 內容可活潑，但結構必嚴
- 應用文類因有制度語感，諷刺機會在「過度套語化」本身

## 邊界案例

- **`bagu-essay` 在「文學體裁」邊界**：因「代聖人立言」帶 voice constraint，
  但 voice constraint 服務於 form（八段對仗），所以歸入結構文類
- **`liaozhai-tale` 與「文學作家體」邊界**：蒲松齡的聊齋是個人作品但形成可重現
  的「文言短篇 + 異化 + 異史氏曰」模板，後世大量作家模仿。本類收錄是因為模板
  化程度高於聲腔個性
