# Haiku-style — 改寫成日本俳句（中譯版）

把任何現代散文壓縮、淘洗、煉成一首（或一組）日本俳句中譯——5-7-5
音節骨架、必有一個季語、以切字承載斷裂與餘韻、以並置而非因果連結
意象。

不是「寫三行短詩加分行」、不是「白話濃縮加意象」、更不是「現代詩
切短」——而是**讓原文最濃的一個瞬間被一首合譜的俳句收住**：含一個
季語、有一處切字、意象之間並置不解釋。

## 一句話靈魂

**季語 + 切字 + 並置**——以季語錨定四季中的某個物象（蛙／月／雪／
蟬）；以切字（中譯版「啊」「呀」「吧」「了」「——」）製造停頓與餘
韻；以兩個（最多三個）意象的並置承載核心張力。**禁因果、禁抒情爆
發、禁末句總結**。

## 三條風格指紋

1. **C-01 季語必現** — 每首俳句含 1 個季語（春／夏／秋／冬擇一）
2. **S-03 切字必現** — 至少 1 處切字（「啊」「呀」「吧」「了」
   「——」），位置首／中／尾擇一
3. **V-01 並置不因果** — 兩個（最多三個）意象之間禁因果連接詞，
   留白讓讀者連

三者缺一就不是俳句體。其餘 18 條 checklist 都在服務這三條。

## 譯派擇一（極重要）

中譯俳句兩派並存：

- **意境派（預設）**：林文月／鄭清茂／周作人／林林短譯本流派——不
  嚴守 5-7-5，每段 4-9 字彈性，重意象並置與節奏
- **嚴格派**：鄭民欽／林林長譯本流派——每句嚴守 5-7-5 中文字數，
  整首 17 字

**切換條件**：使用者明示「嚴格 5-7-5」「嚴守字數」「鄭民欽派」時
切嚴格派；其餘一律意境派。輸出標註該首屬何派。

## 何時使用

- 想把一個瞬間印象壓縮成一首日本俳句
- 想把一段抒情敘事煉成多首連作（《奧之細道》紀行體）
- 想學日本俳句的三元素（季語、切字、並置）
- 想體驗中譯俳句兩派的字數策略差異

## 何時**不**用

- 想寫唐詩、絕句、律詩 — 用 `tang-poem-style`
- 想寫宋詞 — 用 `song-ci-style`
- 想寫自由詩、現代詩 — 本 skill 鎖定俳句三元素
- 想寫漢俳（中文俳句的中文流派）— 本 skill 是日本俳句的中譯版

## 預期輸出規格

| 模式 | 輸出 | 適合內容 |
|---|---|---|
| **Light** | 1 首俳句 | 原文短（< 200 字）／單一情境 |
| **Medium** | 2 首俳句（季節對舉或情景對照） | 原文中等（200–600 字） |
| **Heavy** | 3-7 首俳句連作 + 俳文 prose 串聯 | 原文長（600+ 字）／旅程感 |

## 季語表（速查）

整首俳句含且只含 1 個季語。常用各季 8-10 個：

| 季 | 常用季語 |
|---|---|
| 春 | 梅 / 櫻 / 蛙 / 燕 / 雪解 / 春の海 / 春雨 / 蝶 / 雀の子 / 菜の花 |
| 夏 | 蟬 / 螢 / 夕立 / 蓮 / 夏草 / 涼風 / 五月雨 / 朝顏 / 蛍籠 |
| 秋 | 月 / 紅葉 / 秋風 / 鴈 / 露 / 初霜 / 鈴蟲 / 稻穗 / 案山子 / 天の川 |
| 冬 | 雪 / 枯野 / 寒 / 炭 / 寒椿 / 鴨 / 北風 / 冬の月 / 餅 |

完整季語表與意象屬性見 [SKILL.md](./SKILL.md)。

## 適合的源文

- 個人軼事、瞬間感悟、季節印象
- 自然景物描寫
- 旅程、紀行（適合 Heavy 連作模式）
- 離別、思念、孤獨、寧靜一類傳統母題
- 哲學散文（先抽核心瞬間再壓縮）

## 不太適合的源文

- 純技術文件、新聞報導
- 純對話劇本
- 已經是俳句／詩詞的源文（改寫意義不大）
- 純學術論述（無具體物象可承載季語）

## 運作流程

1. **讀原文 + 判斷單首或連作** — 依文長與情境數定 Light／Medium／
   Heavy
2. **提取核心瞬間** — 一個畫面為一首俳句的軸；連作則 3-7 個推進中
   的瞬間
3. **定季與季語** — 從季語表挑一個；現代軼事須意象搬移
4. **寫初稿** — 意境派 4-9 字彈性／嚴格派 5-7-5 嚴守
5. **切字嵌入** — 「啊」「呀」「吧」「了」「——」擇一處
6. **字數調整** — 視譯派檢查
7. **連作俳文串聯（Heavy）** — 白話 prose 短句交代場景與時序
8. **標點清理 + 自檢指令** — 全形標點零違規
9. **Checklist 自檢** — 21 條（Hard 18 + Soft 3）
10. **抓最弱句重寫** — 通常是末段或末首
11. **輸出** — 寫入 `<原檔名>_haiku.md`，含模式標註、季語標註、
    譯派標註

## 改寫原則（checklist 摘要）

| 類別 | 編號 | 要點 |
|------|------|------|
| Concrete | C-01~C-04 | 季語必現；禁兩季語混入；禁抽象情緒詞；現代軼事須意象搬移 |
| Surface | S-01~S-05 | 譯派擇一；三段結構；切字至少 1 處；禁切字堆疊 |
| Voice | V-01~V-05 | 意象並置不因果；末段忌總結；禁抒情爆發；動詞用力；時地錨點 |
| Meta | M-01~M-XX | 單首不附評論；連作含俳文串聯；不抄原句／原譯；季語＋譯派標註；不保留日文切字；全形標點零違規 |

完整 21 項 checklist 與 12 步 workflow 見 [SKILL.md](./SKILL.md)。
