# PTT BBS-style — 改寫成台灣 PTT 鄉民體 BBS 貼文

把任何文章改寫成 PTT 八卦版／笨版／C_Chat 等流通的鄉民貼文格式。

不是「給句子加幾個鄉民詞」、不是「把原文翻譯成台灣國語」、更**不是
真實 PTT 內容生成器**——而是**把原文重組成「標題分類 + 自介起手 +
鄉民口語正文 + 求支援結尾 + 推噓→ 堆疊」的完整 BBS 貼文格式**：讀
完讓人覺得這就是凌晨三點滑到的一篇廢文，但所有真實 ID、公眾人物、
具體事件都已去識別化。

## 一句話靈魂

**標題分類 + 自介起手 + 鄉民口語正文 + 求支援結尾 + 推噓→ 堆疊**——
標題必含 `[XX]` 分類標籤對位板別；內文以自介起手式（肥宅我／弟弟我
／妹妹我／魯蛇我）開場；正文用鄉民口語（484／笑死／ㄎㄎ／中肯／
RR／齁／喇）；結尾留求支援句（有沒有八卦／求解／在線等）；最後堆
疊 5–15 條混合推噓→ 的泛化 ID 推文。

## 三條風格指紋

1. **C-01 標題必含分類標籤** — `[XX]` 半形括號 + 半形空白 + 標題本
   體；標籤限 12 個之一，不對位板別即破功
2. **V-01 自介起手式必出** — 肥宅我／弟弟我／妹妹我／魯蛇我／是這
   樣的等 7 種起手式之一
3. **M-02 推文混合度** — Medium／Heavy 強度推文必含 ≥1 條噓 + ≥1 條
   →，全推或全噓即 caricature

三者缺一就不是 PTT 鄉民體。其餘 18 條 checklist 都在服務這三條。

## 安全與中性化（極重要）

PTT 鄉民體本身帶嘲諷與自嘲，但本 skill **明文定位為格式致敬，不是
真實 PTT 內容**：

- **不點名真實 PTT ID** — 推文暱稱必為泛化模式（rookie123／
  fatdog2024／pttuser5566／taipei_anon／kindstranger）
- **不指涉具體公眾人物／真實事件** — 原文若涉及，去識別化（某政治
  人物／某網紅／某媒體／某黨派）
- **不創作攻擊性內容** — 保留嘲諷與自嘲，**不寫**人身攻擊、性別歧
  視、族群歧視、地域歧視
- **諷刺對象限抽象普世** — 月經文循環、釣魚與被釣、業配偵測、肥宅
  自嘲、鄉民集體心理可寫；具體真實人事一律不寫

## 何時使用

- 想把一篇現代軼事改寫成 PTT 八卦版貼文格式
- 想體驗鄉民口語 + 推文堆疊的完整 BBS 結構
- 想學「[XX] 分類標籤 + 求支援結尾」的標題公式
- 想把一個尷尬軼事寫成笨版式自嘲心得

## 何時**不**用

- 想抓真實 PTT 文章 — 本 skill **明確不做這件事**，且禁點名真實 ID
- 想對具體公眾人物發動鄉民式評論 — 本 skill 強制去識別化
- 想寫純台灣國語（非 BBS 格式）— 用 [taiwan-mandarin](../taiwan-mandarin/)
- 想寫廢話文學（同義反覆）— 用 [feihua-literature](../feihua-literature/)
- 想寫凡爾賽炫耀文 — 用 [versailles-literature](../versailles-literature/)

## 預期輸出篇幅

繁體中文鄉民體 BBS 貼文，**Medium 強度典型 600–900 字**（含推文）：

| 強度 | 內文字數 | 推文數量 | 總字數 |
|---|---|---|---|
| Light | 200–400 字 | 0（不附推文）| 200–400 字 |
| Medium | 300–600 字 | 5–8 條 | 500–900 字 |
| Heavy | 400–800 字 | 10–15 條 | 700–1200 字 |

## 適合的源文

- 個人軼事（自嘲、尷尬、廢、被冷落）
- 寓言／諷刺寓言（《差不多先生》一類）
- 都市傳說／怪事
- 動漫／影劇／作品討論題
- 求職／薪水／租屋等鄉民日常題

## 不太適合的源文

- 純技術文件、新聞報導
- 純抒情詩
- 已經是 PTT 真實貼文的源文（改寫意義不大）
- 帶具體政治指涉、想借鄉民口吻發政見的文（**本 skill 不做這件事**）
- 涉及具體真實人物的爆料文（去識別化後改寫意義不大）

## 運作流程

1. **讀原文 + 去識別化** — 掃描具體人物／事件／政黨，替換為通名
2. **決定板別與標籤** — 12 個常用標籤擇一（[問卦]／[新聞]／[爆卦]／
   [心得]／[討論]／[請益]／[黑特]／[公告]／[Re: 問卦]／[更]／
   [協尋]／[笑話]）
3. **寫標題** — `[XX]` 半形括號 + 半形空白 + 標題本體
4. **改寫內文** — 自介起手 + 鄉民口語正題 + 求支援結尾
5. **生成推文堆疊** — 5–15 條混合推／噓／→，泛化 ID 暱稱
6. **朗讀檢查鄉民感** — 廢文氣質 + 推文真實度
7. **標點清理 + 自檢** — 全形標點，跑自檢指令計數歸零
8. **去識別化最終檢查** — 確認無真實 ID／公眾人物／攻擊內容
9. **Checklist 自檢** — 21 條（Hard 18 + Soft 3）
10. **抓最弱段重寫**
11. **輸出** — 寫入 `<原檔名>_ptt.md`

## 改寫原則（checklist 摘要）

| 類別 | 編號 | 要點 |
|------|------|------|
| Concrete | C-01~C-04 | 標題必含分類標籤、標籤對位板別、暱稱泛化、去識別化 |
| Surface | S-01~S-05 | 內文 CJK 全形標點、語助詞密度、短句、全形箭頭 |
| Voice | V-01~V-05 | 自介起手必出、鄉民詞密度、求支援結尾、自嘲廢話感 |
| Meta | M-01~M-07 | 三段式結構、推文混合、不附 meta、限抽象諷刺、不攻擊個人、不點名 ID、全形標點零違規 |

完整 21 項 checklist 與 11 步 workflow 見 [SKILL.md](./SKILL.md)。

## 常用標籤對照表

12 個常用標籤：

| 標籤 | 適用板 | 用途 |
|---|---|---|
| [問卦] | Gossiping | 提問求解 |
| [新聞] | Gossiping、HatePolitics | 轉貼新聞 + 一句心得 |
| [爆卦] | Gossiping | 自己知道的內幕 |
| [討論] | C_Chat、movie、NBA、Stock | 開放性議題 |
| [心得] | book、Salary、movie、Tech_Job | 經驗分享 |
| [請益] | Tech_Job、Salary、Stock、CarShop | 求建議 |
| [黑特] | HatePolitics、Hate | 抒發不滿（不點名）|
| [公告] | 各板 | 板務／規則 |
| [Re: 問卦] | 同源板 | 回覆某篇問卦 |
| [更] | Gossiping、笨版 | 後續補充 |
| [協尋] | Gossiping、笨版、CATS_DOGS | 找東西／找人／找寵物 |
| [笑話] | joke、StupidClown | 笑話、糗事 |
