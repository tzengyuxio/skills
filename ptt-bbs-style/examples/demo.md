# PTT BBS-style — 示範

展示 `ptt-bbs-style` 如何把現代文章改寫成 PTT 鄉民體 BBS 貼文格式。
三個範例**各自的板別不同、各自的標題標籤不同、各自的推文堆疊風格不
同**，不共用骨架。

> **源文與引用說明**：範例一源文 [《差不多先生傳》（胡適， 1924)](../../examples/source-texts/mr-chabuduo.md)
> 來自共用源文庫，公有領域。範例二源文 [雨天故事](../../examples/source-texts/weather-rain.md)
> 為共用源文庫自編，無版權疑慮。範例三源文 [The Little Prince](../../examples/source-texts/little-prince.md)
> 為依 Saint-Exupéry 原作風格自編的短摘錄。
>
> **重要定位**：本 skill 為格式致敬，非真實 PTT 內容。下列示範皆以
> 抽象／普世的鄉民現象（差不多心態／自嘲尷尬／告別寂寞）為諷刺對
> 象，所有暱稱皆為泛化 ID，不點名任何真實 PTT 鄉民、不指涉具體公眾
> 人物或真實事件。

## 範例一：改寫示範 — 《差不多先生傳》→ PTT 八卦版 [問卦]（Heavy）

**板別與選題理由**：原文是 1924 年的諷刺寓言，講「差不多先生」這個
代表中國國民性的虛構人物。改寫到 PTT 八卦版 `[問卦]`，因為「有沒
有 OOO 的八卦」是八卦版最自由的格式，剛好可以承接寓言式的提問語氣。
強度設為 Heavy：完整標題 + 自介起手 + 鄉民口語正文 + 求支援結尾 +
12 條混合推文。

### 改寫後

```
[問卦] 有沒有差不多先生死掉的八卦？

肥宅我剛剛在巷口買鹹酥雞，老闆找錯錢給我，我說欸大哥找錯了喔，他說
差不多啦十塊而已，是不是。

然後我就想到一個都市傳說。聽說有個叫差不多先生的，買紅糖買成白糖、
直隸西邊講陝西、最後生病請王大夫——王大夫是醫牛的喔——結果就這
樣 GG 了。我就想說 484 真的有這個人，還是只是寓言釣魚文？

肥宅我認真求解，因為我發現我身邊太多差不多了。同事報告少打一個零
說差不多、捷運末班車慢一分鐘說差不多、薪水單少三千說差不多。是不
是台灣早就被差不多先生附身了齁。

然後最可怕的是，我懷疑我自己也是。剛剛打這篇文章打了三個錯字，我
看了一眼想說 zzz 差不多啦，反正鄉民看得懂。

有沒有差不多先生陰魂不散的八卦？在線等。

推 rookie123: 推認真文
推 fatdog2024: 笑死 我也是肥宅我
→ rookie123: 樓上是不是
噓 newbie456: 484 月經文 上週才有人問
推 taipei_anon: 中肯
→ taipei_anon: 我同事就是這樣 報帳少一張說差不多
推 kindstranger: QQ 抱抱原 PO
噓 watcher07: zzz 又是寓言類
推 pttuser5566: 神扯 我老闆也是差不多先生
→ riceball88: 484R 整個社會都是
推 oldhand789: 推 王大夫醫牛這梗笑死
噓 lurker001: 文長 慎入是基本
```

**強度標註**：Heavy（10–15 條推文 + 完整三段結構 + 同 ID 連推）

## 範例二：改寫示範 — 雨天故事 → PTT 笨版 [心得]（Medium）

**板別與選題理由**：原文是一個小尷尬（淋雨回家、忘記鑰匙、不好意思
說忘記帶錢包）。改寫到 PTT 笨版（StupidClown）的 `[心得]`，因為這
種「我這個白癡又做了什麼蠢事」是笨版的招牌。強度設為 Medium：標題
+ 自介起手 + 正文 + 求支援結尾 + 7 條推文。

### 改寫後

```
[心得] 妹妹我又當白癡了 雨天篇

各位鄉民安安，妹妹我昨天下午本來在圖書館看書看得好好的，突然外面下
起暴雨。妹妹我看了看天空想說沒帶傘，還是走回家好了，反正夏天淋一下
不會死。

結果這個決定真的 zzz。

走到一半雨愈下愈大，整條路上的人都撐傘，只有我一個落湯雞。回到家門
口翻包包想拿鑰匙——欸鑰匙咧。在辦公室。我整個傻眼。

然後鄰居阿姨剛好開窗看到我，笑著問我說怎麼不叫小黃。妹妹我那時候腦
子整個當機，居然回了一句「我忘了帶錢包」——其實錢包就在我口袋裡。

我也不知道為什麼會這樣回，可能是被鄉民教您不要在鄰居面前承認自己
連鑰匙都會忘記的潛規則影響吧齁。

我是不是太敏感想太多了喇。求安慰。

推 ronin2023: 推 笨到笑死
噓 senior321: 484 釣魚 哪有這麼蠢
推 greenbean42: QQ 抱抱原 PO
→ kindstranger: 樓上 笨版本來就放這種文
推 tainan_anon: 中肯 我也做過類似的事
推 pttuser9527: 笑死 鄰居阿姨表示傻眼
→ blackcoffee99: 484R 妹妹我表示懂
```

**強度標註**：Medium（5–8 條推文 + 三段結構 + 推噓→ 混合）

## 範例三：改寫示範 — 小王子摘錄 → PTT C_Chat 板 [討論]（Medium）

**板別與選題理由**：原文是小王子離開星球的告別場景。改寫到 PTT
C_Chat（西洽板，動漫綜合）`[討論]`，因為小王子題材剛好適合動漫板的
「角色討論」氣質——把童話當作大家熟悉的 IP 來討論，符合鄉民日常
語氣。強度設為 Medium：標題 + 自介起手 + 正文 + 求戰結尾 + 8 條推
文。

### 改寫後

```
[討論] 小王子離開那段是不是寫超爛？

是這樣的，弟弟我最近重看小王子，看到他要離開星球那段我整個傻眼。
你想想看欸——一個小屁孩，住在比房子還小的星球上，養了三座火山跟
一朵玫瑰，每天澆花就好——這種設定根本是肥宅夢想吧？

結果作者讓他突然要走。為什麼？因為要去探索宇宙。蛤？484 太隨便
了一點。

而且最扯的是他臨走前還在那邊感傷，說捨不得跟玫瑰道別但不得不去。
弟弟我看到這邊整個 ㄎㄎ——大哥你都要走了還在演什麼苦情戲，玫瑰
要照顧不會找代班嗎齁。

我覺得這段就是作者偷懶寫的。原本可以好好交代為什麼要離開，結果
就一句「不得不去」，我們鄉民教您喔，劇情轉折這樣寫會被噓爆。

不過話說回來，可能這就是寓言的尷尬地方啦——硬要寫「人生終須告別」
這種大主題，反而每個告別都變得很乾。

各位 C 洽鄉民怎麼看？先噓再看。

推 newbie456: 推討論
噓 oldhand789: 484 釣魚 寓言哪有要交代得多細
→ oldhand789: 你是不是國文沒讀
推 fatdog2024: ㄎㄎ 中肯 我也覺得那段很乾
推 lurker001: QQ 不要這樣說小王子
→ rookie123: 樓上 484 玫瑰本人
噓 watcher07: zzz 月經討論文
推 kaohsiung_anon: 神扯這個切入角度 推
```

**強度標註**：Medium（5–8 條推文 + 三段結構 + 推噓→ 混合 + 同 ID 連
推一次）
