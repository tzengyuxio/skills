## 改寫示範 — 小王子摘錄 → PTT C_Chat 板 [討論]（Medium，打臉氣質聚焦版）

**板別與選題理由**：原文是小王子離開星球的告別場景。改寫到 PTT C_Chat（西洽板，動漫綜合） `[討論]`，因為小王子題材適合動漫板的「角色／劇情討論」氣質。

**氣質取捨**（對應 V-08 氣質節制）：
- 主氣質：**打臉**（原文有對手 — 樓主駁斥作者寫離別段太隨便）
- 輔氣質：**圍觀者意識**（辯論場圍觀 — 朝聖打臉討論文）
- **不取**：
  - **洋蔥**（主軸是駁斥不是感動；離別段在原 PO 眼裡是被嘲笑的對象，不是被感動的對象）
  - **賭咒**（無賭注情境）
  - **戰文**（單純劇情討論，非群體對立）
  - **業配**（無關）

**v1 → v2.1 改善要點**：
1. 打臉氣質從**雛形**（「劇情轉折這樣寫會被噓爆」一句帶過）升級到**正式條列**（「以下打臉 / 事實 1-2-3 / 啪啪啪 / 鄉民教您」）
2. 推文 8 大類型混用 + 4 階段節奏清楚分層
3. **4 種氣質明確不取**，內文純走打臉 + 圍觀骨架，主題聚焦

### 改寫後


## 邊界觀察

`噓 rookie123: 484 反串 小王子哪裡爛了` 這條推文有「反串護航小王子」的隱含立場。雖然原 PO 確實在批評特定作品，但因諷刺對象是**寫作技藝 / 寓言美學**（抽象普世）而非攻擊**作家本人 / IP 持有者**，且作品已過版權保護期（Saint-Exupéry 1944 逝），**勉強通過 M-04 邊界**。若改寫的源文是仍在世作家的當代作品，應更嚴格規範（諷刺對象須完全抽象化為「某類寫作手法」而非特定作品）。
