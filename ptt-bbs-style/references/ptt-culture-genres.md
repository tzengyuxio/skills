# PTT 鄉民文化氣質光譜(參照資料)

本檔列出 10 種 PTT 文體子類型的**氣質速寫**——不是要 LLM 機械分類選擇，而是讓改寫時對「鄉民集體心理」有更豐富的參照。每個子類型只記：核心結構、典型套話、推文反應模板、可萃取的氣質要點。

**用法**:Step 4(改寫內文)或 Step 5(推文堆疊)時，若原文情境與某子類型氣質匹配，可借用對應的套話與推文模板。**不必落地完整子類型**,只要相應氣質滲入即可。

**鐵律不變**:本檔氣質參照不豁免去識別化(C-04 / M-04 / M-05 / M-06)。下列著名事件 / 真實 PTT ID / 法律案件當事人**一律不寫**,只取氣質。

---

## 1. 祭品文(許願文)

**核心結構**:「如果 X 達成，我就 Y」承諾體;PO 文或推文皆可發。

**祭品兩類**:
- 處罰性(輕):跑操場、唱跳、戒手機一週、吃素一個月
- 回饋性：請推文者雞排珍奶、捐慈善團體

**禁用祭品**:跳河、切身體部位、用肛門榨甘蔗、性命相關——傷害類一律不取，改為輕度替代(「我請大家雞排」)。

**典型套話**:
- 「如果 X 我就 Y」/「這篇推爆我就 OOO」/「釣得到 XX 我就 OO」
- 「真男人」/「說到做到」(實現後讚)
- 「來備份」(防食言)
- 「朝聖」/「來監督」/「來看戲」

**氣質要點**:契約感、賭咒感、堅定承諾、自體賭注(用自己被嘲笑為祭品)。

---

## 2. 道歉文

**核心結構**:`[道歉]` 標籤 + 三段式(承認錯誤 + 反省經過 + 求原諒 / 賠償宣告)。

**連續性變體**:被法律強制連 30 天 po(可標註「第 N 天 / 共 30 天」)。

**典型套話**:
- 「對不起 / 致歉 / 深感抱歉 / 深深反省」
- 「不應該 / 過於激動 / 言詞偏激」
- 「保證不會再犯 / 願意接受監督 / 以正視聽」
- 「希望 OO 能接受我的道歉」
- 「再次致歉」

**推文反應**:
- `推 ID: 認錯就好` / `推 ID: 給推`
- `推 ID: 連續 PO 30 天就服你`
- `推 ID: 正妹+1` / `→ ID: 樓上認真?`(性別話題介入)
- `→ ID: 來監督` / `→ ID: 不要再犯`
- `噓 ID: 484 法院要求才道歉`
- `推 ID: 朝聖`(連續道歉中)

**氣質要點**:正式 + 自我矮化 + (法律壓力下的)不情願；鄉民圍觀者從「噓」到「同情」的轉折弧線。

---

## 3. 打臉文

**核心結構**:引述對方論點 → 條列駁斥(用事實 / 專業知識)→ 「打臉成功」收尾。

**典型套話**:
- 「以下打臉」/「先講結論：原 PO 錯了」
- 「拿出資料 / 證據 / 文獻 / 官方數據」
- 「事實 1 / 事實 2 / 事實 3」條列
- 「啪啪啪」(模擬打臉聲音)
- 「打臉成功 / 原 PO 死不認錯硬拗 / 臉都腫了」

**推文反應**:
- `推 ID: 專業打臉文`
- `推 ID: 原 PO 被打臉` / `推 ID: 臉腫了`
- `推 ID: 484 硬拗` / `→ ID: 來看原 PO 怎麼回`
- `推 ID: 推有圖有真相`
- `噓 ID: 不對 樓主才是錯的`(若反向打臉成立)

**氣質要點**:鄉民正義感、不容自吹自擂、要有人戳破;**事實 / 專業 / 證據優於情緒**;辯論勝負用「臉腫」標記。

---

## 4. 洋蔥文

**核心結構**:看完會流淚的感人文。源自《食神》「黯然消魂飯加了洋蔥」典故。

**典型套話**(用反差幽默處理感動):
- 「樓主加了洋蔥」/「這篇加了洋蔥」
- 「不是哭 是切到洋蔥」
- 「家裡是賣切片的」/「眼睛突然進沙」
- 「室友在切洋蔥」/「鄰居在炒菜」
- 「冷氣壞了」/「下雨了」

**推文反應**:
- `推 ID: 加了洋蔥` / `推 ID: 含淚推`
- `推 ID: 切洋蔥噓` / `→ ID: 家裡是賣切片的`
- `推 ID: 怎麼會這樣` / `推 ID: QQ`
- `→ ID: 樓主節哀` / `推 ID: 抱抱原 PO`
- `推 ID: 文章不長但好痛`

**氣質要點**:**禁直接寫「我哭了」**;用反差 + 隱喻處理情緒(切洋蔥 / 眼睛進沙 / 冷氣壞);鄉民體保留幽默骨架承載感動。

---

## 5. 反串文

**核心結構**:假裝對立身分發言。兩種目的：
- **誇大敵對特徵以詆毀**(危險：可能被當真信)
- **明示反串以諷刺**(較安全：讓人看穿)

**典型套話**:
- 「我就是 OO 黨支持者」/「身為 XX 派的我」(假身分自介)
- 文末「以上反串」/「反串要註明」/「我覺得反串」自揭穿
- 推文「484 反串」/「反串要註明喔」/「我先當真了」

**推文反應**:
- `推 ID: 反串請註明`
- `推 ID: 484 反串`
- `推 ID: 演得真像` / `→ ID: 我差點當真`
- `噓 ID: 不註明反串就是引戰`

**氣質要點**:有「**雙重契約**」感——一面演，一面留破綻讓鄉民看穿；明示反串較安全,**禁無註明反串**(skill 一律走明示)。

---

## 6. 釣魚文

**核心結構**:故意放錯誤訊息引特定族群上鉤(或激怒對方違反板規)。

**兩種變體**:
- 害人型(用激怒讓人被水桶)— skill **不取**
- 娛樂型(純粹釣特定群體出現)— skill 可取

**典型套話**:
- 「請問 XX 真的 OO 嗎?」(刻意誤資)
- 「我聽說 XX 已經 OO 了」(假消息)
- 文末釣餌:「不知道是不是真的」/「等懂的人解答」

**推文反應**:
- `推 ID: 484 釣魚` / `→ ID: 不要上鉤`
- `推 ID: 已備好爆米花`
- `推 ID: 釣得到 OO 我也加碼`(祭品釣魚結合)
- `推 ID: 樓上中招了`

**氣質要點**:刻意留漏洞、針對特定族群、結尾隱含「等釣中再翻盤」。

---

## 7. 月經文 / 週經文 / 日經文

**核心結構**:重複出現的題目，按頻率分三檔。

**典型套話**:
- 「[問卦] 又有人問 OO 了」(月經主題)
- 「我知道這是月經文 但還是想問」(自覺式)
- 「老問題:OO 到底 XX」

**推文反應**:
- `噓 ID: zzz 月經文`
- `推 ID: 484 釣月經`
- `→ ID: 上週才有 同樣的問題`
- `推 ID: 鄉民教您：精華區去翻`
- `噓 ID: 上個月問過了 不噓嗎`

**氣質要點**:自覺重複 + 鄉民疲態 + 「精華區去查」的勸退；月經文若自我標註反而減少被噓。

---

## 8. 業配文 / 葉佩雯

**核心結構**:業務配合的廣告文。2012 起「葉佩雯」諧音作為識別記號。

**典型套話**(假裝不經意推薦):
- 「這是某阿姨送給我家寶貝的」
- 「之前看中這條 OO 結果老公心電感應買來送我」
- 「姊妹推薦所以立即衝去購買」
- 「不開箱不行」/「真心推薦」

**鄉民識別套路**:
- 「扣除產品名還通順嗎」(去產品名測試)
- 「帳號頻繁推產品」(公關帳號跡象)
- 「文章太完美 連缺點都剛剛好可愛」

**推文反應**:
- `推 ID: 葉佩雯`(諧音識破)
- `推 ID: 484 業配` / `→ ID: 連結咧`
- `→ ID: 公關帳號出沒`
- `噓 ID: 不開箱不知道`

**氣質要點**:**鄉民體裡的業配模擬要明示玩笑**(skill 用業配氣質改寫時，推文必有人喊「葉佩雯」識破);**禁真實品牌名**,改為「某品牌」「某保養品」。

---

## 9. 集氣文

**核心結構**:求祝福祈福(常為親友重病、意外、考試、面試)。

**典型套話**:
- 「跪求集氣」/「請鄉民幫忙集氣」
- 「希望 OO 一切平安」/「希望手術順利」
- 「拜託大家了 跪謝」
- 「在線等好消息」/「等等回報結果」

**推文反應**:
- `推 ID: 集氣` / `推 ID: 平安` / `推 ID: 一切順利`
- `→ ID: 已集氣` / `推 ID: 加油`
- `推 ID: 一定可以的`
- `推 ID: 朝聖 等好消息`

**氣質要點**:正面 + 真誠 + 短句;**禁諷刺與懷疑**(集氣文不可被噓);事後常有「[更]」標題追加結果(順利感謝 / 不順遺憾)。

---

## 10. 戰文(戰南北 / 戰男女 / 戰世代 / 戰學歷 / 戰職業)

**核心結構**:群體對立 + 挑釁 + 引發群情。

**常見題材**(skill 中**全部需走抽象普世**,禁具體族群指名):
- 戰南北(北部 vs 南部)/ 戰男女 / 戰世代 / 戰學歷 / 戰職業

**典型套話**:
- 「真心問:OO 是不是都 XX?」(以偏概全)
- 「身為 OO 我覺得 XX 真的 OO」(身分挑釁)
- 「不是要戰 但...」(假免責後就戰)
- 「以上 開戰」

**推文反應**:
- `推 ID: 推開戰` / `→ ID: 卡位看戰`
- `噓 ID: 不要戰` / `→ ID: 484 釣戰`
- `推 ID: 樓主中肯` / `噓 ID: 樓主才是 OO`
- `推 ID: 朝聖看推爆`

**skill 風險警示**:**戰文是 ptt-bbs-style 最敏感的子類型**。即便走抽象化，戰女文(母豬論)/ 戰男女 / 戰族群 / 戰政黨**一律不取**;只取「戰世代 / 戰職業 / 戰飲食習慣」這類不傷人的軟對立。

**氣質要點**:**skill 採用戰文氣質時走「軟對立」**(早餐派系 / 通勤路線 / 飲食偏好 / 寫程式縮排空格 vs Tab),取**挑釁節奏與引爆推文**的氣質,**不取**身分對立內容。

## 萃取的四向氣質(可用 Soft 規則點綴)

跨多個子類型萃取出的鄉民集體氣質，可在對應場景靈活借用：

### A. **賭咒承諾**(來自祭品文)
條件式承諾 + 自體祭品 + 推文「來備份 / 真男人 / 朝聖」契約感

### B. **圍觀者意識**(來自道歉文 / 集氣文)
鄉民體中推文者**不只是反應者**,而是事件共同見證者;「來監督 / 朝聖 / 打招呼 / 來看戲」常見

### C. **打臉式駁斥**(來自打臉文)
涉及辯論場景時，以**事實 / 專業知識 / 證據條列**回應,**禁情緒鋪排**;推文「專業打臉 / 臉都腫了 / 484 硬拗」標記辯論勝負

### D. **反差隱喻處理情感**(來自洋蔥文)
涉及感人場景時,**禁直接寫「我哭了」**;用反差幽默(切洋蔥 / 眼睛進沙 / 冷氣壞 / 室友切片)承載感動

## 參照原則

1. **氣質吸收，不強制落地**：改寫時若某子類型氣質吻合原文情境，自然滲入；不為了體現子類型而扭曲原文
2. **氣質節制（V-08）——多氣質可疊但不過載**：一篇文章內文宜強烈呈現 **1-2 種**子類型氣質，其餘僅讓推文歪樓時自然出現。**若原文情境沒有對手要打就不取打臉氣質、沒有感動對象就不取洋蔥氣質**；硬塞會像示範題庫而非真實鄉民文。Heavy 強度也不豁免此節制原則
3. **去識別化鐵律不變**：本檔氣質參照不豁免 C-04 / M-04 / M-05 / M-06；真實案件 / 真實 ID / 真實人物**一律不寫**
4. **戰文氣質採軟對立**：取氣質不取身分對立
5. **業配氣質要明示玩笑**：推文必有人喊「葉佩雯」識破
6. **集氣氣質禁被噓**：正面真誠不可被反串
