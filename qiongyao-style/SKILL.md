# Qiongyao-style — 改寫成中期瓊瑤體愛情敘事

把任何文章改寫成中期瓊瑤(《在水一方》《一簾幽夢》《幾度夕陽紅》)流派的
愛情敘事——白話文藝、必有愛情軸與阻礙、中度詩詞引用、結尾保留痛感。

風格參照：中期瓊瑤(1970–1990 年代)，代表作《在水一方》(1975)、《一簾幽夢》
(1976)、《幾度夕陽紅》、《海鷗飛處》、《卻上心頭》。古典化、詩詞引用、
夢境與現實交錯。

## 一句話靈魂

**必有阻礙 + 結尾不抹平痛感**(C-03 + M-02)——沒有阻礙就不是瓊瑤，痛感被
解釋／被化解就不是瓊瑤。其餘 20 條 checklist 都在服務這兩條。

## Arguments

- `$0` —(選填)Markdown 或純文字檔案路徑。若省略，請使用者提供內文，
  或從對話上下文中找最近編輯的檔案。

## Step 1: Load the Text

- 若提供 `$0`，讀取該檔案。
- 若無引數，找對話中最近撰寫或編輯的 Markdown 檔，或請使用者提供文字。
- 若原文不是繁體中文，先在心中譯為繁體中文(不必輸出)，再做改寫。

## Step 2: Extract Emotional Tension

瓊瑤體不是把原文翻譯成濃情風格，而是**從原文找出情感痛點，以「未滿之愛」
框架重講**。

讀完原文後，用一句話自答：

> 這篇文章裡的「**失去**」是什麼？「**錯過**」在哪裡？「**念念不忘**」是什麼？

可能的張力來源：錯過、隔閡、未及說出口、晚了一步、來不及、回不去、看不見
的牆、太相似 / 太不同、第一次相遇就是最後一次。

若原文太長(超過 1500 字)，只取一個情感主題改寫，不要硬塞所有內容。

## Step 3: Caizi-Jiaren Configuration

給雙方一句話人設。**才子佳人不必都優秀**，但要有「藏得住的東西」：

| 才子模板 | 佳人模板 |
|---|---|
| 沉默寡言的詩人 | 表面開朗、內裡傷痕 |
| 才華洋溢但身體有疾 | 等了很多年的人 |
| 從遠方歸來的舊識 | 嫁了不愛的人 |
| 出身低微的青年 | 家族包袱沉重的女子 |
| 內向自卑的學者 | 神祕的鋼琴老師 |

姓名規則(Soft)：用兩字現代化中文名(夢竹、楚雲、綠萍、子軒、寒煙、思盈、
晨曦)。避免太古、太西式。

## Step 4: Choose Obstacle (Mandatory)

**這是瓊瑤體的靈魂條款。**沒有阻礙就沒有瓊瑤。從以下選**至少一個**：

| 原文情境 | 瓊瑤式阻礙映射 |
|---|---|
| 工作 / 競爭 | 階級差(貧富 / 身份)、年齡差、職場規矩 |
| 家庭關係 | 家世深仇、父母反對、寡婦不可改嫁、私生子身世 |
| 友誼 / 同伴 | 第三者(青梅 vs 竹馬)、好友先愛上她 |
| 疾病 / 健康 | 絕症(白血病、心臟病、肺癆、失明、失憶) |
| 時空隔閡 | 戰亂離散、海峽兩岸、出國深造、再見已隔十年 |
| 過往陰影 | 前緣未了、亡夫亡妻陰影、夢中相識卻現實未遇 |
| 道德 / 倫理 | 不倫(師生 / 兄妹疑似 / 已婚)、誤會釀禍 |

選定後在筆記裡寫下：**「阻礙 = X」**。

## Step 5: 場景與物件

時(雨夜 / 夕陽 / 初春 / 燈下)+ 地(海邊 / 舊書齋 / 站台 / 雨中街 / 古宅
庭院)+ 標誌物件(傘 / 書信 / 玉佩 / 琴 / 簾 / 鋼琴 / 鋼筆 / 戒指)。

至少需要 **5 個視覺 / 聽覺 / 觸覺具體物**(見 V-05)。

## Step 6: 詩詞嵌入點(Optional)

在最強情緒點引一句古典詩詞。**最多 1–2 處**。可選：
- 詩經(蒹葭 / 關雎 / 桃夭)
- 唐詩(李商隱無題 / 元稹遣悲懷 / 王維送別)
- 宋詞(蘇軾江城子 / 李清照 / 秦觀浣溪沙 / 辛棄疾青玉案)
- 元曲、明清詩

詩詞要**呼應情緒高峰**，不是炫技。引用後通常會接一句現代白話的解讀(像
「是啊，他始終在水一方」)。

## Step 7: First Draft

寫一稿。原則：

- **語感**：現代白話為主，允許文言句插入(然則 / 奈何 / 何嘗 / 縱使 / 此情)
- **修辭密度**：感嘆、反問、頂真、博喻是必須的
- **內心戲**：必有大段內心獨白，情緒透過內心 OS 直接呈現
- **對話**：佔比 30–50%，要有金句感
- **篇幅**：300–800 字(計入標點)，典型 500 字
- **結尾**：情緒高峰或未完之憾——**不可平淡收尾，不可 happy ending 抹平痛感**

## Step 8: Self-check Against Checklist

逐條對照下面的 21 條 checklist。**任一條 [Hard] 違反就回 Step 7 重寫該段**。

### Checklist: Content(內容)

| 編號 | 強度 | 規則 |
|---|---|---|
| C-01 | Hard | **必有愛情軸線**——愛情是中期瓊瑤的核心。原文無愛情就主動「愛情化」(為兩個現有元素之間建立情感關係) |
| C-02 | Hard | **至少一對「才子 + 佳人」配置**——雙方都要有「藏得住的東西」(才情、傷痕、秘密) |
| C-03 | Hard | **必有阻礙**——從 Step 4 阻礙詞典選一，沒有阻礙就不是瓊瑤 |
| C-04 | Soft | **永恆主題優先**(情、愁、別、念、緣、宿命)，時代性議題需轉化 |
| C-05 | Soft | **至少一處強烈意象**(海、雨、簾、夢、星、書信、櫻、月) |

### Checklist: Structure(結構)

| 編號 | 強度 | 規則 |
|---|---|---|
| S-01 | Hard | **篇幅 300–800 字**(計入標點)，典型 500 字。低於 200 字無法承載瓊瑤的情感密度，超過 1000 字偏連續劇章節 |
| S-02 | Hard | **內心獨白 + 對話並重**——對話佔比 30–50%，內心戲不可缺。這是與 koanify / liaozhai-tale 的最大結構差異 |
| S-03 | Hard | **結尾必有情緒高峰或未完之憾**——不可平淡收尾，不可 happy ending 抹平痛感。痛是瓊瑤的核心 |
| S-04 | Soft | **詩詞節制**——最多 1–2 處，在情緒高峰才引(類比 koanify S-06) |
| S-05 | Hard | **不下白話結論**——禁用「她終於明白」「從此他知道」這類訓誨句。瓊瑤的痛是不解釋的，讀者自己會懂 |
| S-06 | Soft | 結構可三疊式、追憶式、夢境插入、書信式 |

### Checklist: Voice(語感)

| 編號 | 強度 | 規則 |
|---|---|---|
| V-01 | Hard | **現代白話為主**，允許少量文言句插入(然則 / 奈何 / 何嘗 / 縱使 / 此情)。不可純文言或純口語 |
| V-02 | Hard | **修辭密度高**——感嘆、反問、頂真、博喻是必須的 |
| V-03 | Hard | **必有心理描述**——「她聽見自己的聲音」「他想起十年前的那個下午」「她突然發現」。這是與 koanify / liaozhai-tale 最大差異 |
| V-04 | Soft | **三疊感嘆節制**——「我愛你愛你愛你」「不！不！不！」這類最多 1 處，且要在情緒爆發點 |
| V-05 | Soft | **物件 / 色彩密度高**——至少 5 個視覺 / 聽覺 / 觸覺具體物(雨聲、燈光、紙的觸感、玉的溫度) |

### Checklist: Meta(後設)

| 編號 | 強度 | 規則 |
|---|---|---|
| M-01 | Hard | **不可寫成戲謔 / 嘲諷**——本 skill 是嚴肅的瓊瑤體研究。對情感的真誠是底線 |
| M-02 | Hard | **不抹平痛感**——「他們從此幸福快樂」這種收尾是反 M-02。瓊瑤的痛是必須的 |
| M-03 | Soft | 角色取現代中文姓名(可有特色：夢竹 / 楚雲 / 綠萍 / 子軒)。避免太古、太西式 |
| M-04 | Hard | **若原文是議論文 / 抒情文 / 學術文**：必須先抽情感核心再設場景——不要把論點直接「翻譯」成濃情對話 |
| M-05 | Soft | 第三人稱限知 或 第一人稱皆可，但敘事者要與痛感共振 |
| M-06 | Hard | **全形標點零違規**——CJK 字之間的 ASCII 半形 `, ; : ? !` 計數須為 0；破折號用兩個全形「——」；引號用「」/『』；以 Step 10 自檢指令驗證通過才算合格 |

**總計**：22 條(Hard 14 + Soft 8)。

## Step 9: Find the Weakest Paragraph and Rewrite

通常**結尾**或**情緒最高點**最弱——容易過度解釋、容易抹平痛感、容易堆砌
排比。
- 若結尾下了結論(「她終於明白了⋯⋯」「原來愛情就是⋯⋯」)，刪到只剩動作
  或場景定格
- 若情緒高峰處用了過多抽象意象(「無形的牆」「命運的刀」「最深的愛」)，
  挑一兩個換成具體物(信、傘、玉、燈、雨痕)
- 若內心 OS 滿到把場景擠掉，砍一段 OS 換一個動作或物件
- **「能少一句就少一句」是瓊瑤體與其 caricature 的分界線**——濃情要服務真
  誠，不是堆砌

## Step 10: 標點清理

最後一道工序：

- **全形標點(鐵律)**：CJK 文本中所有標點一律全形。**ASCII 半形 `, ; : ? !` 在 CJK 字之間出現一律是 bug**，必須換成全形 `，；：？！`。對照表：

  | 半形(禁) | 全形(用) | Unicode |
  |---|---|---|
  | `,` | `，` | U+FF0C |
  | `;` | `；` | U+FF1B |
  | `:` | `：` | U+FF1A |
  | `?` | `？` | U+FF1F |
  | `!` | `！` | U+FF01 |
  | `(` `)` | `（` `）` | U+FF08 / U+FF09 |

- **破折號**用兩個全形「—」連寫成「——」，不寫成 `--` 也不寫成單個「—」
- **引號**用「」與『』，不用 `"` `'`
- **句號**用「。」，不用 `.`
- **全形標點與 CJK 之間零空格**

- **寫完後必跑自檢指令**(指令名留作機械驗證，不可省略)：

  ```bash
  python3 -c "
  import re, sys
  text = open(sys.argv[1]).read()
  bad = re.findall(r'[^\x00-\x7f][,;:?!][^\x00-\x7f]', text)
  print(f'half-width punct between CJK: {len(bad)}')
  for b in bad[:5]: print(repr(b))
  " 輸出檔.md
  ```

  結果必須為 `0`。非 0 表示輸出時混入了 ASCII 半形，回到輸出檔逐字替換後重跑，直到歸零才算交付。

## Step 11: Output

1. **檔案輸入**：寫入 `<原檔名>_qiongyao.md`，保留原檔
2. **貼文輸入**：直接輸出瓊瑤體
3. **不附說明、不附改寫思路、不附「我選擇了什麼阻礙」這類元資訊**
4. 若使用者明確要求，可額外輸出**改寫筆記**(列出 Step 3–6 的選擇)，但
   **主輸出永遠是瓊瑤體本身**

## Anti-patterns(常見失敗模式)

寫完一稿、自檢之前，先掃一眼這 9 條最容易踩的坑：

1. **戲謔嘲諷** — 把瓊瑤寫成 mock。違反 M-01。瓊瑤體要對情感真誠，不可
   把三疊感嘆寫得像諷刺
2. **詩詞硬塞** — 為引而引，沒有情感高峰承接。違反 S-04。詩詞要呼應情緒，
   不是炫技
3. **happy ending 抹平痛感** — 「他們從此在一起，過著幸福快樂的日子」。
   違反 M-02 與 S-03。瓊瑤的痛是必需
4. **角色臉譜化** — 才子永遠憂鬱、佳人永遠純真、第三者永遠惡毒。要讓
   每個角色都有「藏得住的東西」
5. **三疊感嘆過度** — 「我愛你愛你愛你...」連用三次以上，變 caricature。
   最多 1 處，且要在爆發點
6. **文言過度** — 變成歷史小說。瓊瑤是現代白話，只允許少量文言句點綴
7. **缺乏物件** — 只有對話與心理戲，沒有雨 / 簾 / 海 / 燈這些定錨物。
   違反 V-05
8. **平淡收尾** — 結尾不上揚不下沉，讀完無感。違反 S-03
9. **半形標點混入** — 輸出時把 `,;:?!` 打成 ASCII 半形而非全形 `，；：？！`。
   常見原因是 IME 切換失誤或從英文 prompt 複製字串。寫完務必跑 Step 10 自檢
   指令，計數歸零才算交付(違反 M-06)

## Core Example: 木匠雕神像

源文(現代軼事)：一名工程師接到三日交專案的死線，連夜加班寫出醜陋程式
碼，事後重構，最後產品被取消。下方為改寫成功的版本——克制的內心戲與
「她沒有走過去」的場景定格，把瓊瑤的痛留在那裡。

> 林夢竹站在工坊門口已經很久了。
>
> 屋裡傳來敲鑿聲，一聲，又一聲。她知道阿哲還沒睡。三天的期限，他這是第二夜了。
>
> 她端著一碗熱湯，輕輕推開門。阿哲坐在燭下，一鑿一鑿地刻著神像的眉眼。木屑落了滿地。他沒有抬頭。
>
> 「妳怎麼來了？」他說，聲音啞啞的。
>
> 「我⋯⋯我擔心你。」夢竹聽見自己的聲音，輕得像怕驚動什麼。
>
> 阿哲笑了一下，那笑很苦。「廟祝催得緊。三天交件，他說一定要趕在祭日前。」
>
> 「不交，可以嗎？」
>
> 他放下刻刀，終於抬頭看她。燭光在他眼裡晃了一下。「夢竹，我這雙手，能做的只有這個。如果連這個都做不好⋯⋯」
>
> 他沒說完。
>
> 夢竹把湯放在桌上，沒說話。她看著他眉心那道深深的皺紋，想起小時候他第一次摸刻刀，被劃了一道，血流到衣襟上，他卻笑得開心。那時候，他們是不知道什麼叫「來不及」的。
>
> 半月後，阿哲把第二尊像送到廟裡。廟祝接過，放在桌上，只說了一句：「廟前日已拆。」
>
> 阿哲站在原地，木屑還在他衣襟上。窗外風起，捲走了幾片落葉。
>
> 那一刻，夢竹站在門外的雨裡。她沒有撐傘。她只是看著他抱著神像走出來，雨打濕了他的肩。
>
> 她沒有走過去。
>
> 她想：有些事情，不是來不及，而是從一開始，就不是他能決定的。

**達標清單**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 愛情軸(夢竹 + 阿哲) |
| C-02 | ✓ | 才子 = 沉默自卑的木匠 / 佳人 = 在外面默默等的女子 |
| C-03 | ✓ | 阻礙 = 階級差 + 時間錯位(他被身份綁住，她無法救他) |
| C-04 | ✓ | 永恆主題(來不及、決定不了的命) |
| S-01 | ✓ | 約 530 字 |
| S-02 | ✓ | 內心戲(她想起小時候)+ 對話並重 |
| S-03 | ✓ | 結尾未完之憾(她沒有走過去) |
| S-05 | ✓ | 不下結論——「不是來不及，而是從一開始⋯⋯」是內心思索，不是訓誨 |
| V-01 | ✓ | 現代白話 + 「然則」式留白 |
| V-02 | ✓ | 反問、頂真(「一聲，又一聲」) |
| V-03 | ✓ | 心理描述充足(她聽見自己、她想起小時候、她想：有些事情⋯⋯) |
| V-05 | ✓ | 物件密度(湯 / 燭 / 木屑 / 刻刀 / 落葉 / 雨) |
| M-01 | ✓ | 真誠不戲謔 |
| M-02 | ✓ | 痛感保留(她沒有走過去) |

**對照結論**：瓊瑤體的精神不是「濃情多到溢出來」，而是**情感真誠到讓你
不忍**。克制的內心戲與一個「她沒有走過去」的場景定格，反而比連天的三疊
感嘆更能把瓊瑤的痛留在那裡。

## Important Notes

- 本 skill 是**體裁轉換工具**，不是濃情過濾器。原文不需是愛情故事——任何
  類型(議論、抒情、學術)都可以，但會被**重構為愛情敘事**
- **愛情軸是 Hard 規則**(C-01)。沒有愛情元素的源文，需主動為其「愛情化」
  ——通常是建立兩個元素間的情感關係
- **痛感是必需的**(M-02 + S-03)。瓊瑤的精髓是**未滿之愛**，不是大團圓
- **不是越濃越好**——情感密度要服務真誠，不是堆砌。「以為濃就是瓊瑤」是
  最常見的誤解
- 清單並非窮盡，使用判斷力標記其他感覺不對的句子
