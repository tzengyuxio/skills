# Dongbei Mandarin — 示範

展示 `dongbei-mandarin` skill 在三段強度下的輸出效果，以及好的東北話長什麼樣
子。源文取自 [`examples/source-texts/`](../../examples/source-texts/) 共用源文庫。

> **設計說明**：三個範例分別示範 Light / Medium / Heavy，主題與骨架各不相同——
> 雨天 / 小王子 / 差不多先生——以證明強度差異不是「同一篇文章加調味」，而是
> 不同生活場景帶不同口語層次。

---

## 範例一（Light）：雨天故事

源文：[weather-rain.md](../../examples/source-texts/weather-rain.md)

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### Light 改寫

> 昨兒下午我在圖書館看書呢，外頭嘩啦一下，雨就下來了。我沒帶傘，尋思著走回去得了。一路上人賊多，到處都是打傘的。我整個人淋成個落湯雞，到家才發現鑰匙忘辦公室了。鄰居老姐看我這樣兒，樂呵呵地說：「你咋不叫個車啊？」我只能苦笑：「我錢包也沒帶啊⋯⋯」

### 達標解析

| 編號 | 達成 | 解析 |
|---|---|---|
| G-01 | ✓ | 「整個人淋成個落湯雞」——整字落點 |
| G-02 | ✓ | 「人賊多」 |
| G-05 | ✓ | 「你咋不叫個車啊？」反問 |
| V-01 | ✓ | 看（=瞅的近義口語） / 尋思著 |
| V-02 | ✓ | 賊多 |
| V-04 | ✓ | 「樂呵呵」「老姐」「尋思著」三個輕量口頭禪 |
| S-01 | ✓ | 句末「啊」「了」「呢」分散 |
| S-05 | ✓ | 「外頭嘩啦一下」開場過渡 |
| M-02 | ✓ | 全段 ~3 處標誌詞，符合 Light 密度 |
| M-03 | ✓ | 不加地域刻板（鄰居是「老姐」「樂呵呵」，溫和敘述）|

**Light 重點**：語法骨架仍是普通話，但替換點精準——一個「賊」、一個「咋」、
幾個輕量口頭禪（尋思著 / 樂呵呵 / 這樣兒），就足以讓全段讀來「東北了」。

## 範例二（Medium）：小王子（英文 → 東北話）

源文：[little-prince.md](../../examples/source-texts/little-prince.md)

> The little prince lived alone on a tiny planet, no bigger than a house. He had three volcanoes to clean, and a rose that he loved very much. Every morning, he would clean his volcanoes and water his rose. One day, he decided to leave his planet to explore the universe. He was sad to say goodbye, but he knew he had to go.

### Medium 改寫

> 小王子吧，自個兒住在一個賊小的星球上，攏共也沒一間屋大。星球上有三座小火山——那玩意兒他得天天劃拉，還有一朵玫瑰花，他可稀罕了。每天早上他先把火山整一遍，再給玫瑰澆點兒水，妥了，齊活。後來有那麼一天，他尋思著：這旮旯兒老待著也不是個事兒，得出去整點兒新鮮的。要走那天他心裡也不是滋味，可話又說回來——能不走嗎？該走還得走啊。

### 達標解析

| 編號 | 達成 | 解析 |
|---|---|---|
| G-01 | ✓ | 「把火山整一遍」「整點兒新鮮的」——兩處典型整字 |
| G-02 | ✓ | 「賊小的星球」 |
| G-05 | ✓ | 「能不走嗎？該走還得走啊。」反問加雙重收束 |
| G-08 | ✓ | （第三人稱敘事，未強推；以「咱」省去）|
| V-01 | ✓ | 劃拉、整、尋思 |
| V-02 | ✓ | 賊（小）、可（稀罕了）、老（待著） |
| V-04 | ✓ | 妥了、齊活、不是滋味、那玩意兒 |
| V-05 | ✓ | 兒化：那玩意兒、點兒、旮旯兒、整點兒、那會兒 |
| S-01 | ✓ | 句末助詞：吧、了、嗎、啊 散布 |
| S-02 | ✓ | 平均句長 ~13 字，短句節奏明顯 |
| S-05 | ✓ | 「後來有那麼一天」「可話又說回來」開場接續 |
| M-02 | ✓ | 每 2-3 句 1 處標誌詞，符合 Medium |
| M-03 | ✓ | 全篇情感是「捨不得 / 該走還得走」，溫暖中性，無地域 stereotype |

**Medium 重點**：把「lived alone」轉成「自個兒住在」、「he had to go」轉成
「該走還得走啊」——這是把英文的抽象敘事拉進**東北人慣有的口語邏輯**：先說
事實，再用反問收束情緒。「妥了，齊活」是 Medium 的 sweet spot——既有口頭禪
味，又不喧賓奪主。

## 範例三（Heavy）：差不多先生傳（《鄉村愛情》劇本級）

源文：[mr-chabuduo.md](../../examples/source-texts/mr-chabuduo.md)（胡適 1924，
公有領域）

> 你知道中國最有名的人是誰？他姓差，名不多，是各省各縣各村人氏。差不多先生的名字天天掛在大家的口頭，因為他是中國全國人的代表。他常常說：「凡事只要差不多，就好了。何必太精明呢？」他在學堂的時候，先生問他：「直隸省的西邊是哪一省？」他說是陝西。先生說：「錯了。是山西，不是陝西。」他說：「陝西同山西，不是差不多嗎？」

### Heavy 改寫

> 我跟你說啊，老鐵們——咱中國最有名的人是誰，你知道不？姓差，名不多，哪個屯子哪個旮旯都有他的人，妥妥的全國代表。差不多這仨字兒，天天掛大伙兒嘴邊上，那叫一個響。他自個兒咋說來著？「咳，凡事差不多就完事兒了唄，咋還能整那麼精？沒那必要哈。」

> 想當年他上學那會兒，老師問他：「直隸省西邊是哪個省啊？」他眼皮都不帶抬的，張口就來：「陝西唄。」老師可給氣樂了：「錯啦！是山西，不是陝西！你瞅瞅你瞅瞅。」他還賊有理：「咋的？陝西山西，差不多——不都是西嗎？老師你較這真兒幹啥呀？」

> 嗯哪，這就是差不多先生，可勁兒地差不多，差不多了一輩子。你還別說，這人在咱東北，那是一抓一大把——必須的。

### 達標解析

| 編號 | 達成 | 解析 |
|---|---|---|
| G-01 | ✓ | 「整那麼精」「較這真兒」——整字與口語動詞 |
| G-02 | ✓ | 「賊有理」 |
| G-03 | ✓ | 「老鐵們」「大伙兒」——稱呼框架 |
| G-04 | ✓ | 「老師可給氣樂了」——給字框架 |
| G-05 | ✓ | 「咋還能整那麼精」「咋的？⋯⋯不都是西嗎？」反問連珠 |
| G-06 | ✓ | 「你瞅瞅你瞅瞅」V V 重疊 |
| G-07 | ✓ | 「可給氣樂了」「可勁兒地差不多」可字強調 |
| G-08 | ✓ | 「咱中國最有名的人」「在咱東北」——咱字共謀 |
| V-01 | ✓ | 瞅、較真兒、整、掛嘴邊上 |
| V-02 | ✓ | 賊（有理）、可（給氣樂了）、妥妥的 |
| V-04 | ✓ | 屯子、旮旯 |
| V-05 | ✓ | 嗯哪、必須的、妥妥的、那叫一個響、你還別說 |
| V-05（兒化）| ✓ | 仨字兒、那會兒、事兒、瞅瞅你瞅瞅、較這真兒、可勁兒 |
| S-01 | ✓ | 句末密集：啊、唄、哈、嗎、的、呀 分散不堆疊 |
| S-02 | ✓ | 平均句長 ~12 字，密集短句 |
| S-03 | ✓ | 「咋的？陝西山西，差不多——不都是西嗎？」連珠反問 |
| S-05 | ✓ | 「我跟你說啊」「想當年」「你還別說」三個典型開場 |
| S-06 | ✓ | 破折號、感嘆號、問號適度 |
| M-02 | ✓ | 每句 1-2 處標誌詞，助詞密集——符合 Heavy |
| M-03 | ✓ | 把胡適原文的「諷刺」轉為東北口語的「自嘲與調侃」，差不多先生的形象變成「街坊大伙兒裡都有的那個人」，沒有踩任何地域 stereotype |

**Heavy 重點**：把胡適的雜文諷刺體**轉譯為東北口語表演**——像趙本山小品開
場那樣，先「老鐵們」拉注意，再用反問與感嘆連珠把節奏推上去，最後「必須的」
一句收束。原文的諷刺力沒丟，但載體從「冷冷的書面諷喻」變成了「熱乎乎的街
坊嘮嗑」。**這正是東北口語表演傳統最擅長的**：用親近與自嘲，把刻薄話說得不
刻薄。

## 強度速查

| 強度 | 特徵 | 典型場景 |
|---|---|---|
| **Light** | 賊 / 老 / 整 各出現一兩次，輕量口頭禪（尋思 / 妥了 / 這樣兒），骨架仍是普通話 | 朋友圈、東北人寫日記、輕鬆聊天 |
| **Medium**（預設）| 滿俄借詞偶用、兒化中度、反問與開場詞鑲嵌、短句節奏明顯 | 抖音字幕、東北博主部落格、二人轉中段 |
| **Heavy** | 標誌詞密集、句末助詞每句必有、反問連珠、可勁兒地用口頭禪 |《鄉村愛情》劇本、趙本山小品、直播間即興 |
