# Dongbei-mandarin — 改寫成東北話

把任何文章改寫成東北口語節奏——直爽、誇張、自嘲式幽默，帶大碴子味的
語感。不是換幾個詞而已，是**整個語勢從普通話切到「咱東北人嘮嗑」**
的腔調。

## 什麼是東北話？

東北話屬**東北官話**，分布於黑龍江、吉林、遼寧三省，大部分內蒙東部、
河北東北部亦通行，使用人口超過一億。聲韻接近北京話但聲調平陽（陰平
44/33 低於北京 55），平翹混淆、入聲歸上聲比例高，含滿語、俄語、朝鮮語
借詞（嘎拉哈／列巴／布拉吉）。

文化錨點：趙本山系列小品、東北二人轉、《鄉村愛情》劇集、抖音老鐵直播。

## 一句話靈魂

**東北口語節奏感**——標誌詞密度 + 直爽強調 + 句末助詞密集，讓讀者讀來
像在聽老鐵嘮嗑。

## 三段強度

| Level | 密度 | 效果 |
|---|---|---|
| **Light** | 每 5–6 句 1–2 處標誌詞 | 偶爾「賊」「整」「老 X」點綴 |
| **Medium**（預設）| 每 2–3 句 1 處 + 句式東北化 | 抖音老鐵直播的程度 |
| **Heavy** | 每句 1–2 處 + 助詞密集 | 《鄉村愛情》劇本級 |

未指定時預設 **Medium**。

## 不會做的事

- 不寫成「粗魯／酗酒／打架／沒文化」的刻板印象——東北話不是這個
- 不附評論段、不附「我的改寫思路」
- 不替換成普通話標準音（保留東北語感是 feature）
- 不刻意製造笑點——幽默自然從口語節奏裡長出，不靠耍寶
