# Qiongyao-romance — 示範

展示 `qiongyao-romance` 如何把現代文章改寫成中期瓊瑤體愛情敘事，以及好的
瓊瑤體與失敗的 caricature 之間的差別。本 skill 沒有強度分層，單一目標：
**中期瓊瑤痴情派(《在水一方》《一簾幽夢》流派)**。

> **源文說明**：範例一為自編「風格目標」段落(因瓊瑤作品 1938–2024 著作
> 權尚未到期，不直引)。範例三的源文 [《差不多先生傳》(胡適， 1924)](../../examples/source-texts/mr-chabuduo.md)
> 與範例四的 [雨天故事](../../examples/source-texts/weather-rain.md) 來自共用源文庫。
> 範例二為自編現代軼事 + 對照改寫。

---

## 範例一：風格目標 — 海邊重逢(自編經典瓊瑤式段落)

展示**完整中期瓊瑤結構**：才子佳人 + 絕症阻礙 + 詩詞嵌入(《詩經·蒹葭》)
+ 痛感收尾。設定為「十年後雨中海邊重逢，一方身懷絕症」。

> 雨，從清晨就下個不停。
>
> 楚雲站在海邊，任雨水浸透了她的白色洋裝。她已經站了多久？她也不知道。
> 她只知道，當她聽到那個熟悉的聲音時，整個世界都靜止了。
>
> 「綠萍。」
>
> 是他的聲音，十年沒變。她緩緩轉過身，看見子軒站在不遠處，撐著一把黑傘——
> 那是她當年送他的，他居然還留著。
>
> 「你回來了？」她聽見自己的聲音，啞得不像自己的。
>
> 「我回來了。」他說。「整整十年。」
>
> 海風把雨水打在她臉上，她分不清是雨還是淚。十年前的那個下午，他說要去
> 美國深造，她說好。他說會回來，她說好。然後一封信也沒有，然後就是十年。
>
> 「為什麼？」她問。「為什麼這麼多年都不寫信給我？」
>
> 他低下頭，雨水從傘沿滴落在他蒼白的臉上。半晌，他才說：
>
> 「因為⋯⋯我不能讓妳等我。」
>
> 「為什麼？」
>
> 「因為我⋯⋯我活不到三十歲。」
>
> 雨，還是下個不停。她想起《詩經》裡那句：「所謂伊人，在水一方。」是啊，
> 他始終在水一方，她從未真正抵達過。
>
> 她說：「我等了十年，不是為了讓你告訴我這個。」她轉身，走進雨裡。她不再
> 回頭。但她聽見身後那把傘掉在地上的聲音，和子軒那一聲：「綠萍——」
>
> 海風，依舊吹著。

### 結構標註

| 段落 | 功能 | 對照規則 |
|---|---|---|
| 「雨，從清晨就下個不停」 | 場景定錨 + 意象開場 | C-05、V-05 |
| 「楚雲站在海邊⋯⋯白色洋裝」 | 佳人入場(藏著秘密的等待者) | C-02 |
| 「子軒站在不遠處，撐著一把黑傘」 | 才子入場 + 標誌物件(她送的傘) | C-02、V-05 |
| 「他說要去美國深造⋯⋯然後就是十年」 | 阻礙揭示(時空隔閡 + 失聯) | C-03 |
| 「我活不到三十歲」 | 阻礙升級(絕症，瓊瑤經典) | C-03 |
| 「《詩經》⋯⋯所謂伊人，在水一方」 | 詩詞嵌入點(情緒高峰承接) | S-04 |
| 「她不再回頭⋯⋯海風，依舊吹著」 | 痛感收尾(未完之憾) | S-03、M-02 |

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 「雨，從清晨就下個不停」 | V-02 修辭 | 開頭即用單字句製造節奏 |
| 「她聽見自己的聲音」 | V-03 心理描述必有 | 直接的內心 OS，瓊瑤式典型 |
| 「她分不清是雨還是淚」 | V-02 博喻 | 雨/淚的混同是瓊瑤經典手法 |
| 楚雲、子軒、綠萍 | M-03 現代姓名 | 兩字現代化中文名 |
| 物件：雨、海風、白洋裝、黑傘、淚 | V-05 | 5+ 個視聽觸物件 |

## 範例二：對照範例 — 木匠雕神像(失敗版 vs 成功版)

源文(自編)：**現代軼事** — 一名工程師接到三天內交專案的死線，連夜加班
寫出醜陋的程式碼，事後花更多時間重構，最後產品被取消。

### 失敗版(caricature 的瓊瑤)

> 啊！三天！三天！三天我要怎麼雕完這個神像啊！！工匠小明哭著喊：「老闆！
> 我做不到啊！做不到啊！做不到啊！」
>
> 他的青梅竹馬梨花帶雨地說：「我等你⋯⋯等你⋯⋯等你！無論多久！」
>
> 三天過去⋯⋯
>
> 「我做完了！」他撕心裂肺地喊。
>
> 但是⋯⋯啊！產品取消了！！
>
> 「為什麼？為什麼？天啊為什麼！！」
>
> 梨花淚眼婆娑：「沒關係！沒關係！我們在一起就好了！」他緊緊抱住她：
> 「謝謝妳！我這輩子最幸運的事就是遇見妳！」從此兩人幸福快樂地生活在一起。

**犯規清單**

| 編號 | 違反 | 出處 |
|---|---|---|
| M-01 | 戲謔 / caricature | 三疊感嘆滿篇，讀來像諷刺 |
| V-04 | 三疊感嘆濫用 | 「三天！三天！三天！」「為什麼？為什麼？天啊為什麼！」「沒關係！沒關係！」 |
| M-02 | happy ending 抹平痛感 | 「從此兩人幸福快樂地生活在一起」 |
| S-03 | 結尾無痛感 | 「我這輩子最幸運的事」式收尾 |
| C-03 | 阻礙不明 | 沒有結構性阻礙——只是「壞老闆」式 caricature |
| C-04 | 「老闆」現代專名 | 應抽象化 |

### 成功版(真誠的瓊瑤式)

> 林夢竹站在工坊門口已經很久了。
>
> 屋裡傳來敲鑿聲，一聲，又一聲。她知道阿哲還沒睡。三天的期限，他這是第二
> 夜了。
>
> 她端著一碗熱湯，輕輕推開門。阿哲坐在燭下，一鑿一鑿地刻著神像的眉眼。
> 木屑落了滿地。他沒有抬頭。
>
> 「妳怎麼來了？」他說，聲音啞啞的。
>
> 「我⋯⋯我擔心你。」夢竹聽見自己的聲音，輕得像怕驚動什麼。
>
> 阿哲笑了一下，那笑很苦。「廟祝催得緊。三天交件，他說一定要趕在祭日前。」
>
> 「不交，可以嗎？」
>
> 他放下刻刀，終於抬頭看她。燭光在他眼裡晃了一下。「夢竹，我這雙手，能做
> 的只有這個。如果連這個都做不好⋯⋯」
>
> 他沒說完。
>
> 夢竹把湯放在桌上，沒說話。她看著他眉心那道深深的皺紋，想起小時候他第一
> 次摸刻刀，被劃了一道，血流到衣襟上，他卻笑得開心。那時候，他們是不知道
> 什麼叫「來不及」的。
>
> 半月後，阿哲把第二尊像送到廟裡。廟祝接過，放在桌上，只說了一句：「廟前
> 日已拆。」
>
> 阿哲站在原地，木屑還在他衣襟上。窗外風起，捲走了幾片落葉。
>
> 那一刻，夢竹站在門外的雨裡。她沒有撐傘。她只是看著他抱著神像走出來，
> 雨打濕了他的肩。
>
> 她沒有走過去。
>
> 她想：有些事情，不是來不及，而是從一開始，就不是他能決定的。

**達標清單**

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 愛情軸(夢竹 + 阿哲) |
| C-02 | ✓ | 才子 = 沉默自卑的木匠 / 佳人 = 在外面默默等的女子 |
| C-03 | ✓ | 阻礙 = 階級差 + 時間錯位(他被身份綁住，她無法救他) |
| S-01 | ✓ | 約 530 字 |
| S-02 | ✓ | 內心戲 + 對話並重 |
| S-03 | ✓ | 結尾未完之憾(她沒有走過去) |
| S-05 | ✓ | 不下結論——「不是來不及，而是⋯⋯」是內心思索，不是訓誨 |
| V-02 | ✓ | 反問、頂真(「一聲，又一聲」) |
| V-03 | ✓ | 心理描述充足(她聽見自己、她想起、她想：有些事情⋯⋯) |
| V-05 | ✓ | 物件密度(湯 / 燭 / 木屑 / 刻刀 / 落葉 / 雨) |
| M-01 | ✓ | 真誠不戲謔 |
| M-02 | ✓ | 痛感保留(她沒有走過去) |

**對照結論**：瓊瑤體的精神不是「濃情多到溢出來」，而是**情感真誠到讓你
不忍**。失敗版的三疊感嘆讀來像諷刺；成功版用克制的內心戲與一個「她沒有
走過去」的場景定格，反而把瓊瑤的痛留在那裡。

## 範例三：Stress Test — 《差不多先生傳》→ 瓊瑤體

源文：**胡適《差不多先生傳》(1924)摘錄**，共用源文庫
[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)。

這是 stress test：**原文無愛情元素**。skill 必須主動為其「愛情化」(C-01)，
為兩個現有元素(差不多公 + 他的妻子)建立情感關係。

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽情感張力 | 「差不多」是冷漠 vs 深情的對立——他凡事漠然，旁邊有一個從不被他在意的女人 |
| 才子佳人配置 | 差不多公(無欲無求的男人)+ 小晚(三十年陪在身邊的妻子) |
| 阻礙(必需) | **他的「差不多」本身就是阻礙**——三十年來她從未被認真愛過 |
| 場景與物件 | 婚屋 / 床邊 / 枕頭下舊帳冊 / 紅白糖罐 / 冬至梅 / 雪；具體物：燈、湯、銀針、舊冊、梅、雪 |
| 詩詞嵌入點 | **李清照《一剪梅》「此情無計可消除，才下眉頭，卻上心頭」**(妻翻開舊冊發現真相之際) |
| 結尾 | **痛感反轉**——她發現他從未冷漠，「差不多」是替她說的；雪靜靜落下作場景定格 |

### 改寫後

> 他叫差不多。沒有人記得他真正的名字了。
>
> 三十年前，他娶了一個叫小晚的女子。小晚問他：「你今天買的是紅糖還是白糖？」
> 他說：「差不多。」
>
> 「明天去買米嗎？」
>
> 「差不多。」
>
> 三十年裡，小晚問遍了所有事，他都說「差不多」。她從來沒有生過氣，只是慢慢
> 地，慢慢地，把所有事都自己決定了。她以為，這就是他的個性。她以為，不在意
> 紅糖白糖，也不在意她。
>
> 直到那一天。
>
> 他得了急病。家人去請王大夫，大夫不在。慌亂中，從鄰巷請來了獸醫。獸醫到
> 了，他氣喘：「王⋯⋯王大夫不在？」
>
> 家人說：「獸醫已經到了。」
>
> 他點了點頭，看了小晚一眼——三十年來他第一次，真的看了她——說：「醫人
> 醫獸，差不多吧。」
>
> 小晚的眼淚突然湧出來。她衝過去，跪在床邊，握住他的手。她從來沒有跟他
> 爭過、求過、哭過，但這一次，她聽見自己用三十年從未有過的聲音，大聲喊：
>
> 「不！不！這次不一樣！這次不能差不多！」
>
> 他笑了一下，那笑很淡。「小晚⋯⋯妳⋯⋯妳終於肯為我認真一次了。」
>
> 然後他閉上了眼睛。
>
> 那一夜，小晚整理他的衣物。她在他枕頭下，發現一本舊冊子。
>
> 翻開。她愣住了。
>
> 三十年的家用帳，每一筆都清清楚楚——白糖三斤，紅糖四斤；陝西他在旁邊
> 註「西邊」，山西他寫「西北」；今日是冬至，他畫了一朵小小的梅。
>
> 小晚抱著那本冊子，淚像雪一樣，一片一片落在紙上，把字暈開。
>
> 她想起李清照那句：「此情無計可消除，才下眉頭，卻上心頭。」是啊——他
> 一輩子說的「差不多」，原來都是替她說的。原來這個世界上，他什麼都分得
> 清——只是怕她聽見「不一樣」三個字。
>
> 雪，從窗外靜靜地落。

(約 600 字)

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | **愛情化成功** — 原文諷刺寓言被重構為夫妻三十年隔閡 |
| C-02 | ✓ | 才子 = 不善表達的男人 / 佳人 = 三十年默默陪伴的妻子 |
| C-03 | ✓ | 阻礙 = 他的「差不多」本身——情感上的隔閡是最隱形的阻礙 |
| C-05 | ✓ | 強烈意象(舊冊、梅、雪) |
| S-01 | ✓ | 約 600 字 |
| S-02 | ✓ | 內心 + 對話並重 |
| S-03 | ✓ | 痛感結尾(她翻開帳冊才知道他一直在分，但已來不及) |
| S-04 | ✓ | 詩詞嵌入(李清照《一剪梅》)在情緒高峰，呼應夫妻離別主題 |
| S-05 | ✓ | 不下訓誨——「雪從窗外靜靜地落」是場景定格 |
| V-03 | ✓ | 心理描述充足(她以為、她聽見自己、她想：有些事情) |
| V-04 | ✓ | 三疊感嘆「不！不！不！」僅 1 處，在爆發點 |
| V-05 | ✓ | 具體物(紅糖、白糖、米、燈、銀針、舊冊、梅、雪) |
| M-01 | ✓ | 真誠不戲謔 — 把胡適的諷刺轉化為深情 |
| M-02 | ✓ | 痛感保留 — 真相反轉(他從未冷漠，「差不多」是替她說的) |

**改寫的核心動作**：原文是國民性批判(漠然之惡)，瓊瑤體把這種漠然**重新
詮釋為一種未說出口的愛**——「差不多」不是冷漠，而是不善表達的深情。這個
位移讓胡適的諷刺與瓊瑤的痛感在同一個故事裡共存。

(注：這不是要否定胡適原意，而是示範**體裁轉換的可能性**——同一個故事，
不同體裁讀出不同的東西。)

## 範例四：weather-rain → 瓊瑤體

源文：[`examples/source-texts/weather-rain.md`](../../examples/source-texts/weather-rain.md)

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定
> 走路回家。⋯⋯回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：
>「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽情感張力 | 「窘迫」之下，藏著對連結的渴望——三十二歲的女人在雨中走著，等待什麼？ |
| 才子佳人配置 | 我(三十二歲、未滿足的女子)+ 鄰居(每天電梯遇見卻從未交談的男子) |
| 阻礙 | 錯過(之前沒有勇氣交談)+ 自我懷疑(她以為這次也會錯過) |
| 場景與物件 | 雨、街、家門、手提包、傘、電梯 |
| 詩詞嵌入點 | 辛棄疾《青玉案·元夕》「眾裡尋他千百度，驀然回首，那人卻在，燈火闌珊處」 |
| 結尾 | 未完之憾——他走進雨裡，她站在門口，沒有進去 |

### 改寫後

> 那場雨，我永遠記得。
>
> 那天下午，我從圖書館出來，天突然下起了大雨。我沒帶傘，卻不知為什麼，
> 沒有回頭去借。我撐著手提包，一步一步地走進雨裡。
>
> 街上的人都在跑。只有我，慢慢地走。
>
> 我為什麼要慢慢地走？或許，我是希望能在雨裡遇見什麼人。或許，我是想被雨
> 水打濕，讓眼淚有個藏身之處。或許，什麼都不為。我只是，不想回家而已。
>
> 三十二歲了。一個女人，三十二歲，還能期待什麼？
>
> 我走到家門口，才發現鑰匙忘在辦公室。雨打在我臉上，我突然笑了。我想，
> 這就是我的人生啊——所有想要的，都在剛剛離開的地方。
>
> 「妳怎麼了？」
>
> 是鄰居的聲音。我抬起頭。哦，是他。那個我每天早上會在電梯裡遇見、卻從
> 來沒有交談的人。他撐著傘站在我面前。
>
> 「妳怎麼不叫計程車？」他笑著問。
>
> 我看著他。他的笑很乾淨。我聽見自己說：「我⋯⋯我忘了帶錢包。」
>
> 他愣了一下。然後，他做了一件我以為只會在書裡發生的事。他把傘塞到我手
> 裡，微笑著說：
>
> 「那，先用我的傘吧。明天我們在電梯遇見的時候，妳再還我。」
>
> 然後他走進了雨裡。
>
