# Qiongyao-romance — 改寫成中期瓊瑤體愛情敘事

把任何文章改寫成中期瓊瑤(《在水一方》《一簾幽夢》《幾度夕陽紅》)流派的
愛情敘事——白話文藝、必有愛情軸與阻礙、中度詩詞引用、結尾保留痛感。

## 什麼是中期瓊瑤體？

瓊瑤(1938–2024)是華語世界最具影響力的愛情小說作家。她的作品依風格大致
可分三期：

| 時期 | 代表作 | 風格 |
|---|---|---|
| 早期苦戀派(1960s–1970s) | 《窗外》《煙雨濛濛》《幾度夕陽紅》 | 悲劇、家世、宿命、現實質感 |
| **中期痴情派(1970s–1990s)** | 《在水一方》《一簾幽夢》《海鷗飛處》《卻上心頭》《彩雲飛》 | 古典化、詩詞引用、夢境與現實交錯 |
| 晚期歡愉派(2000s) | 《還珠格格》《情深深雨濛濛》 | 戲劇化、多角關係、留意噯咳咳語勢 |

**`qiongyao-romance` 鎖定中期痴情派**——這是瓊瑤體辨識度最高的時期，
也是「瓊瑤式」一詞的原型。

## 中期瓊瑤的標誌性結構

| 元素 | 特徵 |
|---|---|
| **愛情軸** | 必有，雙線或三角 |
| **阻礙** | 必有，典型者：絕症 / 家世 / 誤會 / 第三者 / 生死隔 |
| **詩詞引用** | 中度密度，常作章名或情緒高峰承接 |
| **內心獨白** | 大段心理描寫，直接抒情 |
| **修辭** | 感嘆、反問、頂真、博喻密度高 |
| **意象** | 雨、海、簾、夢、星、書信、月 |
| **結尾** | 痛感收尾(未滿、錯過、訣別)，不抹平 |

## 與 humanize 互為逆操作(重要)

`humanize` 拿掉的 AI 文風 pattern——浮誇 / 三連排比 / 感嘆句 / 否定平行
結構——正是中期瓊瑤要刻意保留與強化的。但這些 pattern **僅在愛情敘事的
脈絡下才不顯違和**：

- ✅ 用 `qiongyao-romance` 改寫一段愛情故事 → 自然
- ❌ 用 `qiongyao-romance` 改寫一段技術文件 → 違和、像 AI 文風

**不要在愛情敘事以外的場景使用本 skill**。

## 風格參考

- **《在水一方》**(1975)— 蒹葭蒼蒼，白露為霜的源頭。海邊重逢、絕症
- **《一簾幽夢》**(1976)— 夢與現實交錯，姊妹三角，經典詩詞嵌入
- **《幾度夕陽紅》**(1964)— 戰亂離散、二十年後再見
- **《海鷗飛處》**(1972)— 失憶、心結
- **《卻上心頭》**(1974)— 三角戀情、回憶式敘事

## 不會做的事

- 不寫戲謔 / 嘲諷的偽瓊瑤
- 不抹平痛感(「他們從此幸福快樂」是禁忌)
- 不平淡收尾——結尾必有情緒高峰或未完之憾
- 不用本 skill 改寫一般寫作(技術文件、報告、純資訊性文字)

## 預期輸出篇幅

現代白話文藝體，**300–800 字**(計入標點)，依原文長度決定：

| 原文長度 | 瓊瑤體目標 |
|---|---|
| 短(< 300 字) | 300–500 字 |
| 中(300–1000 字) | 500–700 字 |
| 長(1000+ 字) | 700–800 字(只取單一情感主題) |

低於 200 字無法承載瓊瑤的情感密度，超過 1000 字偏連續劇章節。

## 適合的源文

- 個人軼事 / 短篇散文(可直接愛情化)
- 議論文(感慨型最佳)— 必須先抽情感核心再設場景
- 寓言 / 童話(可保留主題並加入愛情線)
- 已有情感張力的故事(失戀、思念、訣別)

## 不太適合的源文

- 純技術文件(無情感張力)
- 純抒情詩(已是濃情，改寫意義不大)
- 已是瓊瑤式 / 言情類的源文
- 偏冷靜哲理性的散文(更適合 koanify)

## 運作流程

1. **讀原文 + 抽情感張力** — 「失去 / 錯過 / 念念不忘」是什麼？
2. **才子佳人配置** — 雙方各有藏不住的東西
3. **阻礙設計**(必需) — 絕症 / 家世 / 誤會 / 第三者 / 生死隔
4. **場景與物件** — 雨夜 + 海邊 + 傘 + 書信 + 燭光，至少 5 個具體物
5. **詩詞嵌入點**(可選) — 在情緒高峰引一句古典詩詞
6. **第一稿** — 內心獨白 + 對話並重，結尾保留痛感
7. **Checklist 自檢** — 21 條(Hard 13 + Soft 8)
8. **抓最弱段重寫** — 通常是結尾(易抹平痛感)
9. **輸出** — 寫入 `<原檔名>_qiongyao.md`

完整 9 步詳述見 [SKILL.md](./SKILL.md)。

## 改寫原則(checklist 摘要)

| 類別 | 編號 | 要點 |
|------|------|------|
| Content | C-01~C-05 | 必有愛情軸、才子佳人、必有阻礙、永恆主題、強烈意象 |
| Structure | S-01~S-06 | 300–800 字、內心+對話並重、痛感收尾、詩詞節制、不下結論、結構不機械 |
| Voice | V-01~V-05 | 現代白話+少量文言、修辭高密度、必有心理描述、三疊感嘆節制、物件密度高 |
| Meta | M-01~M-05 | 不戲謔、不抹平痛感、現代姓名、議論文先抽情感核心、敘事者與痛感共振 |

完整 21 項 checklist 見 [SKILL.md](./SKILL.md)。

## 阻礙詞典

| 原文情境類型 | 瓊瑤式阻礙 |
|---|---|
| 工作 / 競爭 | 階級差(貧富 / 身份)、年齡差 |
| 家庭關係 | 家世深仇、父母反對、寡婦不可改嫁 |
| 友誼 / 同伴 | 第三者(青梅 vs 竹馬)、好友先愛上她 |
| 疾病 / 健康 | 絕症(白血病、心臟病、肺癆、失明、失憶) |
| 時空隔閡 | 戰亂離散、海峽兩岸、出國深造、再見已隔十年 |
| 過往陰影 | 前緣未了、亡夫亡妻陰影、夢中相識卻現實未遇 |
| 道德 / 倫理 | 不倫(師生 / 兄妹疑似 / 已婚)、誤會釀禍 |
