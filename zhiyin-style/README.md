# Zhiyin-style — 改寫成知音體（《知音》雜誌煽情敘事體）

把任何文章改寫成知音體：**長感嘆標題 + 命運三段式 + 親屬呼告 + 淚血情命義
字眼密度**。

不是把句子加感嘆號，不是堆疊網路煽情梗，而是**從原文中抽出一個「命運感」
核心，再用三段式悲情敘事重述**——讓讀者從第一行標題就被攫住情緒，到末尾
讀完還會嘆一聲「人這一生啊」。

## 什麼是知音體？

「知音體」一詞來自《知音》雜誌——一份 1985 年創刊於武漢的情感類半月刊，
定位為「人情美、人性美」的家庭情感故事雜誌。創刊號發行 40 萬份，2008 年
月發行量達 636 萬份，曾居世界綜合性期刊排名第五位。其情感故事欄目發展出
獨特的標題與敘事公式，網路廣為流傳並衍生出大量「童話改編 / 新聞改編」版本。

`zhiyin-style` 鎖定這種文體的核心 DNA：

| 構件 | 內容 |
|---|---|
| 標題 | 長句感嘆標題（≥10 字），含親屬呼告／命運謂語／補述子句 |
| 結構 | 三段式：命運開端 → 苦難中段 → 升華收尾（短-長-中比例）|
| 詞庫 | 淚／血／情／命／義／殤／慟／千里／黃泉／來世／義薄雲天 |
| 主角 | 「苦命修飾語＋親屬定位」雙重標記（苦命的妹子、風雨中的老父）|
| 餘韻 | 淚痕未乾，主角已踏上下一程；不停在最慘處 |

## 風格參考

- **《知音》雜誌情感故事欄**——標題前半句煽情、後半句敘事，內文夾敘夾議，
  「用客觀語調講離奇故事，用離奇語調講客觀故事」
- **網路改編童話**——「苦命的妹子啊，七個義薄雲天的哥哥為你撐起小小的
  一片天」（白雪公主）、「拿什麼來喚醒你啊，我的愛人」（睡美人）、
  「癡心的少女，你甘為泡沫為何番」（海的女兒）等，是知音體標題公式
  的經典演示
- **網路改編新聞**——「可憐女老闆紅顏薄命撒手人寰，無奈男大學生望報興嘆
  竟無語凝噎」式

## 不會做的事

- 不寫網路梗、不寫嘲諷諧仿（嚴肅煽情，不是 parody）
- 不寫純悲到底的悲劇（升華段是知音體的招牌，不可省）
- 不寫冷靜新聞稿（必有親屬呼告與情感修飾）
- 不寫文言腔（半白話 + 通俗文藝腔，比口語雅但不文言）
- 不對《知音》雜誌作褒貶評價——本 skill 將其視為一個現象級中文敘事文體
  的座標，中性學習其技法

## 預期輸出篇幅

繁體中文，**400–900 字**（標題不計），典型 600 字：

| 原文長度 | 知音體目標 |
|---|---|
| 短（< 200 字）| 400–600 字 |
| 中（200–800 字）| 500–800 字 |
| 長（800+ 字）| 600–900 字（取單一情感核心改寫，不全盤翻譯）|

## 適合的源文

- 平凡生活軼事（雨天忘鑰、加班遲歸——可放大為命運象徵）
- 童話 / 寓言（自帶角色，易套親屬關係）
- 新聞報導（特別是裁員、生離死別、家庭糾紛類）
- 哲學散文 / 諷刺寓言（如《差不多先生》——先把抽象主題人格化）
- 個人成長故事（可改寫為「苦熬五年」式悲情敘事）

## 不太適合的源文

- 純技術文件、程式碼說明（沒有情感核心可抽）
- 純抒情詩（缺乏敘事骨架，無法套三段式）
- 已經高度煽情的文本（再煽情會過載）
- 純喜劇 / 諷刺梗（嚴肅煽情底色與喜劇感衝突，違反 M-01）

## 運作流程

1. **讀原文 + 抽情感核心** — 一句話自答：「主角是誰？苦在哪？升華在哪？」
2. **命名苦命主角** — 從七種類型挑一（苦命妹子／癡心少女／風雨老父／苦守
   母親／義薄雲天兄／命途多舛男兒／無辜孤兒）
3. **寫標題** — 套公式：修飾＋呼告＋命運謂語＋補述
4. **草第一段（命運開端）** — 短，留命運伏筆
5. **草第二段（苦難中段）** — 最長，苦難層層加碼
6. **草第三段（升華收尾）** — 中，留餘韻
7. **標點清理 + 朗讀檢查** — 感嘆密度 3–5 處，淚錨點 ≥6 處
8. **Checklist 自檢** — 21 條（Hard 14 + Soft 7）
9. **抓最弱段重寫** — 通常是標題或苦難中段
10. **輸出** — 寫入 `<原檔名>_zhiyin.md`，標題列在最上方

## 改寫原則（checklist 摘要）

| 類別 | 編號 | 要點 |
|------|------|------|
| Content | C-01~C-05 | 煽情標題必現、三段式骨架、標題四項俱全、主角雙重標記、可保留現代背景 |
| Structure | S-01~S-05 | 三段比例短-長-中、每段段尾淚錨點、不用 markdown 子標題切段、400–900 字、結尾留餘韻 |
| Voice | V-01~V-05 | 淚血情命義 ≥6 處、煽情詞庫 ≥5 個、感嘆密度 3–5 處、親屬呼告自然化、半白話通俗文藝腔 |
| Meta | M-01~M-06 | 嚴肅不嘲弄、情緒鋪到滿、不附評論、標題非新聞硬標題、中性化、議論文先人格化 |

完整 21 項 checklist 與 11 步 workflow 見 [SKILL.md](./SKILL.md)。

## 三條靈魂條款

知音體的指紋：

1. **C-01 煽情標題必現** — 列於文章最上方，長度 ≥10 字，含至少一個感嘆／
   呼告／反問
2. **C-02 三段式情感悲劇骨架** — 命運開端 → 苦難中段 → 升華收尾，三段
   缺一不立
3. **V-01 淚血情命義字眼密度** — 全篇 ≥6 處（淚／血／情／命／義／殤／慟），
   每段 ≥1 處

三者缺一就不是知音體。其餘 18 條 checklist 都在服務這三條。

## 示範

完整的源文 / 改寫對照（含三段式標註與達標清單）請見
[examples/demo.md](./examples/demo.md)。

四個示範分別覆蓋：

- **平凡軼事** → 雨天故事改寫為「孤立無援」的命運象徵
- **童話文本** → 小王子改寫為「離別與來世」的悲情敘事
- **諷刺寓言** → 差不多先生從被嘲笑對象改寫為「悔不當初」的悲劇人物
- **冷淡新聞** → 上海裁員報導改寫為「母女三代」的命運敘事

四個示範刻意採用不同主角類型（妹子／少年／男兒＋老娘／母親）、不同苦難
類型（孤立／訣別／誤診／失業）、不同升華路線（人生判語／來世之約／墓碑
遺言／親情共命），不共用同一發明骨架。
