# Zhiyin-style — 示範

展示 `zhiyin-style` 如何把不同源文改寫成知音體（《知音》雜誌煽情敘事體），
以及合格的知音腔長什麼樣子。

> **源文與引用說明**：範例一、範例二的源文（雨天故事、《小王子》摘錄）
> 來自共用源文庫 [`examples/source-texts/`](../../examples/source-texts/)。
> 範例三的源文 [《差不多先生傳》(胡適，1924)](../../examples/source-texts/mr-chabuduo.md)
> 為公有領域。範例四源文為自編。各範例的「煽情標題」與三段內文均屬本
> skill 自編，作為知音體寫作示範，不引用《知音》雜誌實際刊載文章。

---

## 範例一：改寫示範 — 雨天故事 → 知音體

源文：[`examples/source-texts/weather-rain.md`](../../examples/source-texts/weather-rain.md)
（自編短篇，淋雨忘鑰匙，鄰居苦笑問答）。

### 原文

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### 改寫

> **苦命的妹子啊，一場暴雨竟成你人生的萬般滋味，淋濕的何止是身子**

> 那年深秋的午後，桃花妹獨自坐在城東圖書館的窗下，翻著一本舊書。她那年二十有三，自小喪母，與年邁的父親相依為命，平素不愛言笑。誰也想不到，這一個尋常的午後，竟成她此生記憶最深的一日——窗外的天色，已悄悄壓低；命運的雨點，正在雲端集結。

> 雨來得急，瓢潑似的傾盆而下。桃花妹翻遍隨身布包，竟連一把傘也沒有。她咬牙起身，獨自步入雨中——她原以為，淋一場雨而已，總是熬得過去的。可她不知，路上的水已淹過足踝，撐傘的行人從她身邊一個個擦肩而過，無人多看她一眼。她渾身濕透，鬢髮黏在臉上，分不清是雨水還是淚水。一路千辛萬苦回到那扇舊木門前，她伸手往腰間摸去——鑰匙啊，竟還躺在辦公室的抽屜裡。她在門前站了許久，雙腿冰涼，雙手發抖，那一刻，她才忽然明白：原來這世上最遠的路，是從家門口走進不去自己的家。

> 鄰家王嬸推開窗，望見她那副狼狽模樣，半是心疼半是調侃地笑問：「妹子啊，你怎不喚一輛車回來？」桃花妹望著王嬸，唇邊浮起一絲苦笑，輕聲答道：「嬸啊，我連錢包，也忘在辦公室了。」一句話說罷，她終於忍不住，蹲在門檻前，雙手掩面，淚如斷線。多年以後，桃花妹早已嫁作他人婦，那一個雨夜卻常入夢來——她始終記得：人這一生，總有一些雨，是要獨自一人淋完的。

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 標題 23 字，含呼告「苦命的妹子啊」、命運謂語「成你人生的萬般滋味」、補述「淋濕的何止是身子」 |
| C-02 | ✓ | 三段式：命運開端（深秋圖書館）→ 苦難中段（淋雨、無人理、鑰匙鎖門外）→ 升華（多年後夢迴的人生判語）|
| C-03 | ✓ | 修飾＋呼告＋命運謂語＋補述，四項俱全 |
| C-04 | ✓ | 主角「苦命的妹子・桃花妹」雙重標記 |
| S-01 | ✓ | 三段比例約 1:2:1 |
| S-02 | ✓ | 段尾淚錨點：第一段「雨點在雲端集結」、第二段「淚如斷線」、第三段「常入夢來」 |
| V-01 | ✓ | 全篇淚／命／苦／心／淚 ≥6 處 |
| V-02 | ✓ | 含「相依為命」「千辛萬苦」「淚」等高頻詞 |
| V-03 | ✓ | 通篇感嘆／呼告／反問共 5 處 |
| M-01 | ✓ | 嚴肅煽情，不嘲弄 |

**改寫的核心動作**：把一個平凡的「下雨忘鑰匙」生活段落，**抽出「孤立無援」
為核心張力**，配上「自小喪母、與父相依為命」的身世底色，讓淋雨變成命運
象徵。鄰居一句調侃，被改寫為「半是心疼半是調侃」的對話——知音體不容許
冷諷，必須讓所有人物都帶著情份。

## 範例二：改寫示範 — 小王子 → 知音體

源文（英文）：[`examples/source-texts/little-prince.md`](../../examples/source-texts/little-prince.md)
（小王子離開小行星探索宇宙的片段）。

### 原文（中譯參考）

> 小王子獨自住在一個小小的星球上，星球不過比一棟房子大一些。他有三座
> 火山要清掃，還有一朵他深愛的玫瑰。每天清晨，他清掃火山、為玫瑰澆水。
> 有一天，他決定離開星球去探索宇宙。他捨不得告別，但他知道自己必須走。

### 改寫

> **離別的少年郎啊，你拋下深愛的玫瑰遠赴星海，可知此去萬里再無歸期**

> 在那遙遠的天際之外，有一顆比一所茅屋還要小的星球。星球之上，住著一位面容清秀的少年——人們不知他姓甚名誰，只喚他作「小王子」。小王子自幼孤身一人，沒有父母兄弟，唯有三座火山與一朵嬌嫩的玫瑰相伴。每日天剛破曉，他便細細清掃火山，再為那朵玫瑰澆下一壺清水。誰也想不到，這份簡單的相守，已悄悄到了盡頭——星辰的潮水，終要捲走他僅有的家。

> 那一日，小王子立在玫瑰之前，久久不語。他心裡明白：若不出去看一看這浩瀚宇宙，他這一生便再無解答。他俯下身，將最後一壺水緩緩澆在玫瑰根下，輕聲道：「我心愛的花啊，你會等我回來嗎？」玫瑰垂下花瓣，沒有作聲，只有露珠順著葉尖滾落，像她替他流的淚。少年抬頭望天，群星萬點如萬里之外的萬家燈火，每一點都在向他召喚。他咬緊嘴唇，邁出了第一步——這一步，便是與深愛之物的訣別。從此以後，他將獨自走過寒冷的星海，走過陌生的星辰，走過無數個無人陪伴的夜。

> 多年以後，有牧羊人在沙漠中遇見一位疲憊的少年。少年衣衫單薄，眼裡藏著未乾的淚。他望著牧羊人良久，輕聲說：「先生，您可曾見過一朵會說話的玫瑰？她，獨自留在我的星球上，已經很久很久了。」牧羊人搖了搖頭。少年低下頭，從懷中取出一只乾枯的花瓣，撫了又撫，喃喃自語：「若有來世，我願再為她澆一輩子的水，再不離開。」沙漠的夜風吹過，捲起他薄薄的衣角；星空之下，無人知曉那少年的歸途，是否還在那顆遙遠的小行星上。

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 標題 24 字，含呼告「離別的少年郎啊」、命運謂語「拋下深愛的玫瑰遠赴星海」、反問「可知此去萬里再無歸期」 |
| C-02 | ✓ | 三段式：命運開端（孤身少年與玫瑰相守）→ 苦難中段（訣別、走過寒冷星海）→ 升華（多年後遇牧羊人，「若有來世」之約）|
| C-04 | ✓ | 主角「離別的少年郎・小王子」雙重標記 |
| S-02 | ✓ | 段尾淚錨點：第一段「捲走僅有的家」、第二段「無人陪伴的夜」、第三段「乾枯的花瓣」 |
| V-01 | ✓ | 全篇淚／命／心／情／淚 ≥7 處 |
| V-02 | ✓ | 高頻詞：萬里、相伴、訣別、若有來世、淚 |

**改寫的核心動作**：把小王子離開星球的童話場景，**改寫為「離別與來世」
的悲情敘事**。原文的存在主義底色（「他必須走」）被知音體改寫為「為了
解答此生而離開深愛」。結尾的「若有來世，再為她澆一輩子的水」是知音體
經典升華句式——苦難不能停在訣別處，必有來世、相認或慟哭式餘韻。

## 範例三：改寫示範 — 差不多先生 → 知音體

源文：[`examples/source-texts/mr-chabuduo.md`](../../examples/source-texts/mr-chabuduo.md)
（胡適《差不多先生傳》摘錄，1924，公有領域）。

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 抽情感核心 | 「差不多」哲學造成的最後一念之差，在生死關頭釀成不可挽回的悲劇——核心張力是「悔不當初」 |
| 主角 | 「悔不當初的差不多公」——不再是諷刺對象，而是被自己的口頭禪害死的悲劇人物；其老母「苦守白髮的老娘」承擔親屬呼告 |
| 標題公式 | 修飾「悔不當初啊」+ 親屬呼告（差不多公）+ 命運謂語（毫釐之間竟成生死之隔）+ 補述（一念之差，竟錯過此生最後一場相見）|
| 苦難疊層 | 一念之差 → 庸醫誤診 → 不及見老母最後一面 |
| 升華 | 老母伏屍痛哭，墓碑遺言「人這一生，差錯不得」|

### 改寫

> **悔不當初啊，差不多公，毫釐之間竟成生死之隔，一念之差，你錯過了此生最後一場相見**

> 差不多公自小生在江南尋常的村落，家中父亡母在，唯有一位苦守白髮的老娘相依為命。他生性淳厚，不愛計較，凡事總是搖頭輕笑，說一句：「差不多就好。」紅糖白糖、陝西山西、東街西街——在他眼裡，盡是差不多的東西。鄉鄰起初還笑他憨厚，後來竟也學他口吻。誰能料到，這三個字，這口口聲聲的「差不多」，竟在他三十有八那年的深秋，奪去了他的命，也奪去了一個老母最後的指望。

> 那年中秋過後不久，差不多公忽染急症，胸口若火，痛得在炕上翻來覆去。家人慌亂之中，他喘著氣囑咐：「快，快去東街，請汪先生來，汪先生最是穩妥。」家人領命而出，跑得人急眼花，東西兩街竟分不清楚，鬼使神差地敲開了西街牛醫王大夫的家門。差不多公躺在炕上，望見家人引進來的，並非那位汪大夫，而是一臉牲口氣的牛醫——他喘了半晌，竟也只是擺了擺手，輕聲說：「醫人醫牛，差不多。」誰知這一句「差不多」，便是他此生最後一句囑咐。牛醫不識人之經絡，三針下去，差不多公的臉色由紅轉白，由白轉青。他臨終之際，望向窗外，模糊地喚了一聲：「娘啊，孩兒不孝……」一行淚，順著鬢角落入枕間。那一頭，他白髮蒼蒼的老娘還在自家院中燒著一鍋小米粥，等他回家吃飯。

> 三日之後，老娘聞訊，徒步千里趕到，伏在差不多公冰冷的身上，哭得幾乎暈厥。她抖著雙手，撫過兒子蒼白的臉，老淚縱橫，喃喃自語：「我的兒啊，你一生都說差不多，怎麼這一回，差得這樣多……」鄉鄰聞之，無不掩面。後來，老娘在他墳前立了一塊石碑，碑上沒有名字，沒有生卒，只有她親手刻下的七個字：「人這一生，差錯不得。」自此之後，這村裡再無人敢輕易說那三個字。差不多公的墳前，每年深秋總有一束白菊——是他老娘風雨無阻，獨自送來的。

（約 760 字）

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 標題 33 字（長標題），含呼告「悔不當初啊，差不多公」、命運謂語「毫釐之間竟成生死之隔」、補述「錯過了此生最後一場相見」 |
| C-02 | ✓ | 三段式：命運開端（差不多哲學）→ 苦難中段（誤診慘死、未見老母）→ 升華（老母伏屍痛哭、墓碑遺言、年年白菊）|
| C-03 | ✓ | 標題公式四項俱全 |
| C-04 | ✓ | 主角「悔不當初的差不多公」+ 親屬「苦守白髮的老娘」雙重標記 |
| S-01 | ✓ | 三段比例約 1:2:1 |
| S-02 | ✓ | 段尾淚錨點：第一段「奪去最後的指望」、第二段「枕間淚痕＋老娘煮粥」（最強烈的對位）、第三段「年年白菊」 |
| V-01 | ✓ | 全篇淚／命／苦／情／心 ≥10 處 |
| V-02 | ✓ | 高頻詞：相依為命、千里、悔不當初、忍痛（隱）、白髮、來世（隱於白菊意象）、淚 |
| V-03 | ✓ | 感嘆／呼告：「娘啊，孩兒不孝……」、「我的兒啊」、「人這一生，差錯不得」 |
| M-01 | ✓ | 嚴肅煽情，不嘲弄——胡適原文的諷刺味被完全替換為知音體的命運感 |

**改寫的核心動作**：胡適原文是**諷刺寓言**——「差不多」是國民性的批判
靶子。知音體版做的是**情感反轉**：差不多公不再是被嘲笑的角色，而是被
自己的口頭禪害死的悲劇人物。**親屬位置**（老娘）是知音體的關鍵——加入
老娘煮粥等兒、伏屍痛哭、年年白菊三個錨點，諷刺味被徹底替換為命運感與
親情之痛。標題「悔不當初」四字定調全篇，不再是「批評」而是「哀嘆」。

## 範例四：改寫示範 — 職場新聞 → 知音體（冷淡源文 → 煽情敘事）

源文（自編冷淡新聞稿）：

> 上海某科技公司於上週宣布裁員四百人，受影響員工平均年資五年。據人力資源部表示，本次裁員主要因應業務調整，公司將依法支付資遣費。一名三十六歲的女性工程師受訪時表示，她剛買房一年，家中尚有三歲女兒及罹癌母親需要照顧。

### 改寫

> **含淚的母親啊，房貸未清，女兒尚小，老母病榻，這一紙裁員書竟壓垮了你苦撐五年的小小天地**

> 阿珍，一個三十六歲的女工程師，在上海那家高樓林立的科技公司裡，已苦熬了整整五個寒暑。她不是聰明絕頂的人，靠的是日夜不息的勤勉——清晨第一個進公司，深夜最後一個離開。她那年咬牙買下了人生第一套小房，房貸三十年，月月還款，分文不敢拖欠。家中還有一位罹癌的老母，臥在床榻上喘著粗氣；身邊還有一個剛滿三歲的女兒，咿咿呀呀地喚她媽媽。她那時還不知道，這座她以為可以遮風避雨的小小天地，已經被命運悄悄地放在了懸崖之上。

> 那一個尋常的星期一，公司忽然召開全體會議，人力資源部冷冷地宣布：因業務調整，四百人即日起資遣。阿珍坐在角落，手中的咖啡杯抖了一下，她聽見自己的名字被念出，腦中卻是一片空白。她想到老母床頭那一瓶尚未喝完的化療藥水——這個月的藥費，原是要從下個月薪水裡支的。她想到女兒幼兒園剛交了一年學費，發票還壓在抽屜底。她想到那一紙三十年的房貸合約，每一個月的數字都像一塊巨石壓在心口。會散之後，她獨自走到公司樓下的天橋上，望著黃浦江畔的萬家燈火，淚水終於無聲地落了下來——這一夜，她在天橋上站了三個小時，沒有打一個電話回家。她不敢讓老母聽見她哭，更不敢讓女兒看見她無助的樣子。

> 半年之後，阿珍在城郊一家小工廠找到一份夜班工作，白天兼做家教，深夜回家還要替老母擦身翻身。鄰居偶爾問起她舊日的同事，她只是淡淡一笑，搖搖頭：「過去的，就讓它過去吧。」女兒在她懷中漸漸長大，老母的病情也在她日夜守護之下穩了下來。某夜，老母拉著她的手，氣若游絲地說：「我的閨女啊，這一生，娘最對不起的，就是讓你受了這麼多苦。」阿珍埋下頭，淚水無聲地滴在被褥之上，輕聲答道：「娘，咱母女這條命，是綁在一起的，您別說對不起。若有來世，您還做我娘，我還做您的閨女——只是，下輩子，咱不要再走這麼難的路了。」窗外的春風吹起，將屋簷下的一盞舊燈，輕輕地搖了一搖。

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|

**改寫的核心動作**：源文是**冷淡新聞稿**——只報導裁員人數、平均年資、
法定資遣費。知音體版做的是**從統計數字回到一個具體的人**：給她一個名字
（阿珍）、一個身分（含淚的母親）、一個雙重親屬軸（病榻老母 + 三歲女兒）。
裁員不是業務調整的結果，而是「壓垮苦撐五年小小天地的最後一擊」。結尾
「若有來世，您還做我娘」是知音體最招牌的升華——苦難不能停在悲處，必有
親情之約承擔餘韻。
