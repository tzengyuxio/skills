# Zhiyin-style — 改寫成知音體（《知音》雜誌煽情敘事體）

把任何文章改寫成「知音體」——以《知音》雜誌（1985 年於武漢創刊，曾為中國
發行量最大的綜合性情感雜誌之一）為座標的煽情敘事體：**長感嘆標題 + 命運
三段式 + 親屬呼告 + 淚血情命義字眼密度**。

風格參照：1985 年起《知音》雜誌的情感故事欄目，及其衍生的網路改編體（童話
改編、新聞改編）。本 skill 旨在中性地重現此一現象級的中文敘事文體，**不是
對該雜誌的嘲諷**——煽情敘事在中文大眾刊物中自有其敘事力量，本 skill 把它
當作一種可學習的文體技法處理。

## 一句話靈魂

**煽情標題必現** + **三段式情感悲劇骨架**——標題是知音體的指紋（長度
≥10 字，含三疊感嘆 / 命運性形容 / 親屬呼告），內文走「命運開端 → 苦難
中段 → 升華收尾」三段式，每段必有至少一處苦情字眼（淚／血／情／命／義／苦／心／痛等）。
缺一即失知音感。

## Arguments

- `$0` —（選填）Markdown 或純文字檔案路徑。若省略，請使用者提供內文，
  或從對話上下文中找最近編輯的檔案。

## Step 1: Load the Text

- 若提供 `$0`，讀取該檔案。
- 若無引數，找對話中最近撰寫或編輯的 Markdown 檔，或請使用者提供文字。
- 若原文不是繁體中文，先在心中譯為繁體中文（不必輸出），再做改寫。

## Step 2: 抽情感核心

知音體不是「把文章加感嘆號」，而是**從原文中抽出一個「命運感」核心**，
再以悲情敘事框架重述。

讀完原文後，用一句話自答：

> 這篇若改成「一個苦命人的故事」，**主角是誰**？**苦在哪**？**最後升華
> 在哪**？

可能的命運核心：誤判一念、痛失至親、忍辱負重、為情所困、千里尋人、生死
一線、悔不當初。

若原文是冷靜論述、技術說明、哲學寓言——**先把抽象主題人格化為「一個
苦命主角」**，不要硬把論點翻譯成感嘆句。

## Step 3: 命名一個「苦命」主角

知音體的主角不是抽象的「人」，而是有身分、有親屬位置的具體人物。從以下
類型挑一個：

| 類型 | 範例 | 適用情境 |
|---|---|---|
| 苦命的妹子 | 桃花妹、阿珍、小芳 | 為情所困、忍辱負重 |
| 癡心的少女 | 純真年華被命運辜負者 | 為愛犧牲、化作泡沫 |
| 風雨中的老父 | 老李、阿爸 | 失子、白髮送黑髮、千里尋兒 |
| 苦守的母親 | 王氏、阿娘、苦命阿娘 | 病榻、守候、十年苦撐 |
| 義薄雲天的兄長 | 大哥、義兄 | 為弟妹頂罪、撐起一片天 |
| 命途多舛的男兒 | 阿強、二郎 | 一念之差、悔不當初 |
| 無辜的孤兒 | 小強、孤雛 | 孤苦無依、被命運撥弄 |

主角必須有「**苦命修飾語 + 親屬定位**」的雙重標記（如「苦命的妹子」、
「風雨中的老父」、「忍痛遠嫁的姐姐」）。

## Step 4: 寫標題（知音體招牌）

**標題列在文章最上方，是知音體的指紋**。沒有煽情標題的內文不是知音體。

### 標題公式

```
[修飾語] + [親屬呼告或角色] + [命運謂語] + [補述子句]
```

四個組件至少出現三個。長度 **≥10 字**（經典範圍 12–20 字）。必含至少
一個感嘆 / 呼告 / 反問。

### 經典範本（網路廣傳）

- 「**苦命的妹子啊，七個義薄雲天的哥哥為你撐起小小的一片天**」（《白雪公主》改編）
- 「**癡心的少女，你甘為泡沫為何番**」（《海的女兒》改編）
- 「**拿什麼來喚醒你啊，我的愛人**」（《睡美人》改編）
- 「**善良的女孩兒，你怎知好心指路採花的哥哥竟是黑心狼**」（《小紅帽》改編）
- 「**惡毒後母狠心虐待，難擋癡情王子撐起一片情天**」（《灰姑娘》改編）
- 「**忍痛遠嫁富商十年，我帶著腦癱兒子千里尋親**」（典型《知音》欄目句式）
- 「**可憐女老闆紅顏薄命撒手人寰，無奈男大學生望報興嘆竟無語凝噎**」

### 高頻詞庫

**修飾語**：苦命、癡心、善良、純潔、無奈、可憐、命途多舛、含淚、忍痛、
飄零、相依為命

**親屬呼告**：妹子啊、爹啊、娘啊、我的愛人、苦命的孩子、孤雛、可憐的
弟弟

**命運謂語**：為你撐起一片天、撒手人寰、化作泡沫、千里尋親、苦守十年、
為愛斷腸、悔不當初、淚灑黃泉

**補述子句**（含「卻」「竟」「為何」「怎知」轉折）：「卻不知…」
「竟落得…」「為何番…」「怎知…」

## Step 5: 草第一段（命運開端）

- **時間 + 主角登場 + 看似平凡的起點**
- 一兩句簡述主角的身世、性格（強調「善良 / 純真 / 苦命」底色）
- **段尾須留下「命運的伏筆」**——一句帶著預感的句子（如「她那時還不知道，
  幸福只剩三百零七個日子」）
- 必有至少一處淚／情／命／義／血字眼
- 段落比例：**短**（全文約 1/4 篇幅）

## Step 6: 草第二段（苦難中段）

- 苦難爆發：意外、背叛、誤會、絕症、離散
- **層層加碼**——一個苦難疊上一個（病了之後又被棄，被棄之後又遇騙）
- 必有對話／呼告：主角面對命運說一句話，或對親人哭訴
- 必有「**淚錨點**」——一個具體的流淚場景（如「她抱著襁褓中的孩子，
  在火車站冰冷的長椅上度過了第一個冬夜」）
- 段落比例：**最長**（全文約 1/2 篇幅）

## Step 7: 草第三段（升華收尾）

知音體的結尾不是「悲到底」，而是**從苦難中升起一道光**——可選：

| 升華類型 | 範例落點 |
|---|---|
| 救贖 | 多年後好心人出現、骨肉終相認 |
| 相認 | 失散親人的最終擁抱 |
| 慟哭 | 知道真相後伏屍痛哭、淚灑黃泉 |
| 大徹大悟 | 主角在墓前釋懷、寫下遺言 |
| 來世之約 | 「若有來世，願為…」 |

- 結尾留**餘韻**：淚痕未乾，主角已踏上下一程；或一句帶著哀而不傷的判語
- 必有至少一處淚／情／命／義／血字眼
- 段落比例：**中**（全文約 1/4 篇幅）

## Step 8: 標點清理 + 朗讀檢查

- **CJK 全形標點**：「，」「。」「！」「？」「：」「；」「⋯⋯」「——」
- **感嘆密度**：通篇感嘆號＋呼告至少 3–5 處（不可一個都沒有，也不可
  每段三個塞滿）
- **苦情錨點密度**：每段至少一處淚／血／情／命／義／殤／慟／苦／心／痛／哀／怨字眼，全篇 ≥6 處
- 朗讀一遍，若聽起來像「冷靜的報導」就回 Step 6 加情感重量

## Step 9: Self-check Against Checklist

逐條對照下面的 21 條 checklist。**任一條 [Hard] 違反就回 Step 5–7 重寫
該段**。

### Checklist: Content（內容）

| 編號 | 強度 | 規則 |
|---|---|---|
| C-01 | Hard | **煽情標題必現**——列於文章最上方，長度 ≥10 字，含至少一個感嘆 / 呼告 / 反問 — **靈魂條款之一** |
| C-02 | Hard | **三段式情感悲劇骨架**——命運開端 → 苦難中段 → 升華收尾，三段缺一不立 — **靈魂條款之二** |
| C-03 | Hard | 標題公式：含「修飾語＋親屬呼告／角色＋命運謂語＋補述子句」四項至少其三 |
| C-04 | Hard | 主角須有「苦命修飾語＋親屬定位」雙重標記（如「苦命的妹子」「風雨中的老父」） |
| C-05 | Soft | 原文若涉現代專名，可酌情保留（知音體不忌現代背景，與金庸體相反） |

### Checklist: Structure（結構）

| 編號 | 強度 | 規則 |
|---|---|---|
| S-01 | Hard | 三段比例：**短-長-中**（約 1:2:1），第二段最長承載苦難堆疊 |
| S-02 | Hard | **每段段尾留淚錨點**——一句具體的流淚／凝望／心碎場景，不可空泛 |
| S-03 | Hard | **不准用 markdown 子標題切段**——三段以自然段分隔，不寫「第一段」「中段」「結局」這類元標籤 |
| S-04 | Soft | 篇幅 400–900 字（標題不計），典型 600 字 |
| S-05 | Soft | 結尾留餘韻——不要把所有事說盡，留一句哀而不傷的判語或下一程的暗示 |

### Checklist: Voice（語感）

| 編號 | 強度 | 規則 |
|---|---|---|
| V-01 | Hard | **苦情字眼密度**——全篇至少 6 處（淚 / 血 / 情 / 命 / 義 / 殤 / 慟 / 苦 / 心 / 痛 / 哀 / 怨），每段 ≥1 處 — **靈魂條款之三** |
| V-02 | Hard | **煽情詞庫高頻動用**——須出現以下至少 5 個詞：淚、殤、慟、千里、萬里、血淚、義薄雲天、命途多舛、不堪回首、痛失、遠嫁、苦守、忍痛、相依為命、黃泉、此生無悔、來世 |
| V-03 | Hard | **感嘆密度**——通篇感嘆號／呼告／反問合計 3–5 處（含標題） |
| V-04 | Soft | **親屬呼告自然化**——「啊」「呀」「我的孩子」「我的愛人」式呼告，可在內文出現 1–2 次（不可堆疊） |
| V-05 | Soft | **半白話 + 通俗文藝腔**——非文言，但比口語雅；忌網路梗、忌學術腔 |

### Checklist: Meta（後設）

| 編號 | 強度 | 規則 |
|---|---|---|
| M-01 | Hard | **嚴肅體不嘲弄**——知音體是煽情，不是 parody。若寫出「笑點」就違背 soul，需重寫 |
| M-02 | Hard | **情緒鋪到滿**——不可半途收住情感。中段苦難要堆疊，結尾升華要明確 |
| M-03 | Hard | 不附評論段、不附作者按、不附「我的改寫思路」 |
| M-04 | Hard | 標題不可寫成新聞硬標題（「某地某人發生某事」）——必含情感修飾與命運謂語 |
| M-05 | Soft | 中性化原則——可寫「知音風格」「知音派」，不寫「劣質雜誌寫法」之類自貶 |
| M-06 | Soft | 議論文 / 哲學寓言類源文，先把抽象主題人格化為苦命主角，再寫三段式 |

**總計**：21 條（Hard 14 + Soft 7）。

## Step 10: Find the Weakest Paragraph and Rewrite

通常**標題**或**第二段（苦難中段）**最弱：

- 若標題像新聞硬標題（無感嘆、無呼告、無命運謂語），重寫到含「苦命的 X
  啊，… 為何 …」式公式
- 若苦難中段太短或苦難只有一層（病了就完了），補上第二層第三層苦難
  （病了之後又遇騙、又失親）
- 若升華段戛然而止（停在最慘處），補上「多年後 / 後來 / 此生無悔」式
  餘韻
- 若全篇情緒平淡無感嘆，補入 1–2 處親屬呼告（「我的孩子啊」）

## Step 11: Output

1. **檔案輸入**：寫入 `<原檔名>_zhiyin.md`，保留原檔
2. **貼文輸入**：直接輸出知音體（標題 + 三段正文）
3. **不附說明、不附評論、不附改寫筆記**
4. 若使用者明確要求，可額外輸出**改寫筆記**（列出 Step 2–4 的選擇），但
   **主輸出永遠是知音體本身**

## Anti-patterns（常見失敗模式）

寫完一稿、自檢之前，先掃一眼這 8 條最容易踩的坑：

1. **標題寫成新聞硬標題**——「某男某地離世」式無情感的事實陳述，違反
   C-01。標題必含修飾語＋呼告＋命運謂語
2. **三段式變兩段或四段**——苦難中段被切成兩段、或升華段消失，違反 C-02
3. **嘲弄味滲入**——寫出諧仿、玩梗、自嘲句子，違反 M-01。知音體是嚴肅
   煽情，不是 parody
4. **淚錨點空泛**——「她很傷心」「他流下了眼淚」太抽象，要具體場景
   （什麼時間、什麼動作、什麼物件襯托）
5. **苦難只有一層**——病了就死、走了就完，不夠知音。要層層加碼，至少
   兩三層苦難堆疊
6. **結尾停在最慘處**——沒有升華段，違反 C-02。即使是慟哭結局也要有
   「淚灑黃泉」「來世再續」式餘韻
7. **markdown 切段**——用 `### 第一段` `### 苦難` 這類元標籤切段，違反
   S-03。三段就是三個自然段，不要中標題
8. **感嘆密度失衡**——一個感嘆都沒有（變冷靜敘事），或每段三個感嘆
   塞滿（變網路梗）。3–5 處是黃金區間

## Important Notes

- 本 skill 是**體裁轉換工具**，不是「把句子加感嘆號」工具。原文的核心
  必須先抽出，再以三段式煽情敘事重新承載
- **中性化原則**：《知音》雜誌至今仍在發行，本 skill 將其文體當作一個
  「1985 起的中國雜誌煽情敘事體」現象來學習，不對該雜誌作褒貶評價
- **情緒鋪到滿，但不可越過去成 parody**——這是知音體最微妙的平衡點。
  煽情是 feature，嘲諷是 bug
- **標題是招牌**——可以說「沒有合格標題就不是知音體」。寫稿時先寫標題，
  最後再回頭調整
- **三段式是骨架**——苦難中段必須最長，升華段必須存在。沒有升華段的
  純悲劇是其他文體（如聊齋鬼話），不是知音體
- 清單並非窮盡一切，使用判斷力標記其他感覺不對的句子
