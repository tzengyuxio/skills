# Hemingway-style — 示範

展示 `hemingway-style` 如何把現代文章改寫成中譯海明威腔，以及好的海明威
腔長什麼樣子。

> **源文與引用說明**：範例改寫為依海明威風格自編的目標範例，**非實際海明威作品譯本**。範例三的源文 [《差不多先生傳》（胡適，1924）](../../examples/source-texts/mr-chabuduo.md) 來自共用源文庫，公有領域。範例一源文 [《雨天故事》](../../examples/source-texts/weather-rain.md) 為自編。文中對海明威代表作的指涉僅作風格座標說明，未引用整段原文。

---

## 範例一：對話為主 — 雨天回家

**源文**:[《雨天故事》](../../examples/source-texts/weather-rain.md)
（自編，共用源文庫）

> 昨天下午我在圖書館看書的時候，突然下起了大雨。雖然我沒帶傘，但還是決定走路回家。路上人很多，到處都是撐著傘的行人。我全身都淋濕了，回到家才發現鑰匙忘在辦公室了。鄰居看到我的樣子，笑著說：「你怎麼不叫計程車？」我只好苦笑著回答：「我忘了帶錢包。」

### 改寫（對話為主場景模型）

> 雨下下來的時候我在圖書館。我合上書。我走到門口。雨很大。我沒有傘。我走出去。我走路回家。路上的人都撐著傘。我沒有。我走得很慢。我到了家門口。我摸口袋。鑰匙不在。我摸另一個口袋。也不在。鄰居走出來。他看著我。他說，你怎麼不叫計程車？我說，我忘了帶錢包。他笑了。我也笑了。我站在門口。雨還在下。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 對話極簡：「他說」「我說」 | S-05 對話標籤極簡 | 不加「笑著說」「苦笑著回答」 |
| 「和」連接句：「我沒有傘。我走出去。」並列 | S-04 並列結構 | 模仿英文 and 結構 |
| 動詞主導：合、走、摸、站 | V-01 動詞主導 | 沒有抽象形容詞 |
| 句點密度高 | S-03 句點密度 | 一段內超過 30 個句點 |
| 結尾「我站在門口。雨還在下。」 | M-05 外部動作收結 | 不解釋、不抒情 |
| 重複「我走出去」「我走得很慢」「我也笑了」 | V-04 重複 | 動作節奏 |

**風格座標**：與《雨中的貓》《白象似的群山》的對話為主場景結構相承——
**對話極簡 + 動作標記 + 環境收結**。原文中的「苦笑」「淋濕了」這類略
帶抒情的詞，在海明威腔裡都被外部動作取代：笑就只說「他笑了」，濕就用
動作「我摸口袋」呈現。

## 範例二：動作為主 — 木匠雕聖像

**源文**（自編，現代軼事）：

> 一名工程師接到三天內交專案的死線，連夜加班寫出醜陋的程式碼，事後花更多時間重構，最後產品被取消。

### 改寫（動作為主場景模型）

> 木匠在工坊裡。他磨刀。他磨了很久。使者來了。使者說，三天。木匠點頭。木匠說，三天。使者走了。木匠開始雕。他雕了一夜。他雕到天亮。他喝水。他繼續雕。第二夜他也沒睡。第三夜也沒睡。第三天清晨，聖像的眉眼還沒開。他拿起刀。他的手抖。他下刀。眉眼歪了。他看著聖像。聖像看著他。使者來了。使者說，走吧。木匠把聖像交出去。他和使者一起上路。他們走了三天。他們到了城裡。城西郊的空地上沒有那座堂。地是平的。使者說，改建他處了。木匠站著。他抱著聖像。他抱了很久。他坐下來。他把聖像放在膝上。他看聖像的眉眼。眉眼還是歪的。天黑了。他坐著。風很冷。他沒有走。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 連續動作：磨、雕、喝、看、走、抱、放、坐 | V-01 動詞主導 | 動作為主場景模型 |
| 重複：「他雕了一夜」「他雕到天亮」「眉眼歪了」「眉眼還是歪的」 | V-04 重複 | 海明威招牌節奏 |
| 對話標籤只用「使者說」「木匠說」 | S-05 對話標籤極簡 | 不加情緒標籤 |
| 「他和使者一起上路」 | S-04 「和」連接 | 翻譯感自然 |
| 結尾「他坐著。風很冷。他沒有走。」 | M-05 外部動作收結 | 不解釋為何不走 |
| 沒有比喻、沒有抽象形容詞 | V-03 / V-05 | 直接寫物 |
| 「聖像看著他」 | C-01 冰山理論 | 全篇不寫木匠的失落，但都在動作裡 |

**風格座標**：與《老人與海》前段、《大二心河》的連續動作場景結構相
承——**動作節奏承載情緒**。原文「醜陋的程式碼」「重構」「產品被取消」
這類抽象詞，在海明威腔裡都被具體動作取代：醜陋變成「眉眼歪了」，取消
變成「地是平的」。

## 範例三：場景為主 — 差不多先生

**源文**:[《差不多先生傳》（胡適，1924）](../../examples/source-texts/mr-chabuduo.md)
共用源文庫，公有領域。

### 原文

> 後來他得急病，趕快叫家人去請東街的汪先生。一面慌一面跑，人急了，東西兩街，汪王不分，跑到西街牛醫王大夫家裡。⋯⋯王大夫用醫牛之法給他治病，差不多先生就此一命嗚呼。

### 改寫過程筆記

| Step | 選擇 |
|---|---|
| 找冰山 | 水下：對「差不多」的執著終於要付出代價；水上：只寫房間、燈、人來、針、躺著、不動 |
| 場景模型 | 場景為主（《一個乾淨明亮的地方》模式）|
| 替代動作 | 「臨終的恐懼」→「他看天花板」；「家人慌亂」→「他們跑出去。他們跑回來」；「死亡」→「他不動了。燈還亮著」|
| 核心物件 | 房間、燈、針、被子、天花板、門 |

### 改寫後（場景為主場景模型）

> 房間裡有一張床。床上躺著差不多先生。燈亮著。是夜裡。他病了。他叫他太太。他說，去請汪先生。她跑出去。她跑了很遠。她跑到西街。她跑進王大夫家。王大夫在裡面。王大夫是看牛的。她沒有看清楚。她說，我先生病了。王大夫說，我去。他帶著針。他來了。他看差不多先生。差不多先生看他。差不多先生說，你是汪先生嗎？王大夫說，我是王大夫。差不多先生說，汪先生王大夫，差不多。他閉上眼。王大夫拿出針。針是給牛用的。王大夫不知道。差不多先生不知道。王大夫扎了三針。差不多先生不動了。燈還亮著。他太太回來。她看見他不動。她叫他。他不應。她又叫。他還是不應。屋外有風。窗沒關。風吹進來。燈晃了一下。沒滅。

### 達標清單

| 編號 | 達成 | 解析 |
|---|---|---|
| C-01 | ✓ | 冰山：全篇不寫恐懼、不寫死亡之沉重，只寫房間、燈、針、躺著 |
| C-02 | ✓ | 沒有「他想」「他覺得」這類心理活動 |
| C-03 | ✓ | 不評論「差不多」哲學的後果，讓動作自己說 |
| C-05 | ✓ | 場景為主場景模型 |
| S-01 | ✓ | 約 350 字 |
| S-02 | ✓ | 短句為主，平均句長 ~7 字 |
| S-03 | ✓ | 句點密度極高 |
| S-05 | ✓ | 對話標籤只用「她說」「他說」 |
| V-01 | ✓ | 動詞主導：躺、跑、看、扎、閉、叫、應、吹、晃 |
| V-02 | ✓ | 具體名詞：床、燈、針、被子、窗、風 |
| V-03 | ✓ | 沒有抽象形容詞 |
| V-04 | ✓ | 重複：「她跑出去。她跑了很遠。她跑到西街。」「她叫他。他不應。她又叫。他還是不應。」 |
| V-05 | ✓ | 沒有比喻 |
| M-02 | ✓ | 翻譯感自然：「房間裡有一張床」「他閉上眼」這類歐化句式不是違規 |
| M-04 | ✓ | 節奏冷靜，沒有抒情 |
| M-05 | ✓ | 結尾「燈晃了一下。沒滅。」外部動作收結，不解釋 |

**改寫的核心動作**：把胡適原文「明寫的諷刺」轉為「海明威式的場景紀錄」。
原文是雜文體諷刺，海明威版讓「差不多先生」之死成為一個冷靜的場景——
**房間、燈、針、躺著、不動**——他不是被嘲諷死的，是被牛用的針扎死的；
而「差不多」這三個字的代價，由「燈晃了一下。沒滅。」這個外部動作承擔。

## 範例四：旅途 — 公路旁的咖啡館

**源文**（自編短篇）：

> 我和她開了三天的車，終於決定停下來。我們在路邊的咖啡館坐下，點了兩杯咖啡。她說她不想再走下去了。我看著窗外，沒有回答。後來我們各自喝完了咖啡，結了帳，走出店門。她往左，我往右。

### 改寫（旅途場景模型）

> 我們開了三天的車。我們停下來。是中午。路邊有一家咖啡館。我們進去。我們坐下來。我們點了兩杯咖啡。咖啡來了。咖啡是熱的。她拿起杯子。她沒有喝。她放下。她說，我不想再走下去了。我看著窗外。外面有公路。公路上沒有車。我沒有說話。我喝咖啡。她也喝。我們喝完了。我去結帳。我回來。她已經站起來。我們走出店門。外面很亮。她往左。我往右。我走到車那裡。車是熱的。我沒有回頭。我聽見她的腳步聲。後來聽不見了。

### 結構標註

| 條目 | 對照規則 | 解析 |
|---|---|---|
| 旅途場景模型：車、公路、咖啡館、各自離開 | C-05 場景模型 | 與《白象似的群山》結構相承 |
| 「咖啡是熱的」「車是熱的」 | V-02 具體名詞 + V-04 重複 | 物件主導 |
| 對話極簡：「她說，我不想再走下去了。」「我沒有說話。」 | S-05 對話標籤極簡 | 沒有「她憂鬱地說」「他沉默地」 |
| 結尾「我聽見她的腳步聲。後來聽不見了。」 | M-05 外部動作收結 | 不寫離別之痛、不解釋 |
| 「我們進去。我們坐下來。我們點了兩杯咖啡。」 | S-04 並列 | 翻譯感自然 |
| 沒有「離別」「悲傷」「孤獨」這類抽象詞 | V-03 / C-01 | 情緒在水下 |

**風格座標**：與《白象似的群山》（火車站咖啡座的對話）、《一個乾淨
明亮的地方》（店、燈、酒、人）的場景結構相承——**兩人之間的決裂用
最少的話和最具體的物件承載**。原文的「決定停下來」「不想再走下去」
被保留，但「悲傷」「孤獨」這類詞被刪掉，由「咖啡是熱的」「車是熱的」
「腳步聲」這些具體物件承擔。

## 速查：Checklist 重點

21 條中最常踩的：

| 編號 | 規則 | 怎麼用 |
|---|---|---|
| C-01 | 冰山理論 | 強烈情緒不直寫，以動作 / 環境承載 |
| C-02 | 不寫心理活動 | 「他想」「他覺得」要轉成動作或對話 |
| C-03 | 不評論不解釋 | 海明威從不告訴讀者該怎麼感受 |
| S-02 | 短句為主 | 平均句長 ≤14 字 |
| V-01 | 動詞主導 | 數一下動詞是否多於形容詞 |
| V-03 | 拒絕抽象修飾 | 「美麗的」「悲傷的」「孤獨的」要刪 |
| V-05 | 拒絕比喻 | 「彷彿」「宛如」「猶如」要刪 |
| M-02 | 翻譯感是 feature | 「於是」「然後」「和」並列無妨 |
| M-05 | 結尾不解釋 | 以外部動作或環境收結 |

完整 21 項與 9 步流程見 [SKILL.md](../SKILL.md)。
